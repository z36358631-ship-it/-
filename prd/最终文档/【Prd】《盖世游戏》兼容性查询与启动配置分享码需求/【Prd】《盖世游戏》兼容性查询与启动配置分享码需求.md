## 一、文档概述

### 1.1 背景概述

- **需求背景：** 玩家判断目标游戏能否在某款手机上运行时，需要分散查资料、手动试配。
- **当前方式：** 按游戏和硬件参数查经验，再自行调整启动配置。
- **主要问题：** 兼容结论口径不一，运行记录与可复用配置未形成完整链路。
- **入口依据：** 过去 28 天，游戏详情页活跃用户 2,016,043，平均互动 6 分 02 秒；“玩游戏”页活跃用户 1,700,035。详情页承接明确游戏需求，PC 游戏页提供全局查询。

### 1.2 需求边界

| 边界类型 | 范围说明 |
|---|---|
| 产品边界 | Android App 原生入口及内嵌 H5；覆盖手机竖屏、掌机横屏；国内、海外一致。 |
| 业务边界 | 包含 PC 游戏页入口、游戏详情入口、兼容记录查询、评价详情和分享码复制；不含 Mac、浏览器网页、配置下载、一键应用、评价提交、举报、后台、登录及会员限制。 |
| 运营边界 | 不涉及运营配置。 |
| 数据边界 | 展示平台用户评价与实际运行数据；每条记录须关联有效启动配置。 |
| 人力边界 | 客户端增加入口并传入当前机型、可选 `game_id`；H5 负责查询页面；服务端提供记录和配置；客户端提供 WebView 与剪贴板能力。 |

### 1.3 术语定义

| 术语 | 定义与判断口径 |
|---|---|
| 兼容记录 | 一次实际运行结果。同一游戏因机型、系统或配置不同，可有多条记录。 |
| 机型 | Android 手机型号，不提供独立处理器、CPU 或 GPU 筛选。 |
| 评级 | 1—5 分；“X 分及以上”包含 X 分及更高分记录。 |
| 兼容状态 | 不可玩、基本可玩、完美兼容、有部分问题，四选一。 |
| 有效启动配置 | 与当前游戏和兼容记录匹配，并可生成现有格式分享码的配置。 |
| 分享码 | `复制打开盖世游戏导入PC引擎设置方案：[游戏名称][系统智能设置方案][GPU:记录中的GPU]SCFG##现有编码` |
| `game_id` | 游戏详情入口传给 H5 的游戏标识，用于预选当前游戏。 |
| 当前机型 | App 识别的本机型号；进入 H5 时默认选中，识别失败则不预选。 |

| 项目 | 说明 |
|---|---|
| 产品定位 | 在 App 内查询真实兼容记录，并复制对应启动配置。 |
| 目标用户 | 想确认目标游戏是否可玩，或想复用现有配置的玩家。 |

| 使用场景 | 启动游戏前，查询当前或其他机型的运行表现。 |
| 功能概述 | 从 PC 游戏页或游戏详情进入同一 H5；按游戏、机型、评级筛选，查看评价并复制分享码。 |
