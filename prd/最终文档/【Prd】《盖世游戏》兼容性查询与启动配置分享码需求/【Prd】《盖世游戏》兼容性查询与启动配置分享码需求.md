## 一、文档概述

### 1.1 背景概述

- **需求背景：** 盖世游戏缺少按游戏、机型查兼容记录并复用启动配置的入口。
- **当前解决方式：** 用户自行查资料、对硬件、调配置。
- **存在问题：** 信息分散、门槛高，配置依赖试错。

### 1.2 需求边界

| 边界类型 | 范围说明 |
|---|---|
| 产品边界 | Android App 内嵌 H5，含兼容性查询页、评价页；支持横屏、竖屏及桌面宽度；不分地区。 |
| 业务边界 | 展示兼容记录、筛选、查看评价、复制分享码。不含评价提交、举报、后台、配置下载、一键应用、分享页、登录及会员限制。 |
| 运营边界 | 无。 |
| 人力边界 | 产品定规则；UI 出稿；服务端负责 H5、兼容记录和启动配置；客户端提供 H5 容器和剪贴板 Bridge；测试覆盖各尺寸及复制降级。 |

### 1.3 术语定义

| 术语／缩写 | 英文全称（按需） | 定义与判断口径 |
|---|---|---|
| 兼容记录 | Compatibility Record | 一次实际运行结果，不是游戏汇总。同一游戏因机型、系统或环境不同可有多条记录。 |
| 机型 | Device Model | Android 手机型号，不含独立 CPU、处理器或 GPU 选项。 |
| 评级 | Rating | 1—5 分。“X 分及以上”含 X 分及更高分记录。 |
| 兼容状态 | Compatibility Status | 四选一：不可玩、基本可玩、完美兼容、有部分问题。每条记录只显示一个状态。 |
| 有效启动配置 | — | 与当前游戏、兼容记录匹配，且配置与记录可双向关联。 |
| 分享码 | Share Code | 盖世游戏可导入的文本：`复制打开盖世游戏导入PC引擎设置方案：[游戏名称][系统智能设置方案][GPU:原有GPU字段]SCFG##现有编码`。 |
| App Bridge | — | App 向 H5 提供剪贴板等原生能力的调用通道。 |

## 二、产品说明

### 2.1 产品／方案简介

| 项目 | 说明 |
|---|---|
| 产品／方案定位 | 查询真实兼容记录并复制配套启动配置的 App 内 H5。 |
| 目标用户 | 想确认目标游戏能否运行，或想直接复用配置的玩家。 |
| 核心目标 | 降低兼容查询和配置使用门槛。 |
| 使用场景 | 用户运行游戏前，查询本机或目标机型的可玩情况。 |
| 功能概述 | 按游戏、机型、评级筛选；查看评价；复制分享码。 |

#### 3.1.1 兼容性查询页

| 要素 | 内容说明 |
|---|---|
| 功能简介 | 查兼容记录，并复制配套分享码。 |
| 场景描述 | 用户运行游戏前，想确认目标机型是否可玩。 |
| 输入／前置条件 | Android App 内打开；无需登录或会员。 |
| 需求描述 | **图示（当前页面）：**<br>![筛选](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@e17313cabe5bd9fa3659518529f5d12642494b70/public/prd/compatibility-query-share-code/01-filter-portrait.png)<br>竖屏<br><br>![横屏记录](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@e17313cabe5bd9fa3659518529f5d12642494b70/public/prd/compatibility-query-share-code/05-record-list-landscape.png)<br>横屏<br><br>![桌面表格](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@e17313cabe5bd9fa3659518529f5d12642494b70/public/prd/compatibility-query-share-code/06-record-table-desktop.png)<br>桌面<br><br>**详细说明：**<br>1. **展示说明：**<br>（1）顶部展示返回、标题“兼容性查询”和 Android 标签。<br>（2）筛选项为游戏、机型、评级，保持同排。游戏可按中英文名、别名搜索；机型可按名称、别名搜索，提示为“搜索机型”；评级选项为全部、5/4/3/2/1 分及以上。<br>（3）无筛选时显示“热门兼容记录”，最多 6 条，同一游戏取评分最高的一条，同分取验证时间最新的一条。筛选后显示“兼容记录”和结果数。结果默认按评分降序，同分按验证时间降序。<br>（4）默认列表模式。列表／平铺只改样式，不改结果和顺序。<br>（5）移动端记录展示封面、游戏名、机型／硬件、系统、评分、兼容状态、平均帧率和复制图标；桌面表格增加游戏版本、运行环境、盖世版本和备注。<br>（6）兼容状态四选一：不可玩、基本可玩、完美兼容、有部分问题。不显示“评级”、`Wine 9.2`、`GS3` 或单独 FPS。<br>2. **交互说明：**<br>（1）点击游戏或机型打开搜索浮层；点击评级打开选项浮层。浮层覆盖结果区，不顶开页面。<br>（2）选择后立即刷新，多项按 AND 过滤。支持清除单项和“清空”全部。<br>（3）点击列表／平铺切换样式，本次 H5 会话内保留选择。<br>（4）点击记录查看评价；点击复制图标只复制该记录的分享码，不进评价页。 |
| 输出／后置条件 | 筛选或清空后更新列表；关闭评价页后恢复原筛选、样式和滚动位置；复制成功后写入完整分享码。 |
| 补充说明 | 1. 候选无匹配时显示“暂无匹配选项”；筛选无结果时保留条件并提供清空；无数据时显示空态和“重新加载”。<br>2. 正式结果只展示有关联有效配置的记录；H5 不补虚假配置。封面失败时显示本地占位图。<br>3. 结果一次加载，不分页。<br>4. 每次复制使用请求标识；过期结果不得覆盖当前状态。 |

##### 查询页复制状态

| 当前状态 | 进入条件 | 可见内容／可执行操作 | 退出事件 | 下一状态 | 失败与恢复 |
|---|---|---|---|---|---|
| 默认 | 页面初始化 | 显示复制图标，可点击 | 点击复制 | 复制中 | 配置校验失败则进入失败 |
| 复制中 | 配置校验通过 | 图标位置不变，忽略重复点击 | 收到当前请求结果 | 成功或失败 | 按 App Bridge、Clipboard API、`execCommand` 顺序尝试 |
| 成功 | 复制成功 | 图标原位变绿色勾 | 2 秒后 | 默认 | 不加 Toast、提示条或弹窗 |
| 失败 | 配置不匹配或三种方式均失败 | 图标原位变红，可重试 | 点击重试或 2 秒后 | 复制中或默认 | 保留筛选、样式、滚动位置和焦点 |

##### 查询页多端差异

| 场景 | 共同行为 | 横屏 | 竖屏 | 桌面宽度 | 国内／海外 |
|---|---|---|---|---|---|
| 结果布局 | 筛选、排序、记录和复制规则一致 | 双列紧凑列表；600px 及以上平铺为双列 | 单列紧凑列表；600px 以下平铺为单列 | 使用表格，复制列固定在右侧 | 无差异 |
| 操作 | 筛选项不换行，页面不横向溢出 | 触控区不小于 44×44px | 触控区不小于 44×44px | 支持鼠标和键盘 | 无差异 |
