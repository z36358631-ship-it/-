## 一、文档概述

### 1.1 背景概述

- **需求背景：** 玩家判断目标游戏能否在某款手机上运行时，需要分散查资料、手动试配。
- **当前方式：** 按游戏和硬件参数查经验，再自行调整启动配置。
- **主要问题：** 兼容结论口径不一，运行记录与可复用配置未形成完整链路。

### 1.2 需求边界

| 边界类型 | 范围说明 |
|---|---|
| 产品边界 | Android App 内嵌 H5；覆盖手机竖屏、掌机横屏；国内、海外一致。 |
| 业务边界 | 包含兼容记录查询、筛选、评价详情、分享码复制；不含 Mac、浏览器网页、配置下载、一键应用、评价提交、举报、后台、登录及会员限制。 |
| 运营边界 | 不涉及运营配置。 |
| 数据边界 | 展示平台用户评价与实际运行数据；每条记录须关联有效启动配置。 |
| 人力边界 | H5 负责页面与规则；服务端提供记录和配置；客户端提供 WebView 与剪贴板能力。 |

### 1.3 术语定义

| 术语 | 定义与判断口径 |
|---|---|
| 兼容记录 | 一次实际运行结果。同一游戏因机型、系统或配置不同，可有多条记录。 |
| 机型 | Android 手机型号，不提供独立处理器、CPU 或 GPU 筛选。 |
| 评级 | 1—5 分；“X 分及以上”包含 X 分及更高分记录。 |
| 兼容状态 | 不可玩、基本可玩、完美兼容、有部分问题，四选一。 |
| 有效启动配置 | 与当前游戏和兼容记录匹配，并可生成现有格式分享码的配置。 |
| 分享码 | `复制打开盖世游戏导入PC引擎设置方案：[游戏名称][系统智能设置方案][GPU:记录中的GPU]SCFG##现有编码` |

| 目标用户 | 想确认目标游戏是否可玩，或想复用现有配置的玩家。 |
| 核心目标 | 缩短“查能否运行—看问题—取配置”的路径。 |
| 使用场景 | 启动游戏前，查询当前或其他机型的运行表现。 |
| 功能概述 | 按游戏、机型、评级筛选；查看兼容性评价；复制分享码。 |

##### 查询页复制状态

| 状态 | 进入条件 | 页面表现 | 后续 |
|---|---|---|---|
| 默认 | 页面初始化 | 显示复制图标，可点击 | 点击后进入复制中 |
| 复制中 | 配置校验通过 | 图标位置不变，忽略重复点击 | 收到本次请求结果后进入成功或失败 |
| 成功 | 复制成功 | 图标原位显示绿色勾 | 2 秒后恢复默认 |
| 失败 | 配置不匹配或复制失败 | 图标原位变红，可重试 | 重试或 2 秒后恢复默认 |

| 结果 | 单列卡片 | 右侧双列卡片 | 卡片信息、排序、查看及复制逻辑一致 |
