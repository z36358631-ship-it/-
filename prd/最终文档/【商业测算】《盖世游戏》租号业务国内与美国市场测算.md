# 【商业测算】《盖世游戏》租号业务国内与美国市场测算

> 更新时间：2026-07-29  
> 文档用途：回答套餐如何定价、首期需要多少账号和资金、三种账号供给方式哪种收益更高。

## 一、结论

1. **套餐策略：** 时租和周租承担低价引流，永久资格承担主要盈利。
2. **首期范围：** APP与Mac全量开放，至少覆盖热门前30款游戏。
3. **首月账号池：** 基准预计需要1,928个账号席位，采购中位投入约16.5万元。
4. **账号分配：** 前5款游戏配置50%库存，第6～15款配置30%，第16～30款配置20%，不能30款平均分配。
5. **自建账号池：** 长期收益最高，但承担采购、闲置、封禁、维护和永久用户持续扩容。
6. **共享游6:4分成：** 无采购投入、收益稳定，但永久订单平台扣除支付成本后仅保留约35%实付金额。
7. **共享游按次买断：** 单次费用不高于¥1且永久用户累计有效使用少于约30次时，收益优于6:4分成；必须设置成本封顶。
8. **推荐方案：** 前5款热门游戏自建账号池，其余25款先接共享游按次买断，并约定单笔订单累计结算不超过用户实付金额的60%。

## 三、定价与套餐策略

### 3.1 时租：低门槛引流

用户可自定义2～24小时，价格由后台逐小时配置。总价持续增加，平均小时价持续下降：

| 时长 | 总价 | 平均单价 |
|---:|---:|---:|
| 2小时 | ¥6 | ¥3.00/小时 |
| 6小时 | ¥10 | ¥1.67/小时 |
| 12小时 | ¥14 | ¥1.17/小时 |
| 18小时 | ¥16 | ¥0.89/小时 |
| 24小时 | ¥18 | ¥0.75/小时 |

- 任意2～24小时时租均可享受首单5折。
- 时租的目标是降低首次付费门槛，不按原“每小时¥6”追求单笔利润。
- 24小时时租必须低于周租，形成自然升级梯度。

### 3.2 周租：中长周期引流

```text
周租原价 = ¥21
日均价格 = ¥3
首单5折价格 = ¥10.5
```

周租价格低，但账号占用时间长，必须单独设置可售库存，不能无限售卖。

### 3.3 永久资格：主要盈利套餐

永久价格按用户所在地区对应的Steam非促销原价计算，不读取Steam限时促销价：

```text
永久价格 = Steam非促销原价 × 20%～30%
测算基准 = Steam非促销原价 × 25%
```

示例：

```text
Steam国区原价¥198 → 永久价¥39.6～¥59.4，基准¥49.5
Steam美区原价$39.99 → 永久价$8.00～$12.00，基准约$10
```

- 永久资格不参与首单5折。
- 永久表示长期使用共享账号池的资格，不等于永久独占一个Steam账号。
- 永久价不高于周租价时不允许发布，避免价格倒挂。
- 永久能否盈利取决于同一游戏副本能承载多少永久用户，而不是单笔售价是否高于一份游戏采购价。

### 3.4 加权客单价

按时租75%、周租20%、永久5%，并考虑30%的时租或周租订单享受首单5折：

| 市场 | 加权实收客单价 |
|---|---:|
| 国内 | 约¥12.76 |
| 海外 | 约$1.96 |

永久用户逐月累计。按永久订单占5%、永久用户峰值使用率20%且不考虑流失：


永久套餐需要按月扩容，不能把首月1,928个账号视为长期固定投入。

## 五、三种账号供给方式收益对比

以Steam原价¥198、永久实付¥49.5、支付成本5%为统一示例：

| 供给方式 | 前期采购投入 | 平台单笔永久贡献 | 核心差异 |
|---|---:|---:|---|
| 自建账号池 | 首月中位约¥16.5万 | ¥47.03，未摊采购与维护 | 利润空间最高，库存和账号风险最高 |
| 共享游6:4分成 | 0 | ¥17.33 | 收益固定，供应商承担库存 |
| 共享游按次买断 | 0 | `¥47.03－使用次数×单次费` | 轻度用户利润高，重度用户可能倒亏 |

### 5.1 方案一：自建账号池

平台收入：

```text
平台贡献 = 用户实付金额 × 95% - 账号采购与维护成本
```

基准月GMV：

| 市场 | 基准月GMV |
|---|---:|
| 国内APP | 约¥27.4万 |
| 海外APP与Mac | 约$8,988，折合约¥6.5万 |
| 合计 | 约¥33.8万 |

理论上，扣除5%支付成本后约剩¥32.2万，再覆盖首期中位采购投入¥16.5万，静态账面回本约0.5个月。

该结果没有计入账号封禁、闲置、维护、客服、退款、热门账号溢价及永久用户后续扩容。经营决策建议按**2～3个月回本**作为可接受目标，不使用0.5个月作为对外承诺。

### 5.2 方案二：共享游永久订单6:4分成

每笔永久订单：

```text
供应商收入 = 永久实付金额 × 60%
平台收入 = 永久实付金额 × 40% - 5%支付成本
平台净贡献 = 永久实付金额 × 35%
```

以Steam原价¥198、永久实付¥49.5为例：

```text
供应商获得 = ¥29.70
平台分成 = ¥19.80
扣除支付成本后平台净贡献 = ¥17.33/单
```

国内基准月永久订单约1,073单：

```text
平台永久订单月净贡献
= 1,073 × ¥17.33
≈ ¥1.86万
```

优点是没有账号采购投入，供应与库存风险由共享游承担；缺点是永久套餐的大部分利润让渡给供应商。

### 5.3 方案三：共享游按次买断

“买断”在本文中指：每次用户有效使用账号，平台向共享游支付一笔固定费用，不是一次性购买账号。

一次有效使用建议定义为：

```text
账号登录成功 + 游戏启动成功 + 有效游玩达到约定时长
```

断线重连、同次换号、启动失败和退款订单不重复计费。

每笔永久订单的平台贡献：

```text
平台贡献
= 永久实付金额 × 95%
- 永久有效使用次数 × 单次买断费
```

仍以永久实付¥49.5为例，与6:4分成比较：

```text
按次买断优于6:4分成的条件：
累计有效使用次数 × 单次买断费 < ¥49.5 × 60% = ¥29.7
```

| 单次买断费 | 优于6:4分成的累计使用上限 |
|---:|---:|
| ¥0.5/次 | 少于约59次 |
| ¥1/次 | 少于约29次 |
| ¥2/次 | 少于约14次 |

假设永久用户平均累计有效使用30次：

| 合作方式 | 平台单笔净贡献 | 国内约1,073笔永久订单月净贡献 |
|---|---:|---:|
| 自建，未摊采购与维护 | ¥47.03 | 约¥5.05万 |
| 6:4分成 | ¥17.33 | 约¥1.86万 |
| 按次¥0.5 | ¥32.03 | 约¥3.44万 |
| 按次¥1 | ¥17.03 | 约¥1.83万 |
| 按次¥2 | -¥12.98 | 约亏损¥1.39万 |

结论：

- 单次费用¥0.5时，按次买断明显优于6:4。
- 单次费用¥1时，永久用户累计约30次后与6:4基本持平。
- 单次费用¥2时，不适合永久套餐，重度用户会产生负毛利。

### 5.4 推荐的共享游结算条款

推荐使用“按有效使用计费＋单笔成本封顶”：

```text
单笔订单供应商结算额
= min（有效使用次数 × 单次买断费，用户实付金额 × 60%）
```

建议谈判目标：

| 条款 | 推荐值 |
|---|---|
| 单次买断费 | 不高于¥1 |
| 单笔永久订单成本上限 | 不高于实付金额的60% |
| 启动失败、重连、换号 | 不计费或保持幂等 |
| 对账依据 | 订单ID、权益ID、会话ID、账号ID、有效启动结果 |

该方式可以让轻度用户按次结算获得更高利润，重度用户最多回到6:4成本，不会因永久用户长期使用而倒亏。

## 六、最终推荐

### 6.1 首期供给组合

| 游戏范围 | 供给方式 | 首期账号量/成本 |
|---|---|---:|
| 热门前5款 | 自建账号池 | 约964个，中位投入约¥8.2万 |
| 第6～30款 | 共享游按次买断 | 不预付账号采购成本 |
| 供应商未覆盖或报价过高游戏 | 暂不开放永久，保留时租/周租或下架 | 按单款处理 |

### 6.2 转自建条件

第6～30款中，单款连续两周满足以下条件后，再转自建：

1. 账号使用率稳定超过50%。
2. 缺号率超过5%或供应商履约影响转化。
3. 自建采购投入预计能在3个月内回本。
4. 真实采购来源、商业使用权和账号稳定性可接受。

### 6.3 需要管理层拍板的三个数字

1. 首期是否接受约¥8.2万的前5款自建投入。
2. 共享游单次买断费能否谈到¥1以内。
3. 单笔永久订单的供应商累计结算能否封顶为用户实付金额的60%。
