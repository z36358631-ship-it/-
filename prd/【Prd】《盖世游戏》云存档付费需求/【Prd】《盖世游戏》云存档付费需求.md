## 二、背景与目标

背景：盖世用户通过模拟器玩PC游戏，存档管理面临三个痛点：

1）从零开始肝太耗时间；

2）Wine Prefix崩溃/换手机导致存档丢失；

3）想体验全收集但不想自己打。

目标：在APP内建立免费云存档共享体系，跑通“浏览→查看详情→确认使用→直接玩”的使用闭环，并支持玩家上传、分享和管理存档。

核心挑战：Wine Prefix路径自动识别与导入、存档文件安全扫描、文件完整性校验和多端同步。

## 三、故事介绍

### 3\.1 用户与运营场景

❗用户与运营场景：

- **C端使用者（张三）**：张三想玩GTA5线上模式但不想肝几百小时。他在游戏详情页点击“存档”tab，看到“500万CR\+440辆车全收集”的共享存档，查看详情后点击“添加并使用”。系统将存档放入Wine Prefix正确路径并提示重启，启动游戏后直接从对应进度开始玩。

- **C端分享者（李四）**：李四通关了艾尔登法环全Boss，他在“我的存档”中点击“上传”，选择存档文件，填写标题“全Boss击杀\+全武器收集”和内容描述，直接发布给其他玩家。

### 3\.2 价值分析

❗价值分析：

- **降低重复游玩成本**：玩家可以直接使用社区共享存档，快速进入目标进度。

- **保护用户进度**：云端保存和跨设备同步降低Wine Prefix损坏、换手机导致的丢档风险。

- **形成内容供给**：玩家分享存档，平台沉淀更多游戏进度和全收集内容，覆盖更多游戏场景。

- **差异化体验**：一键导入到Wine Prefix，减少用户手动查找路径、复制文件和排查格式的成本。

### 3\.3 核心体验路径

❗核心链路：

- **使用者核心链路**：游戏详情页“存档”tab → 浏览存档列表 → 查看详情 → 确认使用 → 加入“我的存档”并加载 → 启动游戏

- **分享者核心链路**：我的页 → 我的存档 → 发布存档 → 选择游戏\+文件 → 填写信息 → 直接发布

- **运营核心链路**：后台存档管理 → 新建官方存档 → 上传文件\+配置 → 发布 → 管理下架

### 3\.4 产品指标预测

❗产品指标预测：

1. 存档浏览→详情点击率：首月持续观察并建立基线

2. 存档加载成功率：目标 \> 95%

3. 首批覆盖：Top 20游戏，每游戏2\-3个官方存档

4. 玩家上传：首月观察玩家发布存档数量并建立基线

### 3\.5 路径规划

❗路径规划：

- **V1\.0（当前）**：跑通官方存档发布\+玩家直接发布\+免费浏览\+确认使用闭环

*图4.2-11：时间范围筛选面板。*

*页面截图来自当前免费版Demo，下载量及日期为演示数据，正式统计由服务端提供。*

**卡片信息**：官方卡片移除封面“官方存档”标签及“官方存档 · 盖世官方”说明行；玩家卡片也移除封面“玩家分享”标签，标题下仅显示作者昵称，昵称前不再重复“玩家分享”。统计行显示下载图标、累计下载量和首次公开发布日期；游戏中侧栏复用下载图标，原来源文字改为玩家昵称，官方不显示来源说明。日期格式为“年/月/日”，年份显示后两位。数量用千位分隔，如“2,786”；新发布存档显示“0”。数量未返回或获取失败时显示“暂无下载量”，日期缺失显示“日期未知”，不以0替代未知值。重新上架不重置原发布日期。下载图标提供“下载量 N”的可访问语义。

**筛选与排序**：工具栏位于子Tab下方，按“筛选 / 下载量 / 最新 / 放大镜”排列；默认全部时间、选中“下载量”，搜索框收起且无关键词。时间条件、搜索词与排序同时作用于当前游戏公开可见的存档；主页面的新发布记录加入同一筛选、搜索与排序。

| 控件 | 默认或选项 | 操作与结果 |
|---|---|---|
| 筛选 | 全部时间 | 点击展开时间面板；选择预设立即生效并收起。生效后“筛选 · 1”表示存在一个时间条件。 |
| 时间范围 | 全部时间、一天内、一周内、一个月内、三个月内、一年内、自定义 | 按存档首次公开发布时间筛选。预设分别为最近24小时、7天、30天、90天、365天，包含起点至当前时间；全部时间不限制日期。 |
| 自定义 | 开始日期、结束日期 | 两项必选，仅支持日期选择；按设备本地自然日包含起止日期的全天。点击“应用”后生效；关闭面板不应用未提交修改。 |
| 重置 | 清除时间条件 | 恢复全部时间，保留当前排序。 |

| 搜索框 | 空关键词 | 输入后在当前游戏、已生效时间范围的列表内按存档标题包含匹配，忽略首尾空白与英文大小写，结果即时展示并沿用当前排序。中文输入法组词结束后更新结果；清空恢复当前时间条件下的列表。 |

#### 4\.3\.1 边界条件\-内容侧

|场景|处理方式|

|场景|处理方式|
