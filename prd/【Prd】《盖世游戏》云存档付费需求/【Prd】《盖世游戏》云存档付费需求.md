## 二、背景与目标

盖世用户在模拟器中使用PC游戏存档，希望跳过重复游玩、体验指定进度，并减少Wine Prefix损坏或换手机造成的丢档。

本次支持免费浏览、确认使用、玩家发布和存档管理。技术依赖为Wine Prefix路径识别与导入、文件安全扫描、完整性校验及多端同步。

## 三、故事介绍

### 3\.1 用户与运营场景

- **使用者**：在游戏详情“存档”tab选择共享存档，确认后导入Wine Prefix，按提示重启并从对应进度游玩。
- **分享者**：在“我的存档”选择文件，填写标题、描述后发布，供其他玩家免费使用。

### 3\.2 价值分析

免费使用指定进度、云端保存及跨设备同步；自动导入Wine Prefix，减少手动查找路径和复制文件；玩家发布补充官方存档。

### 3\.3 核心体验路径

- **使用者核心链路**：游戏详情页“存档”tab → 浏览存档列表 → 查看详情 → 确认使用 → 加入“我的存档”并加载 → 启动游戏

- **分享者核心链路**：我的页 → 我的存档 → 发布存档 → 选择游戏\+文件 → 填写信息 → 直接发布

- **运营核心链路**：后台存档管理 → 新建官方存档 → 上传文件\+配置 → 发布 → 管理下架

### 3\.4 产品指标预测

1. 存档浏览→详情点击率：首月持续观察并建立基线

2. 存档加载成功率：目标 \> 95%

3. 首批覆盖：Top 20游戏，每游戏2\-3个官方存档

4. 玩家上传：首月观察玩家发布存档数量并建立基线

### 3\.5 路径规划

- **V1\.0（当前）**：跑通官方存档发布\+玩家直接发布\+免费浏览\+确认使用闭环

#### 存档广场：下载量与筛选排序

以下规则适用于主页面及游戏中“存档广场”；“我的存档”的分区、排序与当前使用标识不变。

![存档时间筛选](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@ab32f30bf05d9e191a96070ab10905f2ae043409/public/prd/cloud-save-free-20261023/03-time-filter.png)

*图4.2-11：时间范围筛选面板。*

*页面截图来自当前免费版Demo，下载量及日期为演示数据，正式统计由服务端提供。*

**卡片信息**：官方、玩家均无来源标签；玩家标题下仅显示昵称，官方无说明行。统计行显示下载图标、累计下载量及首次公开发布日期；日期为“年/月/日”，年份取后两位；数量用千位分隔，如“2,786”，新发布为“0”。数量未返回/获取失败显示“暂无下载量”，日期缺失显示“日期未知”，未知值不补0。重新上架不重置发布日期；下载图标提供“下载量 N”的可访问语义。

**筛选与排序**：子Tab下按“筛选 / 下载量 / 最新 / 放大镜”排列；默认全部时间、下载量排序、搜索收起且无关键词。条件共同作用于当前游戏公开存档，包含主页面新发布记录。

| 控件 | 默认或选项 | 操作与结果 |
|---|---|---|
| 筛选 | 全部时间 | 点击展开时间面板；选择预设立即生效并收起。生效后“筛选 · 1”表示存在一个时间条件。 |
| 时间范围 | 全部时间、一天内、一周内、一个月内、三个月内、一年内、自定义 | 按存档首次公开发布时间筛选。预设分别为最近24小时、7天、30天、90天、365天，包含起点至当前时间；全部时间不限制日期。 |
| 自定义 | 开始日期、结束日期 | 两项必选，仅支持日期选择；按设备本地自然日包含起止日期的全天。点击“应用”后生效；关闭面板不应用未提交修改。 |
| 重置 | 清除时间条件 | 恢复全部时间，保留当前排序。 |
| 下载量 | 默认选中，排在“最新”前 | 按累计成功下载次数从高到低；同数量按发布时间从新到旧，再按稳定标识升序。未知数量排在全部已知数量之后。 |
| 最新 | 可切换 | 按首次公开发布时间从新到旧；同时间按存档稳定标识升序。日期未知排最后。 |
| 放大镜 | 默认收起 | 点击在工具栏下展开“搜索存档标题”输入框并聚焦；再次点击收起并清空关键词，保留时间和排序。 |
| 搜索框 | 空关键词 | 输入后在当前游戏、已生效时间范围的列表内按存档标题包含匹配，忽略首尾空白与英文大小写，结果即时展示并沿用当前排序。中文输入法组词结束后更新结果；清空恢复当前时间条件下的列表。 |

时间范围只筛选发布时间，卡片展示及下载量排序均使用累计下载量，不表示该时间段内的下载次数。时间范围受限时不展示日期未知的记录；选择全部时间后可见。

| 条件 | 显示与操作 | 结果与恢复 |
|---|---|---|
| 自定义未填完整 | 面板内显示“请选择开始日期和结束日期” | 保留已填日期和已生效条件，补齐后可再次应用。 |

| 当前时间范围无结果 | 列表显示“该时间范围暂无存档” | 保留工具栏，可修改或重置筛选。 |
| 没有任何公开存档 | 全部时间下显示“暂无存档” | 保留工具栏。 |

切换筛选、排序或搜索词后回到列表顶部；详情返回保留条件及滚动位置。切换“我的存档”、横竖屏或游戏中模式时，同步保留时间、排序、搜索词和展开状态，不改变“我的存档”记录；刷新恢复全部时间、下载量排序、搜索收起且无关键词。

**下载量口径**：实际成功下载文件计1次；取消、失败、仅点击使用或加载已有本地文件不计。同一任务重试成功只计1次，新任务成功分别计数。成功后重读累计数量并按当前排序刷新；读取失败显示“暂无下载量”，不影响下载结果。离线Demo仅模拟首次下载加1，再用本地存档不增加，未接真实接口。

数据结论：本节仅增加展示和排序，复用下载成功结果及首次公开发布时间，不改行为埋点。生产累计下载量来源、历史回填仍需与下载服务确认；未知值按上述规则展示，Demo数值不作真实统计。

#### 4\.3\.1 边界条件\-内容侧

|场景|处理方式|
|---|---|
|存档文件含恶意程序|上传后服务端安全扫描，未通过拒绝上架|
|存档与标注游戏不匹配|用户举报→人工核实→下架并通知分享者修正|
|存档截图与实际不符|用户举报“描述不符”→人工核实→属实则下架并通知分享者|
|存档文件过大（\>500MB）|拦截上传，提示“文件过大”|

#### 4\.3\.2 边界条件\-用户侧

|场景|处理方式|
|---|---|
|换设备或重装APP|登录同一账号后同步云端存档，可重新导入|
|用户导入自己的分享存档|允许导入，导入后按普通存档使用|
|玩家下架存档|下架后不再出现在广场，已导入用户不受影响|
|单日上传限制|单游戏上限不限制，受账号总量和文件大小限制|
|单游戏分享过多|单游戏最多分享4个，超出提示“已达到分享上限，请删除分享存档后重试”|
