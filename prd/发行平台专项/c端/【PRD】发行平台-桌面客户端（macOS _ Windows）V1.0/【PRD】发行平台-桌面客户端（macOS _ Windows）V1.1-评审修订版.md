## 一、文档概述

### 1.1 背景概述

- **当前方式：** 玩家在共享商城购买游戏，由客户端管理本机内容和启动。
- **问题：** V1.0 将下载与安装分成两次操作，详情、游戏库和最近游戏的状态不一致。
- **本期调整：** 下载即安装，统一各页面状态，补齐注册 IP 锁区、CDK 兑换和手柄入口。依据为原 PRD、现有原型及评审修改清单。

### 1.2 需求边界

| 边界类型 | 范围说明 |
|---|---|
| 产品边界 | GameFusion Windows、macOS 客户端。商城内嵌网页；详情、游戏库、任务、启动、设置为原生页面。手柄入口在当前窗口打开。开发者后台另有文档。 |
| 业务边界 | 登录、浏览、购买／领取、兑换、入库、下载即安装、DLC、更新、修复、卸载及授权启动。仅售本体、DLC、捆绑包，不售 CDK；不含购物车、社区、好友／聊天、论坛、秒玩、手游库、第三方游戏管理、P2P 或云游戏。 |
| 运营边界 | 使用已审核且符合地区、语言、时间、平台条件的商品和素材。运营提供推荐兜底及官方群二维码；硬件侧提供 CDK 与 Connect 规则。本轮不建配置后台。 |
| 人力边界 | 客户端：原生页面、本机任务、启动和系统适配；服务端：商城、账号、订单、权益、内容、支付；UI：发行平台视觉；硬件产品：Connect 与账号迁移；运营：推荐和二维码；测试／数据／安全：规则、事件和授权检查。Windows 签名由陈韬跟进。 |

### 1.3 术语定义

| 术语／缩写 | 英文全称 | 定义与判断口径 |
|---|---|---|
| UID | User ID | C 端和开发者端共用的账号唯一标识。同一 UID 可登录两端，开发者业务权限另行校验。 |
| 地区 | 无 | 注册时由 IP 确定并锁定的账号地区；个人页只读，不按每次访问 IP 改写。 |
| 本体／DLC／捆绑包 | Downloadable Content（DLC） | 本体是游戏主商品；DLC 为独立附加内容权益；捆绑包发放约定本体和 DLC，拥有本体不代表拥有全部 DLC。 |
| CDK | 无 | 外部分发的兑换码，用于兑换约定权益；本平台提供兑换入口，不售卖兑换码。奖励、格式、有效期和地区细则需硬件与权益侧确认。 |
| READY | 无 | 本机内容、校验及安装全部完成，可进入启动预检；已下载字节数达到预期不能单独认定 READY。 |
| Build／Manifest | 无 | 目标平台游戏版本及其内容清单，用于选择内容、校验和启动。 |
| Launch Plan | 无 | 本次启动冻结的账号、游戏、版本、内容、主程序、依赖与有效 DLC 快照。 |
| Ticket／Guard | 无 | Ticket 为绑定本次启动的短时一次性授权；Guard 为游戏侧启动校验。两者不能被按钮状态或本机已购缓存替代。 |

## 二、产品说明

### 2.1 产品／方案简介

| 项目 | 说明 |
|---|---|
| 产品／方案定位 | 商城负责浏览和交易，客户端负责本机内容与授权启动。 |
| 目标用户 | 购买、领取 PC 游戏或通过硬件获得 CDK 的用户。 |
| 核心目标 | 各页面操作一致；内容完整后可启动预检；真实权益确认后入库。 |
| 使用场景 | 浏览、交易／兑换、管理和启动游戏，或进入手柄页面。 |
| 功能概述 | 顶部商城／游戏库与右侧手柄入口，底部统一管理下载；详情、游戏库和任务共用当前账号状态。 |

| 状态／分组 | 进入条件 | 显示与操作 | 转换／恢复 |
|---|---|---|---|
| QUEUED／即将进行 | 内容请求通过预检，等待唯一推进位置 | 「等待下载」，无字节或整体百分比；可取消 | 获得位置后进入／恢复原阶段；取消退出未完成计数 |
| DOWNLOADING／下载中 | 获得推进位置且允许下载 | 「下载中」及整体百分比；网络未满可暂停／取消，文件处理阶段仅可取消 | 网络完成转校验／文件处理，不直接完成；暂停保留进度 |

| VERIFYING／下载中 | 内容需完整性校验 | 「校验中」及整体百分比；仅可取消 | 成功转后续处理；失败保已校验内容及恢复入口 |

| UPDATING／下载中 | 已确认更新版本且获得推进位置 | 「更新中」、任务类型及整体百分比；网络未满可暂停／取消，文件处理仅取消 | 完成／暂停／失败后退出；继续或重试按单任务调度。失败保完整旧版，必需更新仍阻止启动 |
| REPAIRING／下载中 | 修复任务获得推进位置 | 「修复中」、任务类型及整体百分比；仅可取消 | 只补缺失／损坏内容，校验完成才 READY；失败可恢复 |
| READY／已完成 | 解压、内容校验和安装全部完成 | 「已安装 · 可启动」、内容大小，整体 100%；整行进入游戏库，可确认删除记录 | 启动仍须授权；删记录不卸载或撤权 |
| RUNNING／已完成 | READY 游戏通过授权且真实进程已运行 | 「运行中」、内容大小；整行进入游戏库，可确认删除记录 | 退出回本机可用状态；不计未完成下载 |
| FAILED／下载中 | 任一阶段发生可恢复失败 | 「任务失败」、可读原因及整体百分比；可重试／取消 | 重试恢复原阶段。原生另记失败阶段、脱敏错误码和时间；错误进度不能判 READY，Demo 不证明诊断接入 |
| CANCELLED／不列未完成 | 用户确认取消 | 退出未完成计数 | 权益不变；暂存按批准策略处理 |

### 4.1 埋点与数据需求

**数据结论：** 改造／复用原链路，新增 CDK 和手柄入口事件。`install_*` 沿用历史事件名，表示下载与安装的一项内容任务；正式指标剔除 Demo。

| 指标名称 | 口径（含分子和分母） | 去重与时间窗口 | 数据源与决策用途 |

### 4.2 启动授权与客户端安全

| 需求项 | 具体要求 |
|---|---|
| 数据来源 | 权益取账号／权益服务；商品、订单、媒体、地区取共享服务；Build／Manifest／Chunk 取内容服务；安装、任务、文件、进程取原生客户端。页面的 owned=true 或本机已购缓存不能授予启动权限。 |
| 启动顺序 | 校验当前账号、本体及所选 DLC 权益 → 检查平台／架构、READY、Manifest、主程序、依赖和关键文件 → 冻结 Launch Plan → 获取短时一次性 Ticket → Guard 校验 → 创建进程 → RUNNING。任一步失败即停止。 |
| 启动快照与防重复 | Launch Plan 保存本次账号、游戏、Build／Manifest、主程序、参数、依赖及有效 DLC。同请求使用同一幂等键，不重复申请 Ticket；单游戏只允许一个启动中或运行实例，发行配置明确允许多实例时例外。 |
| Ticket 约束 | 至少绑定用户、设备、游戏、Build，含签发／失效时间及唯一 ID 或随机数，且仅可使用一次。时长、传递方式和接口由技术／安全评审确定。界面和日志不显示 Ticket、刷新凭据或 Plan 敏感字段。 |
| 启动状态 | PREPARING → AUTHENTICATING → CHECKING_CONTENT → ACQUIRING_TICKET → GUARD_CHECKING → LAUNCHING → RUNNING → EXITED；可执行阶段均可进入 FAILED。显示准备启动、验证账号与权益、检查游戏文件、获取启动授权、启动游戏、运行中。失败保留阶段、脱敏错误码、时间及恢复操作，正常／异常退出分开记录。 |
| 进程与重连 | 真实进程运行后才显示运行中，退出释放临时授权和进程锁。窗口重开、服务重连后查询真实进程及启动任务，不能沿用页面旧状态。 |
| 启动记录 | 界面与原生任务服务按版本识别命令／事件，拒绝未知命令、过期及跨账号事件。每次启动记录 launch_id、game_id、account_id、platform、build_id、phase、result、脱敏 error_code、trace_id 和幂等键；按 launch_id 查询或订阅，断连后可恢复。 |
| 双端与系统差异 | 两端使用相同账号、商品、订单、权益、任务规则和主操作；本机任务、目录、安装记录按设备／平台独立。macOS 处理目录权限、架构、签名／公证；Windows 处理盘符／目录、运行依赖和签名。无兼容 Build 时阻断，不执行错误平台程序。 |
| 程序分发 | 一期 Windows 客户端须签名，不上微软商店；Windows SDK 优先。macOS SDK 及兼容层待评估，保留原型与共用规则，不视为 SDK 已支持。 |
| 账号撤权 | 换号、会话过期、退款／撤权后刷新操作，停止新下载授权及新 Ticket。文件清理和已运行游戏是否强制退出由批准安全策略决定，删除页面记录不能代替处置。 |

| 场景 | 客户端行为 | 用户恢复操作 | 成功依据／限制 |
|---|---|---|---|
| 登录失效 | 停止申请 Ticket，清除敏感上下文 | 重登后再次启动 | 新会话重新读取权益 |
| 无权益／退款／撤权 | 拒绝启动，刷新库和详情 | 查看账号／订单 | 无绕过入口 |
| 无兼容 Build／架构不匹配 | 启动前阻断 | 查看系统要求 | 不执行错误平台程序 |
| 文件缺失／校验失败 | 阻断，保留安装记录和错误码 | 验证／修复后重试 | 关键内容重新有效 |
| 必需更新未完成 | 阻断启动 | 完成更新／查看任务 | 可选更新仅在旧 Build 完整且策略允许时例外 |
| Ticket 过期／重放／绑定不符 | Guard 拒绝，不重用旧 Ticket | 重新启动取新授权；连续失败联系客服 | 用户、设备、游戏、Build 均匹配 |
| 直接运行、无合法上下文 | Guard 拒绝进入可游玩状态 | 从 GameFusion 客户端启动 | 须有合法在线或已批准离线许可 |
| 进程创建失败／异常退出 | 记录阶段和真实结果，不显示成功 | 重试、检查依赖／修复、查看日志或反馈 | 真实进程进入 RUNNING |
| 授权服务不可达 | 在线启动失败 | 重试 | 仅明确支持离线许可的游戏按批准策略执行 |
