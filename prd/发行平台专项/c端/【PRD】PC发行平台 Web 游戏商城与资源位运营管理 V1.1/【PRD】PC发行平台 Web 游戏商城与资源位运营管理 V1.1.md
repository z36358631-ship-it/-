## 一、文档概述

### 1.1 背景概述

- **当前方式：** 玩家在 Web 浏览和购买，再到 GameFusion 客户端下载、运行；运营统一管理三端商城资源。
- **问题：** Web 的地区、账号与支付说明和客户端不一致，旧文档多处重复且保留密码登录等过期规则。
- **本期调整：** 对齐适用规则，保留网页浏览和客户端引导；不在网页加入兑换或本机任务。

### 1.2 需求边界

| 边界类型 | 范围说明 |
|---|---|
| 产品边界 | GameFusion Web 商城及 Web／macOS／Windows 资源位运营后台。网页提供浏览、账号、购买、订单和售后；本机下载、安装、更新、修复与启动由客户端执行。与 GameHub 账号、库和分发不互通。 |
| 业务边界 | 三端共用 GameFusion 账号、商品、订单、支付和权益；C 端与开发者端共用 UID，后台权限另校验。允许大陆 IP 访问；注册地区取注册时 IP 并锁定，商品按账号地区判断可售。Web 暂不做 CDKey 兑换、购物车、愿望单、社区、第三方登录／绑定或本机游戏库。 |
| 运营边界 | 按展示端、地区、语言维护 Banner、促销专题、编辑推荐、新游和畅销。公共页及页脚文案由法务／商务提供，不在本期后台配置。手柄仅保留开发中入口，不做调参、配对、固件或账号迁移。 |
| 人力边界 | 服务端负责 Web、账号、商品、订单、权益、支付和资源配置；客户端负责协议唤起与本机能力；运营负责素材和推荐规则；UI、测试、数据分别核对页面、行为和事件；硬件侧提供 Connect 方案。 |

### 1.3 术语定义

| 术语 | 定义 |
|---|---|
| UID／注册地区 | UID 为账号唯一标识，换绑不变；注册地区取注册 IP，之后不随访问 IP 改变，两者在资料页只读。 |
| 主题／卡片 | 主题按展示端、地区、语言、位置组织资源；卡片是主题下的展示项，游戏卡关联 AppID。 |
| 促销专题 | 独立运营文章，含封面、正文及有序关联游戏。 |
| BASE／Edition | BASE 为本体；Edition 为同游戏的销售版本，如 Standard／Deluxe。 |
| Bundle／DLC | Bundle 组合本体与附加内容，保留组成快照；DLC 依赖指定本体，购买前校验本体资格。 |
| 托管支付／入库 | 本轮仅展示 Stripe 支付占位；正式付款与权益确认后入库，GameFusion 不采集卡号或 CVV。 |
| 客户端交接 | Web 引导安装或尝试唤起 GameFusion 客户端，不执行本机游戏下载或启动。 |

#### 4.1.1 埋点事件

以下沿用原稿事件定义。页面事件每次有效展示记一次，点击事件每次有效点击记一次；结果事件对同一订单、申请或保存请求的相同结果去重，状态变化可再记。参数名与正式采集由数据团队核对；本期不新增统计指标、分母或时间窗。

| 事件 | 页面／类型 | 触发与成功 | 参数 |
|---|---|---|---|
| web_store_home_view | 首页／复用 | 核心资源可见 | front_end, region_code, locale |
| web_store_search | 搜索／复用 | 提交关键词或筛选，结果确定 | query, filters, result_count |
| web_store_banner_click | 首页／复用 | 点击 Banner 进入对应详情 | subject_id, card_id, game_id, position |
| web_store_topic_click | 首页／专题／复用 | 打开专题或点击关联游戏 | subject_id, game_id, position |
| web_store_game_detail_view | 游戏详情／复用 | 核心内容展示完成 | game_id, source, region_code, locale |
| web_store_offer_detail_view | 商品详情／复用 | Bundle／DLC 详情展示完成 | product_type, product_id, base_game_id |
| web_store_purchase_start | 商品详情／复用 | 有效点击购买，不代表付款 | product_type, product_id, edition, region_code, display_price |
| web_store_purchase_blocked | 购买／复用 | 已拥有、缺本体或地区不可售拦截 | product_id, failure_reason |
| web_store_checkout_view | 购买确认／复用 | 确认单展示完成 | product_id, user_id, currency, amount |
| web_store_payment_result_view | 支付结果／复用 | 支付与入库状态展示 | order_id, payment_status, entitlement_status |
| web_store_client_handoff | 结果／下载页／复用 | 下载或获准唤起客户端，记录实际结果 | os_type, installed_state, action, result |
| web_store_refund_submit | 订单／复用 | 退款申请返回结果 | order_id, refund_eligibility, result |
| ops_theme_save | 主题／复用 | 保存返回结果 | front_end, region_code, locale, module, result |
| ops_card_save | 卡片／复用 | 保存返回结果 | subject_id, card_id, game_id, result |
| ops_release_rule_save | 新游／复用 | 当前端规则保存返回 | front_end, time_window, sort_rule, quantity, result |

#### 4.1.2 参数说明

| 参数 | 类型／必填 | 说明 | 枚举／示例 |
|---|---|---|---|
| front_end | enum／是 | 资源展示端 | Web＝网页；macOS＝Mac 客户端；Windows＝Windows 客户端 |
| region_code | string／是 | 游客 IP 地区或登录账号注册地区，不随手动选择更改 | CN、JP；GLOBAL＝全球资源回退；UNKNOWN＝待识别 |
| locale | enum／是 | 页面语言 | en＝英文；zh-Hant＝繁中；ja＝日文 |
| game_id | string／对应事件 | 游戏标识 | AppID |
| subject_id | string／对应事件 | 主题／专题标识 | theme_001 |
| card_id | string／对应事件 | 卡片标识 | card_001 |
| product_type | enum／购买相关 | 商品类型 | BASE＝本体；EDITION＝版本；BUNDLE＝组合；DLC＝附加内容 |
| product_id | string／商品事件 | 实际销售对象 | offer_001 |
| base_game_id | string／DLC事件 | 所需本体 | AppID |
| query | string／搜索时 | 本次关键词 | TEVI |
| filters | object／筛选时 | 本次分类、评分、类型和排序 | 全部商品、8.0 分以上、动作、价格从低到高 |
| result_count | integer／结果确定时 | 可见结果数；失败未知不填 0 | 0 |
| position | integer／点击时 | 当前可见顺序，从 1 开始 | 1 |
| source | string／详情时 | 详情来源 | 首页 Banner、搜索、专题 |
| edition | string／版本商品 | 所选版本 | Standard Edition |
| display_price | number／购买点击时 | 当时展示价，非结算权威 | 29.99 |
| user_id | string／确认单 | 当前 UID，不传邮箱明文 | 现有账号标识 |
| currency | string／金额事件 | 币种 | USD |
| amount | number／确认单 | 订单应付金额 | 29.99 |
| order_id | string／订单事件 | GameFusion 订单 | order_001 |
| payment_status | enum／结果展示 | 支付状态 | pending＝待付；processing＝确认中；success＝确认成功；failed＝失败；expired＝过期；unknown＝未知 |
| entitlement_status | enum／结果展示 | 权益状态 | pending＝入库中；granted＝已入库；error＝异常；unknown＝待核对 |
| os_type | enum／客户端引导 | 目标系统 | Windows＝Windows；macOS＝Mac |
| installed_state | enum／客户端引导 | 是否确认安装客户端 | installed＝已安装；not_installed＝未安装；unknown＝无法确认 |
| refund_eligibility | enum／退款时 | 服务端资格 | eligible＝可申请；ineligible＝不可申请；unknown＝待核对 |
| action | enum／客户端引导 | 本次交接动作 | download＝下载客户端包；launch＝获准尝试唤起客户端 |
| result | enum／结果事件 | 实际操作结果 | success＝成功；fail＝失败；blocked＝拦截；cancelled＝取消；unknown＝未知 |
| failure_reason | string／拦截时 | 可读拦截原因 | 已拥有、缺少本体、地区不可售 |
| module | string／主题保存 | 展示位置 | Banner、促销专题、编辑推荐、畅销 |
| time_window | integer／新游保存 | 天数 | 1～365 |
| sort_rule | object／新游保存 | 当前一级／二级排序 | 上线日期升序、预约人数倒序 |
| quantity | integer／新游保存 | 当前端保存数量 | 1～40 |

### 4.2 数据、安全与页面要求

| 需求项 | 具体要求 |
|---|---|
| 历史数据 | 订单保留商品、版本、组成、金额、币种、地区、折扣和协议快照，不随运营配置变化。换绑邮箱保 UID 和订单归属。 |
| 结果依据 | 商品和结算取共享服务；支付、权益、退款按实际业务结果。跳转、请求发出、按钮点击或 Demo 成功不能代替正式成功。 |
| 安全与权限 | 前台只访问本人数据；后台校验角色和展示端范围。页面、日志及埋点不记录密码、验证码、卡号、CVV 或完整支付令牌。 |
| 响应式与操作 | 桌面、窄窗口和手机宽度下主图、金额、按钮及表单不遮挡；支持键盘、可见焦点及文字错误，关键操作不依赖悬停。 |
| 外部依赖 | 账号侧提供验证、年龄、换绑与会话；商品侧提供媒体、组成、价格和可售性；支付侧接入 Stripe 并提供正式支付结果；权益侧确认入库；邮件承接邮箱验证、购买凭证和退款结果通知。 |
| 运营与法务 | 运营提供推荐／榜单来源、素材和端映射；法务／商务提供政策、公司主体、地区许可与正式文案。公共页不在本后台编辑。 |
