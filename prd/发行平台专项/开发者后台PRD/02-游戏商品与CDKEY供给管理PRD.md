## 一、文档概述

### 1.1 背景概述

- **需求背景：** 企业开发者需把盖世 Key 交给自行合作的第三方渠道。
- **当前方式：** 缺少渠道建档、批次创建、文件/API 交付及兑换数据闭环。
- **问题：** 旧方案混入平台审批、渠道额度、地区及第三方交易结算，不符合开发者自行分销的业务边界。

### 1.2 需求边界

| 边界类型 | 范围说明 |
|---|---|
| 产品边界 | [已确认] 本文只含开发者端渠道管理、批次管理、分销数据和帮助教程；游戏控制台其他能力由对应 PRD 定义。 |
| 业务边界 | [已确认] 平台生成并验证盖世 Key；开发者自行选择渠道并处理合作、定价、销售、售后和结算。 |
| 运营边界 | 不设渠道或批次审批，不设授权计划、地区、渠道额度及平台风险处置。 |
| 人力边界 | 服务端提供渠道、批次、Key 文件、API 和兑换数据；Web 端提供管理页面；测试覆盖数量、状态、下载、API、安全与响应式。 |

### 1.3 术语定义

| 术语／缩写 | 英文全称 | 定义与判断口径 |
|---|---|---|
| 盖世 Key | GameHub Key | 由盖世平台生成并用于兑换已配置游戏权益的兑换码。 |
| 渠道 | Channel | 开发者自行填写的合作方名称；平台不核验其真实身份或商业关系。 |
| 文件批次 | File Batch | 一次生成一组盖世 Key，并以文件交付。 |
| API 批次 | API Batch | 渠道按订单逐个取码的批次，可在原批次追加数量。 |
| 发放量 | Issued Keys | 文件成功交付的 Key 加 API 成功返回的 Key，按 Key 去重。 |

## 四、非功能需求

### 4.1 权限与安全

- 仅企业认证有效的当前厂商成员可管理本厂商渠道和批次；服务端按 `vendor_id + game_id` 校验数据范围。
- Key 文件只允许从原批次下载；Secret 仅生成或轮换时返回一次；页面、日志、埋点和普通导出不得记录明文。
- API 使用 `client_id + HMAC-SHA256 + timestamp + nonce`；订单号用于幂等，超时后查询原订单。

### 4.2 数据结论

**结论：** 改造现有开发者平台数据，记录渠道、批次、文件交付、API 取码、续量及兑换结果。

| 事件 | 触发与成功判定 | 参数 |
|---|---|---|
| `channel_save_result` | 创建或编辑渠道返回成功终态 | `action_id, vendor_id, game_id, channel_id, result` |
| `channel_state_change_result` | 渠道启停或删除返回成功终态 | `action_id, vendor_id, game_id, channel_id, state, result` |
| `key_batch_save_result` | 创建或编辑批次返回成功终态 | `action_id, vendor_id, game_id, batch_id, channel_id, delivery_type, quantity, result` |
| `key_supply_result` | 文件完整交付或 API 成功返回 Key | `action_id, vendor_id, game_id, batch_id, channel_id, delivery_type, quantity, result` |
| `distribution_query_result` | 查询返回卡片与列表数据 | `action_id, vendor_id, game_id, channel_id, time_range, result` |

| 参数 | 类型／必填 | 说明 | 枚举／示例 |
|---|---|---|---|
| `action_id` | string／是 | 单次操作标识 | `ACT-20260918-001` |
| `vendor_id` | string／是 | 厂商标识 | `VEN-202609-001` |
| `game_id` | string／是 | 游戏标识 | `GAME-48291` |
| `channel_id` | string／条件必填 | 渠道标识 | `CH-240901` |
| `batch_id` | string／条件必填 | 批次标识 | `BT-20260918-001` |
| `delivery_type` | enum／条件必填 | 供给方式 | `file＝下载文件；api＝接口取码` |
| `quantity` | integer／条件必填 | 本次创建、追加或供给数量 | `1000` |
| `state` | enum／条件必填 | 渠道操作后的状态 | `active＝启用；disabled＝停用；deleted＝删除` |
| `time_range` | string／条件必填 | 查询的 Key 发放时间范围 | `2026-08-18/2026-09-16` |
| `result` | enum／是 | 操作结果 | `success＝成功；failure＝失败` |
