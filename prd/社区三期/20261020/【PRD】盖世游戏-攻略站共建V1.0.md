## 一、需求概述

### 1.1 背景介绍

玩家查询同一游戏的新手攻略、载具参数、资产资料和版本信息时，目前主要通过社区帖子搜索和收藏留存资料；分散帖子由各作者维护，资料更新后也难以同步。攻略站将可共同维护的资料整理成分类入口和固定模板，保留玩家原帖的作者与互动。玩家可以浏览和更正公共资料；精编负责组织内容、维护结构与处理申请。

### 1.2 需求范围

| 范围 | 内容 |
|---|---|
| 产品 | App 社区游戏圈内攻略站，覆盖竖屏、掌机横屏；配套内容工作台用于词条、配置及治理。当前 GTA V 页面为示例。社区热点、私信由各自需求维护。其他主频道仅沿用现有导航语境。 |
| 业务 | 公共资料与作者原帖分别维护；覆盖分类和全站检索、六类模板、单篇及批量编辑、批量删除、保存与历史、多语言、贡献记录、精编申请、角色和黑名单。公共资料保存成功后直接生效。 |
| 运营 | 精编维护栏目、Tab、分类快捷入口、字段、内容关联和权限，审核初级精编申请。游戏资料、时效、图片许可由内容运营核实；示例价格和配图不作为真实游戏事实。 |

本稿供页面与规则评审，描述已确认的页面行为及当前演示规则。图中的账户、角色、审核、评论、写入均为本地会话数据，刷新后重置。正式登录、服务端鉴权、持久化及接口属于接入依赖，具体缺口见第五章；不能用演示结果认定这些能力已经实现，也不能将本稿当作已完成接口定稿。

### 1.3 术语解释

| 术语 | 说明 |
|---|---|
| 公共词条 | 所有人阅读、按权限共同维护的资料；保存后生成修订号，保留编辑历史。 |
| 实体 | 载具、武器、资产等一条结构化资料；数据表、图鉴和图册可以引用同一实体。 |
| 玩家原帖 | 归属原作者的社区帖子；收录或关联不改变作者，不开放公共词条编辑。 |
| 初级／高级精编 | 参与创建、组织和维护内容的身份。默认权限及按百科调整的规则见3.8，实际可执行操作以当前百科已保存权限为准。 |
| 字段方案 | 一组实体字段的名称、类型、必填规则、枚举及公开展示列、筛选项。 |
| 内容语言 | 词条及首页配置所用语言，与后台界面语言分别设置；不同语言分别保存内容、草稿与修订。 |

## 三、页面与功能说明

### 3.1 App：攻略首页与分类

入口位于社区游戏圈的“攻略站”Tab。进入后显示当前游戏、搜索、编辑身份入口、资料分类、四栏资料、玩家攻略以及收藏攻略站、共建贡献记录和发布动态入口。上下文频道与主导航沿用现有页面；进入独立资料页后收起主导航，返回时恢复攻略上下文。

| 对象 | 展示与默认 | 操作及结果 |
|---|---|---|
| 搜索 | 首页搜索栏；横屏侧栏也提供搜索入口。 | 点击进入检索页，规则见3.2。 |
| 编辑身份入口 | 普通用户显示“成为编辑”；待审显示“申请审核中”；驳回显示“申请未通过”；已有精编身份显示“精编工作台”。 | 均先进入身份／申请页，根据实际身份显示可用操作，见3.5。申请不限制普通用户编辑已有资料。 |
| 资料分类 | 按配置顺序每页8个；多页显示分页点，首尾不循环。当前有16个分类栏目。 | 点击进入栏目或指定公共词条；支持触摸滑动、鼠标拖动、分页点、键盘左右及Home/End切换。返回首页保留本会话页码。 |
| 四栏资料 | 固定顺序为资产与生意、抢劫任务、载具、常用检索。默认数量Tab分别为1、1—4、1—2、1—4，共11个；每栏默认第一个可见Tab。 | 点击数量Tab重排同一组内容，不替换资料集合；点击公共资料进入独立阅读页，点击玩家攻略打开作者原帖。横竖屏保留选中Tab，返回保留滚动位置。 |
| 玩家攻略 | 显示攻略原帖与作者。 | 点击原帖阅读；普通发布见3.4。收录原帖不转为公共词条。 |
| 收藏与贡献记录 | 攻略站收藏入口及共建贡献记录入口。 | 收藏切换本会话状态。贡献记录进入“百科贡献／编辑历史”页，排序与计分见3.9。 |

当前模型共16个栏目、45个Tab，其中43个有命名，其余栏目通过分类进入。后台栏目排序改变分类及配置顺序；首页四栏使用上述固定顺序，新建栏目不会自动插入首页。默认去重不等于后台全局互斥：精编仍能将不同栏目或Tab配置为相同组件。

栏目卡图依次取内容封面、正文首图、图册首图、引用实体首图、栏目兜底图；文字组件不显示图片。没有有效图时显示“暂无对应资料图片”。栏目被隐藏后，指向它的分类入口不展示；公共词条目标不存在时也不展示。栏目不可见时显示“此栏目当前未展示，请返回查看其他分类。”；空栏目显示“暂时没有收录内容”；没有可见分类显示“当前没有展示的分类”。

### 3.2 App：全站检索与分类结果

![资料分类](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@936a174affc626cfc322a9ffe2678e1955e6b4a9/public/prd/community-guide-20261020/images/category.png)

*图3-4：载具分类页，显示当前栏目内容与数量Tab；其他分类使用相同入口规则。*

检索输入不限制长度，输入后实时筛选公共资料与玩家原帖，去除首尾空格、忽略大小写；多个空格分词时须全部命中。检索范围为标题、摘要、适用范围、作者、实体字段值、正文文本块和原帖正文；列表项、引用出处尚无统一的全字段递归检索。结果标识“共建资料”或“作者 · 玩家攻略帖”，点击进入对应对象。

| 条件 | 页面显示 | 操作与恢复 |
|---|---|---|
| 未输入关键词 | “输入关键词查找攻略与共建资料” | 输入关键词后展示匹配结果。 |
| 有匹配项 | “找到 X 条内容”及结果列表 | 改词实时刷新；返回恢复阅读上下文。 |
| 无匹配项 | “没有匹配结果，请尝试更短关键词。” | 删除或缩短关键词后重新检索。 |

当前检索为本地全量过滤，没有热搜、搜索历史、服务端分页或加载失败状态。正式检索的数据范围、分页与失败恢复未定，阻塞范围见第五章。

六类资料均不显示“本篇目录”。集合资料内部不再显示“检索载具”输入框、结果数／总数及“清除搜索”，当前也不提供集合内枚举筛选或排序控件；全站搜索入口仍位于攻略首页。数据表与图鉴按实体引用顺序展示，空集合显示“暂无资料”。后台隐藏展示列只移除数据表对应列，不改变图鉴固定卡片字段，也不删除实体原值。

正常、建设中、暂停维护的资料均可阅读。建设中显示“现有内容不代表完整资料集”；暂停维护显示“请先核对时效；现有说明仍可阅读”。对象不存在时显示“资料不可用”或“资料不存在或已不可用”，可返回选择其他资料。

公共词条底部提供赞、收藏、评论及“…”入口；赞和收藏可取消，按同一账号与词条去重。评论最多500字，空白提交显示“请输入评论内容”；成功清空输入，在列表加入“我／刚刚”。互动均为会话演示，真实账号与服务端接口待接入。

![词条更多操作](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@936a174affc626cfc322a9ffe2678e1955e6b4a9/public/prd/community-guide-20261020/images/reader-more.png)

*图3-8：点击“…”从底部弹出更多操作，国内与海外显示各自分享渠道。*

点击“…”打开底部菜单，背景不可操作，按Esc或关闭菜单后回到来源按钮。国内显示微信、朋友圈、QQ、微博和复制链接；海外显示WhatsApp、Facebook、X、Telegram和复制链接。点击复制链接实际写入剪贴板；其他分享渠道当前仅为演示入口，不表示外部分享完成。点击“词条有误”后确认编辑，复制该词条的网页编辑后台地址，成功提示“已复制编辑后台地址，可前往网页端打开尝试编辑”；复制失败显示失败结果，不显示成功提示。

编辑历史展示每个修订的作者、时间、修改说明。最新编辑时间取当前显示修订，缺少有效记录显示“暂无编辑记录”；旧版使用该旧修订的时间。打开旧版后隐藏编辑及写入类互动，可点“回到当前版本”；查看旧版不改变公开内容，没有回滚入口。正文最新编辑时间及网页后台历史使用北京时间。

### 3.4 App：作者原帖与发布

![玩家攻略原帖](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@936a174affc626cfc322a9ffe2678e1955e6b4a9/public/prd/community-guide-20261020/images/original-post.png)

*图3-9：作者原帖保留作者、关注与互动，不提供公共词条编辑历史。*

从首页玩家攻略、检索结果或词条“更多攻略帖”进入原帖。关注按作者切换，点赞与收藏按原帖切换并更新本地计数；评论为当前会话内容。原帖转发仅静态呈现，当前不可操作。公共词条最多关联24篇有效且不重复的玩家原帖。

点击发布动态进入既有攻略发布表单，沿用当前游戏GTA5及攻略语境。标题和正文必填，去除空白后校验，标题最多160字、正文最多20000字。校验失败保留输入并显示错误；发布成功生成作者“我”的原帖，进入原帖详情并清空发布输入。帖子进入玩家攻略列表，是否收录到栏目由精编配置决定。返回／取消保留本会话发布草稿。当前没有新增图片上传、标签选择、发布审核队列或通知。

### 3.5 App：成为编辑与申请状态

在允许普通用户编辑的百科，普通用户可按当前权限更正已有公共资料正文与数据。申请初级精编用于增加默认创建词条、批量维护和组织栏目能力，申请通过不是普通编辑的前置；后台是否允许进入仍按该百科编辑范围判断。

| 待审核 | “申请审核中”，显示已提交说明，无重复提交按钮。 | 高级精编处理后状态更新。当前没有真实通知、处理时限承诺。 |
| 已驳回 | “申请未通过”、驳回原因、“补充申请说明后可重新提交”。 | 重提创建新申请，保留旧申请处理记录，不覆盖旧结果。 |
| 已通过且身份有效 | “已成为精编”、当前初级／高级身份、“进入精编工作台”。 | 点击时再次检查当前角色和限制状态，按实际身份进入工作台；申请通过只授予初级，不自动成为高级。 |

#### 3.6.2 词条列表与删除

![词条列表](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@936a174affc626cfc322a9ffe2678e1955e6b4a9/public/prd/community-guide-20261020/images/entry-list.png)

*图3-16：列表提供搜索、新建、单条编辑／删除和批量选择。*

词条列表显示当前百科、当前内容语言的ID、名称、类型、更新时间及操作。搜索输入不限制长度，按ID、名称、替代名或模板类型匹配，不区分大小写；无匹配保留搜索条件，显示“没有匹配词条，请调整搜索。”。百科没有词条时显示“当前百科暂无词条，可点击新建。”。点击编辑进入该词条；不同词条会话草稿分别保留。

勾选框只对当前身份可删除的对象可用，表头全选只作用于当前筛选结果中的可删对象；已选的其他筛选结果不因此清除，取消全选只移除本次筛选中的对象。切换百科清空选择。点击“批量删除”打开居中弹窗，显示数量及所选词条名称，点击“取消”、关闭弹窗或按Esc不删除。

点击“确认删除”后，按打开弹窗时的版本校验1—100条不同词条。任一对象不存在、权限变化、版本变化、仍被批次外内容或任一语言的配置引用、提交失败，整批均不删除，公开内容和历史不变，保留选择供调整。批次内词条相互引用不阻止同批删除。成功后移出公开目录、清除对应草稿及选择，删除各语言内容，保留删除记录与已占用ID；当前没有撤销入口。

单条删除也检查当前身份、当前版本及引用，删除说明最多120字，由当前操作自动填写。仍被其他词条、实体列表、图册、版本、正文关联块、分类或快捷入口引用时，显示来源并拒绝删除。后台“编辑记录”可以查看删除记录对应的历史快照。

#### 3.6.3 词条编辑与高级选项

![词条编辑](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@936a174affc626cfc322a9ffe2678e1955e6b4a9/public/prd/community-guide-20261020/images/entry-editor.png)

*图3-17：词条名和替代名位于顶部，正文默认使用宽富文本编辑区；阅读效果按需打开。*

编辑页上方显示词条名和词条替代名，不提供“词条标签”。词条名必填，最多160字。替代名输入最多80字，按Enter加入，最多20个；首尾空格去除，不可与词条名相同或与已有替代名重复，点击已有替代名的移除按钮可删除。未按Enter加入的输入不作为替代名保存。

正文默认占满可用编辑宽度，工具栏提供小标题、字号、粗体、斜体、下划线、清除格式、链接、图片、视频及已有五类共用组件；列表、引用、表格等已有正文内容继续维护。模板类型不因编辑模式变化。数据表、图鉴、实体、图册和版本索引继续显示各自结构字段，不因改为富文本界面丢失已有数据。

![HTML编辑](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@936a174affc626cfc322a9ffe2678e1955e6b4a9/public/prd/community-guide-20261020/images/entry-html.png)

*图3-18：点击HTML编辑模式后修改同一篇正文，切回富文本时保留可支持的内容。*

富文本与HTML编辑模式共用当前草稿。HTML源码最多400万个字符，仍须满足下方正文块与单项限制；仅接受已支持的正文结构及安全链接，不允许脚本、事件属性或其他任意执行内容。无法解析、超长或包含不支持内容时保留原始输入，显示具体错误，阻止预览和保存；修正后再切换或提交，不静默丢弃内容。

| 输入对象 | 内容与校验 | 权限及结果 |
|---|---|---|
| 摘要与管理信息 | 摘要最多1000字；适用范围最多160字；来源说明最多2000字；修改说明必填，最多120字。摘要和管理信息收在可展开区域。 | 普通／初级可改摘要及正文，范围、维护状态与来源由高级维护。已有词条的模板和字段方案固定，改模板须另建词条。 |
| 实体字段 | 名称、类型、版本为当前方案必填项；文本最多2000字，数字须为非负有限数，未知可留空；枚举来自配置选项。 | 标题与实体名称联动，同时输入两个不同值时拒绝。实体创建／编辑沿用既有模板数据权限，删除须有实体删除权限。 |
| 正文内容 | 最多100个正文块；段落／小标题／提示最多20000字；列表1—100项，每项非空且最多2000字；引用正文必填且最多20000字，出处最多1000字。 | 支持添加、修改、删除和排序；保存时校验整篇，任一无效不写入。 |
| 图片、表格与外链 | 图片可选登记素材、填写最多2048字的有效http(s)图片地址或上传PNG／JPG／WebP／GIF，单图最大2 MB；说明最多2000字。表头最多200字、单元格最多2000字、行列一致，界面至少保留1行1列；外链文字必填最多2000字，正文链接地址最多2000字。 | 无效图片或读取失败保留现有草稿并提示错误，不能带着无效图片保存。上传仅为本地会话读取，正式存储待接入。 |
| 关联资料与版本 | 公共关联对象须存在、不能重复或指向自己；原帖最多24个。图册至少1图；版本索引至少1篇文章，目标唯一，名称最多160字，日期格式为YYYY-MM-DD，当期最多1项。 | 普通／初级可改版本名称和日期；关联文章、当期标记与图册结构由高级维护。日期当前只检查格式，日历有效性待正式接入明确。 |

![高级选项](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@936a174affc626cfc322a9ffe2678e1955e6b4a9/public/prd/community-guide-20261020/images/entry-advanced.png)

*图3-19：正文下方提供帖子内容获取、参考资料和四项声明。*

“从帖子获取内容”输入帖子ID，最多100字；点击“获取”后，把当前百科中可获取帖子的正文与有效封面追加到词条草稿末尾，原正文不覆盖，仍需保存才生效。未填ID、找不到帖子、当前百科无可获取帖子、帖子无正文，或追加后超过100个正文块时，显示对应原因，不生成占位内容，也不改公开词条。当前演示只提供国内GTA 5的本地帖子，真实帖子查询及授权待接入。

参考资料最多30条。引用内容必填且最多500字，链接文字选填最多120字，链接选填最多2048字且限http(s)，语言必选，选项为简体中文、英语、俄语、葡萄牙语（巴西）、日语、印地语。点击“添加”校验后加入当前草稿；无效时保留输入，成功清空该组输入；可删除已有参考资料。

“添加声明”提供以下四项复选，可任意组合，预览及阅读显示已选内容：

- 该词条包含部分「个人观点」的内容，仅供读者参考。
- 该词条内容有待补充，欢迎参与完善。
- 该词条含有部分翻译内容，请参考相关来源进行校对。
- 该词条部分段落格式有待规范，请协助修改。

点击“预览词条”打开阅读效果区，按当前草稿展示正文、参考资料及声明，不提交；关闭预览后恢复宽编辑区。底部保留“保存修改”“预览词条”“取消编辑”。保存同时检查权限、对象存在、基准版本、字段结构、修改说明及实际变化，全部满足才增加一版修订并同步公开内容与历史，不经过保存前审核。无变化显示“内容没有变化，未生成新版本”。权限不足、已删除、校验失败或保存失败均保留输入，公开版本与历史不变。

版本冲突不覆盖新公开版，保留草稿供核对；点击“舍弃当前草稿，载入最新版本”才替换为最新内容，不自动合并。取消编辑恢复公开版，不写历史。返回阅读时，若当前对象或模式仍有待保存内容，提供“保留草稿并返回／舍弃并返回／继续编辑”；其他对象的草稿不受影响。保留仅限本次会话，刷新后不保留。

“新建词条”按权限提供六类固定模板；普通用户默认只可创建实体，其他词条创建权限可由当前百科权限配置调整。实体、表格、图鉴须选字段方案，标题和创建说明必填；成功形成初始修订1并进入编辑，不自动加入首页。表格／图鉴初始引用同方案实体，缺少文章时不能新建版本索引。已有或已删除ID不能复用；手动ID最多100字符、字母开头，只含字母、数字、下划线和短横线，不可用post-前缀。失败保留表单，不新增内容。首页新增项目无匹配词条时的空正文创建规则见3.7。

#### 3.6.4 管理多语言

![多语言设置](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@936a174affc626cfc322a9ffe2678e1955e6b4a9/public/prd/community-guide-20261020/images/languages.png)

*图3-20：默认语言固定必选，左侧勾选可用语言，右侧管理已选语言。*

词条与首页配置上方显示内容语言Tab及“管理多语言”。可用语言共六种：简体中文、英语、俄语、葡萄牙语（巴西）、日语、印地语。国内默认简体中文，海外默认英语，默认语言必选且不可移除。

点击“管理多语言”打开居中弹窗，左侧为可用语言复选列表，右侧为已选语言。全选勾选全部语言；取消全选或点击“清除”只保留默认语言。右侧非默认语言可逐项移除。点击“确认”后更新Tab；移除语言只隐藏Tab，已保存内容和未提交草稿仍保留，重新加入可继续查看编辑。移除当前正在编辑的语言后回到默认语言。点击“取消”、关闭、遮罩或按Esc不更改原选择。

切换语言分别保留词条及配置草稿、正文和编辑历史。尚无当前语言版本时，显示源语言内容并明确提示“尚无…内容，当前显示…，保存后建立当前语言版本。”；仅浏览不创建翻译。确认保存才建立当前语言版本，不覆盖源语言或其他译文。不同地区与百科分别保存语言选择。

#### 3.6.5 后台编辑记录

![后台历史快照](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@936a174affc626cfc322a9ffe2678e1955e6b4a9/public/prd/community-guide-20261020/images/history.png)

*图3-21：后台历史详情使用白底深色文字，正文、表格和关联帖可读，只读查看不产生写入。*

侧栏“编辑记录”展示当前百科与内容语言的创建、编辑和删除修订，按时间倒序，同时间按修订号倒序。搜索对象名、操作人或修改说明，最多160字；操作类型默认全部，对象类型默认全部，多条件取交集，点击“重置”恢复默认。无匹配显示“没有符合条件的编辑记录”，保留查询条件供调整。点击“查看版本”进入该条修订的只读快照，标题、作者、时间及修改说明对应所选修订；正文、表格、组件、关联攻略帖均使用后台浅色样式，不显示黑色底。历史内容区域不能触发编辑或互动写入，点击“返回编辑记录”回到列表。

### 3.7 网页后台：首页配置与模板数据

![批量维护](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@936a174affc626cfc322a9ffe2678e1955e6b4a9/public/prd/community-guide-20261020/images/studio-batch.png)

*图3-22：选择同一字段方案的两个实体、勾选统一修改字段，预览逐条差异后再保存。*

初级／高级精编选择一个字段方案后，可勾选1—100个不同的既有实体，并至少勾选一个统一修改字段；未勾字段保留原值。切换方案清除对象选择、字段、说明与差异预览。填写修改说明（必填≤120字）并点击“预览批量差异”，逐条显示旧／新值；没有预览不能保存，任何对象选择、字段或输入值变化都使预览失效。

保存时校验整批权限、版本、字段、引用与失败响应。任一条失败整批不写入、不写历史；成功只对有变化的条目各增一修订，清空批量选择和草稿，无变化条目不生成版本。名称修改与标题同步，不改变实体身份。冲突后点“保留批量填写，载入最新数据”，重载仍存在对象的最新基线、去掉已删除对象，保留字段值与说明，关闭差异预览；须重新预览后保存。

![栏目配置](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@936a174affc626cfc322a9ffe2678e1955e6b4a9/public/prd/community-guide-20261020/images/studio-config.png)

*图3-23：左侧连续展示首页版块和项目，点击齿轮后在右侧编辑版块。*

首页配置左侧为连续可编辑画布，右侧为当前选中版块、分类或项目的操作区。版块齿轮直接打开版块名称、类型、横竖屏每行数量及对应预览；原首页金刚图也可编辑这些内容，保留原项目的跳转目标。没有选中项目时不显示空的“编辑版块”说明框代替表单。版块名称必填，最多80字；搜索版块输入不限制长度，按当前输入实时过滤。

![项目草稿](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@936a174affc626cfc322a9ffe2678e1955e6b4a9/public/prd/community-guide-20261020/images/item-draft.png)

*图3-24：点击添加项目后，右侧先填写项目名称、分类、类型、配图和绑定词条，确认后才加入左侧。*

点击“添加项目”只打开独立项目草稿，不立即插入左侧，不创建词条。项目名称必填，普通版块最多160字，原金刚图项目最多80字；所属分类默认当前分类，有权限时可改选该版块其他分类。项目类型可选词条或链接；原有栏目跳转项目继续保留其原目标。普通项目配图可留空使用默认图；原金刚图指向词条的项目须有配图。图片可选择登记素材、填写最多2048字的有效图片URL、上传2 MB以内的PNG／JPG／WebP／GIF。

### 3.9 App：百科贡献与编辑历史

![百科贡献](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@936a174affc626cfc322a9ffe2678e1955e6b4a9/public/prd/community-guide-20261020/images/contribution.png)

*图3-33：贡献页分为百科贡献和编辑历史，贡献榜显示Top 30及计分明细。*

点击攻略首页“贡献榜”进入当前地区、百科及内容语言的贡献页，默认“百科贡献”Tab。切换到“编辑历史”显示词条名、编辑者、更新时间及查看操作，按成功修订时间倒序排列；两个Tab分别保留本会话滚动位置。点击贡献者名称筛选其编辑记录，可点击“查看全部”恢复；点击某条记录的“查看”打开对应修订的只读内容，返回恢复来源列表。

百科贡献按全部时间统计，最多显示30名。按贡献分从高到低排序，同分依次按有效编辑次数、最近有效编辑时间降序，仍相同时按名称排序；同名账号按实际账号分别计算。无贡献时显示“暂无贡献记录，完成首次有效编辑后会显示在这里。”。贡献分旁以及编辑历史区域的“？”可展开计算规则，关闭后保留列表状态。

贡献分＝有效编辑次数×10＋质量分。有效编辑按每篇词条每个成功修改修订去重，创建初版、初始化、预览、取消、失败、无变化及删除操作不计入。历史成功修改可继续展示，不能把删除记录本身算一次编辑。

每篇现存词条的质量分＝去重点赞人数×2＋去重评论人数×3＋去重收藏人数×5，再按当前保留正文中各编辑者的内容占比分摊；不能按编辑次数平均或比例分摊。同一读者对同一词条多次评论只计一人，取消点赞或收藏后扣减相应人数，无互动记0。只有当前仍保留的有明确作者归属内容进入分摊分母，初始化或无法判断作者的内容不分给任何人；没有可归属内容时质量分为0。

正文文字按非空白字符计，图片、视频等独立内容按项计。新增内容归新增者，未改动内容保留原作者，替换后的新增部分归修改者，删除部分不再占比。只改标题、摘要、排版或移动原有内容不转移正文归属；已删除词条不再产生现存内容质量分。各项点赞、评论、收藏明细显示分摊后的折算值，最多显示三位小数；总分、排序和贡献条长度使用未四舍五入数值。正式互动去重、历史归属和服务端计算依赖见第五章。

## 四、支持要求

### 4.1 状态、权限与业务数据

公共资料、配置和批量保存应使用编辑基准修订号检查并发。预览、取消、失败和冲突不增加公开修订；成功响应必须包含最终公开修订，读取到新版本才可认定读端已同步。正式服务须统一申请、编辑、治理的真实账号标识，进入与每次提交重新检查角色和限制状态。撤权／封禁后的未提交草稿恢复方式待确认，不因演示选择器可切换而放行线上写入。

普通资料修改与修改说明、修订历史一起保存；批量提交整批成功或整批失败；配置整份校验后生效；申请处理结果与身份授予一致。重复点击、超时重试不能生成重复申请／修订。接口、幂等键、失败查询与事务实现尚未提供，阻塞正式写入接入。

删除保留历史及标识，后台编辑记录可只读查看删除快照，当前无撤销。媒体登记素材和示意图片只用于方案评审，正式内容需核实来源与许可。图片支持登记素材、http(s)地址或2 MB以内PNG／JPG／WebP／GIF本地读取；正式上传存储、失败重试、地址有效性及访问控制仍待接入。正文外链只接受http(s)，富文本和HTML模式均不开放任意HTML执行。

横竖屏使用同一资料、身份、草稿与所选Tab；仅组件、列数和布局按方向配置。不得旋转后丢失已输入文字、重新提交申请或生成修订。列表、表格、大图保持各自滚动与焦点规则。当前本地资料全量呈现，正式分页、性能指标和请求失败的恢复需在接口确定后补齐。

| guide_config_open | 工作台配置，新增 | 有权限且配置成功载入时一次；无权限不记成功进入。 | game_id、request_id |

| 参数 | 类型／必填 | 说明 | 枚举／示例 |
|---|---|---|---|
| page_type | string／浏览必填 | 已展示页面类别 | home＝首页；category＝分类；entry＝公共词条；post＝玩家原帖 |
| game_id | string／浏览、搜索、配置进入必填 | 业务游戏标识，不能使用示例文案代替正式标识 | 示例gta5，正式编码待对齐 |
| object_id | string／分类、词条、原帖浏览必填，单篇保存必填 | 对象的正式业务标识；首页省略，批量／配置不填伪对象 | 示例article-beginner |
| orientation | string／浏览必填 | 展示时方向 | portrait＝竖屏；landscape＝横屏 |
| result_count | int／搜索必填 | 查询返回并展示的匹配数，含0 | 示例0、12 |
| request_id | string／结果事件、搜索、配置进入必填 | 本次请求标识，同次重试复用；生成方与格式待接口确认 | 示例req_20261021_001 |
| save_type | string／保存必填 | 本次写入范围 | entry＝单篇；batch＝批量实体；config＝栏目与字段配置 |
| result | string／结果事件必填 | 已确定提交结果 | success＝已成功提交；failed＝已确定未提交。请求未知不伪填终态 |
| error_code | string／failed必填 | 服务端稳定错误码；具体编码表待接口对齐 | 示例VERSION_CONFLICT，示例非既有正式编码 |
| revision | int／单篇或配置保存成功必填 | 服务端提交后的公开修订号，批量各对象修订保留在业务结果 | 示例2 |

| application_id | string／申请成功、审核结果必填 | 服务端申请标识；申请提交失败且未生成时省略 | 示例application_001 |
| decision | string／审核必填 | 审核执行的动作 | approve＝通过授予初级；reject＝驳回并记录原因 |

正文、搜索关键词、联系方式、申请说明、审核原因不作为上述事件参数采集。用户标识、平台与客户端版本使用已有公共参数，须先提供现行规范。核心观察口径为成功阅读、确定成功写入、申请提交及审核结果，不能把按钮点击、预览或未知响应计作业务成功；转化分母、统计窗口和目标值尚未确认。批量删除、语言选择和贡献统计本轮未新增独立采集事件，其正式报表需求与编码须另行对齐，不能把页面内本地计算视作已上报数据。
