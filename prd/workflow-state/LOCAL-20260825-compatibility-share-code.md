## 问题与证据

- 目标用户：不知道手机或 Mac 能否运行目标游戏、希望直接复用可用配置的玩家。
- 核心问题：原筛选混合机型、处理器、GPU，卡片信息口径不清；配置下载不能直接衔接盖世游戏导入。
- 用户当前解决方式：按硬件参数自行比对兼容记录，再手动配置。
- 证据与口径：用户 2026-08-25 连续确认；当前高保真 H5、规格和自动化测试。

## 当前范围

- 涉及端：Android、Mac 共用响应式 H5。
- 涉及地区：不区分地区。
- 横竖屏：手机竖屏、手机/掌机横屏、桌面网页。
- 本期包含：机型筛选、卡片信息重排、全记录启动配置、卡片/详情复制分享码。
- 明确不包含：配置文件下载、应用配置、分享页面、弹窗确认、真实编码算法和线上部署。
