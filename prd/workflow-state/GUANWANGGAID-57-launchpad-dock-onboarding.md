## 问题与证据

- 目标用户：macOS GameHub 用户。
- 核心问题：启动台侧边栏入口重复，程序坞启用与首次使用缺少连贯引导。
- 用户当前解决方式：旧稿从侧边栏进入启动台，再在启动台设置添加程序坞入口。
- 证据与口径：任务 GUANWANGGAID-57、现有 Demo/PRD、用户补充的真实常规设置截图与两次文案反馈；没有新增运营或数据指标。

## 当前范围

- 涉及端：macOS C 端；没有 B 端改造。
- 涉及地区：没有新增地区差异。
- 横竖屏：原 macOS 横屏设置；窄屏只用于查看 Demo，不定义手机端页面。
- 本期包含：移除侧边栏启动台图标及红点、常规设置新增开关、默认关闭、启用成功自动进入、真实控件使用引导、开关同步和异常恢复。
- 明确不包含：应用列表、搜索、分组改造；原设置其他功能；PRD 正文或 Demo 公开发布、飞书正文同步和原生客户端实现。用户随后授权仅公开发布 PRD 引用的 14 张配图。
