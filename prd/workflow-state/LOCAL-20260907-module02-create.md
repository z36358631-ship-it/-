# 02 游戏创建、多语言资料与宣发 / 01 游戏发布审核

更新时间：2026-09-09。02 开发者端与 09 审核后台已同步定价；PRD 03 当前版本 V2.2。

## 当前有效决定

- D-021：素材分组和横竖图切换保留滚动、锚点与焦点；缺项主动定位。
- D-022：增加中国大陆发布地区后，后台界面与基础资料切中文；原文不自动翻译，游戏自身支持语言不被更改。
- D-023：国内服指中国大陆；全球服指中国大陆以外，可同时发行。
- D-024：国内服提审中文名称、简介、完整介绍及版号必填；全球服英语对应三项必填。版号不核验真伪。
- D-025：01 的 P01-08 在企业认证审核基础上增加游戏发布审核，保留原企业审核。
- D-026：不可变提交快照→人工审核→通过只读待发布，或驳回修改重提；不自动上线。
- D-027/028：创建时不选地区的原则保留；提交准备区、第二次确认、逐地区状态和初始空地区已由 D-031 覆盖。
- D-029：游戏名称支持16语种、自定义启用语种与默认语种；创建只要求默认名称。暂移除语种保留原文。
- D-030：基础资料与素材独立管理多语言，按语种保存文字与Blob，缺本语种素材可显示有来源标识的默认预览。图标入口在基础信息。
- D-031：八模块顺序为基础信息→游戏分类与平台→开发者信息→游戏素材→发行设置→收费设置→资质认证→其他设置（收费由D-033补入）。最低运行要求移除。发行设置常驻；新资料默认选中目录内30个非CN地区，明确清空保存后仍为空；统一发行状态，洲仅筛选。顶部唯一提审按钮直接统一校验。
- D-032：审核中顶部可撤销，无额外确认弹窗。成功恢复draft并保留内容及原submissionId作为并发基准；旧快照不变，历史追加withdrawn；01原申请只读。修改后重提新编号。撤销与审核先成功者生效。
- D-033：收费设置选择免费或收费（单次买断），新资料默认免费。买断按已选服填写售价，正数且最多两位小数；当前Demo假设全球USD、国内CNY。草稿保留备用金额，提交快照清除免费模式及未选服的生效价格。历史无pricing显示未配置，编辑后新提审需明确模式。
- D-034：按PC实际服务判断资质，不照搬手游/APK材料。国内版号数字仍必填，扫描件选填。权属声明或有效软件著作权编号+证书可满足自研权属，避免重复上传；发行商仍需授权。ICP与安全评估按服务补充，不统一阻断PC提审。CN需声明是否提供网络游戏服务；CN+online+demo/released才检查防沉迷知悉、游戏方案接入及国家实名接入。全球/离线/仅预约不套该门槛。旧快照不追补新增字段，撤销/驳回后新提审按现行规则。
- D-035：在 D-033 基础上，中国大陆固定 CNY 统一价；全球服使用 USD 基准价，可为已选发行地区配置少量当地币种例外价。免费 SKU 不保存价格；国内／海外切换清空全部价格配置；发布记录与运营审核读取同一不可变定价快照。
