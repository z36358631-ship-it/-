## 问题与证据

- 目标用户：访问开发者首页的未登录用户、已注册平台开发者、申请企业认证的厂商用户，以及负责认证审核和内容维护的平台运营。
- 核心问题：缺少从公开介绍、登录／自动注册、平台开发者选择、企业资料正式提交，到运营审核、结果回显和帮助内容维护的完整首期闭环。
- 用户当前解决方式：依赖官网说明、人工收集企业工商和银行资料、线下协议确认与运营手工反馈，用户无法在统一页面持续查看认证状态。
- 证据与口径：以用户本轮逐项确认、最新 PRD、当前可操作 Demo、Steam／TapTap 本地竞品截图和运营后台参考为当前基线；Figma 已按用户要求冻结，不作为本轮 Demo 的业务事实来源。

## 当前范围

- 涉及端：开发者公开首页与控制台、企业认证申请页、平台发行运营后台和双语内容配置；C 端不新增独立页面。
- 涉及地区与语言：首页、登录、认证介绍及运营内容支持中文／English；企业资料可选择注册地区，具体游戏发行地区由后续 PRD 定义。
- 响应式：公开首页、登录、控制台、帮助中心、认证申请和运营后台覆盖宽屏、1280px 桌面及 320／390px 手机视口。
- 本期包含：手机号／邮箱验证码和盖世游戏 App 扫码登录、自动注册平台账号、平台注册、帮助中心搜索、企业认证介绍与单页正式提交、工商与银行图片附件、两份协议、审核中／通过／拒绝／下架状态、运营筛选／详情／附件受控预览／审核、中文与 English 内容配置。
- 明确不包含：保存草稿、实际游戏创建与详情、商店与 SDK 业务、CDKEY、包体测试发布、精准化投放、自动结算、广告接入和 Figma 继续修改；这些能力仅在控制台或帮助中心占位，等待后续 PRD。
