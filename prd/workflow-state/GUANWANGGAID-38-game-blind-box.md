## 问题与证据

- 目标用户：Android 端个人游戏库中至少存在 2 款可玩游戏，但进入游戏库后没有明确游玩目标的用户。
- 核心问题：用户拥有多个可玩游戏，选择成本阻碍游戏启动和有效游玩。
- 用户当前解决方式：自行在个人游戏库、Steam 库和已导入游戏中浏览选择；秒玩可免下载，Steam 未下载游戏需进入详情获取。
- 证据与口径：用户本轮连续确认；竞品参考为 Bilibili 游戏盲盒，但盖世存在下载与兼容成本，因此采用可玩池和加权随机。

## 当前范围

- 涉及端：Android。
- 涉及地区：国内与海外。
- 横竖屏：竖屏与掌机横屏独立布局。
- 本期包含：“我的游戏”列表第一张盲盒功能卡、游戏库上的居中浮层、固定内容位内候选封面/名称/评分/类型标签轮换、单款命中、查看详情、再抽一次、可玩池、Steam 已登录库、加权随机、多语言和数据验证。
- 明确不包含：任务奖励、抽取次数限制、Steam 登录引导、首页或悬浮入口、后台配置、新启动路径策略。

## 待确认与风险

- 必须确认：跨个人库、Steam、秒玩和导入来源的统一 `game_id` 是否可用；已有启动与游戏会话事件是否能携带抽取归因并提供成功启动和实际游玩时长。
