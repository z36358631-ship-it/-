# 【Prd】《微信 H5 精品游戏》三款游戏制作人总方案

## 一、版本信息

| 时间 | 版本 | 变更人 | 主要变更内容 | 备注 |
|---|---|---|---|---|
| 2026.07.28 | V1.0 | AI 游戏制作团队 | 整合三款纵切片、产品组合、留存、商业化、数据指标与 12 周路线 | 中国大陆 C 端验证方案 |

## 二、制作人结论

三款游戏已经形成可操作的 H5 纵切片，并通过本地浏览器自动验收。当前最合理的产品策略不是同时把三款做成正式商业游戏，而是：

1. 三款使用同一批目标用户、相同入口和统一事件口径完成首轮验证。
2. 用“主动二局率、核心机制完成率、无引导理解率、内容生产成本”进行横向比较。
3. 第 6 周只选择一款进入正式版生产，其余进入储备或停止新增内容。

三款在组合中的职责：

| 顺序 | 游戏 | 产品角色 | 先验证什么 | 主要代价 |
|---|---|---|---|---|
| 1 | 《世界缝补师》 | 低风险探路产品 | 微信 H5 启动、触控、首局理解、内容消费、数据链路 | 长期重玩与商业化空间待验证 |
| 2 | 《五秒之后》 | 品牌旗舰候选 | 独特时间回声机制能否形成记忆与主动重玩 | 理解门槛和关卡制作成本较高 |
| 3 | 《裂隙猎人》 | 留存与商业化候选 | 风险收益、局内成长和重复局是否成立 | 性能、平衡、内容与运营成本最高 |

若数据接近，默认按《世界缝补师》→《五秒之后》→《裂隙猎人》的顺序正式化；任一游戏达到加码门时，可以直接成为正式版候选。

## 三、事实、假设与当前边界

### 3.1 已验证事实

- 三款均为竖屏、单手操作、约三分钟一局的单文件 H5。
- 三款均具备开场、核心机制、局势升级、胜利、失败、无刷新重玩和暂停恢复。
- 本地浏览器自动验收覆盖 `360×800`、`390×844`、`430×932` 三档视口，并补充三款真实触摸拖动与大厅/三款 `file://` 直开。
- 已补充可导入微信开发者工具的最小 `web-view` 承载壳，包含三款选择页、HTTPS 域名门禁和未配置错误态；当前只完成本地静态结构验收。
- 自动验收覆盖确定性胜利路径、失败损失路径、触控目标、横向溢出、控制台错误、外部请求、离线资源、生命周期和公共事件。
- 《五秒之后》已经实现四条五秒回声、双机关、编号时间门和终局合击。
- 《世界缝补师》已经实现有限线长、桥梁、屏障、花园连接及 9/12 获救胜利。
- 《裂隙猎人》已经实现三段武器、普通敌人、精英、战利品、60/150 秒撤离窗、坍缩和死亡保留一件。

### 3.2 待验证假设

- 目标用户是否真正理解并喜欢三款核心机制。
- 主动二局、D1、D7、D30 留存是否达到内部目标。
- 微信好友挑战是否能带来有效新玩家和回流。
- 外观、通行证和奖励广告是否有真实转化。
- 三款内容生产成本是否能支撑长期更新。
- H5 在 iOS/Android 微信 WebView 中的触控、音频、内存和生命周期表现。

### 3.3 当前不具备的能力

- 未完成微信真机验收和微信平台审核。
- 未接登录、服务端账号、云存档、真实分享、广告、支付、排行榜和远程配置。
- 未建设生产事件接收服务，当前事件只满足本地体验和自动验收。
- 未进行非制作人员的无引导首局测试。
- 没有真实留存、商业化和市场数据。

因此，本文件中的用户定位、目标值、留存设计、商业化顺序和立项优先级均是待验证产品建议，不是行业基准或已验证市场结论。

## 五、统一产品目标与体验路径

### 5.1 目标用户

面向中国大陆微信生态中的碎片时间用户，优先验证以下共同需求：

- 三秒内进入可操作状态。
- 十秒内看见“操作→结果”的核心因果。
- 单手完成一局，不依赖复杂按键和长篇教学。
- 三分钟内经历一次完整的选择、升级、高潮和结算。
- 结算后能明确理解“下一局可以改进什么”。

### 5.2 统一体验路径

`大厅选择游戏 → 开场单目标 → 首次有效操作 → 核心机制出现 → 局势升级 → 高潮选择/协作 → 胜利或失败结算 → 主动重玩或退出`

### 5.3 组合北极星

首轮组合决策使用：

```text
主动二局率 =
首局 run_end 后 10 分钟内发生 replay_start 的匿名设备数
÷ 有效首局匿名设备数
```

正式期补充：

```text
每周每活跃玩家的合格核心体验局数 =
合格核心体验局数 ÷ WAU
```

主动二局率用于快速判断“是否自然想再来一次”；合格核心体验局数用于判断长期复玩是否仍在消费核心乐趣。

## 六、《世界缝补师》

### 6.1 产品定义

- 产品角色：组合探路产品。
- 目标用户：偏好轻度解谜、整理修复、低暴力、照护生命和明确视觉反馈的微信碎片时间用户。
- 核心幻想：用一根金色针线亲手修好破碎世界。
- 核心情绪：保护、修复、失而复得。
- 核心取舍：有限线长应该先修哪条路线，如何同时形成桥梁和屏障。

### 6.2 核心循环

`观察生命路线与裂口 → 评估有限线长 → 连接锚点 → 看生命通过 → 撤销或调整 → 连接花园 → 复色结算`

### 6.3 现有纵切片

- 四条救援路线中选择三条。
- 固定有效锚点图，避免自由画线判定失控。
- 针脚同时承担桥梁和风沙屏障两种用途。
- 345 线长资源约束。
- 获救至少 9 个生命并连接花园即胜利。

### 6.4 正式 MVP

- 9 个手工关卡。
- 桥梁、屏障、花园三类规则。
- 章节地图和本地进度。
- 星级、获救数、剩余线长三类目标。
- 生命图鉴和修复结果卡。
- 完整事件协议。

明确不做：UGC 编辑器、实时合作、随机无限关、多币种、装备、支付和排行榜。

### 6.5 长线成长

- D1：查看第一只获救生命进入图鉴，完成一个新三分钟区域。
- D7：完成一块个人花园拼图；失败局也保留发现记录。
- D30：形成四个生态区域、生命图鉴和持续生长的个人花园。
- 长期花园只生长、不衰退；玩家缺席不会导致生命受苦或花园枯萎。

### 6.6 七日内容节奏

| 天 | 内容 |
|---|---|
| Day 0 | 完成首局，领取第一张生命图鉴卡 |
| Day 1 | 新区域只增加一种锚点关系 |
| Day 2 | 开放路线预演，帮助理解线长取舍 |
| Day 3 | 发送或接收一张修复明信片 |
| Day 4 | 单目标委托：例如用一条屏障保护三只云兔 |
| Day 5 | 解锁金线纹理或花园装饰 |
| Day 6 | 自由布置与追赶，不增加限时任务 |
| Day 7 | 拼合本周花园全景，并提供“本周到此为止”出口 |

### 6.7 社交与商业化

- 异步社交：修复明信片、好友同图、共同织锦；不做实时协作。
- P0 外观：金线材质、针脚样式、花园装饰、季节和生命伙伴外观。
- P1 内容/通行证：生态章节、装饰和图鉴页，失败局也能推进。
- P2 奖励广告：结算后自愿领取装饰种子或图鉴边框。

禁止出售更清晰的锚点、无限线长，禁止在生命即将受损时用广告或付费制造情绪勒索。

### 6.8 指标

合格核心体验局：同一局完成至少一条桥梁、一条屏障、连接花园并救出至少 9 个生命。

首局漏斗：

`game_open → run_start → 首次 stitch_attempt → 首次有效 stitch_complete → bridge reveal → barrier reveal → garden_connected → life_saved → saved≥9 → run_end → replay_start`

重点指标：

- 首针成功耗时。
- 有效端点连接成功率。
- 无效连接原因分布。
- 桥梁和屏障双用途体验率。
- 撤销后修正成功率。
- 线长利用率与剩余线长。
- 获救率、花园连接率和主动二局率。

## 七、《五秒之后》

### 7.1 产品定义

- 产品角色：品牌旗舰候选。
- 目标用户：喜欢机制发现、路线规划、轻动作解谜和“聪明解决问题”的中轻度玩家。
- 核心幻想：过去五秒的自己会回来帮助现在的我。
- 核心情绪：从孤身行动到多个自我同步合击的力量膨胀。
- 核心取舍：现在的路线既要解决眼前问题，也要成为下一轮可靠的回声。

### 7.2 核心循环

`规划五秒路线 → 封存回声 → 观察重演 → 现在与过去协作 → 改写下一段路线 → 多回声合击`

### 7.3 现有纵切片

- 最多四条循环重演的五秒回声。
- 双机关要求两个不同角色同时进入。
- 四个编号时间门分别绑定四条回声。
- 当前角色完成终局核心合击。
- 回声轨迹在结算中汇合展示。

### 7.4 正式 MVP

- 6 个时间谜题。
- 四回声、双机关、编号门、障碍和时间核心。
- 固定种子回放与章节解锁。
- 回声外观和结果轨迹卡。
- 关卡必解校验器的最小版本。

明确不做：手动攻击键、装备系统、联网 PVP、自由关卡编辑器、开放地图和复杂剧情分支。

### 7.5 长线成长

- D1：固定种子的“今日时间异常”，只给一个目标。
- D7：个人时间档案，展示最快完成、最少受伤、最少改线三种成就。
- D30：四周规则主题，包括回声入门、时间门组合、干扰规则和复合终局。
- 月末生成个人路线短片和收藏外观，不清空个人记录。

### 7.6 七日内容节奏

| 天 | 内容 |
|---|---|
| Day 0 | 完成首局，提供一次“改写最后五秒” |
| Day 1 | 单目标每日时间异常 |
| Day 2 | 解锁上一局淡化轨迹对照 |
| Day 3 | 首次好友同种子回声蓝图 |
| Day 4 | 增加一个易读规则变量 |
| Day 5 | 累计协作机关数解锁轨迹外观 |
| Day 6 | 追赶日，只显示一项未完成内容 |
| Day 7 | 复合时间核心挑战和一周微总结 |

### 7.7 社交与商业化

- 异步社交：回声蓝图、同种子竞速、好友幽灵路线；接收者完成后才展示双方路线对比。
- P0 外观：回声颜色组、轨迹材质、合击终结动画和角色轮廓。
- P1 通行证：按不同解法类型推进，不按连续登录推进。
- P2 奖励广告：结算后获得外观碎片或路线短片样式。

禁止用广告增加回声、减速时间、跳过机关或失败复活；所有外观必须保持编号、高对比和回声辨识度。

### 7.8 指标

合格核心体验局：生成至少 2 条回声、激活双机关并破坏至少一层时间核心护盾。

首局漏斗：

`game_open → run_start → 10 秒内 first_input → 8 秒内 mechanic_reveal → 生成≥2条回声 → dual_switch_activated → shield_broken → core_payoff/run_end → replay_start`

重点指标：

- 首条回声生成率和耗时。
- 2/3/4 条回声到达率。
- 回声参与摧毁目标占比。
- 双机关激活率。
- 四盾全破率和核心完成率。
- 五秒路径重演位置误差。
- 主动二局率。

## 八、《裂隙猎人》

### 8.1 产品定义

- 产品角色：留存与商业化候选。
- 目标用户：熟悉割草、生存、Roguelite 或撤离玩法，偏好成长、紧张决策和战利品展示的玩家。
- 核心幻想：我已经能安全离开，但还想再拿一个宝箱。
- 核心情绪：贪婪、紧张、死里逃生。
- 核心取舍：现在带走已有战利品，还是承担更高风险继续获取。

### 8.2 核心循环

`移动躲避 → 自动战斗 → 武器升级 → 拾取战利品 → 判断撤离或继续 → 带出/遗失 → 下一局调整`

### 8.3 现有纵切片

- 单指移动，自动瞄准、射击和拾取。
- 单发、双发、穿透散射三段武器形态。
- 普通敌人、精英和危险值成长。
- 60 秒与 150 秒两次撤离窗口。
- 玩家需在撤离区连续站稳三秒。
- 死亡只保留价值最高的一件物品。

### 8.4 正式 MVP

- 1 张竞技场。
- 3 类普通敌人和 2 类精英。
- 2 个初始武器方向及三段成长。
- 约 12 类战利品。
- 两次撤离窗口和轻量图鉴。

明确不做：实时组队、PVP、交易市场、复杂背包、随机词条海、抽卡和多服务器经济。

### 8.5 长线成长

- D1：昨日行动档案和一个新种子悬赏。
- D7：形成个人风险画像，如稳健撤离、临界收手、深层猎手。
- D30：四周轮换敌群、环境规则和撤离区域组合，保留赛季藏品柜。
- 不把某一种风险风格描述为更高级。

### 8.6 七日内容节奏

| 天 | 内容 |
|---|---|
| Day 0 | 首次撤离或死亡，同种子稳健重跑或换种子 |
| Day 1 | 一个风险档位悬赏 |
| Day 2 | 增加一个清晰环境变量 |
| Day 3 | 首次好友同种子悬赏 |
| Day 4 | 生成个人撤离时机复盘 |
| Day 5 | 完成一次不限定胜负的外观合约 |
| Day 6 | 追赶与自由局，不提高掉落诱惑 |
| Day 7 | 周末复合裂隙和一周风险画像 |

### 8.7 社交与商业化

- 异步社交：猎人悬赏单、同种子收益挑战、战利品展示。
- P0 外观：猎人轮廓、武器射线、击杀特效、撤离动画和藏品柜主题。
- P1 通行证：击杀、撤离和死亡后的有效行动均可推进。
- P2 奖励广告：只在结算后兑换外观残片或藏品柜装饰。

禁止广告复活、找回遗失战利品、延长撤离时间、提升掉率或免除死亡损失。任何付费和广告奖励都不能改变当局风险、收益、损失或撤离判断。

### 8.8 指标

合格核心体验局：玩家看到 60 秒撤离机会，做出进入撤离区或继续冒险的可识别决策，随后产生完整 `run_end`。

首局漏斗：

`game_open → run_start → first_input → first_kill/loot_pickup → weapon_upgrade → extraction_offer → extraction_decision → run_end → core_payoff → replay_start`

重点指标：

- 首杀、首件战利品和首次升级到达率。
- 60 秒撤离机会可见率和决策响应率。
- 立即撤离与继续冒险的分布。
- 继续冒险后的增量价值、额外存活时长和最终结果。
- 撤离区进入率、三秒站稳完成率和中断次数。
- 死亡原因、保留价值、遗失价值和主动二局率。

## 九、组合导流

使用情绪互补导流，不在局内打断：

- 《五秒之后》胜利后推荐《裂隙猎人》，承接速度感和操作自信。
- 《裂隙猎人》死亡或高压撤离后推荐《世界缝补师》，提供低压恢复。
- 《世界缝补师》完成修复后推荐《五秒之后》，承接规划和掌控欲。
- 玩家连续失败时不推荐更高压游戏。

每次结算最多出现一张可关闭推荐卡，不自动跳转。跨游戏周旅程只提供互文外观；任何单款玩家都能获得同等级奖励，不能强迫体验全部产品。

## 十、事件协议与数据口径

### 10.1 生产事件信封

现有 V1 协议满足浏览器验收，但不能可靠支持跨日留存和 A/B。进入小流量前升级为：

```js
{
  source: "wechat-h5-premium-games",
  version: 2,
  eventId,
  anonymousId,
  sessionId,
  seq,
  gameId,
  runId,
  event,
  clientTs,
  elapsedMs,
  buildId,
  env,
  testMode,
  acquisition: { channel, campaign },
  experiments: [{ id, variant }],
  payload
}
```

`anonymousId` 使用随机安装标识，不使用 OpenID、手机号或其他直接身份信息。

### 10.2 公共事件

统一最小路径：

`game_open → run_start → first_input → mechanic_reveal/phase_change → core_payoff → run_end`

规则：

- 每局恰好一个 `run_start`。
- 重玩产生新 `runId` 和新的 `run_start`，同时记录 `replay_start`。
- `run_end.result` 统一为 `success|failure|quit`。
- 各游戏原始结果写入 `outcome`。
- 页面退出写入 `quit/censored`，不得直接记为玩法失败。
- 服务端记录 `received_at`，按 `eventId` 去重，检查 `seq` 单调和起止配对。

### 10.3 留存口径

- 新玩家：该 `gameId` 首次发生有效 `run_start` 的 `anonymousId`。
- 有效局：存在 `run_start` 和 `first_input`，且非 QA/testMode。
- D1/D7/D30：按北京时间首次有效局日期建 cohort，在第 1/7/30 个自然日再次发生 `first_input`。
- 同时报告玩法质量留存：返回日再次完成该游戏的合格核心体验。
- 比例报告分子、分母、绝对值和 95% Wilson 置信区间。
- 时长报告中位数、P25 和 P75，不只报告均值。

## 十一、阶段门槛

以下数值全部为 `[内部首轮目标]`，不是行业基准。

### 11.1 Gate A：无引导 Prototype 测试

每款至少 10 名目标用户：

- 继续：至少 8/10 无口头提示完成首次核心动作；至少 6/10 能说明核心取舍；至少 5/10 主动重玩或明确要求再玩。
- 停止：连续两轮修正后仍少于 5/10 理解核心动作，或乐趣必须依赖说明者解释。
- 加码候选：至少 8/10 理解核心幻想且至少 6/10 主动重玩，同时没有 P0/P1 真机问题。

### 11.2 Gate B1：Prototype 进入小流量

每款至少 60 名目标新玩家和 120 个有效局：

- 必填事件字段完整率 ≥98%。
- 有效局起止或明确中断覆盖 ≥95%。
- `run_start → 10 秒内 first_input` 点估计 ≥80%，95% CI 下限 ≥70%。
- `first_input → 首次核心机制` 点估计 ≥70%，95% CI 下限 ≥60%。
- 同会话主动二局率 ≥20%。
- 《五秒之后》：双机关激活率 ≥40%，至少生成 3 条回声的局占比 ≥50%。
- 《世界缝补师》：有效端点连接成功率点估计 ≥95%，桥梁+屏障双体验率 ≥40%。
- 《裂隙猎人》：首次升级到达率 ≥60%，60 秒撤离决策响应率 ≥70%，立即撤离与继续任一侧不得低于 20%。

### 11.3 Gate B2：组合正式化决策

单款至少 500 个有效开局：

- 事件完整率 ≥98%。
- 无致命错误会话 ≥99%。
- `game_start → 10 秒内 first_input` ≥85%。
- `first_input → mechanic_reveal` ≥70%。
- `run_end / game_start` ≥60%。
- 主动二局率 ≥20%。

加码条件：满足底线，主动二局率领先第二名至少 5 个百分点；访谈能明确指出快乐来源；团队能在一周内交付并验收一个新增内容单位。

停止条件：两轮迭代后仍未通过理解或稳定性底线，且没有战略性独特信号。停止表示冻结新增内容并保留代码和研究结论。

### 11.4 小流量进入正式立项

- 至少 1,000 名新玩家和 800 名有效新玩家。
- D7、D30 各有至少 800 名已成熟 cohort 用户。
- 普通留存点估计：D1 ≥22%、D7 ≥8%、D30 ≥3%；95% CI 下限分别不低于 18%、6%、2%。
- 每周每活跃玩家合格核心体验局数 ≥1.3。
- D7 返回玩家中完成合格核心体验的比例 ≥50%。
- 至少一项预注册核心机制实验达到最小效果，95% CI 不跨 0，护栏无显著恶化。
- 未成熟 D30 时只能“有条件立项”，不能写长期留存已验证。

### 11.5 Gate C：正式发布

- Beta 无 P0；P1 有明确规避方案或修复日期。
- 低端目标机型核心局内帧时间和内存无持续恶化。
- 新内容未使主动二局率较小流量基线下降超过 2 个百分点。
- 客服、隐私、监控、回滚和审核材料齐备。
- 未达门槛则延长 Beta，不以日期替代质量判断。

## 十二、A/B 实验顺序

1. P0 数据 A/A：验证匿名身份、稳定分桶、重复/丢失事件和样本比例失衡。
2. P1 首次因果清晰度：
    - 《五秒之后》：现有反馈 vs 轨迹预演和“过去的你正在复现”。
    - 《世界缝补师》：现有锚点 vs 只高亮有效下一锚点。
    - 《裂隙猎人》：现有撤离提示 vs 同屏展示当前带出价值、继续收益和风险。
3. P2 核心机制节奏：双机关出现时机、桥梁/屏障教学顺序、首次升级与撤离前风险斜率。
4. P3 结算与复玩：失败原因、差一步反馈、重玩文案。
5. P4 商业化前置：核心体验和留存过门后，才测试外观、帮助或奖励广告意向。

实验使用 `anonymousId` 稳定 50/50 分桶；双侧 α=0.05、功效 80%；至少覆盖完整 7 天流量周期。报告绝对差、相对差和 95% CI。数据质量异常或样本比例失衡检验 `p<0.01` 时，实验作废。

## 十四、非功能与微信接入

| 类型 | 要求 |
|---|---|
| 运行环境 | 首版由普通微信小程序 `web-view` 承载 HTTPS H5 |
| 适配 | 竖屏 `360×800` 至 `430×932`；关键触控目标不小于 44px |
| 性能 | 核心玩法使用 Canvas；低端机优先减少特效，不改变规则 |
| 生命周期 | 页面失焦立即暂停计时、动画和声音；恢复后由玩家主动继续 |
| 离线资源 | 单文件版本不依赖 CDN、外部图片、在线字体和 iframe |
| 安全 | 正式接入把 `postMessage("*")` 改为可信来源白名单，并由服务端校验事件 |
| 隐私 | URL 不传 OpenID、`session_key` 或长期令牌；只收集实现验证所需的最小匿名数据 |
| 容错 | 事件采用批量上报、重试、服务端时间和去重；游戏本身不依赖实时事件通道 |
| 回滚 | H5 版本、资源和远程配置可独立回滚；微信容器保留稳定入口 |

若后续迁移微信小游戏，可复用核心规则、数值、固定时间步、确定性随机、Canvas 绘制思路、事件口径和胜负规则；登录、广告、支付、分享、排行榜、平台 UI、分包、审核、实名防沉迷和隐私授权需要按小游戏 API 重新实现。

## 十五、合规与业务边界

- 当前范围仅面向中国大陆 C 端，中文界面，不包含海外包和多语言。
- `web-view` 依赖公司已备案 HTTPS 业务域名及支持该能力的小程序主体。
- 正式发布前确认小程序类目、内容审核、隐私指引、未成年人保护和必要资质。
- 若迁移微信小游戏，另行确认版号、实名防沉迷、广告和支付资格。
- 当前纵切片不得对外表述为“已通过微信审核”“已完成真机认证”或“已验证留存/收入”。

## 十六、主要风险

| 风险 | 影响 | 处理 |
|---|---|---|
| 只有自动化和制作人员证据 | 把“能运行”误判为“好玩” | W1–2 完成每款至少 10 人无引导测试 |
| 三款同时正式化 | 内容、技术和运营投入被摊薄 | W6 强制只选一款胜者 |
| 缝补师重玩动力不足 | 关卡耗尽后流失 | 先验证效率目标和同图挑战 |
| 五秒回声认知负担高 | 玩家不知道当前路线会影响哪条回声 | 轨迹预览、编号形状和录像观察 |
| 裂隙猎人差异化不足 | 退化为普通自动战斗 | 以撤离选择和遗失展示为核心指标 |
| 裂隙猎人低端机掉帧 | 性能改变难度和撤离结果 | 对象池、特效降级和真机性能预算 |
| H5 与小游戏环境不同 | 迁移需重写平台层 | 玩法核与平台适配层隔离 |
| 无合规身份口径 | 跨端留存不可测 | 小流量先用匿名 ID，正式版再接账号 |
| 商业化破坏核心体验 | 谜题或撤离取舍失真 | 留存成立后再测试，奖励只放结算外层 |
| 内容工具建设过早 | 为停止产品制造沉没成本 | W6 胜者确定后才建设正式工具 |
