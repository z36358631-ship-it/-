## 二、背景与目标

背景：Mac MODS“已安装”页当前同时展示“全部、已启用、未启用、可更新”四个筛选。启用值已在卡片和详情中持续展示，继续保留“已启用、未启用”筛选会增加控件数量，且与更新处理入口并列后信息层级偏重。

目标：Mac“已安装”页只保留“全部、可更新”，减少列表顶部控件，同时保留启用值展示和启停管理能力。

核心边界：

- 仅调整 Mac MODS“已安装”页。
- 不调整 APP 竖屏、APP 横屏和运行中旋转。
- 不调整创意工坊。
- 不删除 MOD 的启用值，不删除启用、停用、更新和卸载操作。
- 国内包与海外包规则一致；本需求不涉及云游戏、登录、实名认证和渠道能力。

## 三、故事介绍

### 3.1 用户场景

- 用户进入 Mac 游戏详情 → 打开 MODS → 切换“已安装” → 默认查看当前设备全部已安装 MOD。
- 用户点击“可更新” → 只查看存在新版本或更新失败仍可重试的 MOD → 点击卡片进入详情 → 更新或继续管理旧版。
- 用户仍可从卡片和详情识别“已启用/未启用”，并进入详情执行启用或停用。

### 3.2 价值分析

- 降低已安装页控件密度，突出“查看全部”和“处理更新”两个主要任务。
- 启用值仍在内容层展示，列表精简不影响设备级管理。
- 只修改筛选枚举和展示，开发与回归范围可控。

### 3.3 核心体验路径

- 全部：游戏详情 → MODS → 已安装 → 全部 → 查看任意已安装 MOD。
- 更新：游戏详情 → MODS → 已安装 → 可更新 → 进入 MOD 详情 → 更新。
- 启停：游戏详情 → MODS → 已安装 → 点击卡片 → 在详情中启用或停用。

### 3.4 产品指标预测

- 已安装页可见筛选项由 4 个降为 2 个。
- 合法筛选值命中率为 100%，非法或旧值全部回退“全部”。
- 本次改动不新增业务转化指标，沿用 MODS 已安装页曝光、筛选点击和更新转化指标。
- APP 和创意工坊回归用例通过率为 100%。

### 3.5 路径规划

- V1.0：Mac 已安装页仅保留“全部、可更新”，同步状态兼容和验收标准。
- 后续版本：根据真实筛选点击数据决定是否增加其他高频筛选，不在本期预留空入口。

|旧状态兼容|无图，以 Demo 为准|筛选值为 `已启用`、`未启用`、`异常` 或其他非法值时，进入页面后回退“全部”，不出现空白页或无选中态。|

#### 4.2.1 页面状态

|场景|展示|可执行操作|
|---|---|---|
|当前设备有已安装 MOD|默认显示全部已安装 MOD|切换筛选、搜索、点击卡片|
|当前设备无已安装 MOD|显示“当前设备尚未安装 MOD”|进入“浏览”查看可安装 MOD|
|“可更新”无结果|显示“没有符合当前筛选的已安装 MOD”|点击“全部”|
|搜索无结果|显示“没有找到匹配的 MOD”|清空搜索；当前筛选不变|
|本地状态读取失败|保留页签和返回操作，显示失败原因与重试|重试；不得用目录缓存覆盖本地状态|
|更新检查失败|旧版和启用值继续展示；若仍存在有效新版本且可重试，归入“可更新”|进入详情重试更新|

#### 4.2.2 状态边界

- 筛选只改变列表展示集合，不修改安装事实、启用值、更新事实或任务状态。
- “已启用/未启用”是当前设备状态，不随筛选切换变化。
- “可更新”与启用值独立：已启用和未启用 MOD 均可进入。
- 更新任务失败时保留旧版；筛选不得把失败状态包装成安装失败或自动停用。
- 返回详情再回列表时保留本次会话内筛选和搜索。
- 关闭 Demo 或重新初始化后默认回到“全部”。

#### 4.2.3 国内与海外

- 国内包页面使用“盖世游戏”，沿用国内包语言规则。
- 海外包页面使用“GameHub”，沿用海外包多语言规则，不使用“GaishiGame”。
- 两套包的 Mac 已安装筛选均为“全部、可更新”。
- 本需求不触发登录方式、云游戏、实名认证、运营资源位或渠道包差异。

## 五、非功能需求

|需求类型|详细要求|
|---|---|
|性能|筛选使用当前设备已加载的安装状态，不新增网络请求；点击后一次渲染完成。|
|兼容性|支持当前 Mac Demo 覆盖的系统和窗口尺寸；不修改 APP 横竖屏。|
|安全|筛选不得写入 MOD 文件、存档和用户配置；不得改写启用值。|
|容错|非法或旧筛选值回退“全部”；本地状态失败时保留重试，不显示错误的跨设备状态。|
|可访问性|筛选使用原生按钮，选中态可识别，支持键盘聚焦与触发。|
|多语言|海外包使用现有翻译资源；筛选语义对应 All、Updates available。|

## 六、埋点需求

本次不新增事件，复用已安装页曝光和筛选点击事件。筛选参数枚举收敛为 `all、update`；历史数据中的 `enabled、disabled、exception` 保留，不回写。

### 6.1 埋点事件表

|事件ID|事件名称|触发时机|关键参数|
|---|---|---|---|
|mods_installed_view|已安装页曝光|Mac 已安装页展示完成|game_id、device_id、installed_count、update_available_count|
|mods_installed_filter_click|已安装筛选点击|用户点击“全部”或“可更新”|game_id、filter_type、result_count|
|mods_card_click|已安装卡片点击|用户从筛选结果进入 MOD 详情|game_id、mod_id、filter_type、enabled_value、update_fact|

### 6.2 埋点参数表

|参数名|类型|必填|说明|枚举/示例|
|---|---|---|---|---|
|game_id|string|是|当前游戏|steam:322330|
|device_id|string|是|当前设备安装标识|设备级匿名标识|
|filter_type|string|是|当前筛选|all、update|
|result_count|number|是|筛选后结果数|0、4|
|enabled_value|string|卡片点击必填|当前设备启用值|enabled、disabled|
|update_fact|string|卡片点击必填|更新事实|no_update、update_available、source_unknown|

## 八、验收标准

|编号|场景|前置条件|操作|预期结果|
|---|---|---|---|---|
|AC-MAC-FILTER-01|筛选控件|进入 Mac 已安装页|检查筛选区|仅显示“全部、可更新”；“全部”默认选中；不存在“已启用、未启用、异常”筛选|
|AC-MAC-FILTER-02|全部|同时存在已启用、未启用、有更新和已是最新的已安装 MOD|点击“全部”|全部已安装 MOD 均展示；卡片启用值和启停操作保持可用|
|AC-MAC-FILTER-03|可更新|已启用和未启用 MOD 均有新版本，另有已是最新项|点击“可更新”|有新版本或更新失败可重试的项目展示；已是最新、更新状态未知和来源失效项不展示；启用值不影响结果|
|AC-MAC-FILTER-04|搜索联动|“可更新”结果中包含多个 MOD|选中“可更新”并输入关键词，再清空关键词|搜索与筛选取交集；清空搜索不重置筛选；无结果时显示对应提示|
|AC-MAC-FILTER-05|筛选切换|已输入搜索词|依次点击“可更新”“全部”|搜索词保留；列表按当前筛选重新派生；页面回到列表顶部|
|AC-MAC-FILTER-06|初始空状态|当前设备无已安装 MOD，搜索为空，筛选为“全部”|进入已安装页|显示“当前设备尚未安装 MOD”，可进入“浏览”|
|AC-MAC-FILTER-07|筛选无结果|当前设备有已安装 MOD，但无可更新项|点击“可更新”|显示“没有符合当前筛选的已安装 MOD”；可点击“全部”恢复|
|AC-MAC-FILTER-08|旧值兼容|缓存或调用传入已移除、异常或非法筛选值|进入已安装页|回退“全部”；不出现空白页或不可见选中态|
|AC-MAC-FILTER-09|启停回归|存在已启用和未启用 MOD|分别进入两张卡片详情并执行启停|启用值正常变化；筛选精简不阻断启停|
|AC-MAC-FILTER-10|范围回归|Mac、APP 和创意工坊均可访问|完成 Mac 修改后分别检查|Mac 仅变更筛选入口；APP、创意工坊及启停能力无变化|
|AC-MAC-FILTER-11|国内海外|国内包与海外包均可运行|分别进入 Mac 已安装页|两套包筛选规则一致；产品名和语言遵循各自包规则|
