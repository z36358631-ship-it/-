# 【Prd】《盖世游戏》GOG平台接入需求

## 一、版本信息

|时间|版本|变更人|主要变更内容|备注|
|---|---|---|---|---|

## 二、背景与目标

### 2.1 需求背景

拥有 GOG 游戏的用户目前无法在盖世游戏内绑定 GOG、查看个人游戏库、识别 GOG 搜索结果，也无法从游戏详情明确选择 GOG 启动。用户只能离开应用，通过 GOG Galaxy 或 GOG 网站查看账号和游戏资产，盖世游戏内的发现、查看、启动链路不完整。

现有产品已在我的页、游戏库、游戏详情和搜索结果中接入 Steam、EPIC。本期沿用该结构增加 GOG，不新增平台管理中心，不改变 Steam、EPIC 既有核心流程。

需求证据与判断：

|类型|当前证据|结论|
|---|---|---|
|业务输入|任务明确要求接入 GOG，并覆盖我的页、游戏库、游戏详情和横竖屏搜索结果|范围已确认|
|现有产品|Steam、EPIC 已具备账号卡、平台游戏库、详情启动和搜索平台标识|GOG 可复用现有信息架构|
|用户替代方案|用户需通过 GOG Galaxy 或 GOG 网站查看 GOG 资产|应用内链路存在缺口|
|用户研究与行为数据|当前没有 GOG 用户规模、绑定意愿、有效库覆盖率和启动增量基线|[高风险假设] 用户存在足够的 GOG 资产管理和启动需求；上线前后必须通过埋点验证|
|外部能力|尚未完成 GOG 官方授权方式、游戏库字段、令牌刷新和退出能力验证|[高风险假设] 正式开发以官方可用能力为前提，禁止用采集用户密码替代|

## 三、故事介绍

### 3.1 用户与运营场景

- GOG 资产用户：在我的页看到 GOG 平台入口，点击绑定后进入 GOG 官方网页。授权成功并完成首次同步后，返回原入口查看用户名、账号价值、游玩时长、游戏数量和最近同步时间。
- GOG 游戏用户：在游戏库切换到 GOG 游戏，看到已同步的游戏。点击游戏后进入详情，页面保留 GOG 来源并展示 GOG 启动方式。
- 多平台用户：从某个平台的游戏库或搜索结果进入详情时，默认使用该来源平台；从没有平台上下文的入口进入时，系统才在已拥有且账号可用的平台中按 Steam > EPIC > GOG 选择。
- 搜索用户：在竖屏或横屏搜索结果中看到 EPIC、GOG 平台标识。同一游戏存在多个平台版本时，每个平台单独展示，点击后进入对应平台详情。
- 运营与产品：无需新增 B 端配置，通过既有版本开关、语言资源和监控体系上线；上线后观察绑定、同步、映射和启动指标。

### 3.2 价值分析

- 用户价值：减少用户在盖世游戏与 GOG Galaxy、GOG 网站之间往返的操作，在同一应用内完成资产查看和启动。
- 产品价值：补齐 Steam、EPIC、GOG 三个平台的核心消费链路，提高个人游戏资产覆盖范围。
- 风险与取舍：复用现有平台卡和页面结构可控制学习与开发成本，但继续增加平台时会增加 Tab 空间压力。本期沿用现有横向滚动或自适应规则，不提前建设平台管理中心。
- [高风险假设] 当前没有用户覆盖和启动增量数据，商业价值只能通过上线后的绑定、同步、映射与启动数据验证。

### 3.3 核心体验路径

1. 首次绑定：我的页或游戏库 GOG 未绑定入口 → 点击“绑定 GOG 账号” → 打开 GOG 官方网页 → 用户在官方页面完成登录授权 → 首次同步 → 返回原入口并展示 GOG 数据。
2. 游戏库启动：游戏库 → GOG 游戏 → 点击游戏 → 携带 `sourcePlatform=GOG` 与对应 `platformAppId` 进入详情 → 展示 GOG 上下文 → 点击 GOG 启动。
3. 搜索启动：探索页搜索 → 竖屏或横屏搜索结果 → 点击 GOG 结果 → 携带 GOG 来源进入详情 → 展示 GOG 启动。
4. 平台切换：游戏详情 → 点击当前平台入口 → 打开切换启动平台 → 选择已拥有的平台 → 同步切换时长、云存档、平台标识和启动按钮。
5. 账号维护：我的页 GOG 已绑定 → 查看更多 → 更新刷新、切换账号或退出账号 → 只更新当前 GOG 状态，不改变 Steam、EPIC。

### 3.4 产品指标预测

|指标|当前判断|使用方式|
|---|---|---|
|GOG 绑定点击率|[高风险假设] 无基线，不预测绝对值|判断入口是否被目标用户发现|
|GOG 绑定成功率|[高风险假设] 默认建议不低于 80%|定位官方授权或网络阻塞|
|首次同步成功率|[高风险假设] 默认建议不低于 90%|判断接口与数据处理稳定性|
|有效库覆盖率|[高风险假设] 取决于 GOG 字段及游戏映射库|识别映射缺口，不以名称强行合并|
|GOG 启动成功率|[待确认] 默认与现有 EPIC 同口径比较|判断 GOG 启动能力是否可上线|
|GOG 启动增量|[待确认] 先建立上线前同周期基线|验证是否改变用户启动行为|

### 3.5 路径规划

|阶段|范围|进入下一阶段的条件|
|---|---|---|
|技术验证|验证 GOG 官方授权、令牌生命周期、游戏库字段和退出机制|不采集用户密码即可完成授权；关键字段与失败码可识别|
|内部验收|完成九个页面、账号隔离、来源路由、异常恢复和安全检查|9.1 P0 用例全部通过；无敏感凭证进入日志、埋点或本地存储|
|灰度验证|国内包与海外包按既有灰度能力开放|绑定、首次同步、启动及映射抽样达到确认后的阈值|
|全量开放|两包功能规则一致，多语言与监控就绪|无 P0/P1 缺陷，主要指标无异常，具备关闭开关与回退方案|

具体灰度比例和时间点为 [待确认]，默认建议从内部账号和小比例用户开始，见 9.2。

本 PRD 无图示；交互与页面状态以同目录交付的单文件标注 Demo 为准。

#### 4.2.10 全局平台路由与游戏归类

平台路由：

1. 入口有明确 `sourcePlatform` 且用户拥有、账号可用：`selectedPlatform` 使用来源平台。
2. 入口有明确 `sourcePlatform`，但账号未绑定、授权失效或平台不可用：保留来源平台，展示绑定、重新登录或切换平台；不得自动替换。
3. 入口没有 `sourcePlatform`：在用户已拥有且账号已绑定、令牌有效的平台中按 Steam > EPIC > GOG 选择。
4. 用户主动切换后，`selectedPlatform` 使用用户选择，直到离开详情或再次切换。

游戏归类：

1. 统一 `gameId` 表示盖世游戏内同一个游戏。
2. `platform + platformAppId` 唯一定位一个平台版本；`platformAppId` 不跨平台复用。
3. 中英文标题、别名和发行版本只用于生成候选匹配，不直接决定归类。
4. 低置信度候选不合并；经人工映射或服务端确认后，才能调整统一 `gameId`。
5. 搜索结果始终按平台版本分条展示；游戏详情可基于统一 `gameId` 展示用户拥有的平台。

#### 4.2.11 用户故事与前后条件

- 用户故事：作为拥有 GOG 游戏的用户，我希望绑定 GOG 并在盖世游戏或 GameHub 中查看、搜索和启动自己的 GOG 游戏，以便减少跨应用查找与启动。
- 前置条件：用户已进入既有账号体系；客户端版本支持 GOG；GOG 官方授权和对应接口可用；入口能传递平台上下文。
- 成功后置条件：保存授权结果及按既有安全体系保存的令牌；完成当前 GOG 账号首次同步；更新 GOG 账号、游戏库和详情数据；不改变 Steam、EPIC。
- 失败后置条件：失败、取消、超时不替换旧账号；无旧账号时维持未绑定；来源平台上下文不丢失；用户可重试或返回。

#### 4.2.12 状态流转

|当前状态|触发事件|条件|下一状态|失败处理|
|---|---|---|---|---|
|unbound|点击绑定|GOG 官方页可达|authorizing|进入 error，提供重试和返回|
|authorizing|授权成功|回调合法|syncing|授权拒绝或 cancelled 时返回原入口，原状态不变|
|syncing|首次同步成功|账号和基础库数据可用|bound|有旧账号时保留旧账号；无旧账号时回到 unbound 或 error|
|bound|点击更新刷新|未有进行中的刷新|loading 后回到 bound|保留旧数据，显示 error；有缓存时进入 cached 表现|
|bound|点击切换账号|新账号未完成授权和同步|authorizing|cancelled 或 error 时保留旧账号|
|bound|确认退出|用户二次确认|unbound|清理失败时不得伪装退出成功，记录非敏感错误并重试|
|bound|令牌失效|接口返回授权失效|expired|重新登录成功后回到原入口；Steam、EPIC 不变|
|error|点击重试|接口恢复|loading 后进入目标状态|继续保留重试和返回|
|cached|点击重试|存在上次缓存|成功进入 bound 并更新时间|继续展示缓存和时间，不清空可用内容|
|任一登录入口|用户取消|未产生有效新授权|cancelled 后返回原入口|恢复进入前状态和滚动位置|

六类可模拟恢复状态定义：

|状态值|触发条件|页面表现|允许操作|恢复要求|
|---|---|---|---|---|
|loading|正在授权、同步、刷新或拉取列表|骨架或加载提示，提交按钮禁用|返回；不可重复提交|成功进入内容，失败进入 error、expired 或 cached|
|empty|已绑定且接口成功返回 0 个游戏|空数据说明|刷新、返回|有数据后展示列表|
|error|请求失败且没有可用缓存|错误说明|重试、返回|成功后进入目标内容|
|expired|令牌过期或被撤销|重新登录说明|重新登录、返回|成功后回到原入口，不改其他平台|
|cancelled|用户取消官方登录或账号切换|返回原入口|再次绑定或切换|恢复原账号与原页面状态|
|cached|请求失败且有上次可用缓存|缓存内容、缓存时间、重试入口|重试、返回|成功后替换缓存并更新时间|
