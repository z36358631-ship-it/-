## 二、背景与目标

### 2.1 需求背景

盖世游戏已具备暗黑系列 PC 游戏兼容运行能力，需要通过启动弹窗引导用户进入首发适配 H5，完成以下目标：

- 让用户知道盖世具备暗黑系列首发适配能力。
- 让用户看懂 Battle.net 下载、导入、登录、安装和回到盖世启动的完整链路。
- 让用户查看暗黑4、暗黑3的实机视频、推荐配置和图文启动攻略。
- 通过独立运营活动 H5 承接登录、游玩任务、抽奖和奖品履约。

当前用户如果没有清晰的流程说明，容易出现已安装 Battle.net 但不会导入、已下载游戏但不知道回到盖世启动、配置不清楚导致启动失败等问题。

## 三、故事介绍

### 3.1 用户与运营场景

#### 场景一：用户从启动弹窗进入首发适配页

用户打开盖世游戏，看到暗黑系列首发适配弹窗，点击“立即参与”后回到首发适配 H5 首屏，查看宣传 Banner、实机视频和暗黑4/暗黑3游戏卡片。

#### 场景二：用户查看推荐配置

用户选择《暗黑破坏神 IV》或《暗黑破坏神 III》，在“推荐配置”Tab查看对应方案、适用设备、分辨率、帧率、画质和操控建议，并按图文配置指引操作。

#### 场景三：用户查看启动方法

用户进入“启动方法”Tab，按图文步骤完成：

1. 下载 Battle.net 客户端。
2. 回到盖世游戏导入当前游戏。
3. 点击导入并启动 Battle.net。
4. 在 Battle.net 官方客户端登录。
5. 下载自己拥有的游戏。
6. 完成安装。
7. 回到盖世游戏使用配置方案启动。

#### 场景四：用户参加游玩活动

用户在 H5 的“游玩活动”Tab点击活动入口，进入绑定当前游戏的运营活动 H5，完成登录、PC游戏游玩时长和兼容性评价任务，获得抽奖次数并查看奖品。

### 3.2 价值分析

- **首发认知：** 让用户知道盖世是暗黑系列首发适配平台。
- **降低启动失败：** 用 Battle.net完整流程和图文配置说明减少误操作。
- **提升首次游玩：** 将推荐配置和游戏详情入口放在同一内容链路。
- **活动转化：** 通过PC游戏有效游玩任务引导用户进入游戏，而非只完成签到。
- **可复用资产：** H5结构可复用于后续首发适配游戏。

### 3.3 核心体验路径

```text
启动弹窗
→ 暗黑系列首发适配 H5
→ 查看视频/推荐配置/启动方法
→ 进入当前游戏详情
→ 导入 Battle.net
→ 登录、下载、安装游戏
→ 回到盖世使用配置启动
→ 进入对应运营活动 H5
→ 完成任务获得抽奖次数
→ 抽奖、查看奖品、填写地址或查看虚拟权益
```

### 3.4 产品指标预测

以下为上线前需建立基线的指标，不作为当前承诺值：

1. 启动弹窗点击率。
2. 首发 H5 到游戏详情点击率。
3. 启动方法 Tab 查看率和七步内容阅读完成率。
4. 活动 H5 进入率。
5. 玩PC游戏5/30/60/180分钟任务完成率。
6. 兼容性评价任务完成率。
7. 抽奖参与率、奖品到账率和实物地址提交率。
8. 活动用户 D7 再次有效游玩率。

### 3.5 路径规划

- **V1.0：** 完成启动弹窗、首发适配 H5、暗黑4/3内容、Battle.net图文攻略、推荐配置和活动 H5。
- **后续版本：** 根据实际验证结果补充更多暗黑作品和机型数据；若需要，再增加游戏 ID 维度的有效启动统计。

#### 4.3.1 边界条件-内容侧

|场景|触发条件|处理方式|提示文案|

#### 4.3.2 边界条件-用户侧

|场景|触发条件|处理方式|提示文案|
|---|---|---|---|

|弱网加载失败|H5接口超时或返回失败|保留已加载内容，展示重试入口|“加载失败，请重试”|
|实物奖未实名|用户中奖实物奖但未认证|引导实名认证，不改变中奖记录|“完成实名认证后填写收货地址”|
|地址不完整|姓名、电话或地址为空/格式错误|阻止保存，定位第一个错误字段|“请填写完整收货信息”|
|数字时长发放失败|虚拟奖品到账接口失败|保留中奖记录并进入重试状态|“奖励发放中，请稍后查看”|

### 9.2 待确认项

#### 必须确认（阻塞开发）

1. **暗黑4、暗黑3的最终兼容结论和版本。**
    - 默认建议：暗黑4使用当前已验证数据；暗黑3使用已确认的推荐配置数据。
    - 影响：前端内容、测试用例和宣传文案。
    - 正文引用：4.2推荐配置、7运营准备事项。

2. **活动是否仅面向新用户，还是所有用户均可参与。**
    - 默认建议：先按现有后台的“新用户（注册7天内）”配置，老用户只查看首发 H5。
    - 影响：活动资格、任务数据和奖品成本。
    - 正文引用：4.3参与门槛。

3. **奖品库存、权重和兜底奖品。**
    - 默认建议：先配置30/60分钟秒玩时长、小鸡手柄、手机散热器、快充配件和谢谢参与。
    - 影响：运营后台配置、活动规则和发货。
    - 正文引用：4.3奖品配置、7运营准备事项。

4. **“兼容性评价”任务的现有接口口径。**
    - 默认建议：复用现有活动任务接口；如果只能软判断，任务文案不得写成已完成真实兼容测试。
    - 影响：任务有效性和防刷。
    - 正文引用：4.3任务配置、5容错。

    - 影响：视频区完整度。

    - 影响：宣传风险和用户预期。
