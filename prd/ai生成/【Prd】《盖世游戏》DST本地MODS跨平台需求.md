## 二、背景与目标

背景：

- 程序已在 Mac 端完成一版 MOD 功能效果，入口基本确定在游戏详情，但页面结构、交互、状态和跨端规则未经过完整产品设计。
- 创意工坊可作为信息层级参考，但创意工坊使用“订阅”；本期 MOD 来自外部非官方来源，用户执行“下载、安装和本机管理”，两者不能合并。
- 本期同时定义并更新 Mac 与 APP 端。APP 支持竖屏、横屏以及运行中切换，两端 Demo 与本 PRD 使用同一业务规则。

目标：

- 为适配验证通过的游戏建立从“游戏详情发现 → 浏览 → 查看详情 → 安装 → 本机管理”的 MOD 完整路径。
- 让 Mac 与 APP 使用同一业务规则，并明确两端布局差异、APP 横竖屏切换和设备级安装边界。
- 国内包与海外包共用 MOD 能力；海外使用 `GameHub` 和现有多语言能力，不依赖海外不存在的云游戏。

核心边界：

- 本期仅做 C 端，不输出 B 端章节。
- 外部内容由既有来源同步，来源安全性暂按现有方案处理，本期不新增上传、审核和安全运营后台。
- 安装跟随设备。同一账号在其他设备登录后，需要在该设备重新安装。
- 本期不展示启动检查、启动恢复或异常退出恢复页面，不改造游戏启动流程。
- 本期不改造创意工坊，只参考其页面信息层级。

## 三、故事介绍

### 3.1 用户场景

- Mac 用户在适配验证通过的游戏详情看到独立的“MOD”区域，直接浏览最多 3 个热门 MOD；点击热门卡片查看详情，或点击“查看全部”进入 MOD 浏览页。
- 用户在浏览页通过搜索和排序找到目标 MOD，点击整张卡片进入详情；未安装项可在卡片右下角安装，已安装项可直接切换当前设备的启用状态。
- 用户进入“已安装”，通过“全部、可更新”找到需要管理的 MOD，可直接切换启用状态，也可进入详情更新或删除。
- APP 用户从游戏详情“更多”进入 MOD，在竖屏和横屏之间切换时继续查看同一页签、同一 MOD 和同一任务，不重复下载或安装。
- 海外用户在 `GameHub` 使用同一 MOD 能力，界面跟随海外包现有语言设置；页面不出现云游戏入口或云游戏依赖。

### 3.2 价值分析

- 发现效率：游戏详情直接露出 3 个热门内容，减少从详情到目标 MOD 的路径。
- 使用效率：浏览、详情、安装和管理形成连续路径，卡片信息收敛到判断所需字段。
- 状态可信：持续展示“仅此设备”，避免用户把 Mac、手机和平板的安装状态误认为账号同步。
- 跨端一致：Mac 与 APP 使用同一业务状态；APP 横竖屏仅改变布局，不改变数据和任务。
- 业务隔离：MOD 使用下载和安装语义，创意工坊保持订阅语义，避免用户混淆来源和结果。

### 3.3 核心体验路径

- Mac 热门路径：游戏详情 → MOD 热门卡片 → MOD 详情 → 安装到此设备。
- Mac 全量路径：游戏详情 → 查看全部 → 浏览 → 搜索或排序 → 点击卡片 → MOD 详情 → 安装。
- Mac 管理路径：MOD → 已安装 → 全部或可更新 → 点击卡片 → 启用、停用、更新或删除。
- APP 路径：游戏详情 → 更多 → MOD → 浏览或已安装 → MOD 详情 → 安装或管理。
- APP 旋转路径：竖屏页面 → 旋转为横屏 → 保留页面与任务 → 继续操作；横屏转竖屏同理。

### 3.4 产品指标预测

|指标|首期目标|统计口径|
|---|---|---|
|游戏详情 MOD 区点击率|建立基线，灰度期持续观察|点击热门 MOD 或“查看全部”的设备数 / MOD 区曝光设备数|
|详情到安装点击转化率|不低于 20%|点击安装的唯一设备与 MOD 组合 / 详情曝光的唯一设备与 MOD 组合|
|安装成功率|不低于 95%|安装成功任务数 / 创建成功的安装任务数|
|重复任务数|0|同一设备、游戏、MOD 同时存在的重复活动任务数|
|APP 旋转任务连续率|100%|旋转后仍复用原任务的次数 / 有活动任务时旋转次数|
|跨设备状态误写事件|0|本机状态被其他设备安装记录覆盖的确认事件数|

### 3.5 路径规划

- V1.7：完成 Mac 与 APP 双端高保真 Demo；支持发现、浏览、详情、安装、更新、启停、删除、依赖补装和设备级状态。
- 后续版本：根据灰度数据评估更多游戏接入、内容推荐和运营配置，不在本期预留空入口。

本期非目标：

- 创意工坊订阅、取消订阅和官方内容管理。
- MOD 上传、发布、评论、评分和用户创作工具。
- 账号级安装同步、跨设备自动安装和跨设备启用值同步。
- 启动检查、启动确认、异常退出恢复和游戏内 MOD 管理。
- 海外云游戏能力。

## 四、概要设计

### 4.1 模块设计

|模块|Mac|APP 竖屏|APP 横屏|
|---|---|---|---|
|游戏详情入口|独立 MOD 区，最多露出 3 个热门组件、总量和查看全部|游戏详情“更多”菜单中的 MOD 入口|与竖屏入口一致|
|浏览页|两列卡片；未安装只显示安装，已安装只显示启停|单列卡片；操作与 Mac 一致|两列卡片；操作与竖屏一致|
|已安装页|两列卡片；筛选仅“全部、可更新”；不提供搜索和排序|单列卡片；筛选仅“全部、可更新”；不提供搜索|两列卡片；规则与竖屏一致|
|MOD 详情|居中弹窗；已安装固定删除、更新、启停|近全屏底部弹层；固定三项操作|居中宽弹窗；固定三项操作|
|安装与更新|进度显示在操作按钮内|进度显示在操作按钮内|旋转后复用同一任务|
|安装失败|缺依赖时弹出组件安装弹窗|与 Mac 统一|与竖屏统一|
|删除|二次确认弹窗|二次确认弹窗|二次确认弹窗|

#### 4.2.1 列表、搜索与分页

- 浏览列表使用分页或滚动追加；已加载内容继续保留。
- <mark><strong><span style="color:#3370ff">搜索只匹配当前客户端已经加载的分页数据</span></strong></mark>，不会为搜索主动请求未加载页；搜索无结果代表“当前已加载内容无匹配”，不得写成全量目录无结果。
- 排序与搜索同时生效；切换排序回到顶部。返回列表保留已加载数据、筛选、搜索和滚动位置。
- 首次加载显示占位；追加失败保留已有卡片并提供重试；数据结束显示“没有更多了”。
- 浏览目录为空、当前设备未安装、筛选无结果、搜索无结果使用不同空态。

#### 4.2.2 状态与操作矩阵

|安装状态|列表操作|详情操作|更新表现|启停反馈|
|---|---|---|---|---|
|未安装|安装|安装|不显示|不适用|
|安装中|安装按钮内显示进度|安装按钮内显示进度|不显示|不适用|
|已安装、已是最新|启用/停用|删除、已是最新、启用/停用|按钮不可点击|成功静默切换|
|已安装、有更新|启用/停用，卡片红点|删除、可更新、启用/停用|点击后按钮内显示更新进度|成功静默切换|
|更新失败、旧版可用|启用/停用，卡片红点|删除、重试更新、启用/停用|保留旧版和原启用值|成功静默切换|
|安装失败、缺依赖|安装或重试|安装或重试|弹出依赖组件弹窗|不适用|

#### 4.2.3 安装与更新任务

1. 同一设备、游戏、MOD 同时只能有一个活动安装或更新任务。
2. 状态为：等待下载 → 下载中 → 正在校验 → 正在安装/更新 → 成功；任一阶段可失败。
3. 进度显示在当前操作按钮内；进行中禁止重复点击。
4. 安装成功写入当前设备安装事实并默认启用；更新成功保留更新前启用值。
5. 更新失败不切换新版本，旧版和启用值不变。
6. 本期不支持断点续传；下载中断后重新开始下载，不保留已下载字节。
7. 页面返回、APP 旋转和前后台切换不得创建第二个任务；进程重启读取本机任务记录，无法确认完整性的临时文件先清理。

#### 4.2.4 设备级边界

- 安装文件、已安装状态和启用值按设备隔离。
- 同一账号更换设备后，新设备不继承旧设备安装文件或启用值。
- 服务端可同步目录、说明、版本和来源状态，不把某一设备安装事实覆盖到其他设备。

#### 4.2.5 MOD 与创意工坊隔离

- 创意工坊使用“订阅/取消订阅”，MOD 使用“下载/安装/启用/停用/删除”。
- 两者目录、状态、任务和埋点分别统计。
- MOD 不伪装为官方 DLC，不显示订阅量或订阅按钮。

#### 4.2.6 国内与海外

- 国内包与海外包功能一致。
- 国内产品名为“盖世游戏”；海外产品名只能使用 GameHub。
- 海外包跟随现有多语言能力，不依赖云游戏、实名认证或国内登录方式。
- 来源动态内容有当前语言译文时显示译文；无译文时显示来源原文，客户端不自动翻译。

#### 4.2.7 支持游戏准入

- 理论可获取数据不等于已支持。
- 游戏必须完成对应安装方式、依赖、启停、删除和启动生效验证，且当前端存在可安装数据，才显示 MOD 入口。
- 首批游戏由产品、运营和测试按热门 MOD 需求选择；未通过验证的游戏不进入总量、推荐、浏览和搜索。
- 每增加一款游戏，必须执行该游戏完整安装与启动生效用例。

## 七、运营需求

1. 首批内容准备
    - 准备 20–50 个唯一 DST MOD，不按双端包重复计数。进入首批灰度池的每个 MOD 必须同时通过 Mac 与 APP 准入，因此两端各自可安装内容数均为 20–50 个。
    - 缺少任一端可用包的 MOD 可保留在候选池，但不得进入本期总量、热门、浏览和搜索结果。
    - 每个 MOD 至少包含名称、作者、封面、短简介、完整说明、版本、文件大小、发布时间、下载量、近 24 小时下载激增百分比、兼容性、依赖和更新说明；兼容性和最新版本仅用于安装、更新判断，<mark><strong><span style="color:#3370ff">不在 Mac 详情展示</span></strong></mark>。
    - 游戏详情热门区按近 24 小时下载激增百分比选择前 3 个，不单独维护另一套内容。
2. 多语言准备
    - 海外包固定文案、状态、错误、弹窗和空状态完成中文、英语、日语、俄语、巴西葡萄牙语翻译。
    - <mark><strong><span style="color:#3370ff">本轮新增状态文案“已启用”“已停用”必须进入海外包中文、英语、日语、俄语、巴西葡萄牙语资源；不得把列表“未启用”直接复用于详情“已停用”。上线验收需逐一切换五种语言检查两种状态，缺少任一资源时阻断发布。</span></strong></mark>
    - 产品名称统一使用 `GameHub`。
3. 上线前检查
    - 核对近 24 小时下载激增百分比、下载量和发布时间的外部同步口径。
    - 核对来源失效时的下架规则：停止新曝光、新安装和更新，不远程卸载用户本机版本。
    - 核对国内官方包、代表渠道包、`Global`、`GooglePlay` 的页面和安装结果。
4. 数据观察
    - 建立入口曝光、热门点击、查看全部、详情、安装、安装结果、更新结果和删除结果漏斗。
    - 单独监控重复任务、跨设备状态误写、APP 旋转后任务丢失和更新失败后旧版不可用。

- 下架只停止目录曝光、新安装和更新，不远程卸载，不删除本机已安装版本，不修改用户启用值。

### 11.2 缺少依赖的安装失败处理

1. <mark><strong><span style="color:#3370ff">触发条件：</span></strong>用户已经开始安装原 MOD，客户端取得清单后因缺少依赖组件失败；网络、空间、校验或写入失败不进入依赖弹窗。修改日期：2026.08.06。</mark>
2. <mark><strong><span style="color:#3370ff">弹窗信息：</span></strong>显示失败原因、原 MOD 名称、本机可用空间、依赖总大小，以及每项依赖的名称、大小、状态和安装按钮。修改日期：2026.08.06。</mark>
3. <mark><strong><span style="color:#3370ff">逐项安装：</span></strong>用户逐项点击安装；进度显示在依赖按钮内；安装中不可重复触发；完成项显示已安装；本机可用空间按成功安装的依赖大小扣减。修改日期：2026.08.06。</mark>
4. <mark><strong><span style="color:#3370ff">空间不足：</span></strong>可用空间小于依赖大小时不创建任务，显示“本机可用空间不足”；空间满足后允许重新安装该依赖。修改日期：2026.08.06。</mark>
5. <mark><strong><span style="color:#3370ff">继续安装：</span></strong>全部依赖完成前“继续安装”不可用；全部完成后仍不得自动重试，由用户主动点击，原 MOD 从 0 重新安装。修改日期：2026.08.06。</mark>
6. <mark><strong><span style="color:#3370ff">关闭弹窗：</span></strong>原 MOD 保持未安装；已成功依赖保留为本机事实，未完成项不得伪造成功。修改日期：2026.08.06。</mark>
