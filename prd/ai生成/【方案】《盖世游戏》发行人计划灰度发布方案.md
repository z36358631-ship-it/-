## 1. 账号、UID与国内／海外分别灰度

账号是登录身份，UID是该账号在服务端的唯一标识，系统使用UID稳定选择开放用户，不按设备ID选择。同一账号国内海外共用同一UID，换设备不换UID；切换账号按新UID判断。

国内／海外不是从UID数字或手机号、邮箱猜出的身份：按照账号最近一次登录包体识别国内包与海外包，仅成功登录更新最近登录包体；普通冷启动或业务请求不改写登录事实，仅结合当前包体和App版本匹配访问规则。跨包登录重新判断，不能沿用另一包体缓存；本期海外包请求始终不开放发行人计划。

| 配置维度 | 规则 |
|---|---|
| 功能 | 灰度列表内分别配置各功能，本期为发行人计划 |
| 包体 | 国内、海外分别配置开关和比例，各自按本包体UID人群选取 |
| App版本 | 不同版本可分别开放或关闭，不能用“配置版本号”代替App版本控制 |
| 账号UID | 在上述适用范围中稳定选人，20%用户包含在50%中，关闭重开不换人 |

**独立比例示例：** 国内20%、海外20%，指国内UID人群中选20%、海外UID人群中另选20%；国内50%、海外20%，分别按自己的比例执行。不能从全体账号先取20%，再让国内海外分享名额。通用能力支持两边分别配置，**发行人计划本期仅国内开放，海外关闭**。

候选人群按同一统计快照的最近登录包体和适用版本归属，同UID不重复计入两个候选分母。研发提供选取算法、分布与边界测试方法；0～9999只是旧参考，不是必须实现的桶数。内部测试白名单沿用既有规则并从正式统计排除，不能绕过总开关或包体范围。

## 2. 谁能看到入口

| 当前范围状态 | 登录／命中 | 页面表现 |
|---|---|---|
| 国内、适用版本、开启20%或50% | 未登录 | 隐藏所有发行人计划入口 |
| 国内、适用版本、开启20%或50% | UID命中 | 入口可见，可进入；业务操作仍校验实名、认证、余额等各自条件 |
| 国内、适用版本、开启20%或50% | UID未命中 | 入口隐藏，旧链接不得绕过 |
| 国内、适用版本、开启100% | 全部用户，包括未登录 | 入口可见；[推导]游客点击沿用现有登录流程，不新增匿名个人数据或交易能力 |
| 总开关关闭 | 包括已命中、有任务或余额者 | 客户端下次成功取得关闭结果后隐藏所有发行人计划入口，无存量入口豁免 |
| 海外或版本不适用 | 任意 | 不展示发行人计划入口 |

个人中心卡片、创作者中心内的发行人计划入口及其他已有直达入口统一控制。创作者中心主入口、认证与专属标签、任务中心主入口保持各自规则；海外创作者中心不会因发行人关闭一起消失。

## 3. 只扩量，或直接关闭

本轮按20%→50%→100%逐步开放，不支持50%→20%、100%→50%等缩量；前后台均拦截降档。关闭保留原比例与命中用户，重新开启沿用原档，不能借关闭重开降档或洗牌。

新App版本建立独立规则，不覆盖旧版本；同一功能、包体、版本不能命中冲突规则。后台保存成功生成新配置版本，记录前后值、操作人、时间及结果；保存失败或并发旧版本不覆盖现有有效配置。

严重故障、权限绕过、资金或奖励错误时关闭对应范围；观察无严重问题后由运营人工扩量。原稿24/48/72小时、固定技术样本和成功率门槛不作为本次会议确认标准。

## 4. 冷启动与失败缓存

每次冷启动拉取配置，不要求每次回前台或切页请求，也不要求后台关闭后实时推送撤去所有在线入口。请求失败、超时或返回不可用数据时沿用相同账号状态、包体与版本的最近成功结果；无有效缓存默认隐藏。成功取得关闭结果后必须覆盖旧开启缓存。

登录、退出、切号、切包或版本变化后重新判断，不能串用其他身份／范围缓存；退出清除个人任务和钱包数据。20%、50%退出后入口隐藏，100%可保留通用入口但不显示原账号数据。

缓存只用于客户端入口展示；服务端仍按当前有效配置执行请求终审。旧页面仍可见时，关闭后的请求不能据此建立新的业务记录。

## 5. 关闭与存量（已确认）

会议确认总开关关闭时所有入口隐藏；用户在本轮补充确认以下前台操作与后台履约边界：

- 不删除任务、参与、投稿、预算、余额和订单，不清空用户资产。
- 前台暂停继续投稿、追加预算、充值、新兑换等操作，未受理请求不生成记录、不冻结预算、不扣币。
- 已受理机审、取数、人工结算、确认发奖、兑换发卡／退款及外部回调继续按原业务规则和幂等要求完成。
- 风险任务仍由运营普通下架或风险下架；总开关不自动取消订单。长期关闭的待办与用户服务由既有客服承接。

以上规则仅暂停前台操作，不取消既有权益。重新开启并准入通过后恢复历史记录与余额展示。

## 6. 验证与数据口径

1. 账号与UID映射、同账号换设备、切换账号、跨包登录、退出登录与版本变化。
2. 国内／海外独立比例、独立候选分母及规则，本期海外发行人关闭；不同App版本互不覆盖。
3. UID选择稳定、扩量包含原人群、关闭原档重开仍同批；降档和规则冲突保存失败。
4. 20%、50%游客隐藏与100%游客可见，所有发行人入口一致，创作者／任务中心主入口不受连带影响。
5. 冷启动成功、失败沿用缓存、无缓存隐藏、有效关闭替换旧开启，以及迟到响应不覆盖新账号状态。
6. 残留入口、功能直达、接口直调不能绕过服务端；已受理事务不能因入口关闭丢失或重复。

UID命中比例按包体、App版本规则、轮次和配置版本单独统计；100%游客入口仅单列曝光／点击次数，不伪造UID，不混入登录比例和转化。具体事件与参数统一维护在主PRD第四章。双包同时登录的归属与统计快照、App版本录入方式，见主PRD第五章待确认项。
