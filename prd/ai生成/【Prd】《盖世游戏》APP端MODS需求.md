## 二、背景与目标

### 2.1 背景

Mac 端已有 MOD 功能，APP 端尚无完整方案。APP 现有创意工坊采用官方订阅模式；MODS 内容来自外部同步，采用下载、安装和本机管理。两套业务需独立。

### 2.2 目标

- 在游戏详情和 Steam 个人中心增加独立 MODS 入口。
- 支持浏览、搜索、排序、下载安装、启停、更新和卸载。
- 支持竖屏、横屏和运行中旋转，旋转不丢失页面和前台任务状态。
- 安装文件、安装状态和启用值仅属于当前设备。

### 2.3 范围

|类型|内容|
|---|---|
|本期|APP C 端；游戏详情入口；Steam 个人中心 MODS；浏览、已安装、详情；下载安装、启停、更新、卸载；横竖屏；国内包和海外包|
|不做|改造创意工坊；启动检查；冲突检查；断点续传；异常退出恢复；跨设备同步；新增 B 端|
|前提|目录、文案、图片和文件沿用外部同步链路；外部内容已完成安全处理|

## 三、使用场景

### 3.1 核心路径

1. 游戏详情 → 更多 → MODS → 浏览或已安装。
2. 浏览 → 搜索或排序 → MOD 详情 → 下载安装。
3. 已安装或个人中心 MODS → 直接更新、卸载或切换启停开关，也可进入详情执行同样操作。
4. Steam 个人中心 → MODS → 按游戏查看当前设备已安装 MOD → 查看全部 → 对应游戏 `MODS > 浏览`。
5. 任一 MODS 页面旋转设备 → 保留页面、条件、位置和任务。

### 3.2 指标

|指标|目标|口径|
|---|---|---|
|入口成功率|≥99.9%|成功进入 MODS 次数/入口点击次数|
|安装成功率|≥95%|安装成功任务数/安装任务数，主动取消不计失败|
|启停成功率|≥99.5%|写入成功次数/启停次数|
|重复任务率|0|同设备、同游戏、同 MOD 同时出现两条安装或更新任务的次数/任务请求次数|
|旋转状态丢失率|0|旋转后关键状态丢失次数/旋转次数|
|无崩溃会话率|≥99.8%|进入 MODS 且未发生相关崩溃的会话数/进入 MODS 的会话数|

国内包和海外包分别统计。每个包体的安装、启停均达到 200 次后，指标才用于放量判断。

#### 4.2.9 创意工坊隔离

|维度|MODS|创意工坊|
|---|---|---|
|内容来源|外部同步|官方接入|
|用户动作|下载、安装、启停、更新、卸载|订阅、取消订阅|
|设备状态|仅当前设备|沿用现有规则|
|本期处理|实现本需求|不改造|

MODS 页面不得出现“订阅”“取消订阅”“我的订阅”。两套业务不得互改状态。

两套业务使用独立 ID 命名空间、安装目录、任务和状态存储；同名内容不得互相覆盖。

#### 4.2.10 浏览、搜索和卡片

##### 搜索与排序

- 仅浏览页显示搜索；按 MOD 名称和作者模糊匹配。
- 最多 50 个字符；输入后 300ms 搜索，清空后恢复当前排序。
- 竖屏搜索独占一行；横屏与排序、刷新同一行。
- 横屏空间不足时先压缩搜索框；达到最小可用宽度后，排序区横向滚动，刷新始终可见。

|排序|第一排序|第二排序|第三排序|
|---|---|---|---|
|热门|近 24 小时下载增幅降序|发布时间倒序|MOD ID 升序|
|下载最多|累计下载量降序|发布时间倒序|MOD ID 升序|
|最新发布|发布时间倒序|累计下载量降序|MOD ID 升序|

默认“热门”。切换排序后保留搜索词，重新请求首批数据并回到顶部。

##### 列表与卡片

- 每批 20 条，滚动追加；不显示总页数。
- 返回列表时恢复 Tab、条件和滚动位置。
- 首次加载显示骨架；追加加载保留已有内容。
- 标题最多两行，作者最多一行；超出截断。
- 列表卡片不展示简介，简介仅在 MOD 详情展示。
- 下载量 10,000 起用“万”缩写，最多一位小数；文件大小统一用 KB、MB、GB。
- 图片失败显示占位图，不影响详情和操作。
- 同一 MOD 操作中禁用重复操作；其他 MOD 可继续操作。

#### 4.2.11 已安装与个人中心

- 安装状态、启用值和任务均以当前设备为准。
- 已安装页“全部 / 可更新”使用子 Tab；“全部”显示当前设备全部已安装 MOD，“可更新”仅显示已确认有更新的 MOD。
- 已安装页不读取浏览搜索词；切换 Tab 不清空浏览搜索词。
- 已安装列表、Steam 个人中心和 MOD 详情统一显示“更新 / 卸载 / 启停开关”；两个按钮和一个开关，三个操作位等宽铺满，启停开关固定在最右侧。
- 三项操作不触发卡片详情；点击卡片其他区域进入详情。
- 启停成功后直接切换开关，不显示成功 Toast；失败时恢复原值并提示重试。
- 个人中心按游戏分组，只显示有已安装 MOD 的游戏；安装、卸载或归属变化后同步数量和卡片。
- 个人中心与游戏详情共用安装清单、启用值、MOD 信息和任务，不维护第二套状态。
- 个人中心空态“查看支持 MODS 的游戏”进入现有游戏库的 MODS 支持列表；加载失败留在空态并可重试。

#### 4.2.12 详情与设备任务

已安装状态下，详情底部与卡片使用同一套操作：

`更新 | 卸载 | 启停开关`

- 有更新时仅在“更新”按钮内显示红点；不显示黄色圆点。
- 无更新或状态未知时，“更新”禁用且不显示红点。
- 更新完成后清除红点并禁用按钮；失败且新版本仍可用时，恢复按钮和红点。
- 卸载按钮绑定当前 MOD 打开统一确认弹窗；取消不改状态，确认后三处同步移除。

|当前状态|操作|结果|失败处理|
|---|---|---|---|
|未安装|下载安装|下载 → 校验 → 安装 → 已安装且启用|保留失败原因，可重试|
|已启用|停用|已停用|恢复启用|
|已停用|启用|已启用|恢复停用|
|已安装|更新|安装新版本并保留原启用值|保留旧版和原启用值|
|已安装|确认卸载|未安装|保留原文件和状态|

- 设备层按“设备 + 游戏 + MOD”持有唯一操作状态：空闲、安装中、更新中、启用中、停用中、卸载中。
- 同一设备、同一游戏、同一 MOD 同时只能有一条操作。
- 操作后立即禁用当前 MOD 的冲突操作；重复输入不再提交。
- 冲突操作提示“当前 MOD 正在处理，请稍后再试”。
- 不同 MOD 可并行处理。
- 本期不支持断点续传。下载和更新仅在 APP 前台执行；切页或旋转不中断任务，也不创建重复任务。
- 断网、进入后台或进程退出后中断，清理临时进度；返回后不自动恢复，重试时从 0 创建新任务。
- 更新中断保留旧版本和原启用状态。

卸载弹窗：

|类型|内容|
|---|---|
|标题|卸载“{MOD名称}”？|
|内容|将删除当前设备中的安装文件和启用状态，不影响其他设备和游戏存档。|
|按钮|取消 / 确认卸载|

#### 4.2.13 横竖屏切换

旋转时保留：

- 当前页面、Tab、搜索词、排序和筛选。
- 当前 MOD、列表位置和详情阅读位置。
- 任务 ID、阶段和进度。
- 安装状态、启用值和卸载确认。

旋转只重排布局，不重新请求首批数据，不重复创建任务。

#### 4.2.14 国内与海外

- **国内包显示“盖世游戏”，使用中文界面。**
- **海外包显示“GameHub”，沿用海外包多语言能力，不得使用“GaishiGame”。**
- **国内包和海外包均提供完整 MODS 能力，不依赖云游戏、实名认证或登录。**
- 未登录用户可浏览和管理当前设备 MOD；登录过期不取消设备任务。
- 来源内容无当前语言译文时显示原文。
- 目录按包体区域返回内容；区域下架后不再显示和更新，已安装文件仍可启停和卸载。

#### 4.2.15 页面状态与异常

|场景|页面反馈|操作|
|---|---|---|
|首次加载|卡片骨架|返回、切换已安装|
|首次加载失败|加载失败|重试、返回|
|追加失败|保留已有内容，显示重新加载|重试、使用已有内容|
|目录为空|暂时没有可用 MOD|刷新、切换已安装|
|搜索无结果|没有找到相关 MOD|清空搜索|
|已安装为空|当前设备尚未安装 MOD|去浏览|
|可更新为空|暂无可更新的 MOD|查看全部|
|个人中心为空|当前设备暂未安装 MOD|查看支持 MODS 的游戏|
|设备读取失败|暂时无法读取当前设备的 MOD|重试|
|个人中心目标游戏不可用|暂时无法打开该游戏的 MODS|保留原分组和位置，可重试|
|图片失败|显示占位图|详情和操作不受影响|
|下载或更新时断网|任务中断，清理临时进度|重试时从 0 开始|
|下载或更新时进入后台|任务中断，清理临时进度|返回后不自动恢复|
|更新中断|保留旧版本和原启用状态|可从 0 重试|

## 七、运营要求

1. 上线前准备不少于 20 条《饥荒》MOD，包含 MOD ID、区域、授权记录、封面、名称、作者、简介、安装说明、更新记录、下载量和文件大小。
2. 首批目录在上线前 2 个工作日冻结；冻结后只处理阻断问题和紧急下架。
3. 目录至少每小时同步一次；连续两次失败需告警，并保留最近一次成功目录。
4. 海外包需验收固定文案和支持语言；来源内容无译文时显示原文。
5. MODS 入口支持按包体、版本和灰度人群关闭；单条 MOD 支持按区域隐藏。

## 八、灰度与回退

### 8.1 灰度

国内包和海外包分别按 1% → 10% → 30% → 100% 放量。每档至少观察 24 小时；样本不足 200 次时继续观察，最长 7 天后由产品负责人决定维持、放量或终止。

|类型|条件|处理|
|---|---|---|
|放量|安装成功率≥95%；启停成功率≥99.5%；重复任务率=0；旋转状态丢失率=0；无崩溃会话率≥99.8%|进入下一档|
|暂停|滚动 2 小时且安装≥50 次时，安装成功率<90%或无崩溃会话率<99.5%；或出现重复任务、区域越界|停止当前包体放量|
|回退|暂停 2 小时未恢复；出现批量文件损坏、连续崩溃或区域内容无法单条隐藏|关闭对应包体入口|

### 8.2 回退

- 关闭入口后不删除已安装文件。
- 已开始的下载或更新任务允许完成；关闭入口后不再创建新任务。
- 不修改创意工坊状态。
