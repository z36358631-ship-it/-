## 一、文档概述

### 1.1 背景

- **目标用户：** Android 端游戏库内有至少 2 款可玩游戏，但暂时不知道玩什么的用户。
- **当前解决方式：** 用户逐款浏览个人库、Steam 库和导入游戏，再进入详情获取或启动。
- **问题：** 游戏多时，选择和比较耗时；随机到不兼容或无法启动的游戏会增加失败成本。
- **目标：** 降低选择成本，提高游戏启动率和有效游玩率。

### 1.2 范围

| 类型 | 说明 |
|---|---|
| 本期包含 | Android 国内版和海外版；竖屏和掌机横屏；游戏库首位盲盒卡；候选过滤、去重、加权随机、同轮不重复、结果校验；查看详情、再抽一次、关闭；五种语言和数据归因。 |
| 本期不含 | Mac、Web、iOS、B 端；首页入口；直接启动、下载或 Steam 登录引导；次数、任务、奖励、活动、后台、灰度和新的游戏获取或启动流程。 |

### 1.3 术语

| 术语 | 说明 |
|---|---|
| 有效推荐池 | 合并候选并按 `game_id` 去重后，排除待验证、不兼容、下架、维护中、链路失效和无法确认可玩的游戏。 |
| 可直接游玩 | 当前设备已有可用的秒玩、Steam 或导入启动链路，无需先下载游戏包。 |
| 未下载 Steam 游戏 | Steam 已登录、游戏已适配，但当前设备未下载游戏包；命中后进入现有详情页获取。 |
| 抽取会话 | 打开盲盒弹窗至关闭的过程；“再抽一次”不新建会话。 |
| 有效游玩 | 结果展示后 24 小时内，用户从该结果进入详情，启动同一游戏，且单次实际游玩达到 5 分钟。 |
| `game_id` | 同一游戏跨个人库、Steam、秒玩和导入来源的统一标识。 |

## 二、产品说明

### 2.1 方案

游戏盲盒位于“我的游戏”首位。用户点击后，在当前页弹窗内随机命中 1 款可玩游戏，可查看详情、再抽一次或关闭。

### 2.2 产品流程

![产品流程](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@f8325b47129e1cfd1f9186e217979e22729e438d/public/prd/game-blind-box/05-product-flow.png)

流程止于现有游戏详情页。获取、下载和启动沿用现有流程。

## 三、功能需求

### 3.1 业务规则

| 编号 | 规则 |
|---|---|
| R1 入口 | 有效推荐池不少于 2 款时，盲盒卡固定在“我的游戏”第一位，不计入游戏数；少于 2 款或数量获取失败时隐藏，真实游戏补回第一位。 |
| R2 候选 | 候选来自盖世个人库；Steam 已登录且库同步成功时，再加入已适配的 Steam 库游戏，包含未下载游戏。Steam 未登录或同步失败时只用个人库，不弹登录引导。同一游戏跨来源按 `game_id` 只保留 1 款。 |
| R3 权重 | 可直接游玩且从未启动或超过 30 天未启动：权重 2；30 天内启动过：权重 1；未下载 Steam 游戏：权重 1，不加“从未启动”权重。存在可直接游玩游戏时，未下载游戏初始总概率超过 30%则封顶 30%，其余候选按权重重算；未超过则不调。候选全未下载时不设上限。 |
| R4 抽取与成功结果 | 点击入口前、结果展示前各校验一次候选。每次命中 1 款；同一抽取会话内，所有候选命中过一轮前不重复，全部命中后清空本轮记录。抽取中只更新封面、名称、评分和最多 2 个类型标签；页面、遮罩、弹窗和按钮不重建。 |
| R5 结果 | 结果固定显示“查看详情”“再抽一次”。不显示直接启动、下载、安装状态、抽取序号或“已命中”。“查看详情”进入现有详情；“再抽一次”在原弹窗继续；关闭后恢复原平台、筛选、滚动或焦点并结束会话。详情返回时恢复上次结果和同轮记录，不自动重抽。 |
| R6 异常 | 候选失效时移出并继续抽取。候选请求失败、结果校验失败或无剩余候选时，原弹窗显示“暂时无法抽取”“网络异常，请稍后再试”；“查看详情”禁用，“再抽一次”用于重试。再次失败时保留失败态；关闭后返回游戏库。不得用缓存或失效结果。单张封面失败时保留其余封面和暗色底图；评分缺失显示“暂无评分”。 |
| R7 端与语言 | 竖屏用触控；掌机横屏用焦点和 A 键确认、B 键关闭。两种方向共用候选和状态规则，但使用各自布局，不旋转或拉伸复用。国内版和海外版业务一致；新增文案覆盖简中、英语、俄语、日语和巴西葡萄牙语。 |

## 四、支撑需求

### 4.1 指标

| 指标 | 口径 | 去重与窗口 |
|---|---|---|
| 24 小时启动转化率 | 结果展示后 24 小时内，从结果进入详情并成功启动同一游戏的用户数 ÷ 获得有效结果的用户数 | 用户按自然日去重；每次结果独立计算 24 小时 |
| 24 小时有效游玩率 | 结果展示后 24 小时内，从结果进入详情、成功启动同一游戏且单次游玩达到 5 分钟的用户数 ÷ 获得有效结果的用户数 | 用户按自然日去重；同日多次达标只计 1 人 |
| 查看详情率 | “查看详情”点击次数 ÷ 有效结果展示次数 | 按 `draw_session_id + draw_index` 去重 |
| 再抽一次率 | “再抽一次”点击次数 ÷ 有效结果展示次数 | 按 `draw_session_id + draw_index` 去重 |

### 4.2 埋点事件

| 事件 | 类型 | 触发时机 | 参数 |
|---|---|---|---|
| `game_blind_box_entry_expose` | 新增 | 盲盒卡进入可见区；同一游戏库页面会话只报首次 | `orientation, locale, eligible_pool_size, steam_login_state` |
| `game_blind_box_entry_click` | 新增 | 点击或 A 键确认入口，并生成抽取会话 | `orientation, locale, eligible_pool_size, steam_login_state, draw_session_id` |
| `game_blind_box_result_expose` | 新增 | 结果校验通过并停止随机；每个结果只报 1 次 | `orientation, locale, draw_session_id, draw_index, game_id, result_state, weight_class, pool_size, steam_login_state` |
| `game_blind_box_action_click` | 新增 | 结果态点击“查看详情”“再抽一次”或关闭 | `orientation, locale, draw_session_id, draw_index, game_id, result_state, action` |
| `game_launch_result` | 改造已有 | 详情页启动成功、失败或取消；成功口径不变 | `game_id, launch_result, launch_source, draw_session_id, draw_index, failure_reason` |
| `game_blind_box_effective_play` | 新增 | 归因游戏单次游玩首次达到 5 分钟；每个结果只报 1 次 | `game_id, draw_session_id, draw_index, play_duration_bucket` |
| 已有游戏会话时长事件 | 复用 | 沿用现有上报时机，不重复上报 | `game_id, actual_play_duration_seconds` |

### 4.3 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `orientation` | enum | 是 | `portrait` 竖屏；`landscape` 横屏 |
| `locale` | enum | 是 | `zh-CN` 简中；`en-US` 英语；`ru-RU` 俄语；`ja-JP` 日语；`pt-BR` 巴西葡萄牙语 |
| `eligible_pool_size` | integer | 是 | 进入页面时的有效候选数 |
| `steam_login_state` | enum | 是 | `logged_in` 已登录且库可读；`logged_out` 未登录；`sync_failed` 同步失败 |
| `draw_session_id` | string | 是 | 每次打开弹窗生成的会话标识 |
| `draw_index` | integer | 是 | 会话内有效结果序号，从 1 开始 |
| `game_id` | string | 是 | 统一游戏标识 |
| `result_state` | enum | 是 | `ready` 可直接游玩；`uninstalled` 未下载 |
| `weight_class` | enum | 是 | `recent_1x` 30 天内玩过；`inactive_2x` 超过 30 天未玩；`never_2x` 可直接游玩且从未启动；`uninstalled_1x` 未下载 |
| `pool_size` | integer | 是 | 本次抽取的有效候选数 |
| `action` | enum | 是 | `details` 查看详情；`redraw` 再抽一次；`close` 关闭 |
| `launch_result` | enum | 是 | `success` 成功；`failed` 失败；`cancelled` 取消 |
| `launch_source` | enum | 是 | `blind_box_details` 从盲盒结果进入详情；其他值沿用现有定义 |
| `failure_reason` | enum | 否 | 沿用现有失败枚举；成功或取消时为空 |
| `play_duration_bucket` | enum | 是 | `5m` 首次达到 5 分钟 |
| `actual_play_duration_seconds` | integer | 是 | 实际游玩秒数 |

### 4.4 技术、运营与版权

| 类型 | 要求 |
|---|---|
| 动画 | 正常模式约每 100ms 切换 1 款，总时长约 1.2 秒，命中收束约 190ms；系统开启“减少动态效果”时约 180ms 直接命中。只允许封面、名称、评分和标签变化，弹窗及按钮不闪烁或重建。 |
| 兼容 | 支持 Android 国内版、海外版、竖屏和掌机横屏。横竖屏分别检查布局、焦点、返回和长文案；不得通过旋转、拉伸或整体缩放复用。 |
| 稳定 | 重抽、切换语言或方向后，不得出现多弹窗、多结果、整页闪屏或焦点丢失。 |
| 文案 | 运营校对五种语言的标题、副文案、进度、按钮、失败文案、关闭和“暂无评分”；俄语和巴西葡萄牙语按最长文案检查，核心动词不得截断。翻译缺失时不得显示空白或语言键名。 |
| 素材 | 使用客户端现有且可展示的游戏封面、名称、评分和标签；不新增、修改或伪造游戏素材。 |
| 基线 | 数据侧提供符合入口资格用户的历史 24 小时启动率和有效游玩率；目标值在基线提供后补充，不用抽取次数代替效果指标。 |

## 五、待确认项

| 待确认问题 | 默认建议 | 影响 | 是否阻塞 |
|---|---|---|---|
| 是否已有跨个人库、Steam、秒玩和导入来源的统一 `game_id` | 复用现有统一游戏实体，不新建映射 | 无法稳定去重会影响概率、同轮不重复和归因 | 阻塞候选和数据开发 |
| 已有启动和会话事件能否携带盲盒归因，并提供启动结果和实际时长 | 改造已有启动结果事件，复用会话时长事件 | 无法计算启动率和有效游玩率 | 阻塞数据开发与验收，不阻塞 UI |
| 历史启动率、有效游玩率和本期目标值 | 先按 4.1 开发；数据侧提供基线后补目标值 | 目标值确认前无法判断效果是否达成 | 不阻塞 |
