## 一、文档概述

### 1.1 背景概述

- **需求背景：** 在现有游戏库中增加随机推荐，帮助有多款游戏但暂时不知道玩什么的用户快速选择。
- **当前方式：** 用户逐款浏览个人库、Steam 库和导入游戏，再进入详情获取或启动。
- **问题：** 游戏多时，选择和比较耗时；随机到不兼容或无法启动的游戏会增加失败成本。
- **证据：** 参考页证明单款揭晓和“再抽一次”可减少选择步骤；但 PC 游戏还有下载、安装和兼容成本。本期以启动和有效游玩判断价值。

### 1.2 需求边界

| 边界类型 | 范围说明 |
|---|---|
| 产品边界 | 覆盖 Android 国内版和海外版、竖屏和掌机横屏；涉及现有游戏库及游戏详情。不覆盖 Mac、Web、iOS 和 B 端。 |
| 业务边界 | 包含首位盲盒卡、候选过滤与去重、加权随机、同轮不重复、结果校验、查看详情、再抽一次、五种语言和数据归因。不新增首页入口、直接启动、下载、Steam 登录引导、次数、任务、奖励、后台或新启动流程。 |
| 运营边界 | 运营校对五种语言，检查现有封面、评分和标签；无运营后台、活动、奖品和投放。 |
| 人力边界 | 产品定义候选、权重和指标；UI 提供横竖屏设计；Android 客户端负责入口、弹窗、动画、详情承接和埋点；服务端／数据侧提供候选依赖和归因；测试覆盖算法、状态、横竖屏和多语言；运营／本地化校对文案与素材。 |

### 1.3 术语定义

| 术语／缩写 | 英文全称（按需） | 定义与判断口径 |
|---|---|---|
| 有效推荐池 | Eligible pool | 合并候选并按 `game_id` 去重后，排除待验证、不兼容、下架、维护中、链路失效和无法确认可玩的游戏。 |
| 可直接游玩 | Ready | 当前设备已有可用的秒玩、Steam 或导入启动链路，无需先下载游戏包。 |
| 未下载 Steam 游戏 | Uninstalled | Steam 已登录、游戏已适配，但当前设备未下载游戏包；命中后进入现有详情页获取。 |
| 抽取会话 | Draw session | 打开盲盒弹窗至关闭的过程；“再抽一次”不新建会话。 |
| 有效游玩 | Effective play | 结果展示后 24 小时内，用户从该结果进入详情并启动同一游戏，且单次实际游玩达到 5 分钟。 |
| `game_id` | Game identifier | 同一游戏跨个人库、Steam、秒玩和导入来源的统一标识。 |

## 二、产品说明

### 2.1 产品／方案简介

| 项目 | 说明 |
|---|---|
| 产品／方案定位 | 游戏库内的随机推荐功能，从当前明确可玩的游戏中命中 1 款，不新增获取或启动流程。 |
| 目标用户 | Android 端有效推荐池不少于 2 款，进入游戏库后没有明确目标的用户。 |
| 核心目标 | 降低选择成本，提高成功启动和有效游玩。抽取次数只用于分析过程。 |
| 使用场景 | 用户进入“我的游戏”，不想逐款比较，希望快速获得一款可玩建议。 |
| 功能概述 | 盲盒卡位于列表首位；点击后在当前页弹窗内随机；用户可查看详情、再抽一次或关闭。 |

| 当前状态 | 进入条件 | 可见内容／可执行操作 | 退出事件 | 下一状态 | 失败与恢复 |
|---|---|---|---|---|---|
| 入口不可见 | 有效推荐池少于 2 款或数量获取失败 | 不显示盲盒卡；真实游戏从第一位开始 | 刷新后推荐池不少于 2 款 | 入口可见 | 数量仍无法获取时保持隐藏 |

## 四、支撑及非功能需求

### 4.1 埋点与数据需求

**数据结论：** 新增盲盒埋点，改造已有启动结果埋点，复用已有游戏会话时长事件及成功口径。

#### 4.1.1 指标口径

| 指标名称 | 口径（含公式、分子和分母） | 去重与时间窗口 | 数据源与决策用途 |
|---|---|---|---|
| 24 小时启动转化率 | 结果展示后 24 小时内，从该结果进入详情并成功启动同一游戏的用户数 ÷ 获得有效结果的用户数 | 用户按自然日去重；每次结果独立计算 24 小时 | 结果展示 + 启动结果；判断是否促进启动 |
| 24 小时有效游玩率 | 结果展示后 24 小时内，从结果进入详情、成功启动同一游戏且单次游玩达到 5 分钟的用户数 ÷ 获得有效结果的用户数 | 用户按自然日去重；同日多次达标只计 1 人 | 结果展示 + 启动结果 + 会话时长；核心效果指标 |
| 查看详情率 | “查看详情”点击次数 ÷ 有效结果展示次数 | 按 `draw_session_id + draw_index` 去重 | 判断用户是否接受结果 |
| 再抽一次率 | “再抽一次”点击次数 ÷ 有效结果展示次数 | 按 `draw_session_id + draw_index` 去重 | 判断重抽情况 |

#### 4.1.2 埋点事件

| 事件名称 | 类型 | 对应页面 | 触发时机与成功判定 | 参数 |
|---|---|---|---|---|
| `game_blind_box_entry_expose` | 新增 | 游戏库／盲盒卡 | 盲盒卡进入可见区；同一页面会话只报首次 | `orientation, locale, eligible_pool_size, steam_login_state` |
| `game_blind_box_entry_click` | 新增 | 游戏库／盲盒卡 | 点击或 A 键确认入口，并生成抽取会话 | `orientation, locale, eligible_pool_size, steam_login_state, draw_session_id` |
| `game_blind_box_result_expose` | 新增 | 游戏库／命中结果 | 结果校验通过并停止随机；每个结果只报 1 次 | `orientation, locale, draw_session_id, draw_index, game_id, result_state, weight_class, pool_size, steam_login_state` |
| `game_blind_box_action_click` | 新增 | 游戏库／命中结果 | 结果态点击“查看详情”“再抽一次”或关闭 | `orientation, locale, draw_session_id, draw_index, game_id, result_state, action` |
| `game_launch_result` | 改造已有 | 游戏详情／启动结果 | 启动成功、失败或取消；成功口径不变 | `game_id, launch_result, launch_source, draw_session_id, draw_index, failure_reason` |
| `game_blind_box_effective_play` | 新增 | 游戏详情／游戏会话 | 归因游戏单次游玩首次达到 5 分钟；每个结果只报 1 次 | `game_id, draw_session_id, draw_index, play_duration_bucket` |
| 已有游戏会话时长事件 | 复用 | 游戏会话 | 沿用现有时机，不重复上报 | `game_id, actual_play_duration_seconds` |

#### 4.1.3 参数说明

| 参数名 | 类型 | 必填 | 说明 | 枚举／示例 |
|---|---|---|---|---|
| `orientation` | string（enum） | 是 | 当前方向 | `portrait` = 竖屏；`landscape` = 横屏 |
| `locale` | string（enum） | 是 | 当前语言 | `zh-CN` = 简中；`en-US` = 英语；`ru-RU` = 俄语；`ja-JP` = 日语；`pt-BR` = 巴西葡萄牙语 |
| `eligible_pool_size` | integer | 是 | 进入页面时的有效候选数 | `12` |
| `steam_login_state` | string（enum） | 是 | Steam 登录与库同步状态 | `logged_in` = 已登录且库可读；`logged_out` = 未登录；`sync_failed` = 同步失败 |
| `draw_session_id` | string | 是 | 每次打开弹窗生成的会话标识 | `a7f...` |
| `draw_index` | integer | 是 | 会话内有效结果序号，从 1 开始 | `2` |
| `game_id` | string | 是 | 统一游戏标识 | `silksong` |
| `result_state` | string（enum） | 是 | 结果状态，只用于数据分析 | `ready` = 可直接游玩；`uninstalled` = 未下载 |
| `weight_class` | string（enum） | 是 | 命中权重档 | `recent_1x` = 30 天内玩过；`inactive_2x` = 超过 30 天未玩；`never_2x` = 可直接游玩且从未启动；`uninstalled_1x` = 未下载 |
| `pool_size` | integer | 是 | 本次抽取的有效候选数 | `12` |
| `action` | string（enum） | 是 | 结果操作 | `details` = 查看详情；`redraw` = 再抽一次；`close` = 关闭 |
| `launch_result` | string（enum） | 是 | 启动结果 | `success` = 成功；`failed` = 失败；`cancelled` = 取消 |
| `launch_source` | string（enum） | 是 | 启动归因 | `blind_box_details` = 从盲盒结果进入详情；其他值 = 沿用已有启动来源枚举字典 |
| `failure_reason` | string（enum） | 否 | 启动失败原因 | `engine_failed` = 引擎启动失败；其他值 = 沿用已有启动失败枚举字典。成功或取消时为空 |
| `play_duration_bucket` | string（enum） | 是 | 有效游玩档 | `5m` = 首次达到 5 分钟 |
| `actual_play_duration_seconds` | integer | 是 | 实际游玩秒数 | `600` |

### 4.2 技术需求

| 需求项 | 具体要求 |
|---|---|
| 性能与动画 | 正常模式约每 100ms 切换 1 款，总时长约 1.2 秒，命中收束约 190ms；系统开启“减少动态效果”时约 180ms 直接命中。只有封面、名称、评分和标签变化，弹窗及按钮不闪烁或重建。 |
| 兼容性 | 支持 Android 国内版、海外版、竖屏和掌机横屏。横竖屏使用各自布局和焦点顺序，不旋转、拉伸或整体缩放复用。 |
| 稳定性 | 重抽、切换语言或方向后，不得出现多弹窗、多结果、整页闪屏或焦点丢失。 |
| 异常降级 | 请求、结果校验或封面加载失败时，按 3.1.1 的失败和重试规则处理，不得展示缓存或失效结果。 |
| 数据一致性 | 建池前和结果展示前校验兼容与可用状态；跨来源按 `game_id` 去重；归因校验 `game_id + draw_session_id + draw_index` 和 24 小时窗口。 |

### 4.3 运营需求

| 需求项 | 具体要求 |
|---|---|
| 五语言文案校对 | 校对标题、副文案、进度、按钮、失败文案、关闭和“暂无评分”。俄语和巴西葡萄牙语按最长文案检查，核心动词不得截断；翻译缺失时不得显示空白或语言键名。 |
| 内容／素材准备 | 检查现有封面、评分、类型标签和游戏名本地化；不新增、修改或伪造游戏素材。 |
| 指标基线准备 | 数据侧提供符合入口资格用户的历史 24 小时启动率和有效游玩率；目标值在基线提供后补充，不用抽取次数代替效果指标。 |

### 4.4 财务、法务、版权与合规需求

| 需求项 | 具体要求 |
|---|---|
| 版权需求 | 盲盒卡、随机内容和结果只使用客户端现有且允许展示的游戏封面、名称、评分和标签，不引入第三方新素材。 |

## 五、待确认项

| 待确认问题 | 默认建议 | 未确认的影响 | 是否阻塞 |
|---|---|---|---|
| 是否已有跨个人库、Steam、秒玩和导入来源的统一 `game_id` | 复用现有统一游戏实体，不新建映射 | 无法稳定去重会影响概率、同轮不重复和归因 | 阻塞候选与数据开发 |
| 已有启动和会话事件能否携带盲盒归因，并提供启动结果和实际时长 | 改造已有启动结果事件，复用会话时长事件 | 无法计算启动率和有效游玩率 | 阻塞数据开发与验收，不阻塞 UI |
| 历史启动率、有效游玩率和本期目标值 | 先按 4.1 开发；数据侧提供基线后补目标值 | 目标值确认前无法判断效果是否达成 | 不阻塞 |
