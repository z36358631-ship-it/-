# demo标记

## 触发

当需要生成带交互标注的产品demo时使用。适用于需要展示给开发/设计/领导的交互演示文档。

## 框架结构

三栏布局（左导航 + 中间demo + 右侧标注面板），暗色主题。

```
┌────────────┬──────────────────────────┬──────────────┐
│  左侧导航   │      中间Demo容器         │  右侧标注面板  │
│  220px     │      flex:1              │    400px     │
│            │                          │              │
│ ·页面标题   │   iframe嵌入demo.html     │ ·交互说明tab  │
│ ·国内/海外   │   或直接渲染内容           │ ·异常边界tab  │
│ ·页面列表   │                          │              │
│ ·模拟按钮   │   居中展示，带阴影         │ ·标注编号列表  │
│            │                          │ ·展开/折叠    │
└────────────┴──────────────────────────┴──────────────┘
```

## 详细规范

### 左侧导航（220px）

- 背景：`#1e2235`
- 顶部标题区：功能名称 + 副标题"交互标注文档"
- 国内/海外切换按钮（如涉及双版本）
- 页面流程列表：每项含图标 + 页面名称，点击跳转对应页面
- 可选"模拟按钮"（如模拟扫描完成、模拟登录成功等状态触发）
- 底部留空或放操作按钮

**交互：**
- 点击导航项 → 中间demo跳转到对应页面 + 右侧面板滚动到对应标注区
- 当前激活项左侧蓝色竖线 + 蓝色文字高亮

### 中间Demo容器（flex:1）

- 背景：`#14161e`
- demo内容直接渲染在容器内（不用iframe，所有内容在同一个HTML文件里）
- 居中显示，带圆角8px和阴影
- 右侧有面板展开/折叠按钮（面板收起时显示）

**尺寸参考：**
- 移动端demo：402×874px（竖屏手机）
- 桌面端demo：1076×734px（Mac应用）
- 后台demo：1200×800px

### 右侧标注面板（400px）

- 背景：`#1a1e2a`
- 可收起/展开（折叠时width:0+overflow:hidden）
- 顶部：标题 + "显示标号"按钮 + 折叠按钮
- Tab切换：**交互说明** | **异常&边界**

**标注项结构（.anno-item）：**
```html
<div class="anno-item" data-id="编号" data-page="页面名">
  <div class="anno-head">
    <span class="anno-badge">编号</span>
    <span class="anno-title">标注标题</span>
  </div>
  <div class="anno-body">
    描述内容（支持strong/br/span.tag标签）
  </div>
</div>
```

**标注编号规则：**
- 交互说明：数字编号（1, 2, 3...），橙色圆形底
- 全局逻辑：字母G，蓝色底
- 异常边界：E+数字（E1, E2...），红色底

**标签类型（.tag）：**
- `.tag-blue`：可交互的元素
- `.tag-green`：国内/海外差异点
- `.tag-orange`：注意事项/自动流程

**按页面分组：**
- 用`.anno-section`作为页面分隔标题
- 每个section对应左侧导航的一个页面

### 联动交互

1. 左侧点击导航项 → iframe跳转页面 + 右侧滚动到对应section
2. 右侧点击标注项 → 对应标注在demo中高亮闪烁（通过postMessage通信）
3. "显示标号"按钮 → demo中显示/隐藏橙色数字标号角标
4. 国内/海外切换 → demo切换对应版本内容

## Demo主体规范

所有内容在同一个HTML文件内，不拆分iframe：

1. 左侧导航点击 → 通过JS切换中间容器内的页面（display:none/block切换）
2. 标号角标直接在demo内容上用绝对定位的橙色圆形，通过CSS class `.badge` 控制显隐
3. 国内/海外切换通过JS控制内容差异（文案/列表条目显隐）

## 文件命名

- 单文件：`XXX-标注版.html`（如：Mac端新手分流引导-标注版.html）
- 一个文件包含全部内容（三栏布局 + demo内容 + 标注数据 + 交互逻辑）
