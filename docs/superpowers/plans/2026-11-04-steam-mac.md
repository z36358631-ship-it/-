# Mac 重构版 Steam 接入 Implementation Plan

**Goal:** 以 GameHub 1.0.0 构建 74ddda9f 实机页面为基线，制作可离线操作的 Mac Steam 接入 Demo。
**Architecture:** 宿主页面与 Steam 接入各自独立，构建脚本把样式、脚本及素材内联为单文件。公开目录独立，不修改 Android 版本。
**Tech Stack:** 原生 HTML/CSS/JavaScript、Node 构建、Playwright 行为与截图校验。

## 文件与步骤
- [x] `outputs/steam-mac-integration-20261104/host.js`、`host.css`：还原发现、游戏库、游戏详情、常规设置与 Steam 设置。基线与接入版可切换，展示差异。
- [x] 同目录 `steam.js`、`steam.css`：模式与勾选、原文协议、准备弹窗、演示登录、Steam 内容、球、账号、同步与网络状态。
- [x] 同目录 `build.mjs`：内联素材与模块，生成 `MacSteam接入Demo.html`。模块约定见下。
- [x] 同目录 `verify.cjs`：验证新用户与旧登录用户必经勾选；准备无暂停；恢复目标；模式/缩放；设置启动；网络与同步重试；刷新重置。
- [x] 同目录 `review.html`、`README.md`：基线来源、页面差异与直达可操作演示，截图脱敏。
- [x] 发布 `public/steam-mac-integration/`，使用隔离索引仅更新该目录，验证直达链接。

## 模块约定
页面含 `#host-root`、`#steam-root`、`#demo-controls`。构建注入 `window.MAC_ASSETS`（logo/steam/stardew/elden/hades/cyber/wukong/hero）与 `window.MAC_LEGAL`（HTML）。
宿主暴露 `MacHost.init()`、`navigate(page)`、`setAccount(account)`、`setBaseline(bool)`、`reset()`、`getState()`；state 包含 landing（默认 discovery）、preferredMode（默认 window）、remember、account。可选 `setPreference(key,value)`。
Steam 暴露 `SteamDemo.init()`、`enter({target,legacy})`、`scenario(key)`、`reset()`、`getState()`；通过 MacHost.setAccount 回传演示账号，通过 MacHost.navigate('library') 返回宿主。enter 从 MacHost.getState 读取模式偏好。场景名 first/legacy/ready/network-error/sync-error/empty/download-error。
所有身份、统计为演示数据，不保存真实密码或 Token。宿主控件未纳入范围时使用明确的页内说明，不伪造原生操作成功。

## 业务适配
Mac 原有进入主屏时选项发现、游戏库、云游戏、手游库保留，增加 Steam；默认发现不变。Demo 为方便评审初始展示游戏库。Steam 默认窗口，协议原文不改。资源位不纳入。原始截图只作本地取证，不发布含真实账号的图片。
