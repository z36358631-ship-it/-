# 发行人计划投稿要求与自动校验实施计划

**目标：** 将原任务要求、两个必带话题和投稿时间下限同步到任务详情、提交投稿页、自动校验、PRD 与证据。

## Task 1：数据与展示

- [ ] 为任务增加 `submittedAt`，为成功取数增加 `publishedAt` 和实际话题。
- [ ] 建立统一投稿要求生成方法，供任务详情和提交投稿页复用。
- [ ] 在“提交投稿”页新增投稿要求卡片，展示实际游戏名称和具体任务提交时间。

## Task 2：自动校验

- [ ] 校验 `#{推广游戏名称}` 与 `#盖世游戏` 均存在。
- [ ] 校验 `publishedAt >= task.submittedAt`。
- [ ] 不符合时提示具体原因，且不增加投稿记录或预留预算。

## Task 3：PRD 与验证

- [ ] PRD 增加展示、字段、状态、埋点参数和异常规则。
- [ ] 静态合同锁定文案、字段和方法。
- [ ] 离线 UI 覆盖正常、缺话题和时间过早场景，并重生成截图。
- [ ] 运行 PRD、视觉与公网验证，固定图片提交并推送。
