# APP 租号开发变更同步计划

## 目标

以已确认的 APP 租号 PRD V3.0 为唯一业务基线，同步普通 Demo、标注版、后台预览和 PRD 截图，并用固定 Git SHA 图片地址回写 PRD。

## 改动

1. 客户端只保留首期首次体验·2小时、单游戏永久和会员周/月/季卡；移除首期时租、日租、周租及续租入口。
2. 同步退款后重购、高频退款、Steam 验证码自动输入、游戏提示语、延后换号、会员与售后规则。
3. 后台首期商品配置只展示权益方案，补齐提示语、供应商参考、目录同步与换号待执行状态。
4. 扩展自动验证，同步构建普通 Demo 和标注版。
5. 重新生成横竖屏及后台截图，人工复核关键页面可读性与越界。
6. 精确提交并推送 Demo 与截图；获取固定 SHA 后回写 PRD 图片地址，校验 PRD/ZIP 后再次推送。

## 验收

- Demo 全量契约与新增首期业务契约全部 PASS。
- 横竖屏确认订单、会员、订单、登录、售后与后台截图无遮挡、越界或旧规则。
- PRD 质量校验 0 错误、0 警告，全部图片公网可访问。
