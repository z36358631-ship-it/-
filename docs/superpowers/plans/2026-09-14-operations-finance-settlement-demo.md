# Operations Finance Ledger Demo Implementation Plan

**Goal:** 在不覆盖原运营后台 Demo 的前提下，新增按月查询和导出游戏结算记录的单页财务台账。

**Architecture:** 构建脚本从现有运营后台派生独立 HTML，在主应用启动前注入 `demo16` 的模型、页面和样式；财务模块只维护结算记录和导出记录，不模拟线上付款。

**Tech Stack:** 单文件 HTML、原生 JavaScript、CSS、Node.js、Node Test、Playwright Core。

## Task 1：隔离构建

- 新建 `build-finance-operations.mjs`。
- 从 `发行平台运营后台demo.html` 派生 `发行平台运营后台财务整合demo.html`。
- 增加 P16-01 路由和“财务结算”导航，不修改原文件。

## Task 2：月度结算模型

- 一款游戏按结算月和币种生成一条记录。
- 记录销售额、退款、平台分成、调整额、应付金额、财务主体和收款账户。
- 页面账户脱敏，CSV 使用完整账户和可计算金额。
- 导出后回写导出时间和导出人。

## Task 3：单页台账

- 页面只保留主标题、筛选区、游戏结算表、分页和导出按钮。
- 支持结算月、游戏/开发者/财务主体和币种筛选。
- 支持导出选中记录；未选择时导出全部筛选结果。
- 每页 20 条，默认穷举态，状态球可切换缺省态。
- 不展示打款批次、付款状态、凭证、结果回填和详情抽屉。

## Task 4：验收

- 验证原后台未被覆盖，生成文件无外部依赖。
- 验证默认月、20条分页、筛选、重置、选择和两种导出方式。
- 验证 CSV 包含完整收款字段，导出后更新导出记录。
- 验证 1280px 和 390px 无页面级横向溢出。
