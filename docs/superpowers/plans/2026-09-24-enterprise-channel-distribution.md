# 企业级渠道分销调整

用户已确认：渠道归企业统一管理，批次关联具体游戏和商品/SKU；保留渠道与供给、分销数据及原供给规则。

1. 将渠道分销从单游戏侧栏迁到企业侧栏，兼容旧页面状态恢复。
2. 批次增加游戏选择并联动 SKU；列表、详情、数据增加游戏维度；供给后的核心字段保持锁定。
3. 更新渠道停用的跨游戏影响说明，保留历史批次、凭证及 Key。
4. 仅同步渠道 PRD、相关帮助文案及涉及截图。
5. 构建官方及专项 Demo，验证权限、联动、筛选、恢复、空态和既有供给流程，保留截图证据。

职责：主管负责导航、事件整合、构建和交付；模型员工负责渠道模型与视图；文档员工负责渠道 PRD；测试员工负责浏览器回归。

验收：企业共用渠道；创建批次不能跨游戏选 SKU；旧状态能进入企业渠道页；游戏内无渠道入口；既有文件下载与 API 规则通过回归；右下角 Demo 状态可用。
