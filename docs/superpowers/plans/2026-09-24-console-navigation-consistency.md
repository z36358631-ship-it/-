# 控制台导航一致性修复

用户问题：进入财务主体/对账结算后，开发者控制台标题及分销入口消失；“渠道与供给”“分销数据”应在左侧“发行与供给”下直接并列显示。审核状态需在右下角“Demo 状态”面板内切换。

实施：财务页复用企业控制台侧栏；所有企业顶层入口在同一组件维护，选中项随页面更新；跨财务路由返回游戏/渠道/厂商设置支持同一动作。“发行与供给”下直接提供“渠道与供给”“分销数据”两个入口，移除“渠道分销”总入口及页面顶部的两个主 Tab；“渠道与供给”保留渠道管理、批次管理子 Tab。为两个入口提供 P02-01 的 view/section 直达参数，消费后保留正常导航和刷新恢复。审核状态切换并入 Demo 状态面板，移除独立悬浮按钮，默认审核通过。

验证：1440 与 390 宽度的六项入口、标题、选中态及页面往返；两条直达链接、刷新与离开后恢复；Demo 状态面板内审核状态切换、默认通过及面板外无额外按钮。构建并推送原 developer-platform-demo 分支，使用新缓存参数在用户预览中展示两个独立侧栏入口。
