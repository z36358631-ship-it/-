# 控制台导航一致性修复

用户问题：进入财务主体/对账结算后，开发者控制台标题及渠道分销入口消失；希望直接查看渠道分销的两个 Tab。

实施：财务页复用企业控制台侧栏；所有企业顶层入口在同一组件维护，选中项随页面更新；跨财务路由返回游戏/渠道/厂商设置支持同一动作。为渠道与供给、分销数据提供 P02-01 的 view/section 直达参数，消费后保留正常导航和刷新恢复。

验证：1440 与 390 宽度的五项入口、标题、选中态及页面往返；两条直达链接、刷新与离开后恢复。构建并推送原 developer-platform-demo 分支，使用新缓存参数在用户预览中展示两个 Tab。
