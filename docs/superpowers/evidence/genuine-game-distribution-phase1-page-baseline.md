## 1. 基线结论

1. 当前客户端的真实截图可证明游戏详情外壳、PC 游戏库、下载管理入口与空状态，以及首页／搜索页已有推荐内容的展示形态；截图核验日期为 2026-08-05。
2. 当前截图不能证明正版发行的确认订单、订单结果、下载进行态，也不能证明首页或推荐区中的哪一个位置已具备可直接复用的运营配置能力。
3. CDKEY 旧 PRD、评审记录和历史 Demo 只能证明曾设计／评审过的页面结构与规则。2026-07-31 修订结论覆盖旧方案冲突：当前默认采用供应商 API 供货，废止本地批量导码、本地定价和本地库存预警。
4. 会议 `01:55:40` 明确提到“包体管理流，我们现在已经现有了”。当前没有该现有流的页面、入口、字段和状态截图，因此不得再断言 PRD 4 全部页面不存在；版本列表、版本编辑、包体上传等可能受现有流影响的页面在完成盘点前阻塞页面图定稿。
5. 开发者平台、厂商主页、供给管理、权益处理和精准投放后台按本期新页面处理；测试／发布页面结构来自已批准规格，但现有包体管理流是否已覆盖这些页面仍是 `[推导]` 边界。现有后台截图仅提供列表、详情、审核、资源位配置、操作记录和看板组件依据。
6. 本基线保留四项业务决策阻塞：当前 CDKEY 实际供给方式、首款包体游戏及付费／免费类型、可复用的现有资源位、可直接使用的用户标签。“现有包体管理流及页面盘点”属于证据缺口，不是第五项业务决策。

## 2. 证据口径

- `现状截图可用`：存在当前盖世产品截图，可用于还原页面外壳或局部组件；只能修改本表明确列出的区域。
- `新页面且结构已由产品规格确认`：目标页面当前不存在，但规格已确认页面职责、核心字段、状态或动作，可在后续输出标注为“产品低保真结构”的页面图。
- `缺少依据，阻塞定稿`：现有材料不能证明目标页面或关键业务输入；后续 PRD 必须保留待确认项，不得用历史 Demo、其他业务页面或竞品页面替代。
- 确定性只使用 `[已确认]`、`[推导]`、`[建议方案]`、`[待确认]`、`[高风险假设]`。

### 11.1 仅解析 §7 表格并校验第二列枚举

```powershell
$path = 'docs/superpowers/evidence/genuine-game-distribution-phase1-page-baseline.md'
$allowed = @('现状截图可用', '新页面且结构已由产品规格确认', '缺少依据，阻塞定稿')
$bytes = [System.IO.File]::ReadAllBytes((Resolve-Path -LiteralPath $path))
$utf8 = [System.Text.UTF8Encoding]::new($false, $true)
$text = $utf8.GetString($bytes)
$section = [regex]::Match($text, '(?ms)^## 7\. 页面证据矩阵\r?\n(?<body>.*?)(?=^## 8\.)')
if (-not $section.Success) { throw '未找到 §7' }
$rows = @()
foreach ($line in ($section.Groups['body'].Value -split "`r?`n")) {
    if ($line -match '^\|\s*(?<page>[^|]+?)\s*\|\s*(?<status>[^|]+?)\s*\|') {
        $page = $Matches.page.Trim()
        $status = $Matches.status.Trim()
        if ($page -ne '页面' -and $page -notmatch '^-+$') {
            $rows += [pscustomobject]@{ Page = $page; Status = $status }
        }
    }
}
$invalid = @($rows | Where-Object { $_.Status -notin $allowed })
if ($rows.Count -ne 64) { throw "记录数错误: $($rows.Count)" }
if ($invalid.Count) { throw "非法枚举: $($invalid | ConvertTo-Json -Compress)" }
$groups = @($rows | Group-Object Page)
if ($groups.Count -ne 63) { throw "唯一页面名错误: $($groups.Count)" }
$duplicates = @($groups | Where-Object Count -gt 1)
if ($duplicates.Count -ne 1 -or $duplicates[0].Name -ne '开发者工作台首页' -or $duplicates[0].Count -ne 2) {
    throw "重复页面异常: $($duplicates | Select-Object Name, Count | ConvertTo-Json -Compress)"
}
$rows | Group-Object Status | Sort-Object Name | Select-Object Name, Count
```

### 11.3 来源清单与二进制副本哈希

来源清单校验命令：

```powershell
$path = 'docs/superpowers/evidence/genuine-game-distribution-phase1-page-baseline.md'
$text = [System.IO.File]::ReadAllText((Resolve-Path -LiteralPath $path), [System.Text.Encoding]::UTF8)

        $rows += [pscustomobject]@{ Path = $Matches.path; Expected = $Matches.hash }

"SOURCE_MANIFEST_HASH=PASS ($($rows.Count)/$($rows.Count))"
```
