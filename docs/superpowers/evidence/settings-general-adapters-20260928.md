日期：2026-09-28。范围仅本地 Demo 集成入口与返回；未实现或修改生产业务。

## 改动与接口

- 帮助中心源 `demos/帮助中心/src/app.js` 与交付 `帮助中心demo.html` 同步最小返回分支。入口 `?page=help&orientation=portrait&from=settings-general`；帮助目录返回中央 Demo `?panel=settings&orientation=portrait`。文章仍先返回帮助目录。横屏枚举为 `landscape`。
- 深色模式源 `demos/深色模式/src.html` 与交付 `深色模式demo.html` 同步支持 `?open=1&orientation=portrait&from=settings-general`。直接打开已有面板，选择成功或取消返回中央 Demo `?panel=general&orientation=当前方向`；写入失败不返回。未新增面板或复制主题业务。
- 返回目标是代码常量 `../默认跳转页/盖世游戏APP-默认跳转页流程图.html`；只接受严格匹配 `from=settings-general`，方向输出只取 `portrait/landscape`，不接受任意 return URL。
- 保留原存储 `gamehub-dark-mode-v1`：`system=跟随系统`、`on=开启`、`off=关闭`。不创建第二份主题偏好。
- 已与中央 Demo 负责者确认 `panel/settings/general` 及 `orientation` 契约。
- 生成流程读取已修改源文件；未执行会重写后台或复制资源的整包构建，避免触及本任务范围外文件。

## 实测

通过本地 Chromium + Playwright 对交付 HTML 实际点击，7 项通过：

1. 帮助目录返回中央设置页 URL。
2. 横屏文章先返回帮助目录，再返回中央设置，保留横屏。
3. 主题变更成功返回中央通用设置 URL。
4. 主题取消返回中央通用设置，保留横屏。
5. 模拟 localStorage 写入失败，停留深色模式 Demo，不错误返回中央。
6. 独立打开深色 Demo 默认不打开选项；点入口后取消仍在原 Demo。
7. 独立打开帮助 Demo 返回行为仍回原设置。

以上验证入口、返回、持久化失败分支与独立打开回归。中央目标页实际布局与联动由中央 Demo 负责人验收，本记录未把 URL 成功视为目标界面已验收；无外部发布。
