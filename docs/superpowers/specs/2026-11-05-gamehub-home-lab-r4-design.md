# 首页好价入库方向设计（r4）

## 用户、问题与取舍

主要用户为导入游戏用户，Steam和秒玩用户补充。此方向服务“想找到值得买、适合设备的下一款PC游戏”；不把导入用户等同于愿意购买者。现有方案优惠位于下方，缺乏购前判断和持续关注。参考商店价格/折扣与关注入口的做法，盖世增加设备适配判断；不复制完整商店，不虚构史低、销量、云供给或账号租用权益。

## 已确认的呈现

- 新增第四方向“好价入库”，保留前三方向，可在左侧切换。默认打开新方向，便于评审。
- 首屏紧凑继续游玩（符合原条件时）、优惠主视觉、四个快捷入口：兼容性查询、喜加一、Steam折扣、Steam租号。
- 四方向共享快捷入口，前三方向原主内容继续保留。
- 优惠主视觉和列表显示游戏、现价、折扣、原价及适配状态，进入购前详情后分别查看适配、关注降价、访问官方商店。
- 预算筛选为全部/¥30内/¥50内/¥100内，展示实际满足条件的列表，空结果有空态。

- 关注区显示已关注游戏当前价格与折扣状态；关注按本地演示状态变更，不伪称已发送通知。
- 原社区三条左文右图整组翻页、日历、喜加一、任务、秒玩及组队保留。
- Steam租号无确认供给或链接，仅保留入口及未接入页，不能购买、登录或输入账号。

本轮直接读取Steam国区appdetails记录于purchase-source-probe.json。R.E.P.O. ¥22.75/-35%、Raft ¥51.59/-33%；Hades ¥92、法环¥298、生化4¥198当前无折扣。不使用旧快照里的生化4促销。采集日期写在价格区；无核实截止时间或历史最低价的数据不显示倒计时、即将结束或史低标签。
