# 财务主体阶梯分成配置设计

## 1. 目标与范围

- 平台运营按财务主体维护阶梯平台分成规则。
- 同一财务主体下全部游戏共用同一版规则，不再按游戏配置。
- 本次只修改运营后台阶梯分成 Demo、相关 PRD 及必要的图示；不新增独立 Tab。

## 2. 入口与抽屉

- 入口位于“主体汇总”工具栏，名称为“配置阶梯分成”。
- “游戏明细”不再显示该入口。
- 点击后打开右侧半屏抽屉。
- 抽屉字段：财务主体、规则有效期、变更原因。
- 规则有效期复用数据看板的日期范围组件，保留快捷选择、双月日历、取消和应用操作。
- 快捷项为 1 个月、3 个月、6 个月、1 年、长期和自定义；财务主体、开始日期必填，结束日期、变更原因选填。
- 有效期不限制 180 天；结束日期为空时长期有效。

## 3. 阶梯配置

- 档位使用紧凑多列卡片，宽屏每排展示 3 档，空间不足时自动换行。
- 每档显示：`[下限] < 月结算金额（元） ≤ [上限]`、平台分成比例。
- 仅首档下限固定为 `0`，末档上限固定为“不设上限”；其余下限、上限均可编辑。
- 保存时校验上一档上限等于下一档下限，区间不得重叠或留空。
- 点击“添加档位”在无上限档之前插入新档，下限预填原末档下限，上限和比例待填写；原无上限档保留原比例且下限可改。
- 首档和末档不显示删除；中间档可删除，删除后自动衔接前后边界。
- 平台分成比例取值 `0%—100%`；按已有分段累进口径计算。

## 4. 时间与版本

- 日期按日选择，区间包含开始、结束日期，不限制时长。
- 同一财务主体的规则时间段不得重叠；保存时阻止冲突规则。
- 每次保存生成新规则版本，记录财务主体、时间范围、阶梯明细、变更原因、操作人和操作时间。
- 已生成的账单保留规则版本快照，不随后续配置变更。

## 5. 校验与反馈

- 保存前校验：主体已选、开始日期已填、结束日期不早于开始日期、有限上限严格递增、分成比例合法、有效期不冲突。
- 校验失败时保留已填内容，就近标记错误字段，不新增二次页面。
- 保存成功后关闭抽屉，回到主体汇总，并显示简短成功提示。
