# 新手引导欢迎页文案排布设计

## 目标

调整欢迎页信息顺序，让用户依次理解产品定位、平台价值和开始引导的原因；不修改现有功能链路及文案内容。

## 页面结构

页面从上到下排列：

1. 英文眉题 `WELCOME TO GAMEHUB`。
2. 主标题 `欢迎来到盖世游戏`。
3. 平台特色卡片。
4. 弹性留白。
5. 两行引导语。
6. `开始`按钮。

平台特色卡片紧跟主标题，不再使用 `margin-top:auto` 沉底。两行引导语从标题区移至按钮上方，与下一步操作形成连续语义。

## 文案层级

- `为了您的绝佳体验`：原因说明，使用较小的弱化文字。
- `请与我们分享您的游玩经验～`：行动提示，字号和对比度高于第一行。
- 两行左对齐，保持独立换行，不合并、不改写。
- `开始`按钮文案保持不变。

## 视觉规则

- 主标题与平台特色卡片间距为 24–28px。
- 两行引导语间距为 3–4px，与按钮间距为 12–16px。
- 装饰圆点不得贴近或覆盖标题、引导语、特色卡片文字。
- 平台特色卡片保持现有内容，不增加字段；控制整体高度，确保按钮始终位于首屏。

## 中英文适配

- 海外版沿用相同信息顺序。
- 英文引导语允许自然换行，但不得挤压或遮挡按钮。
- 在 390×844 竖屏容器中，中文和英文均完整显示标题、特色卡片、引导语和按钮。

## 验收标准

1. 页面阅读顺序为“欢迎标题 → 平台价值 → 引导原因 → 开始操作”。
2. 引导语位于开始按钮上方，不再位于主标题下方。
3. 平台特色卡片紧跟标题，页面中部不出现由自动沉底造成的大面积断层。
4. 中文、英文状态均无文字截断、重叠或按钮出屏。
5. 欢迎页后的来源采集及后续新手引导流程保持不变。
