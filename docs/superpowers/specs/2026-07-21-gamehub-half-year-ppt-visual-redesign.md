# 盖世游戏2026半年度汇报PPT视觉重设计说明

## 1. 目标

依据`APP半年汇报/盖世游戏半年汇报PPT内容大纲 - 1.0.md`，使用`APP半年汇报/模板1.pptx`重新制作5页内部汇报PPT。

新版采用用户确认的C方向：**数据主导＋真实功能证据图**。页面不再将大纲拆成大量文字卡片，而是使用关键指标先给结论，再以真实功能截图、原生图标和简短说明证明结论。

- 内容提纲：`APP半年汇报/盖世游戏半年汇报PPT内容大纲 - 1.0.md`

- 模板视觉：白底、深紫标题、紫/青强调色、微软雅黑与Arial、圆角数据卡片、少量原生矢量图标。

## 3. 页面结构

## 3.1 第1页：一页总结

**标题：** 上半年完成关键能力建设，价值兑现进入攻坚阶段

**页面目标：** 30秒内让管理层看到成绩、业务价值和核心问题。

**版式：** 左侧关键数据，右侧使用`横竖屏.jpg`作为产品主视觉。

**关键数据：**

- 主要版本：5个。
- MAU：264万提升至347万，增长约31%。
- 人均互动时长：928秒提升至2508秒，增长约170%。
- 云游6月毛利率：54.2%。
- 核心缺口：卸载率约80%、D1留存19.26%、启动到进入游戏约52%。

**页尾结论：** 上半年解决“有没有能力”，下半年解决“能力能否持续产生用户价值和业务价值”。

## 3.2 第2页：为什么做、做了什么

**标题：** 四类真实需求，驱动四类能力建设

**版式：** 使用4个“问题→方向→证据图”模块，不再使用大面积纯文字表格。

1. 产品形态限制覆盖 → 横竖屏双模式 → `横竖屏 (2).jpg`。
2. PC游戏运行与配置门槛高 → 平台接入、游戏导入、性能兼容、云分享和操控 → `平台接入.jpg`、`导入游戏.jpg`、`按键布局云分享.png`。
3. 云游供应商退出 → 迁移云游服务并恢复权益及支付链路 → `云游.jpg`。
4. 厂商及硬件交付需求 → SDK、平板预装包和小鸡游戏世界支撑 → PowerPoint原生图标与简短文字。

页面只展示核心交付，不展开全部功能明细。

## 3.3 第3页：三类成果验证

**标题：** 产品采用、商业模型和外部交付获得阶段验证

本页采用三栏结构，是整套PPT的核心证据页。

### 产品采用

- 证据图：`按键布局云分享.png`、`启动配置云分享.jpg`。
- 数据：竖屏覆盖48.1%、按键布局云分享20.2万、启动方案云分享12.3万、WineActivity人均停留59分钟。

### 商业模型

- 证据图：`云游.jpg`。
- 数据：6月收入19.22万元、服务器成本8.81万元、毛利10.41万元、毛利率54.2%。
- 表述边界：只表述为“正毛利空间获得阶段验证”，不表述为稳定商业成功。

### 厂商交付与小鸡硬件

厂商交付只展示两种交付形态，使用PowerPoint原生矢量图标：

- SDK。
- 平板预装包。

小鸡游戏世界只展示三个结果：

- 上半年版本更新12次。
- 累计支持手柄`___款`。
- 上半年新款手柄适配率100%。

`___款`是用户确认保留的手动编辑占位。PPT中使用琥珀色虚线框并标记“定稿前补齐”，不得伪装成正式统计数据。100%的口径固定为“上半年新款手柄适配率”，不得简写为无口径的“适配率100%”。

## 3.4 第4页：复盘与问题

**标题：** 能力建设方向正确，但尚未充分转化为用户成功

**版式：** 上半部分以问题漏斗展示卸载、留存和启动成功缺口；下半部分左右对照“已验证的判断”和“需要纠正的判断”。

**已验证：**

- 双模式获得用户采用。
- 云分享降低复杂配置复用成本。
- 云游具备收费与正毛利空间。
- SDK和平板预装包具备交付条件。

**需要纠正：**

- 能力更多不等于新用户更容易玩上游戏。
- 规模和时长提升不等于留存已经解决。
- 跑通收费不等于商业模型稳定。
- 完成项目不等于形成标准化复制能力。

## 3.5 第5页：下半年重点

**标题：** 从能力建设转向用户价值、经营结果和交付效率

采用三栏目标卡片：

1. 用户成功：降低登录、资源、兼容、启动和异常门槛。
2. 商业闭环：优化试用、套餐、付费转化、复购和成本。
3. 标准化交付：明确SDK和平板预装包边界，沉淀模块、文档、验收和成本模型。

**结果标准：** 用户是否成功、业务是否增长、能力是否复用、商业化是否兑现。

## 4. 设计约束

1. 每页只保留一个主结论，最多4个核心数字。
2. 截图必须与所在页面的结论一一对应，不使用纯装饰图片。
3. 正文字号以投屏可读为准；中文正文不得低于12pt，数据标签不得低于10pt。
4. SDK和平板预装包图标使用PowerPoint原生形状组合，保持可编辑。
5. 所有文字、数据、图标和图片位置均可在PowerPoint内继续修改。
6. MAU、互动时长、云游毛利、用户漏斗均标明时间或指标名称，避免无口径数字。
7. “阶段验证”是统一表述，不使用“已经成功”“已经平台化”等过度承诺。

## 5. 输出与验收

输出：

- 可编辑PPTX。
- PDF预览。
- 5张1600×900逐页PNG。
- 总览图。

验收标准：

1. PPTX和PDF均为5页。
2. PowerPoint可正常打开并导出，不出现修复提示。
3. 所有关键数据和图片映射完整。
4. 无文字溢出、孤字换行、图片拉伸或关键界面裁切。
5. `___款`占位清晰可见并可直接手动替换。
6. 第4页问题能够自然推导第5页三个下半年方向。
