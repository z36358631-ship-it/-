# 兼容性查询分享码与机型筛选设计规格

**日期：** 2026-08-25

**目标：** 简化机型筛选和卡片信息，用复制分享码替换配置下载，让用户可直接在盖世游戏导入对应设置方案。

## 1. 范围

- Android、Mac 第二筛选统一命名为“机型”。
- Android 仅展示手机型号；Mac 仅展示 Mac 机型。
- 卡片移除 `Wine 9.2`、`GS3` 和独立 FPS 文案。
- 平均帧率作为兼容状态右侧标签。
- 卡片复制图标替换下载图标。
- 详情页底部按钮改为“复制分享码”。
- Android、Mac 每条兼容记录均关联一份启动配置。

不新增弹窗、确认步骤、分享页面或下载能力。

## 2. 筛选

筛选顺序保持：游戏、机型、评级。

| 平台 | 机型候选 | 不展示 |
|---|---|---|
| Android | 手机型号，如一加 13、红魔 10 Pro、小米 15 | SoC、CPU、GPU 独立候选 |
| Mac | Mac 机型，如 MacBook Pro、Mac mini、Mac Studio | Apple 芯片独立候选 |

- 按钮名称和搜索提示统一为“机型”“搜索机型”。
- 搜索仅匹配机型名称和机型别名。
- 三个筛选按钮保持同排，完整显示“游戏、机型、评级”。
- 候选浮层保持覆盖结果，不推高页面。

## 3. 卡片

卡片信息顺序：

1. 游戏封面和名称。
2. 机型及原有硬件摘要。
3. 系统版本，如 `Android 15`、`macOS 26`。
4. 兼容状态与平均帧率标签。
5. 右侧评分和复制图标。

规则：

- 移除 `Wine 9.2`、`GS3`。
- 右上角仅显示评分，如 `5.0`。
- 删除原独立 `46 FPS`。
- 状态右侧显示 `平均帧率 46`，与兼容状态同一行。
- 复制图标使用两个重叠方框，点击区域不小于 44×44px。
- 点击卡片主体进入兼容性评价；点击复制图标不打开详情。

## 4. 分享码

文本格式：

```text
复制打开盖世游戏导入PC引擎设置方案：[游戏名称][系统智能设置方案][GPU:原有GPU字段]SCFG##现有编码
```

- GPU 沿用兼容记录原字段，不受机型筛选调整影响。
- `SCFG##` 后编码沿用现成前端生成逻辑；本规格不重新定义算法。
- Demo 为每份配置提供稳定模拟编码。
- 卡片复制图标和详情按钮复制完全相同的完整文本。
- 成功提示：`分享码已复制，可打开盖世游戏导入`。
- 失败提示：`复制失败，请重试`。

## 5. 配置关联

- 每条兼容记录必须且至少关联一份当前平台、当前游戏、当前记录的有效配置。
- `record.configIds` 必须包含配置 ID，配置的 `recordId` 必须反向指向该记录。
- 卡片复制按 `configId → recordId` 独立校验，不依赖详情页是否打开。
- 生产数据不得由前端默认补出虚假配置；无真实配置的记录不应进入正式数据集。
- Demo 可使用明确的模拟配置补齐展示数据。

## 6. 复制流程

```text
点击卡片复制图标或详情“复制分享码”
  → 校验配置、记录、平台和游戏
  → 生成完整分享文本
  → App Bridge 或 Clipboard API
  → 失败时尝试 execCommand
  → 显示成功或失败提示
```

- 复制事件必须先于卡片点击处理，并阻止冒泡。
- 复制中禁用重复提交。
- 卡片复制支持鼠标、触摸和键盘操作。
- App Bridge 返回失败、Promise 拒绝或超时均不得提示成功。

## 7. 详情页

- 兼容性评价结构和参数内容不变。
- 底部“复制启动配置”改为“复制分享码”。
- 移除旧的配置下载语义和文案。
- 复制后保留当前滚动位置。

## 8. 验收

- Android、Mac 第二筛选均显示“机型”。
- Android 候选只有手机型号；Mac 候选只有 Mac 机型。
- 卡片不出现 `Wine 9.2`、`GS3` 或独立 `FPS`。
- 平均帧率标签位于兼容状态右侧。
- 每条记录都有一个可用复制图标和有效配置。
- 点击复制图标不打开兼容性评价。
- 卡片和详情复制内容一致。
- 分享文本包含游戏名称、系统智能设置方案、原 GPU 和 `SCFG##`。
- 复制成功、Bridge 失败、Clipboard 失败和配置不匹配均有明确结果。
- Android、Mac、竖屏、横屏和桌面无数据串线或布局溢出。

## 9. 快速评审结论

- 用户视角：筛选和复制路径清晰；平均帧率按已确认文案显示。
- 开发视角：通过独立配置校验、事件分流和复制降级处理规避误开详情与伪成功。
- 商业视角：范围符合 MVP；生产环境禁止用默认值伪造配置，避免损害兼容数据可信度。
