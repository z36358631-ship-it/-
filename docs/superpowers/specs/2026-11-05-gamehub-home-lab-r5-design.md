# 首页三方向归位设计 r5

日期2026-11-05。用户重新明确并批准仅三方向：导入用户付费转化、本机适配开玩、丰富内容持续活跃；要求更新Demo并提供按竞品参考→关注点→展示权重组织的话术。

## 决定

D070：替代D063与D067造成的方向偏移。direction value/play/content仅三项，默认value；好价入库合并value的辅助购游区，不作为第四方向。
D071：删除首页中逐款编造的盾牌/弓箭/技巧攻略和玩法专题，不再依靠逐游戏编写内容支撑通用首页。社区精选仅运营选择少量帖子，样例不冒充真实投稿；无匹配内容时可不展示，不把运营配置当作内容来源。
D072：付费主线用已确认APP租号方案的结构化SKU演示，来源 demos/APP租号功能/盖世游戏APP租号功能demo.template.html 与 GUANWANGGAID-3状态卡。影之刃零首租2小时¥1.9、单游戏永久账号权益¥198、会员周卡¥39/7天、月卡¥129/30天均为历史Demo样例，非当前在售。首租资格独立开关，已用过不显示首租价。会员库仅展示源方案确认游戏艾尔登法环，角色未知不宣称已拥有权益。租号是账号权益，不新增个人Steam库所有权；云服务与本机运行条件分别确认。无库存/套餐实时连接，不执行支付或账号操作。
D073：对应三方向设计说明同时写到外侧可展开思路面板与design-rationale.md，按用户话术陈述依据、关注点、权重、内容供给和缺省；只引用所提供详情页截图的可见布局，不推断竞品首页实测结果。

## 内容和交互

方向1：继续游玩保持原条件；租号体验主视觉+来源价格+首租条件；四快捷区；会员游戏库与套餐价值；云游服务辅助（弱设备时优先），Steam优惠/预算/关注为辅助；原社区/日历/喜加一/任务/秒玩组队保留。主CTA进入租号购前详情、会员中心或云供给条件，不跳攻略。详情复用同源规则，实际购买禁用，明确账号权益/设备条件。首租资格外侧控制。

方向2：继续游玩、适配游戏主视觉和设备结论、四快捷区、本机可玩与已匹配记录；官方玩法片段只能手动播放，非手机实机；准备/适配未知不承诺即玩；最新适配不捏造上线日期，展示现有匹配记录且没有数据明确空态。移除逐款创作的技巧/主题/文章模块。首屏CTA按已准备/未准备/未知指向游戏详情，保留既有启动终点。

方向3：社区三条左文右图组翻页、日历/每日发售订阅、折扣和领免/提醒、任务、原业务及本机可玩。内容依赖运营选帖与结构化数据聚合；保留的编辑样例外侧明确非真实玩家，不写虚构热度。

## 范围和验证

保留暗色、独立横竖Shell、左控右Demo、宽屏游戏库第一/整行栏目/无继续游玩、标题后箭头和单返回箭头、设备兼容角标、原福利承接及价格快照。只改实验Demo，原正式首页/PC Demo/PRD不覆盖。

验收三方向×四用户情境×三形态和窄屏；付费主路径/资格切换/无真实支付、可玩条件与来源独立、内容供给边界、原栏目返回链路、三条社区滑动、预算/关注与通知边界、价格来源和租号源方案逐项核对。真实用户反馈和商业效果未验证。
