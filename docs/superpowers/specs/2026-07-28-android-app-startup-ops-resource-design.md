# Android APP 开屏运营资源位设计

## 一、背景

Android 启动开屏不接入穿山甲或 Google AdMob，不作为广告资源位参与广告请求、计费、实验和收入统计。平台仍需要在冷启动阶段展示活动、新游或合作内容，因此改由现有运营资源系统承载。

## 二、最终方案

- 在“首页卡片管理 → 运营资源位置配置”的“资源位置”下拉中新增独立选项“APP开屏页”。
- “APP开屏页”不复用现有“启动弹窗”，两者为不同资源位置。
- 新资源位复用运营资源位置配置的列表、新增、编辑、删除、查询、状态和权限能力，不新建后台模块。
- 国内包与海外包均可配置，通过现有 APP 协议、APP 渠道和系统语言确定投放范围。
- 启动开屏从广告投放配置、A/B 测试配置和广告效果统计中移除。

## 三、用户端流程

1. 用户点击 App 图标产生冷启动。
2. 客户端展示盖世游戏 Logo 动画。
3. 客户端查询当前包体、渠道、语言和屏幕方向命中的“APP开屏页”运营资源。
4. 命中有效资源时展示全屏运营内容；未命中时直接进入目标页。
5. 用户点击“查看详情”时，按后台配置的跳转类型打开目标内容。
6. 启动运营页沿用当前开屏流程的 3 秒展示时长，右上角保留可点击的“跳过 3s”；用户跳过或倒计时结束后，竖屏进入首页，横屏进入游戏库，不新增展示时长配置。

启动运营页不显示 `Ad`、广告网络标识和广告 SDK 落地页，不触发广告曝光、点击或收益事件。

## 四、后台配置

配置路径：`首页卡片管理 → 运营资源位置配置 → 添加`

资源位置新增：

- APP开屏页

复用字段：

- 资源位置
- 屏幕方向
- 系统语言
- APP 协议
- APP 渠道
- 跳转类型
- 跳转参数或关联内容
- 标题
- 副标题
- 投放开始时间
- 投放结束时间
- 封面或 Banner 图
- 展示频率
- 状态
- 排序

复用规则：

- 新增、编辑、删除、查询、重置、状态切换和权限规则沿用运营资源位置配置现有能力。
- 跳转目标、渠道、语言、投放时间、展示频率和排序沿用现有校验及生效规则。
- “启动弹窗”和“APP开屏页”分别配置、分别查询、分别生效，不能互相覆盖。

## 五、广告后台调整

- 广告投放配置不再显示启动开屏。
- A/B 测试配置不能选择启动开屏。
- 广告效果统计不再统计启动开屏的请求、填充、曝光、点击、eCPM、收入和广告退出率。
- 启动运营页复用运营资源系统原有曝光和点击统计口径。

## 六、异常与降级

- 无有效配置、状态隐藏、未到投放时间、已过期或定向不匹配：Logo 后直接进入首页或游戏库。
- 素材下载失败或加载超时：不展示空白页，直接进入首页或游戏库。
- 跳转目标失效：按运营资源系统现有失败处理执行，不调用广告 SDK。
- 多条资源同时命中：沿用运营资源位置配置现有排序规则。
- 横竖屏切换：按屏幕方向重新匹配资源；无匹配素材时直接进入目标页，不拉伸另一方向素材。

## 七、Demo 与 PRD 调整范围

- 用户端将“启动开屏广告”改为“APP 开屏运营资源”，保留 Logo、全屏内容、查看详情、跳过和进入目标页流程。
- 用户端移除 `Ad`、广告网络、SDK 落地页和广告失败模拟。
- 运营后台新增“运营资源位置配置”页面，展示现有列表和添加弹窗，在资源位置中增加“APP开屏页”。
- 广告投放配置、A/B 测试配置和效果统计中删除启动开屏。
- PRD 将启动开屏从广告资源位清单、广告链路、广告埋点、收入测算和上线顺序中移除，并增加运营资源配置及降级规则。

## 八、验收标准

- “APP开屏页”与“启动弹窗”同时存在且互不复用。
- 国内包和海外包均可按协议、渠道和语言配置“APP开屏页”。
- 用户端启动运营页不出现任何广告标识，不调用广告 SDK。
- 无有效资源或素材失败时不阻塞启动。
- 广告后台三个页面均不再出现启动开屏。
- 运营资源位置配置页可新增、查询、编辑和删除“APP开屏页”配置。
