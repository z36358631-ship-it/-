## 目标

为盖世游戏 APP 单独制作一份 MODS 高保真交互 Demo 和一份可供开发、测试执行的 PRD。Demo 从现有《饥荒》游戏详情开始，完整还原“更多菜单”入口，再沿用创意工坊的页面层级实现外部来源 MOD 的浏览、下载、安装、详情和本机启停。

## 范围

- 仅做 C 端 APP。
- 国内包与海外包均包含 MODS；页面结构和本机状态规则一致。
- 国内包产品名显示“盖世游戏”，海外包产品名显示“GameHub”。
- 本期不实现创意工坊页面，只保留其原有入口作为官方订阅能力参照。
- 本期不展示启动检查、冲突检查、安全拦截或跨设备同步。
- 外部内容已由上游同步，安全性按当前前提处理。

## 方案比较

### 方案 A：复用创意工坊骨架，替换业务语义（采用）

保留游戏详情、更多菜单、列表、已安装和覆盖式详情的页面层级；把订阅语义替换为下载、安装、本机启停和卸载。

优点：与 APP 现有认知一致，进入路径短，官方创意工坊与非官方 MODS 的状态不会混淆。

### 方案 B：独立下载管理器

把 MODS 做成任务中心式页面，突出下载队列和文件管理。

优点：管理能力强。缺点：偏离创意工坊参考，发现内容效率较低。

### 方案 C：把创意工坊和 MODS 合并为“扩展内容”

入口先进入来源选择，再进入各自页面。

优点：入口数量少。缺点：增加一步，并弱化官方订阅与本机安装的本质差异。

## 页面结构

### 1. 游戏详情与更多菜单

- 竖屏和横屏均先展示《饥荒》现有游戏详情。
- 点击“更多”打开原有更多菜单。
- 菜单每行最多五项、最多两行，共 5+4：
    - 第一行：PC 引擎设置、创意工坊、MODS、分享、添加到桌面。
    - 第二行：版本切换、移除游戏、修改信息、按键与布局。
- 横屏菜单弹层按标题和两行入口自适应高度并垂直居中，第二行下方只保留正常内边距，不得出现可容纳第三行入口的空白。
- 创意工坊保留原位置和官方订阅语义；MODS 为独立入口。

### 2. MODS 浏览

- 顶部：返回按钮和“饥荒 MODS”。
- 主 Tab：“浏览 / 已安装”。
- 浏览页搜索框按 MOD 名称和作者模糊匹配：
    - 竖屏：独占主 Tab 下方一整行，不与“浏览 / 已安装”同行。
    - 横屏：不再独占一行，与排序和刷新共用工具栏，顺序为“热门 / 下载最多 / 最新发布 → 搜索框 → 刷新”。
- 三个排序项使用独立横向子 Tab：
    - 热门：默认选中，按近 24 小时下载增幅降序。
    - 下载最多：按累计下载量降序。
    - 最新发布：按发布时间倒序。
- 排序值相同时按发布时间倒序，再按 MOD ID 稳定排序。
- 切换排序后回到列表顶部。
- 竖屏单列卡片；横屏双列卡片。
- 卡片展示封面、名称、短简介、作者、下载量和文件大小。
- 整张卡片可进入详情，不显示“详情”按钮；未安装卡片右下角显示“安装”。
- 标题最多两行，短简介最多两行；超出截断。

### 3. 已安装

- 不显示搜索框。
- 使用一个筛选下拉，选项为“全部 / 可更新”，默认“全部”；不再平铺为两个 Tab。
- 筛选器与刷新组成右侧操作组，筛选器在刷新左侧，同组间距 8px；横竖屏一致。
- 横屏第一行仅放返回、标题和主 Tab；筛选与刷新位于第二行右侧，列表紧跟第二行。
- 竖屏单列、横屏双列。
- 卡片保留快捷启用/停用开关；安装、启用状态仅属于当前 APP 设备。
- 点击卡片进入同一个 MOD 详情。
- 无已安装内容时显示“当前设备尚未安装 MOD”，并提供“去浏览”。

### 4. MOD 详情

- 竖屏参考创意工坊使用覆盖式详情层；横屏使用宽弹层和左右分栏。
- 展示封面、名称、作者、下载量、文件大小、简介、安装说明和更新记录。
- 不显示兼容性、最新版本和“非官方”标签。
- 未安装时显示“下载安装”；安装进度在原操作区显示。
- 已安装时不用滑块，使用整颗状态按钮：
    - “已启用”为绿色背景。
    - “已停用”为灰色背景。
- 同时提供“检查更新 / 更新”和“卸载”。
- 卸载需要二次确认；取消不改变本机状态。

## 横竖屏规则

- 竖屏基准 390×844，横屏基准 874×402。
- 旋转只重排布局，不重新请求目录、不重建下载任务。
- 必须保留当前页面、主 Tab、排序子 Tab、浏览搜索词、已安装筛选、列表滚动锚点、当前 MOD、详情阅读位置、安装进度和启用值。
- 搜索框处于焦点时旋转，旋转后恢复搜索焦点和光标位置。
- 输入法正在组词时不重绘搜索框；若此时发生多次方向切换，组词结束后只执行最后一个有效目标方向。
- 横竖屏属于同一 APP 设备；状态不会同步到 Mac 或其他 APP 设备。

## 状态与异常

- 首次加载显示卡片骨架，不显示空状态。
- 加载失败显示“加载失败，点击重试”，保留返回和刷新。
- 搜索无结果显示“没有找到相关 MOD”，提供清空搜索。
- 列表为空与搜索无结果使用不同文案。
- 下载、校验、安装均绑定同一任务；重复点击不创建第二条任务。
- 弱网或进入后台时保留当前进度；回到前台继续同一任务。
- 图片失败显示占位图，不影响文字和操作。
- 启停失败恢复原状态并显示失败提示。

## Demo 交互范围

1. 游戏详情 → 更多菜单 → MODS。
2. 浏览搜索、三个排序子 Tab、刷新。
3. 浏览卡片 → 详情 → 下载安装 → 安装完成。
4. 已安装卡片快捷启停。
5. 详情页整颗“已启用 / 已停用”状态按钮。
6. 全过程竖屏、横屏切换并保留状态。
7. 空搜索、卸载确认和操作 Toast。

## 验收

1. 更多菜单仅两行且每行不超过五项，9 个入口无遗漏；横屏弹层不预留第三行空白。
2. 创意工坊与 MODS 为两个独立入口，页面内不混用订阅和安装文案。
3. 竖屏浏览按“主 Tab → 独占行搜索 → 排序 → 列表”排列；横屏浏览按“主 Tab → 排序 / 搜索 / 刷新同一工具栏 → 列表”排列，搜索紧靠刷新左侧，所有工具栏控件满足最小触控热区；默认排序为“热门”。
4. 已安装页不显示搜索；“全部 / 可更新”为单个下拉筛选器，并与刷新按“筛选 → 刷新”紧凑排列。
5. 竖屏单列、横屏双列；详情分别为覆盖层和左右分栏宽弹层。
6. 卡片和详情不显示兼容性、最新版本、非官方标签。
7. 作者、下载量、文件大小显示完整；卡片可直接进入详情。
8. 详情启停使用绿色/灰色整颗按钮，不使用滑块；列表快捷开关保留。
9. 旋转后页面、筛选、滚动位置、详情和任务状态不丢失。
10. 国内包显示“盖世游戏”，海外包显示“GameHub”，其余功能规则一致。
