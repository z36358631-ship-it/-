# 秒玩页云游戏权益卡紧凑布局设计

## 问题

当前权益卡纵向间距过大，充值按钮占满整行，签到被切成独立大区块，卡片视觉重心分散。

## 方案

采用紧凑横向布局，业务内容与交互不变：

1. 用户信息保留在顶部，缩短与分割线的间距。
2. 时长区域左侧展示标题、剩余时长和说明，右侧展示“立即充值”。
3. 充值按钮改为中等宽度胶囊按钮，取消外层大面积光圈。
4. 签到区域左侧展示标题与签到状态，右侧展示“签到/明日再来”。
5. 卡片整体高度减少约 30%，与最近常玩首屏内容上沿保持一致。

## 交互

- 点击剩余时长右侧箭头：打开现有时长明细。
- 点击“立即充值”：打开现有充值页面。
- 点击“签到”：沿用现有签到状态与反馈。
- 不新增弹窗、Toast、字段、接口或业务规则。

## 验收

- 右侧卡片不再出现大面积空白。
- 时长和充值为同一操作层，签到信息和按钮为同一操作层。
- 昵称、UID、时长、说明、充值和签到内容均完整显示。
- 1520×1034 页面下卡片不遮挡、不溢出，其他模块位置不变。
