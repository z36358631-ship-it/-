# 开发者后台 Figma 可读性修复设计

## 目标

修复现有 Figma 正式页的两类交付缺陷，不改变 37 个业务路由、页面布局、字段、状态、角色权限或交互逻辑：

1. `01 开发者平台与资料` 中中文 Text 图层已导入但画布只显示数字和拉丁字符。
2. `03 包体测试与发布`、`04 精准投放与数据` 云端仍使用旧稿，顶部深色栏未同步，出现白底白字。

## 根因

- P01：业务页正文使用单一 `font-family="Microsoft YaHei"`。Figma 云端导入大 SVG 时无法稳定解析该字体的中文 glyph；保留 Arial 的拉丁字符仍能显示，因此看起来像“缺少元素”。
- P03/P04：本地当前源已经包含 `#0b1220` 顶栏底色，但本轮只替换了 P01、P02 和组件母版，云端 P03/P04 仍是旧根画板。

## 方案

- 生成器统一把业务页中文字体输出为 `Microsoft YaHei, Arial, sans-serif`，沿用已在云端正常显示的页标题字体栈；保持 `<text>`，不转曲、不栅格化。
- 增加回归测试：正式业务页不得出现裸 `font-family="Microsoft YaHei"`；P03/P04 每个业务页的顶部栏必须保留 `#0b1220`。
- 重建全部 Figma SVG，但云端只替换受影响的正式根：P01、P02、P03、P04 和组件母版；`00 全局流程索引`、历史页和页面数量保持不变。
- 替换后核对中文显示、文字/矢量可编辑、根图层唯一、坐标尺寸和 `9/6/13/9` 页面数量。

## 验收

- P01-01 的“从首款签约游戏开始，完成发行闭环”、四步说明和“开始入驻”等中文在画布可见。
- P01-01—P01-09 均无系统性中文缺字或明显裁切。
- P03/P04 所有页面顶部栏为深色背景，白色品牌、模块、帮助和用户信息可读。
- 正式根分别为 `figma-page-01`、`figma-page-02`、`figma-page-03`、`figma-page-04`、`figma-page-components`，每页仅一份。
- 本地 43 条回归及 SVG 结构校验通过；不新增业务路由。

## 三视角评审

- 用户视角：修复中文可读性与顶栏对比是必要补齐，无任务路径变化；需复核缺字、裁切和至少 4.5:1 的文本对比。
- 开发视角：保持 Text 图层，禁止转路径或图片；用兼容字体栈并对 37 页做结构与视觉回归。
- 商业视角：修复直接提升评审与交付专业度，范围限定为字体兼容和顶栏同步，ROI 合理。
