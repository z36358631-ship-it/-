# Mac MODS 紧凑同排头部设计

## 修订记录

## 目标

在不改变 MOD 数据、卡片、启停和详情交互的前提下，将 Mac MODS 列表页的范围 Tab 与当前范围操作合并到同一头部行，减少纵向占用并避免切换页面时列表跳动。

## 范围

- 仅修改 Mac MODS 列表页。
- 浏览页删除“MODS”和“非官方来源 · 仅此设备”。
- 已安装页同步删除同一标题区。
- 浏览页工具栏从左到右为：排序下拉、搜索、刷新。
- 已安装页工具栏从左到右为：筛选下拉、刷新，不显示搜索或空占位。
- 同一行左侧固定显示“浏览 / 已安装”Tab，右侧显示当前 Tab 的工具栏。
- 整行共用底部分隔线，选中 Tab 的下划线贴住分隔线。
- 浏览页排序选项保持“热门趋势、下载量、最新发布”，默认“热门趋势”。
- 已安装页筛选选项保持“全部、可更新”，默认“全部”。
- 列表卡片快捷启停小开关保留。
- 详情页不恢复滑块，继续使用整颗“已启用/已停用”状态按钮。
- 已安装数量摘要保留在头部下一行；浏览页保留同高空白行但不显示占位文案。
- 列表卡片、返回详情和详情弹窗不改。

## 方案比较

### 方案 A：Tab 与原生下拉组成统一头部

头部使用单一 flex 容器。左侧渲染 Tab，右侧渲染带可见语义的原生下拉、搜索和刷新。复用现有排序与筛选状态。

优点：范围切换与当前范围操作形成同一视觉组；结构稳定，键盘和系统辅助能力完整。

### 方案 B：保留两个绝对定位区域

Tab 和工具栏仍是独立绝对定位块，只把坐标调整到同一高度。

优点：改动少。缺点：工具栏宽度变化时容易重叠，选中下划线和分隔线也容易错位。

### 方案 C：把已安装摘要并入统一头部

Tab、工具栏和“X 个已安装 · 仅此设备”全部放在同一行。

优点：纵向最紧凑。缺点：会压缩搜索宽度，且浏览页与已安装页的信息密度不一致。

## 选定方案

采用方案 A。

- `.mods-list-header` 是统一头部容器，使用正常 flex 布局，不依赖 Tab 与工具栏的独立绝对定位。
- `.mods-tabs` 位于左侧并贴住头部底线；`.list-tools` 位于右侧，不再占满整行。
- 头部底部分隔线贯穿可用宽度，选中 Tab 的下划线覆盖在分隔线上。
- 排序和筛选下拉保持现有尺寸；已安装页移除搜索后，筛选与刷新整体右对齐且不保留空占位。
- 浏览页 DOM 与键盘顺序固定为：浏览 Tab、已安装 Tab、排序下拉、搜索、刷新。
- 已安装页 DOM 与键盘顺序固定为：浏览 Tab、已安装 Tab、筛选下拉、刷新。
- `.catalog-toolbar` 作为头部下一行，两页保持相同高度；仅已安装页显示摘要文字。
- 浏览页与已安装页的 `.mods-grid` 使用相同 `top`，切换 Tab 时首张卡片不发生垂直位移。
- 下拉触发器同时显示“排序/筛选”语义和当前值，避免只显示“全部”或“热门趋势”造成歧义。
- 浏览和已安装分别使用现有 `browseSort`、`installedFilter` 状态。
- 下拉 `change` 事件分别派发 `SET_BROWSE_SORT`、`SET_INSTALLED_FILTER`。
- 浏览页搜索输入和两页刷新按钮沿用现有事件，不改变浏览搜索结果和刷新反馈。
- 已安装页不渲染 `data-input="search"`，也不读取、提交或展示 `searchByTab.installed`；已安装列表结果仅由筛选条件决定。

## V1.2 已安装搜索收敛方案

### 方案 A：直接移除并自然收拢（选定）

已安装页仅渲染筛选与刷新，工具栏继续右对齐，不为搜索保留宽度。优点是信息最精简，符合已安装内容量较少、主要任务是筛选和管理的场景；浏览页搜索完全不受影响。

### 方案 B：隐藏搜索但保留占位

仅把搜索设为不可见，继续占用原宽度。优点是切换 Tab 时刷新位置不变；缺点是已安装页出现无意义空白，工具栏结构与可见操作不一致。

### 方案 C：移除搜索并扩大筛选

移除搜索后扩大筛选宽度或把刷新移到原搜索位置。优点是视觉填充更满；缺点是扩大了本次改动，也会让相同筛选控件在不同上下文中的尺寸不一致。

## 状态与异常

- 无效排序值回退到“热门趋势”。
- 无效筛选值回退到“全部”。
- 刷新过程中保留当前 Tab、排序/筛选、浏览页搜索词和滚动位置。
- 浏览页搜索或已安装页筛选无结果时继续使用现有空状态。
- 排序或筛选切换后列表回到顶部，避免用户停留在旧结果的中段。
- 当窗口宽度不足以容纳同排内容时，本 Demo 维持 Mac 设计稿宽度，不新增换行；正式客户端按既有最小窗口宽度限制处理。

## 验收

1. 浏览页和已安装页均不显示“MODS”标题和对应副标题。
2. Tab 与当前页工具栏位于同一头部行，垂直中心误差不超过 1px。
3. 浏览页视觉、DOM 与键盘顺序为浏览、已安装、排序、搜索、刷新。
4. 已安装页视觉、DOM 与键盘顺序为浏览、已安装、筛选、刷新，页面内不存在搜索输入或搜索占位。
5. 头部底部分隔线贯穿整行，选中 Tab 下划线贴住分隔线。
6. 浏览排序下拉包含 3 项，默认“热门趋势”，切换后顺序正确。
7. 已安装筛选下拉包含 2 项，默认“全部”，切换“可更新”后仅显示可更新项。
8. 已安装数量摘要位于头部下一行且不与头部、卡片重叠；浏览页不显示摘要占位文案。
9. 浏览页与已安装页第一张卡片的顶部坐标一致，切换 Tab 时列表不跳动。
10. 浏览页搜索可用；浏览页和已安装页刷新均可用。
11. 浏览列表和已安装列表的快捷启停小开关存在且可操作。
12. 详情页无滑块，整颗状态按钮存在且可操作。

## 快速评审

- 用户视角：通过。已安装页主要任务是查看、筛选和管理，移除低价值搜索可降低头部信息密度；筛选、刷新和快捷启停仍完整。
- 开发视角：通过。采用条件渲染移除已安装搜索，不保留隐藏 DOM；自动化分别断言两页 DOM、焦点顺序和状态隔离。
- 业务视角：通过。只精简 Mac 已安装页，不改变浏览发现效率、MOD 安装管理能力，也不扩到 APP、创意工坊、内容供给或商业化。
