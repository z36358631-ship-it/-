# Mac MODS 紧凑工具栏设计

## 目标

在不改变 MOD 数据、卡片、启停和详情交互的前提下，压缩 Mac MODS 列表页头部信息，将浏览页和已安装页的列表控制集中到同一行。

## 范围

- 仅修改 Mac MODS 列表页。
- 浏览页删除“MODS”和“非官方来源 · 仅此设备”。
- 已安装页同步删除同一标题区。
- 浏览页工具栏从左到右为：排序下拉、搜索、刷新。
- 已安装页工具栏从左到右为：筛选下拉、搜索、刷新。
- 浏览页排序选项保持“热门趋势、下载量、最新发布”，默认“热门趋势”。
- 已安装页筛选选项保持“全部、可更新”，默认“全部”。
- 列表卡片快捷启停小开关保留。
- 详情页不恢复滑块，继续使用整颗“已启用/已停用”状态按钮。
- Tab、已安装数量摘要、列表卡片、返回详情和详情弹窗不改。

## 方案比较

### 方案 A：原生下拉并入顶部工具栏

浏览页和已安装页分别渲染带可见语义的原生下拉，例如“排序：热门趋势”和“筛选：全部”，与搜索、刷新组成一行。复用现有排序与筛选状态。

优点：结构最紧凑，键盘和系统辅助能力完整，改动范围最小。

### 方案 B：自定义下拉菜单

使用按钮加浮层模拟下拉。

优点：视觉可完全自定义。缺点：需要补充打开、关闭、焦点、键盘和点击外部收起逻辑，超出本次必要范围。

### 方案 C：保留平铺选项并缩小尺寸

继续显示所有排序和筛选项，只调整尺寸。

优点：无需展开即可看到所有选项。缺点：不符合“排序作为下拉选项”的明确要求。

## 选定方案

采用方案 A。

- 顶部工具栏仍位于 Tab 上方，整体右对齐。
- 排序和筛选下拉使用相同宽度，切换 Tab 时搜索和刷新位置不跳动。
- 下拉触发器同时显示“排序/筛选”语义和当前值，避免只显示“全部”或“热门趋势”造成歧义。
- 浏览和已安装分别使用现有 `browseSort`、`installedFilter` 状态。
- 下拉 `change` 事件分别派发 `SET_BROWSE_SORT`、`SET_INSTALLED_FILTER`。
- 搜索输入和刷新按钮沿用现有事件，不改变搜索结果和刷新反馈。

## 状态与异常

- 无效排序值回退到“热门趋势”。
- 无效筛选值回退到“全部”。
- 刷新过程中保留当前 Tab、排序/筛选、搜索词和滚动位置。
- 搜索或筛选无结果时继续使用现有空状态。
- 排序或筛选切换后列表回到顶部，避免用户停留在旧结果的中段。

## 验收

1. 浏览页和已安装页均不显示“MODS”标题和对应副标题。
2. 浏览页工具栏 DOM 与视觉顺序均为排序、搜索、刷新。
3. 已安装页工具栏 DOM 与视觉顺序均为筛选、搜索、刷新。
4. 浏览排序下拉包含 3 项，默认“热门趋势”，切换后顺序正确。
5. 已安装筛选下拉包含 2 项，默认“全部”，切换“可更新”后仅显示可更新项。
6. 两页搜索和刷新可用。
7. 浏览列表和已安装列表的快捷启停小开关存在且可操作。
8. 详情页无滑块，整颗状态按钮存在且可操作。

## 快速评审

- 用户视角：紧凑布局不减少能力；下拉必须显示“排序/筛选”语义和当前值。
- 开发视角：复用现有状态和 reducer，只替换控件与事件入口，不改数据模型。
- 业务视角：仅调整 Mac MODS 展示，不扩到 APP、创意工坊、内容供给或商业化。
