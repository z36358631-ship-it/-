# 云存档月度套餐顶部卡片精简设计

## 1. 背景

当前“存档广场”顶部的云存档月度套餐卡片包含促销标签、套餐名称、权益说明、价格、两行规则说明和满宽开通按钮，整体高度约为 160～180px，占用首屏空间较多，影响用户浏览下方存档内容。

本次仅优化顶部套餐卡片的信息密度和视觉布局，不调整套餐价格、购买流程、套餐权益、¥6 单个存档永久购买能力及后台规则。

## 2. 设计结论

顶部套餐入口改为左右两栏的横向紧凑卡片，高度控制在 88～96px，约为当前高度的一半。

### 2.1 左侧信息

- 保留“试运营优惠”标签。
- 保留套餐名称“云存档月度套餐”。
- 权益说明精简为“全部存档 30 天不限次使用”。

### 2.2 右侧信息

- 展示价格“¥18/30天”。
- 价格下方展示紧凑操作按钮。
- 按钮点击热区不小于 72×44px。

### 2.3 删除内容

顶部卡片不再展示以下两行说明：

- “购买后立即生效 · 30 天有效 · 非自动续费”
- “原 ¥6 单个存档永久购买仍可选择”

“30 天有效”“非自动续费”等购买规则继续在套餐购买确认弹窗中展示。¥6 单个存档永久购买入口继续保留在存档详情页，本次不取消单买能力。

## 3. 套餐状态

| 套餐状态 | 右侧按钮 | 交互 |
|---|---|---|
| 未开通 | 开通 | 打开套餐购买确认弹窗 |
| 有效 | 续费 | 打开续费确认弹窗 |
| 已到期 | 续费 | 打开续费确认弹窗 |
| 已提前续费下一周期 | 已续费 | 置灰，不可重复点击 |

顶部卡片不展示详细到期说明、退款说明或提前续费说明；这些信息继续由“我的存档”套餐状态卡、购买确认弹窗和到期拦截弹窗承载。

## 4. 视觉与响应式

- 卡片沿用现有黑金视觉、圆角、边框和促销标签样式。
- 竖屏采用左右两栏：左侧标题与权益，右侧价格与按钮纵向排列。
- 横屏沿用同一结构，不新增独立样式。
- 标题、权益和按钮均保持单行；空间不足时优先压缩左右间距，不缩小到低于现有最小字号。
- 移除说明后，下方首排存档卡片自然上移，原滚动逻辑不变。

## 5. 修改范围

- 更新 `demos/充值与商城/云存档付费demo.html` 的套餐卡片结构、样式及四种状态文案。
- 同步更新云存档付费 PRD 中顶部套餐卡片的界面说明。
- 重新生成包含顶部套餐卡片的 PRD 截图，并使用可供飞书直接访问的固定 Git 提交图片地址。

## 6. 不在本次范围

- 不取消 ¥6 单个存档永久购买。
- 不调整 ¥18 套餐售价、30 天有效期和非自动续费规则。
- 不调整退款、续费、作者奖励、套餐周期和后台配置逻辑。
- 不修改存档详情页双权益选择结构。

## 7. 验证要点

- 390px 竖屏下卡片高度为 88～96px，内容无截断、换行或重叠。
- 价格、标签、标题和按钮互不挤压，按钮点击热区不小于 72×44px。
- 未开通、有效、已到期和已提前续费四种状态文案与交互正确。
- 顶部卡片不再出现两行已删除说明。
- 存档详情页仍可选择 ¥6 永久购买。
- 套餐购买确认弹窗仍展示有效期和非自动续费等必要规则。
