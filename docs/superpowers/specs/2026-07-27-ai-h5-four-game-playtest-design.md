# AI H5 四赛道可玩 Demo 与体验对比设计

## 1. 目标

面向 CrazyGames、Poki 等全球 Web/H5 游戏平台，制作四个可以在桌面与手机浏览器直接操作的玩法 Demo，用同一套体验量表完成对比，选出最值得继续开发的两个方向。

本轮验证的不是完整商业游戏，而是以下三个问题：

1. 玩家能否在 10 秒内理解核心目标并开始操作。
2. 玩家能否在 45 秒内明确感知“自适应导演”因自己的行为改变了玩法。
3. 奖励广告是否出现在自然决策点，且拒绝广告后仍能完整游玩。

## 2. 已锁定方案

采用“四个独立单文件 HTML Demo + 一个统一评测大厅”的结构。

- 每个游戏均可单独打开、单独分享，不依赖云端接口或外部素材。
- 评测大厅提供四款入口、玩法说明、统一测试任务与最终排序。
- 每款目标有效体验时长为 60–120 秒，首轮不加入强制插屏。
- 广告只以 3 秒本地模拟层呈现，不产生真实广告请求和收入。
- AI 使用本地规则、行为统计与固定响应库，统一对外称“自适应导演”，不宣称为生成式 AI。

未采用的方案：

- 把四款游戏写进一个共享引擎：代码耦合高，单款异常会影响其余游戏，不利于独立分享和测试。
- 只制作 UI 流程或视频：无法验证操作爽感、AI 可感知性和广告中断后的状态恢复。

## 3. 统一自适应规则

四款游戏都遵循同一条可解释链路：

`观察玩家 20–30 秒 → 归类行为标签 → 提前说明 AI 判断 → 从预验证响应库选择一次变化 → 保留明确反制方式 → 结算时复盘`

约束：

- 每局最多出现一次显著自适应变化。
- 变化必须在 45 秒内出现。
- 不读取玩家是否观看广告来调整难度。
- 不通过暗中增加生命、攻击或速度制造“AI 作弊”。
- 使用固定种子记录 `ai_profile` 与 `ai_response_id`，相同行为可重复验证。

## 4. 四款 Demo

### 4.1 GhostGrid：AI 自适应迷宫追逃

宣传句：它不是守着出口，它在学习你的逃跑习惯。

核心循环：

1. 玩家使用方向键、WASD 或屏幕方向键移动。
2. 收集两枚能量钥匙并前往出口。
3. 猎手记录贴墙、回头和直线冲刺倾向。
4. 系统在约 25 秒时提示判断，并调整猎手巡逻或开放替代通道。
5. 玩家利用新通道或诱饵完成反制。

广告节点：被抓后可选择模拟广告回退到 8 秒前；拒绝则从检查点继续。

### 4.2 TrapLab：AI 机关导演跑酷

宣传句：关卡导演看懂每一次跳跃，下一段专门为你改拍。

核心循环：

1. 角色自动向右移动，玩家点击、触控或按空格跳跃。
2. 前三段记录起跳时机、失败类型和连续成功次数。
3. 导演无人机提示“谨慎”“激进”或“节奏不稳”。
4. 后半段从摆锤、塌板、弹簧、移动台、滚筒和低顶中选择一组针对性机关。
5. 完成后展示导演评价与同种子重试。

广告节点：跌落后可选择模拟广告原地复拍；拒绝则返回最近检查点。

### 4.3 BioForge：AI 怪物融合工坊

宣传句：任意两种怪物基因都能融合，AI 会根据首战弱点提出专属变异。

核心循环：

1. 从四种基因核心中选择两个，生成具有可解释继承关系的怪物。
2. 融合结果同时改变轮廓、颜色、技能和战斗行为。
3. 玩家在自动战斗中主动释放一次过载技能。
4. 自适应导演根据承伤、输出和技能时机推荐两项变异。
5. 选择变异后进入 Boss 战，并解锁新的组合剪影。

广告节点：变异选择页可选择模拟广告刷新三个变异；原始选项均能通关。

### 4.4 Lotus Guardian：AI 反制护送塔防

用户口述中的“造字”按“操作英雄与 AI 对战的塔防”理解，本轮不实现文字构造玩法。玩法参考“强力守护者护送重要目标”的情绪结构，但不使用“赵云”“阿斗”、三国角色名称、现有游戏造型或儿童受伤表现。

宣传句：你摆下防线后，对手会针对你换兵；读懂预告、及时反制才能护送车队突围。

世界观采用原创的“莲灯车队与遗迹守护者”，仅使用通用幻想符号，不把印度或东南亚的神祇、寺庙、王室、国旗、种姓或神圣动物作为可攻击对象。

核心循环：

1. 玩家在三条路线旁部署弓塔、重炮或缓速塔，并保护自动前进的莲灯车队。
2. 第一波结束固定获得两枚活跃代币。
3. AI 根据玩家防线构成，提前预告第二波将选择盾兵、迅捷兵或分流兵。
4. 波次间提供装备、技能道具和普通道具，均可用两枚代币或一次模拟广告获得。
5. 玩家使用英雄技能和所选道具完成第二波及小 Boss。

公平规则：

- 广告和代币获得同一个物品、相同属性、相同时长。
- 每局最多装备一个奖励物品，不能叠加广告强化。
- 装备是侧向选择，例如射程提高但攻速下降。
- 不获取任何物品也存在稳定通关路径。
- AI 不读取玩家是否观看广告，也不会因奖励物品暗中加难。

## 5. 统一广告模拟

- 仅模拟奖励广告，固定 3 秒。
- 首次邀请只能出现在有效操作 30 秒之后或自然失败/波次节点。
- 每局最多一次。
- 按钮直接说明奖励内容，并始终提供“不观看”路径。
- 广告开始时暂停游戏、物理和计时；完成、取消或不可用均恢复原状态。
- 同一次广告只能发放一次奖励。

## 6. 评测大厅

评测大厅展示：

- 四款游戏的宣传句、预计时长、操作方式和开始按钮。
- 统一测试任务：完成核心循环、触发一次 AI 变化、体验一次广告节点、再玩一局。
- 每款的完成状态与本地事件摘要。
- 评测完成后的综合排名和 Top 2 标记。

页面通过 `postMessage` 接收游戏事件，事件仅保存在浏览器本地，不上传服务器。

统一事件：

`game_start`、`first_input`、`ai_observation_locked`、`ai_change_shown`、`core_payoff`、`run_end`、`replay_start`、`ad_offer_view`、`ad_accept`、`ad_complete`、`ad_cancel`、`reward_grant`、`token_earn`、`token_spend`。

## 7. 体验评测

每款至少完成：

1. 1440×900 桌面冷启动。
2. 390×844 移动冷启动。
3. AI 行为与广告状态恢复定向复测。

评分权重：

| 维度 | 权重 |
|---|---:|
| 首局理解 | 15 |
| 操作爽感 | 20 |
| 核心闭环与节奏 | 10 |
| AI 可感知性 | 20 |
| 广告接受度 | 10 |
| 复玩意愿 | 15 |
| 全球文化可理解性 | 5 |
| 无障碍与设备适配 | 5 |

进入 Top 2 的硬条件：

- 桌面和移动端都能完成核心闭环。
- 无 P0，且没有持续阻断闭环的 P1。
- AI 可感知性至少 3/5，并有两条可复现证据。
- 不看广告也能继续或通关。

本轮由多角色代理实际操作 Demo 并保留截图、控制台错误和事件结果。该结论属于专家代理体验对比，不冒充外部真人用户研究；若进入正式立项，再招募目标国家玩家做小样本可用性测试。

## 8. 预期排序与待验证假设

产品预评估排序：

1. TrapLab：操作钩子、短视频传播与失败复活广告最自然。
2. BioForge：融合揭晓、收藏扩展和广告刷新潜力最强。
3. GhostGrid：开发最轻、AI 因果清楚，但广告入口相对单一。
4. Lotus Guardian：商业系统空间最大，但首局认知、开发复杂度和文化风险最高。

最终排序必须以完成后的实际操作证据为准，不直接沿用预评估结论。

## 9. 非目标

- 不接真实广告 SDK、登录、付费、服务器、排行榜或实时多人。
- 不调用在线大模型或运行时生图。
- 不制作长期任务、卡池、跨局战力成长或付费货币。
- 不使用未经授权的 IP 名称、角色造型或文化宗教资产。
