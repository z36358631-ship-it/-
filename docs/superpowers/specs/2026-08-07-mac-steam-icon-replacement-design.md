# Mac 版本管理 Demo Steam 图标替换设计

## 目标

将现有手绘的“圆形＋连线”Steam 图标替换为用户截图中的标准 Steam 连杆圆环标志，提升 12–22px 多尺寸下的识别度，同时保持现有单文件 Demo、布局、背景和交互不变。

## 设计方案

1. 仅替换公共 SVG Symbol `#i-steam` 的内部图形。
2. 新图形采用准确、可识别的 Steam 填充轮廓，不再使用普通圆形、圆环和线段近似。
3. Glyph 使用 `currentColor`，由使用场景决定颜色：
   - 版本弹窗、设置页、安装版本选择等蓝灰色图标容器中显示白色；
   - 详情白色主按钮中显示深色；
   - 封面角标、搜索结果、账号区和详情信息区沿用现有前景色。
4. 用户截图对应的大图标保持现状：`36×36px` 蓝灰色圆角底、`9px` 圆角、内部约 `19×19px` 白色 Steam 标志。
5. 不为小尺寸图标额外增加容器，不改变已有蓝灰底、封面深色角标或按钮底色。

## 覆盖位置

- 游戏库封面 Steam 角标：约 `12px`。
- 搜索结果：约 `15px`。
- 账号区：约 `18px`。
- 游戏详情主按钮：约 `17px`。
- 游戏详情平台信息与成就：`13–18px`。
- 版本切换弹窗：约 `19px`。
- 设置页版本卡片：约 `22px`。
- 安装弹窗摘要及版本选择：`15–18px`。

## 不在范围内

- 不修改 Epic、GOG、Apple/Mac 原生版图标。
- 不调整弹窗、列表、按钮、间距、文字或交互。
- 不使用截图位图、CDN、远程 SVG 或外部字体图标。
- 不增加新的图标组件或页面。

## 验收标准

1. 版本弹窗中的 Steam 图标与用户截图一致：蓝灰圆角底＋白色 Steam 连杆圆环标志。
2. Steam 标志在 `12px`、`15px`、`17px`、`19px`、`22px` 下均可识别，无粘连、裁切或退化成黑点。
3. 详情白色主按钮中 Steam 标志为深色，内部结构清楚。
4. 所有 Steam 图标复用同一个 `#i-steam` Symbol。
5. Epic、GOG、Apple/Mac 图标及页面布局无视觉回归。
6. 单文件 HTML 无外部依赖，现有自动测试全部通过，浏览器 `error` 日志为 `0`。

## 风险控制

- 公共 Symbol 被多处复用，实施后必须逐尺寸截图检查，不能只验证版本弹窗。
- Glyph 必须由单一填充轮廓构成并继承 `currentColor`，避免旧版硬编码描边在不同背景下失去对比度。
