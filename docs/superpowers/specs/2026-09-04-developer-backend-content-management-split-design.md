# 开发者后台认证内容与帮助中心拆分设计

## 1. 目标与范围

本轮只重构发行平台运营后台的内容管理信息架构：将“企业认证内容配置”和“帮助中心”拆成左侧两个独立入口，使认证文章与帮助目录各自形成清晰、可维护的闭环。

本轮不修改企业认证申请、运营审核、开发者控制台、02～04 Demo 或 Figma；公开帮助中心继续读取运营发布后的中文或 English 内容。

## 2. 页面架构

### 2.1 左侧导航

发行平台后台保留以下正式入口：

1. 企业认证审核。
2. 企业认证内容配置。
3. 帮助中心。

“企业认证内容配置”与“帮助中心”分别使用独立路由和选中态。游戏资料审核与发行数据管理继续作为后续能力禁用展示。

### 2.2 企业认证内容配置

页面仅展示文章列表，不再使用“认证介绍、保密协议、发行协议、帮助中心”四个内容 Tab。

列表字段：

- 文章标题／唯一编号；
- 文章位置：认证介绍、保密协议、合作协议；
- 中文与 English 配置状态；
- 更新时间；
- 操作：编辑、删除。

页面提供标题或编号搜索、新建文章、中文／English 编辑切换以及“保存并生效”。企业认证文章不支持排序。

同一文章位置最多存在一篇当前文章。三个位置均已配置时仍展示“新建文章”入口，但点击后提示没有可用位置；删除原文章后可重新创建该位置。唯一编号在创建时由系统生成，生成后只读且不可复用。

编辑页按当前语言填写文章标题和富文本正文，文章位置在中文与 English 间共用。切换语言前收集当前输入，避免丢失未发布内容。

### 2.3 帮助中心

帮助中心页包含两个二级 Tab：

#### 导航目录

展示全部导航，字段包括导航名称／唯一编号、中文与 English 配置状态、子文档数量、更新时间和操作。

支持：

- 按名称或编号搜索；
- 新建、编辑、删除；
- 上移、下移排序；
- 中文与 English 名称配置。

创建时系统生成 `HC-NAV-` 前缀唯一编号。导航被子文档引用时禁止删除，并提示先迁移或删除子文档。排序结果决定开发者侧帮助中心左侧导航顺序。

#### 目录子文档

展示全部目录子文档，字段包括文章标题／唯一编号、所属导航、中文与 English 配置状态、更新时间和操作。

支持：

- 按标题或编号搜索；
- 按所属导航筛选；
- 新建、编辑、删除；
- 在同一导航内上移、下移排序；
- 中文与 English 标题、富文本正文配置。

创建时系统生成 `HC-DOC-` 前缀唯一编号，并必须选择一个现有导航。更改所属导航后，该文档移动到目标导航末尾。排序只影响同一导航内的文档顺序。

## 3. 数据结构

运营编辑态使用以下稳定对象：

- `certificationArticles[]`：`id`、`position`、`zh`、`en`、`updatedAt`；不含排序字段。
- `helpNavigations[]`：`id`、`sortOrder`、`zh.title`、`en.title`、`updatedAt`。
- `helpDocuments[]`：`id`、`navigationId`、`sortOrder`、`zh.title/bodyHtml`、`en.title/bodyHtml`、`updatedAt`。

旧数据首次加载时按现有三类认证内容、帮助分类和 FAQ 自动归一化；历史无稳定导航编号的文章按分类名称匹配并生成导航编号，不丢失正文。

发布时同时校验中文和 English：

- 企业认证三个文章位置齐全，标题与正文非空；
- 每个导航的中英文名称非空；
- 每篇子文档的所属导航存在，中英文标题与正文非空；
- 富文本清除脚本、事件属性、非法标签和 `javascript:` 链接。

全部通过后生成一个新的内容版本，认证页与公开帮助中心原子切换；任一项失败时不发布半成品，开发者端继续读取上一版本。

## 4. 交互与反馈

- 搜索和导航筛选仅改变当前列表可见项，不修改数据。
- 新建、编辑完成后返回对应列表，并展示成功反馈。
- 删除使用确认弹窗；取消不改变数据。
- 删除成功后返回列表并展示成功反馈；受引用导航删除失败时保留原数据并展示阻断原因。
- 上移、下移到达边界时对应按钮禁用；排序后立即在列表中更新，发布成功后才影响开发者侧。
- 唯一编号由系统生成，创建后不可编辑；删除后也不复用。
- 富文本编辑器支持标题、加粗、列表、链接和图片；图片只接受 JPG、PNG、WEBP。
- 所有列表、编辑页和弹窗适配 320px、390px、1280px 及宽屏。

## 5. 三视角快速审查

- 用户视角：认证文章与帮助文档分开后，运营无需在四类内容间来回切换；帮助目录和子文档的职责清晰。
- 开发视角：子文档通过稳定导航 ID 关联，导航改名不会破坏关系；删除引用校验避免孤儿文档。
- 商业视角：保留企业认证和帮助中心最小内容闭环，不引入版本库、审批流、定时发布或复杂权限。

审查结论：方案通过。企业认证内容明确不支持排序；帮助中心排序仅作用于导航和同导航内子文档。

## 6. 验收条件

1. 第一份 Demo 暴露 P01-01、P01-03、P01-08、P01-09、P01-10 五个业务路由。
2. 运营左侧同时显示“企业认证内容配置”和“帮助中心”，选中态与路由一致。
3. 企业认证内容页只有文章列表；无帮助中心 Tab、无排序操作，支持搜索、新建、编辑、删除、唯一编号和双语编辑。
4. 帮助中心含“导航目录”和“目录子文档”两个 Tab，两类对象均支持增删查改；导航和子文档支持规定范围内排序。
5. 删除被引用导航会被阻止，创建对象会生成不重复且只读的唯一编号。
6. 发布前完成双语、位置、关联和富文本安全校验；失败时不覆盖已发布版本。
7. 开发者侧帮助中心按导航顺序和子文档顺序展示，搜索与关键词高亮继续可用。
8. 320px 与 390px 无根节点横向溢出，核心入口、列表卡片和编辑表单清晰可操作。
