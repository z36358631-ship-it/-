# GameHub GOG UI Corrections Design

## 目标

在现有 `demos/PC与Mac端/盖世游戏GOG平台接入-交互标注版.html` 中修正以下已确认问题，不增加页面、字段、Toast 或独立业务流程：

1. GOG 账号二次退出确认复用现有 Steam 退出确认组件。
2. “我的”页使用用户选择的官方 GOG.com 方形全字标，并修正不同场景的等比缩放。
3. 详情页将 Steam、EPIC、GOG 三个平台切换入口前移到游戏类型标签之前，并消除重复入口。
4. GOG 库右上角“切换账号”先进入账号选择弹窗，不直接跳转授权登录。
5. 详情页兼容性评分的 `3.8` 与星星同行，并移除 PC 游戏引擎标题右侧的平台胶囊。
6. “我的”页 GOG 个人信息卡调整为标题、头像昵称和两项统计，不展示 GOG ID、同步时间或账号价值。

## 已确认决策

### 1. 退出确认弹窗

来源：用户提供截图 `C:/Users/z3635/AppData/Local/Temp/codex-clipboard-3db950d8-de64-41b3-b08d-bbe5f5969c38.png`，对应现有 GameHub 危险确认模式 `C-DIALOG`。

弹窗结构保持：

- 标题：`提示`
- 右上角关闭按钮
- 正文：`是否退出该 GOG 账号？`
- 左侧次操作：`取消`
- 右侧主操作：`确认`
- 遮罩覆盖当前 App 画布，背景不可操作

确认后沿用现有退出逻辑，仅清除当前 GOG 绑定状态；取消、关闭均返回原页面且不修改账号。竖屏与掌机横屏复用同一组件视觉和语义，在各自 Shell 中居中，不再把确认区域嵌入账号卡或覆盖游戏卡。

### 2. GOG 品牌标识

用户在可视化对照中选择 B：官方 GOG.com 方形全字标。继续复用单一 `PLATFORM_MARKS.gog` 资源，保持 `data-source-status="derived"`，不冒充已取得的 Figma 原始 SVG。

展示规则：

- 平台 Tab：方形容器内完整等比缩放。
- 账号头像：圆形紫色容器内完整等比缩放。
- 游戏库入口、封面角标、详情平台切换和启动按钮：使用同一资源的场景尺寸变体。
- 仅设置受约束的一边尺寸，另一边按固有比例自适应；禁止拉伸、裁切、文字重绘和临时字母图标。

### 3. GOG 库切换账号

来源：用户提供 `codex-clipboard-3843f5d4-b6de-43d9-b762-e124ccf5177a.png` 与 `codex-clipboard-434bbf91-52f3-44f7-a5fa-bc1aa6f980a3.png`。

- GOG 库右上角入口的语义和可访问名称固定为`切换账号`，图标使用用户切换图形，不使用“登录”语义。
- 点击入口只打开`切换账号`弹窗，不直接执行 `beginAuthorization('switch')`。
- 弹窗展示当前账号 `GalaxyRider`、GOG ID 和`当前使用`状态。
- “+”为使用新凭证入口；只有点击“+”才进入 GOG 官方授权。
- `移除账号`按来源图展示为禁用态，不新增移除账号流程。
- 点击当前账号或关闭按钮只关闭弹窗，不修改账号状态。
- `accountSwitchOpen` 与平台切换、退出确认互斥，切页或进入授权时统一清理。

### 4. 详情页平台切换层级

竖屏与横屏的信息顺序统一为：

1. 游戏标题与评分
2. 游戏简介
3. Steam / EPIC / GOG 平台切换
4. `动作`、`冒险游戏`等游戏类型标签
5. 发行与基础信息
6. PC 游戏引擎及当前平台能力
7. 游戏介绍或横屏指标
8. 固定底部启动操作或掌机主操作

平台入口使用三个真实按钮，不再使用不可点击的 `span`。每个按钮包含平台官方标识、可访问名称和明确选中态；点击 Steam、EPIC 或 GOG 任意入口都只打开`切换平台`弹窗，不立即更新平台。

`切换平台`弹窗来源为用户提供的 `codex-clipboard-b924ccb3-3b28-4340-8432-210a0367c031.png`：标题居中、右上关闭、平台选项纵向排列，当前平台右侧显示勾选。只有点击弹窗中的平台选项才执行 `select-detail-platform`，更新 `state.selectedPlatform` 并关闭弹窗，同时同步：

- 当前平台标识
- 云存档状态
- 游戏时长
- 评分缺省规则
- 启动按钮文案、图标和动作

删除 PC 游戏引擎底部原 `获取游戏` 图标行；只保留一套新的纵向平台选择弹窗。当前来源不可用时继续展示已有错误说明，不静默切换到其他平台。

### 5. PC 游戏引擎细节

来源：用户提供 `codex-clipboard-53f0d29f-c534-41ca-b69e-67c7690f4d74.png`。

- `兼容性评价`中的 `3.8` 与星星使用独立 `inline-flex` 容器同行展示。
- 移除 `PC游戏引擎`标题右侧的 Steam、EPIC 或 GOG 胶囊；平台选择只保留在类型标签之前和`切换平台`弹窗中。
- 云存档、游戏时长和底部启动按钮继续由当前平台驱动。

### 6. “我的”页 GOG 个人信息卡

来源：用户提供 `codex-clipboard-e45412db-a1f7-4b9b-aebc-d357686c932c.png` 并明确修订字段范围。

保留页面级 Steam / EPIC / GOG 平台 Tab，只对 `platform==='gog'` 的已绑定卡使用独立结构：

1. 第一行：左侧标题固定为`GOG个人信息`，右侧为现有三个点菜单。
2. 第二行：只展示 GOG 官方头像和昵称 `GalaxyRider`。
3. 第三行：两列统计，左侧`游玩时长 / 438 小时`，右侧`游戏数量 / 126`。

GOG 卡不得展示：

- GOG ID 字段、标签或数值。
- `今天 14:32`等同步时间。
- 账号价值及其占位。

三个点菜单中的更新数据、切换账号和退出账号行为保持不变；Steam、EPIC 已绑定卡结构不修改。

## 冲突裁决

### CR-GOG-017-01：退出确认视觉

- 证据 A：当前 Demo 使用账号卡内嵌确认区或无完整遮罩。
- 证据 B：用户明确提供现有 Steam 退出确认组件并要求复用。
- 采用：证据 B，只替换平台名为 GOG。
- 废弃：重新设计的红色危险弹窗和账号卡内嵌确认。
- 影响：我的页、GOG 账号库横竖屏。
- 置信度：高。

### CR-GOG-017-02：GOG 图标

- 证据 A：当前 GOG.com 全字标尺寸约束导致小尺寸呈现为竖向碎块。
- 证据 B：用户在官方 GOG Galaxy 与 GOG.com 对照中选择 GOG.com 方形全字标 B。
- 采用：证据 B，保留同一资源并按场景等比缩放。
- 废弃：GOG Galaxy 标识和临时字母图标。
- 影响：我的页为本期必改；其他复用点统一受益但不改变布局。
- 置信度：高。

### CR-GOG-017-03：详情页平台入口位置

- 证据 A：当前平台图标位于 PC 游戏引擎卡底部，且不可点击；另有重复平台弹层。
- 证据 B：用户明确要求三个游戏平台切换位于类型标签之前。
- 采用：证据 B，前移为弹窗触发按钮；在纵向选择弹窗中确认平台后再切换。
- 废弃：图标直接切换、引擎卡底部重复入口和旧三列弹层。
- 影响：详情页横竖屏。
- 置信度：高。

### CR-GOG-017-04：右上角切换账号行为

- 证据 A：当前 Demo 点击右上角入口后直接进入授权登录。
- 证据 B：用户明确指出入口是`切换账号`，并提供账号选择弹窗来源图。
- 采用：证据 B，先展示当前账号与“+”新凭证入口。
- 废弃：右上角直接登录和新增独立账号管理页。
- 影响：GOG 账号库横竖屏。
- 置信度：高。

### CR-GOG-017-05：GOG 个人信息字段

- 证据 A：当前卡片显示 GOG ID、游戏数、总时长和同步时间。
- 证据 B：用户明确要求只保留头像、昵称、游玩时长和游戏数量。
- 采用：证据 B，移除 GOG ID、同步时间和账号价值，只重排 GOG 卡。
- 废弃：把 GOG ID 移到昵称下方、修改 Steam/EPIC 卡或新增独立个人信息页面。
- 影响：“我的”页 GOG 已绑定卡。
- 置信度：高。

## 状态与异常

- 退出确认：打开、取消、关闭、确认四条路径。
- GOG 图标：Tab、账号头像、入口、角标、详情和启动按钮尺寸变体。
- 账号切换：打开、关闭、选择当前账号、点击“+”进入授权、授权取消/失败/成功。
- 平台切换：点击三个入口只打开弹窗；关闭不改平台；选择选项后才切换。默认 Steam > EPIC > GOG 优先级；从平台游戏库进入时优先来源平台；不可用来源保留原错误说明。
- GOG 无评分继续显示`暂无评分`，不显示 `0`。
- 切换平台不新增 Toast，不修改账号绑定状态。
- 账号选择、平台选择和退出确认不能同时出现，切页后不保留弹窗状态。
- GOG 个人信息卡仅显示标题、头像、昵称、游玩时长和游戏数量；刷新状态可以显示临时进度文案，但不得恢复同步时间字段。
