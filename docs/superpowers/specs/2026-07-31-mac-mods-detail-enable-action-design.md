# Mac MODS 详情启用操作视觉优化设计

## 目标

解决 MOD 详情底部启用状态控件与“检查更新、卸载”按钮在尺寸、文字层级和点击反馈上的割裂感，同时保持设备级启用状态、失败回滚和跨页面同步逻辑不变。

## 方案比较

1. 仅放大现有控件：改动最小，但整块看似按钮、实际只有右侧小开关可点击，会产生误触预期。
2. 整颗胶囊作为开关：与相邻操作等高、等宽、同圆角，整块可点击并获得统一焦点反馈；按钮背景色直接表达状态。采用此方案。
3. 去掉胶囊，只保留文字与裸开关：状态语义清晰，但不能解决底部三项操作风格不统一的问题。

## 视觉与交互

- 详情底栏三项操作等分宽度，统一为 72px 高、36px 圆角。
- 启用操作使用与相邻操作一致的 24px/600 文字和胶囊结构，不显示内部滑块。
- 文案使用“已启用/已停用”；已启用为绿色背景，已停用为灰色背景。
- 整颗启用胶囊使用原生 `button` 与 `role="switch"`，点击任意位置都切换状态；键盘焦点落在整颗胶囊上。
- 请求期间整颗胶囊禁用，成功、失败回滚、Toast 和三处状态同步逻辑保持不变。
- 浏览列表与已安装列表中的紧凑型小开关不改。

## 状态与异常

- 已安装、可更新和更新失败详情都使用同一详情启用按钮。
- 启用态为绿色按钮，停用态为灰色按钮；文字、背景色与 `aria-checked` 同步。
- 请求失败后恢复操作前状态并提示，不因视觉改造改变状态机。

## 验证

- 自动断言详情启用按钮与“检查更新、卸载”等高、近似等宽。
- 自动断言详情启用按钮自身承担 `role="switch"`，不存在嵌套按钮。
- 复跑启用、停用、失败回滚和跨页面同步用例。
- 重新生成详情截图，检查三项操作对齐、文字层级和启停背景色。
