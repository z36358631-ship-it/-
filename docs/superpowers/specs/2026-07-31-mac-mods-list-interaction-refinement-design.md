# Mac MODS 列表交互精修设计

- 日期：2026-07-31
- 状态：用户已通过明确修改指令确认
- 范围：仅修改 `demos/Mod与发行人/Mod功能Mac端demo.html`

## 1. 目标

在现有 MODS 内容发现 Demo 上收敛操作层级，使列表更接近创意工坊的浏览体验：

1. 点击卡片任意非操作区域进入 MOD 详情。
2. 移除“详情”按钮。
3. 未安装 MOD 的“安装”按钮固定在卡片右下角。
4. 已安装 MOD 在浏览 Tab 中使用非交互“已安装”状态，不制造无反馈按钮。
5. 已安装 Tab 不提供排序，固定按最近安装排列，仅保留状态筛选。
6. 浏览排序由下拉框改为四个平铺选项。
7. 游戏详情 MODS 模块副标题精简为“热门推荐”。

## 2. 卡片交互

卡片本体不嵌套交互角色，而是在卡片内部增加一个覆盖整卡的透明按钮：

```html
<button
  class="mod-card-hit-area"
  data-action="open-detail"
  data-mod-id="..."
  aria-label="查看……详情">
</button>
```

内容层不拦截点击；右下角安装按钮位于更高层级：

```html
<button
  class="install-button"
  data-action="install"
  data-mod-id="...">
  安装
</button>
```

因此：

- 鼠标点击卡片打开详情。
- `Tab` 可聚焦整卡透明按钮。
- `Enter` 或 `Space` 由原生按钮行为打开详情。
- 点击安装按钮只发起安装，不会打开详情。
- 已安装浏览卡右下角显示非交互“已安装”状态。
- 已安装 Tab 通过整卡点击进入管理详情，不再显示冗余详情或管理按钮。

## 3. 排序与筛选

浏览 Tab 显示四个平铺排序按钮：

```text
热门推荐 / 下载量 / 最近更新 / 名称
```

点击后继续派发已有 `SET_BROWSE_SORT`，不改变状态模型和排序算法。

已安装 Tab：

- 不渲染排序控件。
- 固定使用现有 `recent` 比较器。
- 保留“全部 / 已启用 / 未启用 / 可更新”四个筛选按钮。

## 4. 详情页 MODS 模块标题

标题区调整为：

```text
MODS  [非官方]
热门推荐
```

右侧继续显示 `128 个 MOD / 查看全部`。移除副标题中的安装数量和“仅此设备”，这些状态继续在 MODS 列表、已安装 Tab 和详情页表达。

## 5. 验收

- 8 张浏览卡均存在整卡详情按钮。
- 卡片不再出现“详情”按钮。
- 未安装卡右下角存在安装按钮；已安装浏览卡右下角为非交互状态。
- 安装按钮点击不会打开详情；整卡点击可打开并关闭详情。
- 浏览排序四项均平铺且排序结果正确。
- 已安装 Tab 无排序控件，四个筛选仍可用。
- MODS 模块副标题只有“热门推荐”，标题旁存在“非官方”标签。
- 既有 23 项发现页合同、17 项参考合同、DOM 点击流和 Mac 静态合同通过。

## 6. 三视角快速审查

- 用户视角：整卡详情和右下角安装符合内容浏览习惯，平铺排序比下拉更易发现。
- 开发视角：透明原生按钮避免手写键盘模拟和嵌套交互角色，安装按钮通过层级自然隔离。
- 商业视角：不增加新业务能力，只降低操作成本和界面噪音，改动范围可控。
