# 暗黑系列首发适配落地页移除运营活动设计

## 目标

将首发适配落地页 Demo 调整为“即将支持”预热页：移除运营活动展示与跳转，保留独立运营活动 Demo 供后续正式支持阶段使用。

## 方案

- 删除落地页的“游玩活动”Tab、活动面板、奖品卡片和进入活动按钮。
- 清理活动相关 JavaScript 数据、渲染函数、跳转地址与事件监听，避免残留报错。
- 将弹窗 CTA 从“立即参与”改为“查看适配进度”，与预热定位一致。
- 删除 FAQ 中关于参加活动的问题，避免对外产生“当前可参加活动”的误解。
- 不修改独立的 `暗黑系列运营活动demo.html`。

## 验收

- 落地页只保留推荐配置、启动方法、常见问题三个 Tab。
- 页面源码不再引用 `activityUrl`、`openActivity`、`renderActivity` 或活动面板选择器。
- 弹窗 CTA 不再使用“立即参与”。
- 独立运营活动 Demo 文件保持可访问。
