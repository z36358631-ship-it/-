# 盖世游戏 Mac 租号权益、会员与地区外放调整设计

## 一、背景

现有租号方案将多个地区配置在同一条外放策略中，无法分别控制开关、灰度和回滚；前台仅区分首次体验、单游戏永久版和月度会员，不能覆盖热门游戏仅开放时租、会员游戏库独立准入及多周期会员套餐。

本次统一调整租号权益、会员中心、个人中心、会员游戏库后台和地区外放后台，并保留既有订单、售后、账号回收及安全规则。

## 二、目标

1. 每款游戏可独立配置时租、单游戏永久版和会员免费玩。
2. 时租可重复购买，使用后台配置的固定时长和价格。
3. 单游戏永久版按 Steam 原价的1.6–5折浮动。
4. 会员只可免费玩运营加入会员游戏库的游戏。
5. 提供永久、年度、月度三个会员 SKU，并在个人中心展示会员身份和权益。
6. 不同地区使用独立外放策略，可分别新增、启停、灰度和回滚。

## 三、范围边界

### 3.1 本期包含

- Mac 客户端确认订单、会员中心和个人中心。
- 租号运营后台商品权益管理、会员游戏库管理、会员套餐管理和地区外放策略管理。
- 时租、单游戏永久版、会员权益的服务端判定、价格快照、订单幂等和账号分配校验。
- 会员手动续费、升级和到期状态。
- 前后台 Demo、PRD、埋点及截图同步更新。

### 3.2 本期不包含

- 会员自动续费。
- 月度或年度会员剩余价值抵扣永久会员价格。
- 会员权益转赠、共享或退款。
- 用户自主选择时租时长。
- 未加入会员游戏库的游戏使用会员权益取号。

## 四、术语

|术语|定义|
|---|---|
|时租|当前游戏的限时使用权，可重复购买；时长和价格由后台按游戏及版本配置|
|单游戏永久版|当前游戏及版本的长期使用权，不代表永久独占账号|
|永久会员|会员身份永久有效，可玩会员游戏库中的游戏|
|会员免费玩|有效会员对会员游戏库内游戏发起的 ¥0 使用单|
|会员游戏库|运营明确加入并启用会员权益的游戏及版本集合|
|地区策略|针对一个地区独立配置的租号功能开关、灰度比例和灰度轮次|

## 五、C端设计

### 5.1 确认订单

“获取方式”显示时租、单游戏永久版、会员免费玩三个 Tab，服务端按游戏配置和用户权益返回状态。

|获取方式|可用条件|展示与操作|
|---|---|---|
|时租|后台已启用时租且当前版本存在可售配置|显示固定时长、价格和“可重复购买”；支付后创建限时使用单|
|单游戏永久版|后台已启用永久版且售价通过折扣校验|显示 Steam 原价、永久版价格和折扣；支付后发放当前游戏及版本的永久权益|
|会员免费玩：有效会员|游戏及版本已加入会员游戏库、会员有效且存在可用账号|订单金额显示 ¥0，按钮为“会员免费玩”；点击后直接创建会员使用单，不显示支付方式|
|会员免费玩：未开会员|游戏及版本已加入会员游戏库|显示会员权益说明和“开通会员”；点击进入独立会员中心|
|会员免费玩：未入库|游戏或当前版本未加入会员游戏库|Tab 保留但置灰，提示“暂未加入会员游戏库”，不可取号|

后台可将 GTA6 等热门游戏配置为“仅时租”。此类游戏不展示单游戏永久版入口；会员免费玩 Tab 保留置灰，即使用户已是会员也不能使用。

### 5.2 会员中心（独立 Tab）

会员开通使用独立业务 Tab，不与单游戏订单合并支付。确认订单和个人中心均可进入。

|SKU|试运营价|有效期|说明|
|---|---:|---|---|
|永久会员|¥399|永久有效|试运营限时价格，开通后不再展示其他会员购买入口|
|年度会员|¥499|365天|手动购买，到期前提醒续费|
|月度会员|¥129|30天|手动购买，到期前提醒续费|

三个 SKU 的名称、文案、试运营价、原价、试运营标识、排序、上下架状态均由后台配置。后台修改后立即影响新创建的订单；已支付订单继续按订单快照履约。

试运营阶段不提供自动续费，不保存自动扣款授权。永久会员价格低于年度会员属于试运营价格策略，年度会员预计转化较低，需要单独监控各 SKU 的曝光、点击和支付数据。

### 5.3 会员续费与升级

|当前会员|购买SKU|结果|
|---|---|---|
|无会员或已过期|月度/年度/永久|从支付成功时间开始生效|
|月度|月度|从当前到期时间顺延30天|
|月度|年度|保留剩余月度时长，到期后顺延365天|
|年度|年度|从当前到期时间顺延365天|
|月度或年度|永久|支付成功后立即变为永久会员；剩余时长不折现、不退款|
|永久|任意SKU|不允许再次购买，不展示购买按钮|

会员套餐均为手动购买，不存在降级、下周期自动切换或自动扣款。

### 5.4 个人中心

个人中心顶部增加会员卡片：

- 展示会员身份、当前 SKU、开通时间和到期时间。
- 永久会员显示“永久有效”。
- 展示“会员游戏免费玩、会员游戏库持续更新”两项核心权益。
- 有效月度或年度会员显示“续费/升级”，永久会员不显示购买入口。
- 提供“查看会员游戏”，进入会员中心的会员游戏库。
- 已过期时保留历史身份和到期时间，显示“重新开通”。
- 点击会员卡片进入独立会员中心，查看完整权益、会员游戏库和可购 SKU。

### 5.5 会员游戏使用

- 同一会员同一时间最多存在一个有效会员使用单和一个占用账号。
- 切换会员游戏时，先结束原使用单、撤销会话并回收凭据，再为新游戏分配账号。
- 旧账号回收失败时不得占用第二个账号。
- 游戏被移出会员游戏库后，不允许后续新取号；已开始且仍有效的使用单继续履约至本次结束。
- 会员到期后不能新启动；正在使用的会员会话按到期规则结束并释放账号。

## 六、B端设计

### 6.1 商品权益管理

每个游戏及版本独立配置：

|配置项|规则|
|---|---|
|时租开关|开启后才展示时租；关闭只阻止新订单|
|时租时长|固定正整数时长，用户不可修改|
|时租价格|固定售价，用户可重复购买|
|单游戏永久版开关|开启后才展示永久版|
|Steam 原价|记录原价、币种和更新时间|
|单游戏永久版售价|运营直接输入，系统实时计算折扣|
|永久版折扣校验|售价必须处于 Steam 原价的1.6–5折，超出范围禁止保存|
|会员游戏库状态|只读展示是否已加入会员库，并提供快捷跳转|

商品可配置为仅时租、时租加永久版、时租加会员、三种权益同时开放。会员游戏库资格只由会员游戏库管理页维护。

### 6.2 会员游戏库管理

租号运营后台新增独立 Tab“会员游戏库管理”。

- 支持按游戏名、Steam AppID、版本和状态筛选。
- 支持单个或批量加入会员库、移出会员库、启用和停用。
- 加入时选择支持的游戏版本并校验可用账号库存。
- 同一游戏及版本在会员库中只能存在一条有效记录。
- 移出或停用前展示影响范围并二次确认。
- 列表展示游戏、版本、状态、可用库存、加入时间、更新人和更新时间。
- 所有写操作记录操作人、原因、前后值、配置版本和结果。

### 6.3 会员套餐管理

新增永久、年度、月度三个固定类型的 SKU 配置。

- 支持配置名称、权益文案、原价、现价、试运营标识、排序和状态。
- SKU 类型和有效期创建后不可修改。
- 改价、上下架和权益文案变更需要二次确认，保存成功后立即影响新订单。
- 配置保存生成新版本，支持查看历史版本和回滚。
- 后台价格变化只影响新订单，不改变已支付会员的有效期和权益。
- 不提供自动续费配置。

### 6.4 地区外放策略管理

“租号外放设置”改为独立列表页，不再使用多地区共用一条配置的弹窗。

|列表字段|说明|
|---|---|
|策略ID|每条地区策略的唯一标识|
|地区|一个地区一条配置，不允许重复|
|状态|独立启用或关闭|
|灰度比例|20%、50%、100%或1–100自定义整数|
|灰度轮次|控制稳定分桶；只调整比例时不更换|
|配置版本|每次保存生成新版本|
|更新人/更新时间|记录最后一次操作|
|操作|编辑、查看记录|

页面右上角提供“新增地区策略”。新增或编辑弹窗只选择一个地区。

- 中国大陆、美国为精确地区策略。
- “其他海外”为排除中国大陆、美国及后续单独配置国家后的兜底策略，匹配优先级最低。
- 未配置地区默认不外放。
- 开关变更需要二次确认；停用记录保留，不提供直接删除。
- 保存携带配置版本，版本不一致时拒绝覆盖并提示刷新。
- 缩量、关闭或移除地区只影响新曝光、新订单和新取号；已支付权益和进行中的使用单继续履约。

## 七、服务端规则

### 7.1 权益与商品校验

浏览、创建订单、提交支付和取号四个节点均由服务端重新校验：

- 游戏及版本支持的获取方式。
- 时租或单游戏永久版是否启用。
- 会员是否有效、游戏版本是否在会员库。
- 当前价格版本和订单价格快照。
- 可用账号库存及账号履约能力。
- 用户所在地区和地区策略命中结果。

客户端只展示服务端结果，不自行计算折扣、会员资格或外放资格。

### 7.2 订单价格快照

创建订单时保存：

- 权益类型、游戏、版本和时租时长。
- Steam 原价、币种、更新时间和来源。
- 时租价格、单游戏永久版价格、折扣结果。
- 会员 SKU、会员价格和有效期。
- 商品价格版本、会员套餐版本和地区策略版本。

支付回调按订单快照结算。后台改价、文案变更、会员库调整和地区策略变化不得修改已支付订单。

### 7.3 幂等与资源一致性

- 创单、支付回调、会员取号和账号分配使用唯一操作号。
- 重复请求返回首次结果，不重复扣款或重复占用账号。
- 支付成功但资源仍在分配时继续履约；最终无资源则自动退款。
- 账号分配、会话撤销、凭据轮换和资源释放沿用现有安全规则。

### 7.4 地区与灰度

- 地区以服务端账号地区结果为准，客户端和 IP 不能覆盖。
- 登录、客户端回前台、进入交易页、提交支付和新取号前刷新地区策略。
- 稳定桶按“用户ID + 地区策略ID + 灰度轮次”计算。
- 同一灰度轮次扩大或缩小比例不重新分桶。
- 精确地区策略优先于“其他海外”兜底策略。

## 八、异常处理

|场景|处理|
|---|---|
|时租或永久版配置失效|隐藏或禁用对应获取方式，不影响已支付订单|
|Steam 原价缺失或永久版折扣超限|后台禁止保存或上架永久版|
|会员有效但游戏未入库|会员免费玩 Tab 置灰，不允许取号|
|会员游戏库移出游戏|阻止新取号，进行中的使用单继续履约|
|会员价格修改|新订单使用新价格，历史订单保持原快照|
|地区策略未配置或未命中|隐藏租号曝光并阻止新交易；既有权益继续履约|
|地区策略并发修改|拒绝旧版本保存，要求刷新后重试|
|会员升级永久时重复回调|只发放一次永久会员权益|
|会员到期|阻止新启动，进行中会话按到期规则回收|

## 九、数据关注

- 时租重复购买率、平均购买次数和时租收入。
- 单游戏永久版按游戏热度、折扣区间的支付转化率。
- 会员免费玩 Tab 曝光、置灰、开通会员和会员取号转化。
- 永久、年度、月度三个 SKU 的曝光、点击、支付和升级分布。
- 个人中心会员卡点击率、续费率和升级永久率。
- 会员游戏库覆盖游戏数、会员取号成功率和账号使用率。
- 各地区策略命中率、新交易拦截量和既有权益保护量。

## 十、Demo 与 PRD 交付约束

- Demo 需要覆盖确认订单三种获取方式、仅时租游戏、会员免费玩置灰、会员中心三个 SKU、个人中心会员卡、会员游戏库管理、会员套餐管理和地区策略列表。
- 所有页面和弹窗必须可实际点击，覆盖新增、编辑、开关、购买、续费、升级和异常状态。
- PRD 保留 C 端一张汇总大表、B 端一张汇总大表。
- 飞书图示单元格最多放2张图；图片较多的模块拆成同一大表内的连续行。
- 修改前已验证可导入的图片继续使用原固定 Git 提交地址；新增截图使用实际包含图片的固定提交地址。
- 全部图片逐张验证 HTTP 200 和正确的 Content-Type 后才可交付。

## 十一、方案评审结论

|视角|结论|处理结果|
|---|---|---|
|用户体验|通过|会员未入库保留置灰提示；个人中心提供会员身份、到期和权益入口；不启用自动续费|
|开发实现|通过|补充价格与权益快照、四节点服务端校验、操作幂等、稳定分桶和配置乐观锁|
|商业运营|通过|三个 SKU 明确为试运营价；价格和文案后台控制；改价只影响新订单；配置支持确认、版本和回滚|

年度会员 ¥499 高于试运营永久会员 ¥399，预计年度 SKU 转化较低。本期按已确认的试运营价格执行，通过 SKU 数据决定后续正式价格。

## 十二、已确认决策

- 时租可重复购买，使用固定时长和价格。
- 单游戏永久版售价由运营输入，系统校验为 Steam 原价的1.6–5折。
- 未加入会员游戏库的游戏保留置灰“会员免费玩”Tab。
- 永久、年度、月度会员均为试运营 SKU，价格和文案后台即时控制。
- 试运营阶段不支持自动续费。
- 个人中心展示会员身份、到期时间和会员权益。
- 月度、年度续费顺延；升级永久立即生效，剩余时长不折现、不退款。
- 地区外放使用一地区一策略的独立列表。
- 本设计无待确认项。
