# APP租号PRD竖屏产品流程图设计

## 目标

仅重做《盖世游戏APP》游戏租号需求的“2.2 产品流程”图片。7个流程节点全部直接使用现有APP竖屏页面截图，第一排4张、第二排3张；2.1及其他正文、页面规则与业务状态不变。

## 版式

- 输出一张横向合成PNG，第一排依次为01—04，第二排依次为05—07。
- 每个节点展示完整竖屏截图，不再截取横向局部；截图保持原始宽高比，不拉伸。
- 每张卡保留两位序号、短标题和一句结果说明；通过减少卡片留白、加高画布保证竖屏截图尺寸。
- 01—04、05—07分别使用水平箭头连接；04通过折返箭头连接05。
- 07继续标注“按需”，底部异常恢复文案保持不变。

## 流程节点

1. 发现租号：展示租号价格与当前权益。
2. 游戏详情：核验权益和商品可售状态。
3. 选择权益：选择首次体验、单游戏永久或开会员畅玩。
4. 确认并支付：核对订单金额和支付方式后购买。
5. 权益生效：支付成功后计时或发放权益。
6. 登录与启动：登录成功后进入详情下载或启动。
7. 订单管理／续租／售后（按需）：查看有效期、续租和售后进度。

## 验收

- 7张截图均为完整竖屏图，排布为4＋3。
- 截图不变形、不横向裁切，标题、顺序和箭头无歧义。
- PRD只更新修订记录与2.2图片固定提交SHA，其他正文不变。
- 最终ZIP内Markdown与源PRD一致；PRD质量、图片公网地址和远端提交校验通过。
