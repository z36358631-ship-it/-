# Mac 安装路径左侧对齐调整设计

## 问题

安装位置收起态中，文件夹图标跨两行居中，导致图标低于路径文字，左侧信息看起来不属于同一组。

## 方案

1. 文件夹图标只占第一行，与路径文字垂直居中。
2. 路径与“可用空间”在第一行按文字基线对齐。
3. “安装到其他位置”继续独占第二行并右对齐。
4. 路径、容量、操作提示和箭头仍共用同一个下拉点击区域，不改变交互。

## 验证

- 图标中心与第一行路径文字中心的垂直偏差不超过 1 px。
- 路径和容量不重叠，超长路径仍可截断。
- 第二行操作提示保持右对齐。
- 点击控件任意位置仍打开同一下拉菜单。

## 范围

仅调整安装位置收起态的左侧对齐，不改文案、弹窗尺寸、路径选择规则、安装流程或其他页面。
