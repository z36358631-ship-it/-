# 开发者后台 Demo 06 国内发行准备设计

## 1. 目标与范围

在不改变“一期以国内厂商面向海外发行”为主线的前提下，为 Demo 06 预埋中国大陆发行资质、国家／地区级发行范围和对应门禁，避免未来增加大陆发行能力时重做资质数据结构和发行申请流程。

本次只修改 `06-游戏商品资料与发行范围demo.html` 及其源文件，不修改 Demo 01、其他 Demo 或 PRD。

## 2. 核心业务口径

1. 厂商主体地区与游戏发行地区是两个独立维度。国内厂商面向海外发行时，不要求中国大陆版号。
2. 无版号游戏可以维护资料、上传包体、进行平台允许的受控测试并申请海外发行；不得因为厂商位于国内而阻断海外流程。
3. 中国大陆一旦进入本次正式发行范围，必须启用大陆发行资质门禁。免费公开获取不因“不收费”自动绕过门禁。
4. 网络下载的 PC 单机游戏同样进入大陆网络游戏出版审批判断范围。
5. 软件著作权是权属证明之一，不等同于版号，也不是国产游戏唯一可接受的权属证明。
6. 已有版号不能自动放行，仍需校验批准游戏名称、申报类别、出版单位、运营单位、批复文号及当前平台角色。
7. 游戏名称、申报类别、出版或运营主体发生变化时，必须转人工复核；系统不得自行判断原审批结果继续有效。

## 3. 页面框架

### 3.1 导航与默认入口

- 保留单游戏工作台、面包屑和现有一级导航。
- 点击游戏卡片后默认进入“概览”，不再直接进入“游戏资料”。
- 将“商店管理”更名为“发行准备”，其下保留：游戏资料、游戏资质、商品与 SKU、发行范围。
- 游戏运营、游戏服务、数据分析继续保持独立一级入口。

### 3.2 游戏资质页

页面分为两个独立区块：

1. **权属与授权**：所有游戏都必须维护。支持自研和代理发行两种模式。
2. **中国大陆发行资质**：长期保留但默认折叠；不计划大陆发行时不增加海外发行填写负担。

中国大陆发行状态固定为：

- 暂不在中国大陆发行
- 准备中／尚未取得版号
- 版号申请中
- 已取得版号
- 变更审批中
- 审批信息异常

选择“已取得版号”时展示并校验：批准游戏名称、申报类别、批复文号、ISBN、出版单位、运营单位、批准日期和证明文件。申报类别必须可以表达“客户端”。

国产游戏的权属证明类型支持：软件著作权登记证书、相关公证、自我声明／承诺；进口游戏展示著作权合同登记批复及境外授权链字段。Demo 只表达材料和人工复核状态，不建设自动法务审批。

### 3.3 发行范围页

- 国家／地区改为可搜索多选，不再使用北美、欧洲、东南亚等粗粒度大区作为最终保存值。
- 底层使用稳定国家／地区编码；中文名称只负责展示。
- 顶部提供“常用市场”，取用户提供的 APP 与 Mac 活跃国家并集；其他国家／地区可通过搜索添加。
- 中国大陆、中国香港、中国台湾分别作为商业地区管理；只有中国大陆触发大陆出版审批门禁。
- “全球发行”统一表达为“全球（不含中国大陆及受限制国家／地区）”。

常用市场包含：美国、中国大陆、俄罗斯、法国、德国、日本、印度、中国香港、英国、印度尼西亚、泰国、澳大利亚、加拿大、巴西、土耳其、菲律宾、中国台湾、新加坡、荷兰、意大利、墨西哥、伊拉克、巴基斯坦、哥伦比亚、埃及、阿尔及利亚、阿根廷、越南、委内瑞拉。

国家选择器采用弹窗：顶部搜索，中部展示常用市场和搜索结果，底部固定显示已选数量、取消和确认按钮。已选国家以标签摘要展示，数量较多时收敛为“已选 N 个国家／地区”。

## 4. 门禁与状态流转

海外发行门禁继续检查企业认证、线下合作、权属授权、游戏资料、SKU、发行范围、Build 和价格，不检查中国大陆版号。

当发行范围包含中国大陆时，正式发行申请额外检查：

1. 大陆发行状态为“已取得版号”；
2. 批准游戏名称与当前提交对象一致；
3. 申报类别覆盖客户端；
4. 出版单位、运营单位和当前平台角色已由人工确认；
5. 国产／进口对应的权属材料完整；
6. 当前提交版本没有处于变更审批或异常状态。

不满足时，中国大陆进入“准备中”，并阻断大陆公开发行、公开获取和面向大陆渠道的新 Key 分配；其他已选海外国家仍可形成独立海外发行申请。Demo 中明确展示“大陆范围未通过不影响海外发行”，避免开发者误解为整个游戏不可发行。

## 5. 授权范围预埋

代理发行材料不能只记录一份授权文件，Demo 摘要至少表达以下覆盖关系：

- 原始权利人、直接授权方、被授权主体；
- Product／SKU；
- Windows、macOS、Linux；
- 国家／地区；
- 自营商城、合作渠道、渠道 API；
- 直接下载、盖世 Key 生成与分配；
- 授权生效和到期时间；
- 是否允许转授权；
- 音乐、美术、字体、商标、人物形象等第三方内容权利声明。

授权到期、撤销或范围不匹配时停止新增销售、发布和 Key 分配，保留历史审核、交付和兑换记录。

## 6. 人工复核边界

- 页面按钮使用“提交平台人工复核”，不使用会暗示自动审批的文案。
- 结果记录包含：材料版本、复核状态、复核来源、复核人、结论时间、补充／拒绝原因和证据引用。
- 状态覆盖草稿、待人工复核、待补充、已通过、不通过、已过期、已撤销、范围不匹配。
- 一期不建设合同自动审核、版号真伪自动判断或监管系统接口。

## 7. 交互演示要求

1. 自研／代理切换可动态显示对应权属材料。
2. 大陆发行状态切换可展示无版号、申请中和已有版号字段。
3. 国家／地区选择器支持搜索、常用市场多选、清空和确认。
4. 添加或移除中国大陆后，资质页和发行申请门禁立即同步。
5. 海外范围可以在无版号状态下提交；包含中国大陆且资质不满足时，明确显示大陆缺项及海外继续提交路径。
6. 编辑草稿不覆盖已经生成的发行审核快照。

## 8. 验收标准

- 页面可离线打开，不新增外部运行依赖。
- 点击游戏卡片默认进入概览。
- “发行准备”导航层级、面包屑和页面标题一致。
- 国家／地区选择器在常用市场和搜索结果中不会重复选择同一编码。
- 中国大陆与中国香港、中国台湾的门禁判断相互独立。
- 无版号且仅选择海外国家时，正式发行门禁不因版号失败。
- 选择中国大陆但无有效版号时，大陆正式发行不能通过，海外发行仍可继续。
- 已有版号示例完整展示名称、客户端类别、出版单位、运营单位、批复文号、ISBN和证明文件。
- JavaScript 语法检查通过，关键交互无控制台错误，宽屏与窄屏无横向溢出。

## 9. 依据

- 国家新闻出版署《出版国产网络游戏作品审批》：客户端、网页和网络下载单机游戏均纳入对应申报；国产游戏著作权证明可使用登记证书、公证或自我声明。
- 国家新闻出版署《出版境外著作权人授权的互联网游戏作品审批》：进口游戏涉及著作权合同登记批复和境外授权链。
- 国家新闻出版署游戏审批变更公示：游戏名称、申报类别、出版单位、运营单位和版本变化均可能形成变更事项。
- 《计算机软件保护条例》第七条：软件登记证明是登记事项的初步证明。
