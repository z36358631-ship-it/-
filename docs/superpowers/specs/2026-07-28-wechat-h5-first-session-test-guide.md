# 微信 H5 精品游戏三款首局无引导测试手册

## 1. 研究目标

验证首次接触的目标用户能否在没有口头教学的情况下：

1. 十秒内完成首次有效操作。
2. 说明操作与画面结果的因果。
3. 有意完成首次核心机制，而非偶然触发。
4. 在高潮前说出这一局的核心取舍。
5. 理解胜负原因并独立找到重玩入口。

本测试用于发现理解和交互硬伤，不用于证明市场规模、长期留存或商业化能力。

## 2. 样本

- 总人数：首轮 10 人。
- 地区：中国大陆。
- 设备：参与者自己的 iOS/Android 微信常用手机。
- 游戏经验：
    - 高频手游用户 3–4 人。
    - 低频或轻度游戏用户 3–4 人。
    - 介于两者之间 2–4 人。
- 可访问性覆盖：尽量包含大字号使用者、色觉差异者或轻度精细动作困难者。
- 三款游戏顺序使用拉丁方轮换，避免所有人都按同一顺序产生学习和疲劳偏差。

样本只有 10 人，结果报告使用“X/10”和具体行为证据，不把比例外推为总体结论。

## 3. 测试环境

- 使用真实微信 `web-view` 测试包，不使用桌面浏览器代替。
- 开启真机录屏，记录触控点、画面和声音。
- 记录设备型号、系统版本、微信版本、屏幕字号和网络状态。
- 每款游戏从全新本地状态开始。
- 测试员不解释玩法，不代替点击，不使用“你应该……”类引导。
- 遇到程序错误只记录现象；除非无法继续，不现场修复或换测试路径。

### 3.1 知情同意与数据治理

- 测试前用口头和书面方式说明：研究目的、预计时长、将录制的画面/触控/声音、用途、保存期限和退出权利。
- 参与者明确同意后才开始录屏；不同意录音者只保留去声画面和观察笔记。
- 参与者可随时暂停或退出，无需说明原因；退出不影响约定激励。
- 研究文件只使用 `P01–P10` 编号，不在文件名、转写稿或报告中保存姓名、微信号、手机号、头像、聊天消息和通知内容。
- 开启勿扰模式；录屏中意外出现个人通知时，交付报告前必须裁切或打码。
- 原始录屏、音频和逐字稿仅向项目研究成员开放，使用受控目录保存；默认 90 天后删除。需要延长保存时，重新记录目的、期限和负责人。
- 汇总报告保留匿名行为证据与必要截图，不附可识别参与者身份的信息。
- 删除清单由研究负责人复核，记录删除日期；参与者在保存期内提出删除请求时，按编号删除对应原始材料。

## 4. 主持词

开场只说：

> 接下来请你试玩三款约三分钟的小游戏。请像平时自己打开一款新游戏一样操作。过程中可以把你看到的、认为要做的和困惑的地方说出来。我不会告诉你怎么玩，因为我们想检查游戏自己有没有讲清楚。这里没有对错，出现问题是产品的问题。

每款开始前只说：

> 现在请打开这款游戏并开始。

除非参与者连续 20 秒无操作且明确表示无法继续，否则不追加提示。若必须救场，记录救场时间和原话，该局不计为“无引导完成”。

## 5. 共通观察记录

| 观察项 | 记录方式 |
|---|---|
| 开始按钮停留 | 从页面可操作到点击开始的秒数 |
| 首次有效输入 | 从进入玩法到产生有效移动/缝合的秒数 |
| 十秒因果解释 | 原话记录；判断是否准确 |
| 首次核心机制 | 有意完成 / 偶然完成 / 未完成 |
| 连续无操作 | 任意连续 ≥10 秒的时段和当时画面 |
| 重复错误 | 同类错误连续发生次数及错误原因 |
| 高潮取舍 | 玩家能否在选择前说明利弊 |
| 结算理解 | 能否说出胜负原因和损失 |
| 重玩发现 | 结算后 5 秒内是否独立找到入口 |
| 主动二局 | 是否主动点击；若未点击，记录原因 |

## 6. 《五秒之后》观察题

测试中只观察，不提问：

- 首次有效拖动发生在第几秒。
- 玩家是否能指出哪个标记是“现在的我”。
- 第一条回声出现后，是否自发说出“它在重复我刚才的路线”。
- A/B 阶段是提前规划一条停留路线，还是反复拖当前角色试错。
- 编号门阶段是否知道正在录制哪一号回声。
- 当前角色穿门无效后，能否根据反馈修正理解。

结算后追问：

1. 刚才的回声在做什么？
2. A/B 两个机关为什么会成功或失败？
3. Ⅰ、Ⅱ、Ⅲ、Ⅳ号门应该由谁打开？
4. 这局为什么赢了或输了？
5. 如果再玩一次，你会先改哪一步？

通过信号：

- 至少 8/10 能无口头提示完成一段有明显位移的五秒轨迹，并准确指出第一条回声正在重复这段路线；静止后自动计时或偶然生成不计为通过。
- 至少 6/10 能解释“当前五秒会成为下一条编号回声”。
- 至少 5/10 主动重玩或明确要求再玩。

## 7. 《世界缝补师》观察题

测试中只观察，不提问：

- 玩家第一次依据虚线、距离、颜色还是猜测判断锚点匹配。
- 第一次缝合后，是否注意到线长扣除、土地复色和生命通行。
- 花掉第三笔线长前，能否说出胜利条件。
- 是否主动为花园保留 76cm。
- 是否理解只能选择三条外围救援路线。
- 完成线路选择后是否出现连续 10 秒无操作、乱拖或退出。

结算后追问：

1. 两个锚点为什么可以连接？
2. 这局需要救多少个生命，还必须完成什么？
3. 为什么不能把所有外围路线都缝上？
4. 哪条路线让这些生命没有抵达？
5. 如果重玩，你会改变哪条针脚？

通过信号：

- 至少 8/10 能无口头提示完成第一针。
- 至少 6/10 在资源耗尽前理解“9/12＋花园＋三条救援”的取舍。
- 有效邻接锚点连接成功率点估计不低于 95%。
- 至少 5/10 主动重玩或明确要求尝试另一种路线。

## 8. 《裂隙猎人》观察题

测试中只观察，不提问：

- 前十秒能否区分猎人、敌人、敌弹和橙金战利品。
- 是否理解瞄准、开火和拾取自动完成。
- 危险值上升时如何解释其原因。
- 首次撤离信标开放时，是有意比较收益与风险，还是偶然进入或完全忽略。
- 作出选择前，能否预测撤离与死亡分别保留多少战利品。
- 150 秒后是否前往唯一最终三角信标区。

结算后追问：

1. 危险为什么上升？
2. 继续停留会得到什么，又会承担什么？
3. 现在撤离能带走多少？
4. 死亡会保留和遗失什么？
5. 你为什么选择撤离或继续？

通过信号：

- 至少 8/10 十秒内完成有效移动并理解自动战斗。
- 至少 6/10 在第一次撤离前准确预测死亡损失。
- 60 秒撤离机会的可识别决策响应率不低于 70%。
- 立即撤离与继续冒险任一侧不得低于 20%；若单侧过低，先检查取舍是否表达清楚。

## 9. 结算后统一访谈

每款结束后按顺序询问：

1. 用一句话说，这款游戏要你做什么？
2. 哪个瞬间最有趣？
3. 哪个瞬间最困惑？
4. 你觉得这局结果是操作、策略、运气还是程序造成的？为什么？
5. 你愿不愿马上再玩一局？为什么？

三款全部结束后询问：

1. 最想继续玩哪一款？只能选一款。
2. 最不想继续玩哪一款？原因是什么？
3. 哪一款的玩法最容易复述给朋友？
4. 如果明天微信里只能出现一款，你希望是哪款？

不得用“喜欢吗”“好玩吗”作为唯一结论。优先使用行为、原话、录像和主动重玩证据。

## 11. 问题分级

- P0：多数参与者无法开始、核心机制不可理解、胜负与规则矛盾、触控或性能导致无法完成。
- P1：可以完成，但关键取舍、资源或损失在决策前没有讲清。
- P2：不阻断完成，但降低辨识、节奏、复盘或情绪回报。

每个问题必须附：

- 参与者数量，例如 4/10。
- 发生时间点。
- 至少一条原话。
- 对应录像片段。
- 是否跨设备/游戏经验重复出现。

Gate A：

- 继续：至少 8/10 无提示完成首次核心动作、至少 6/10 能说明核心取舍、至少 5/10 主动重玩或明确要求再玩。
- 停止：连续两轮修正后仍少于 5/10 理解核心动作，或乐趣必须依赖主持人解释。
- 加码候选：至少 8/10 理解核心幻想且至少 6/10 主动重玩，同时没有 P0/P1 真机问题。

首轮样本只用于发现问题和筛选方向。正式立项仍需小流量漏斗、D1/D7/D30、性能、内容成本和合规证据。
