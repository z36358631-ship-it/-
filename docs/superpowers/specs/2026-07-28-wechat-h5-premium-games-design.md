# 微信 H5 精品游戏三款纵切片设计

## 1. 立项目标

为中国大陆 C 端微信用户制作三款可独立体验的竖屏 H5 游戏纵切片，用真实操作验证三种不同的核心乐趣：

1. 《五秒之后》：时间回声带来的自我协作和力量膨胀。
2. 《世界缝补师》：修复世界、保护生命的触控满足感。
3. 《裂隙猎人》：安全撤离与继续贪取战利品之间的风险博弈。

三款游戏均采用单手操作、三分钟完整首局、离线可运行的单文件 HTML 形态。首版通过普通微信小程序 `web-view` 承载远程 H5，暂不接入登录、支付、广告、排行榜与云存档。

## 2. 共同设计原则

- 打开后三秒内可以开始操作。
- 不阅读说明，十秒内能观察到“操作—结果”的核心因果。
- 只有一种主要游戏操作，不增加技能键、背包或复杂面板。
- 每局包含开场、局势升级、高潮、结算和无需刷新的重玩。
- 核心玩法和渲染使用 Canvas，DOM 仅承载开始、暂停、结算和无障碍控件。
- 基准画布为 `390×844`，覆盖 `360×800` 至 `430×932` 的竖屏比例。
- 页面失焦立即暂停计时、动画逻辑与声音，恢复后由玩家主动继续。
- 无外部素材、CDN、iframe 和网络依赖。

## 3. 《五秒之后》

### 3.1 产品定义

- 核心幻想：过去五秒的自己会回来帮我。
- 核心情绪：从孤身行动到多个自我同步合击的力量膨胀。
- 核心操作：拖动角色移动并留下五秒行动轨迹。
- 视觉钩子：透明回声沿玩家历史路线循环，多个自己同时触发机关和攻击核心。

### 3.2 规则

- 当前角色跟随玩家拖动位置移动，靠近目标时自动发出脉冲。
- 每五秒封存一次轨迹，生成一个循环重演该轨迹的回声。
- 场上最多保留四条回声；第五条生成时替换最旧回声。
- 普通目标可由任意角色摧毁；双机关要求两个不同角色同时站入。
- 终局核心有四层护盾，旧回声经过对应时间门时破盾，当前角色完成终击。
- 玩家受到时间障碍伤害会损失能量，能量归零则失败。

### 3.3 三分钟节奏

- 0–5 秒：穿过首个目标并生成第一条回声。
- 5–20 秒：当前角色与回声同时摧毁两个目标。
- 20–60 秒：出现双机关，建立主动规划路线的需求。
- 60–120 秒：第三、第四条回声加入，障碍开始要求预判。
- 120–165 秒：终局核心出现，回声负责破盾。
- 165–180 秒：同步合击、世界复色、成绩结算。

### 3.4 验收

- 第一条回声必须准确重复玩家前五秒路线。
- 双机关不能由当前角色单独完成。
- 四条回声同时存在时，当前角色仍能在一秒内被识别。
- 重玩必须生成不同目标布局，但核心教学顺序保持一致。

## 4. 《世界缝补师》

### 4.1 产品定义

- 核心幻想：用一根金色针线把破碎世界亲手缝好。
- 核心情绪：保护、修复、失而复得。
- 核心操作：从一个有效锚点拖到另一个有效锚点完成缝合。
- 视觉钩子：灰暗裂口闭合，土地复色，小生命沿针脚逃生。

### 4.2 规则

- 锚点之间由确定性连接图控制，不支持任意自由画线。
- 针线消耗长度预算，连接完成后可作为桥梁或风沙屏障。
- 三批共十二个小生命按固定路径前往中心花园。
- 桥梁让生命跨越裂口，屏障让生命安全穿越风沙区。
- 玩家可撤销最近一针并返还对应线长。
- 180 秒内救出至少九个生命并连接中心花园即胜利。

### 4.3 三分钟节奏

- 0–10 秒：第一针救下一只即将坠落的生命。
- 10–40 秒：两道简单桥梁裂口。
- 40–80 秒：针线第一次作为风沙屏障。
- 80–130 秒：有限线长迫使玩家选择救援顺序。
- 130–165 秒：连续崩裂，要求复用已完成路线。
- 165–180 秒：中心花园连接、整体复色、获救数量结算。

### 4.4 验收

- 有效锚点间的连接成功率达到 95%。
- 无效连接给出明确反馈，不消耗针线。
- 首局必须观察到桥梁和屏障两种用途。
- 失败原因来自路线和线长选择，不来自触控判定。

## 5. 《裂隙猎人》

### 5.1 产品定义

- 核心幻想：我已经能安全离开，但还想再拿一个宝箱。
- 核心情绪：贪婪、紧张、死里逃生。
- 核心操作：拖动角色移动；瞄准、攻击和拾取自动完成。
- 视觉钩子：敌群与掉落持续升级，绿色撤离区和橙金战利品形成直接取舍。

### 5.2 规则

- 角色自动攻击最近敌人，击杀获得经验与战利品。
- 经验达到两次阈值时，武器从单发升级为双发和穿透散射。
- 危险值随时间上升，同时提高敌人密度、移速与战利品价值。
- 60 秒和 150 秒开放撤离信标；站入三秒并承受敌人压力即可撤离。
- 150 秒后裂隙坍缩，精英首领追击玩家。
- 成功撤离保留全部战利品；死亡只保留最高价值的一件。

### 5.3 三分钟节奏

- 0–10 秒：自动开火、首杀、获得首件高价值物。
- 10–45 秒：第一次武器变形。
- 45–60 秒：精英出现并掉落稀有物，同时再次说明死亡损失。
- 60 秒：第一次撤离选择。
- 90–150 秒：风险和收益同步上升。
- 150 秒：最终主动撤离窗口。
- 150–180 秒：坍缩与首领追击，随后结算。

### 5.4 验收

- 首次玩家在 60 秒前能看懂“现在能撤，继续会得到更多”。
- 撤离必须通过站位承压完成，不能退化成按钮。
- 结算明确分开展示带出和遗失物品。
- 同屏对象达到上限时仍保持可操作，优先减少特效而非改变规则。

## 6. 技术与微信接入

统一事件格式：

```js
{
  source: "wechat-h5-premium-games",
  version: 1,
  gameId,
  runId,
  event,
  ts,
  payload
}
```

统一平台接口：

```js
GamePlatform.getEnv();
GamePlatform.emit(event, payload);
GamePlatform.saveLocal(key, value);
GamePlatform.loadLocal(key, fallback);
GamePlatform.pause();
GamePlatform.resume();
GamePlatform.requestShare(payload);
```

H5 版只实现环境识别、本地设置、事件投递与暂停恢复。微信登录、支付、广告和分享不在纵切片范围内。`web-view postMessage` 不作为局内实时通信总线。

自动验收模式使用：

```text
?test=1&seed=20260728&speed=20&mute=1
```

测试模式允许固定随机种子和加速时间，但不得改变碰撞、胜负和结算规则。

## 7. 视觉与可访问性

- 使用盖世游戏的深色基础色、清晰字号层级和至少 44px 的触控目标。
- 游戏画面各自使用独立主题色，避免三款看起来像换皮。
- 颜色不是唯一信息渠道；重要状态同时使用形状、文字或动效区分。
- 提供静音、暂停、重新开始和减少动态效果选项。
- 结算文案使用简体中文，事件字段和代码标识保持英文。

## 8. 交付边界

交付称谓为“三款经过完整首局与交叉验收的可玩 H5 纵切片”。自动化浏览器验收不等同于 iOS、Android 微信真机认证。商业上线仍需公司主体、业务域名、游戏类目、版号、实名防沉迷、隐私指引和支付资格确认。
