# 兼容性评价“本次启动配置”文案与最终 PRD 设计

## 目标

将评价所关联的单次运行配置快照统一命名为“本次启动配置”，消除“启动方案”可能被理解为持续维护方案的歧义；基于当前有效 Demo、状态卡和已确认规则，输出一份可供产品、设计、研发和测试直接执行的最终 PRD，并推送至 Git。

## 当前事实

- 当前 C 端评价卡和快照详情使用“本次启动方案”，实际对象是评价人当次成功运行时上传的一份不可变配置快照。
- 正式产品仍存在“启动方案页”“应用方案”“复制方案”等可复用方案实体和动作，不能全局替换“方案”一词。
- 现有 `prd/ai生成/APP兼容性评价改版需求.md` 为早期版本，包含“同设备”“支持最多”等已被当前 Demo 与状态卡替代的口径，不适合作为当前基线直接增量修订。
- 当前有效依据依次为：用户本轮确认、状态卡、当前 C/B 端 Demo、当前规格与浏览器契约；旧 PRD 只作为历史参考。

## 文案设计

### 统一改名

仅将指向“评价绑定的单次配置快照”的用户可见文案由“本次启动方案”改为“本次启动配置”，包括：

- 评价卡标题和无障碍名称。
- 快照详情页固定标题。
- 当前已应用快照的展示名称。
- C/B 端快照预览中代表同一对象的展示值。
- 新建评价快照时写入的固定展示名称。
- Demo 测试断言、截图脚本、状态卡和最终 PRD 中的对应口径。

### 明确不改

- 不替换“启动方案页”“应用方案”“复制方案”等正式方案实体或动作名称。
- 不修改 `solutionName`、`reviewSnapshotId` 等内部字段名。
- 不改变快照一对一、不可变、云端存储、白名单、大小限制、删除生命周期及应用／复制行为。
- 不新增数据迁移。历史快照即使保留旧展示值，C 端与 B 端展示层仍固定呈现“本次启动配置”，保证新旧数据口径一致。

## PRD 策略

### 文档定位

新建一份当前最终口径 PRD，作为 GUANWANGGAID-25 的唯一现行产品基线；旧 PRD 保留原文件并在新 PRD 附录中标记为历史资料，不继续承载当前规则。

### 范围

PRD 按标准／复杂需求编写，覆盖：

- C 端：游戏详情兼容性入口、评价列表与筛选、查看和应用他人配置、横屏启动与退出、主动评价、评分联动、分享本次启动配置、我的评价、异常与边界。
- B 端：评价管理、关联快照筛选、完整配置只读预览、隐藏与删除生命周期、导出字段。
- 业务规则：全平台累计 30 分钟评价门槛、全局可配置的 7 天邀评冷却、1～5 星映射、G-01～G-07 客态显隐矩阵、一对一云端快照、复制后的启动方案页跳转占位。
- 明确不包含：启动失败流程改造、个人云方案自动创建、跨评价配置复用或去重、多人验证聚合、成功率和最近验证。

### 图示

- 生成一张从游戏详情查看评价、应用他人配置、启动游戏、退出游戏、提交评价到查看我的评价的横向产品流程合成图。
- 页面六要素使用当前 Demo 的最新截图，页面内明确全部可见元素、展示状态、交互结果、失败恢复和冲突规则。
- 图片使用固定提交 SHA 的 HTTPS 地址；推送后执行公网状态与 MIME 校验。若无法完成飞书真实导入，只声明公网验证，不声明飞书已转存。

### 数据结论

本轮不新增埋点，PRD 数据结论写“不涉及”；不补写未经确认的指标、灰度或运营配置。

## 实施与验证

1. 先增加会失败的文案契约，确保“本次启动方案”不再作为该快照的用户可见标题。
2. 更新 C 端 Demo 的展示层和新建快照固定名称；按需同步 B 端同对象展示值，但不改正式方案实体。
3. 更新测试、截图脚本并重新生成全部当前截图。
4. 新建最终 PRD及横向产品流程图，运行 PRD 质量校验和图片校验。
5. 更新状态卡与工作流，提交本任务文件并推送远端分支。

## 验收标准

- 评价卡、快照详情和相关预览统一显示“本次启动配置”。
- 正式“启动方案”实体与“应用／复制方案”动作未被误改。
- 内部字段和快照数据模型不变，历史数据无需迁移即可显示新文案。
- Demo 全量浏览器契约、截图脚本、静态检查和原尺寸人工审图通过。
- PRD 符合 `/to-prd` 模板：修订记录四列、C/B 分端、页面六要素、单张横向产品流程图、数据结论与待确认项完整，无旧口径和占位符。
- Git 只提交本任务文件并成功推送；公开图片链接固定到不可变提交且公网校验通过。

## 方案快速评审

- 用户视角：通过。“本次启动配置”更符合单次运行快照心智，但必须避免页面内“方案／配置”混用。
- 开发视角：通过。展示层改名、内部字段不改，可避免接口和存量数据迁移；需同步测试和截图。
- 商业视角：通过。改动小、歧义降低；新 PRD 应成为唯一现行基线，旧 PRD只保留历史用途。
