# 新手引流文案与用户来源字典设计

## 目标

让用户在进入引导前理解接下来会根据其游玩经验提供更快的开始路径，同时为运营补齐“用户来源”字典维护能力。

## 范围

- C 端：欢迎页文案、平台特色文案、非新用户选游戏按钮状态。
- B 端：运营后台“系统配置 → 字典管理”中的用户来源字典及多语言配置。
- 同步更新现有新手引流 Demo 与 PRD，不新增独立后台或截图外流程。

## C 端设计

### 欢迎页

- 中文标题：`为了您的绝佳体验`
- 中文说明：`请与我们分享您的游玩经验～`
- 两行合为一句话，介绍后续将根据用户是新手、已有游戏文件或已有 Steam 账号提供对应路径。
- 海外版同步英文语义，不改变页面结构。

### 平台特色

- 保留“手机上的 PC 游戏平台”及现有平台特色说明。
- 第一条统一为：`与 Steam、Epic 数据互通，海量大作应有尽有`。
- 国内继续展示云游戏特色；海外不展示云游戏特色。

### 非新用户选游戏

- 未选择游戏时，按钮显示“选好了”并置灰。
- 选择 1～9 款后，按钮仍显示“选好了”并高亮，可提交。
- 最多选择 9 款；不再要求至少选择 3 款。
- 不新增 Toast、确认弹窗或额外步骤。

## B 端设计

### 入口

`运营后台 → 系统配置 → 字典管理`

### 字典管理

- 列表支持按字典名称、字典编码筛选，并提供重置、查询和新建字典。
- 列表字段：ID、字典名称、字典编码、字典描述、多语言、创建时间、更新时间、操作。
- 操作包含编辑、字典项、删除。
- 新建/编辑字段：字典名称、字典编码、字典描述、多语言参数。
- 本期字典：`用户来源 / userSource`。

### 字典子项

- 子项管理标题：`字典子项管理 - 用户来源(userSource)`。
- 支持按子项值筛选，并提供重置、查询和新建字典子项。
- 列表字段：ID、字典子项名、字典子项值、字典项描述、多语言、排序、创建时间、更新时间、操作。
- 新建/编辑字段：字典子项名、字典子项值、字典项描述、排序、多语言参数。
- 国内、海外继续使用现有来源编码；多语言配置维护对应显示名称。

### 多语言

- 字典和字典子项均可打开多语言配置。
- 展示“已配置 N 种语言”；保存后返回上一级弹窗并更新数量。
- 取消不保存，确定保存当前配置；不新增独立多语言页面。

## 异常与验证

- 必填项为空时不允许保存，并在当前字段提示。
- 字典编码、字典子项值重复时不允许保存。
- 删除沿用现有字典管理确认流程；取消后数据不变。
- C 端验证 0、1、9、超过 9 款四种按钮状态。
- B 端验证查询、重置、新建、编辑、删除、子项管理和多语言保存链路。

## 快速评审

- 用户视角：欢迎页先说明用户收益，后续选项与说明一致。
- 开发视角：沿用现有页面、字典结构和来源编码，无额外状态模型。
- 业务视角：运营可维护来源名称、编码、排序和多语言，满足本期配置需求。
