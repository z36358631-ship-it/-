# 渠道分销表单与供给数量设计

## 目标

修复渠道与批次表单的布局和交互问题，收紧列表筛选区，并补全文件下载与接口取码的数量规则。

## 范围

- 渠道创建、编辑抽屉。
- 批次创建、编辑抽屉。
- 渠道管理、批次管理、分销数据筛选区。
- 文件批次下载。
- API 批次数量及追加。
- 帮助中心入口和现有文章。

不新增审批、平台处置、渠道校验或结算流程。

## 表单

### 布局

- 修复文件批次中“Key 有效期”错位、遮挡和跨行问题。
- 数量与 Key 有效期可同排展示，但各字段必须完整占据自己的网格单元。
- 生效时间、状态、备注各占一整行。
- 渠道和批次表单使用相同的状态、备注布局。
- 手机端改为单列，不产生根节点横向滚动。

### 状态

- 创建渠道、创建批次时默认选择“停用”。
- 状态使用横向单选项：停用、启用。
- 编辑时回显原状态，不重置为停用。
- 状态只控制供给或取码，不控制文件批次是否可生成下载。

### 日期

- 点击日期字段打开原时间选择组件。
- 点击组件外空白处或按 `Esc` 关闭组件。
- 外部关闭等同“取消”：丢弃未点击“应用”的临时选择，保留原值。
- 点击“应用”后才写入开始和结束时间。

## 使用说明

- 移除“渠道与供给”页面顶部的“使用说明”按钮。
- 不删除帮助中心文章或文章编号。
- 帮助中心继续保留渠道管理、批次管理、文件下载和 API 接入说明。
- API 接入抽屉中的“查看接口文档”入口保留。

## 筛选区

渠道管理、批次管理、分销数据均使用稳定的内容宽度，不再按剩余空间平均拉伸。

- 名称或编号：能容纳常见最长名称和编号。
- 渠道：能完整展示渠道名称与编号。
- 时间范围：能完整展示最长日期范围或“长期有效”。
- 供给方式、状态：按最长选项设置较窄宽度。
- 查询、重置按钮保持固定宽度。
- 空值和选项切换不改变控件宽度。
- 空间不足时整项换行；320px、390px 下使用单列。

## 文件批次下载

- 非删除的文件批次可执行首次生成并下载，不受渠道或批次的启停、生效时间限制。
- 待生效、未启用、已停用状态均可点击“下载文件”。
- 下载不改变批次启停或生效状态。
- 平台不保存明文兑换码；首次下载完成后只展示下载记录，不提供同一明文文件的重复下载。
- 生成失败时允许重试；已删除批次不可下载。
- 接口取码批次不显示文件下载操作。

## API 数量

### 创建

- 接口取码批次增加“初始可取数量”。
- 支持输入整数 `1–100,000`，单次最多 10 万。
- 辅助文案：`单次 1–100,000 个，可在原批次追加。`
- 创建后接口地址、`client_id`、Secret 按原流程生成。

### 展示

- API 批次列表数量列显示“剩余 / 累计总量”。
- 剩余量为累计总量减成功取码量，最小为 0。
- 文件批次仍显示该文件的 Key 数量。

### 追加

- API 批次操作区增加“追加数量”，库存未用完时也可提前追加。
- 每次追加支持整数 `1–100,000`；批次累计总量不设产品硬上限。
- 追加抽屉展示当前剩余量、本次追加数量和提示：`追加后接口凭证与取码地址不变。`
- 提交后只增加累计总量，不改接口地址、`client_id`、Secret、启停状态或生效时间。
- 追加数量继承原批次销售项、有效期及供给规则。
- 已结束或已删除批次不可追加；待生效、停用批次可追加，但仍按自身状态决定是否可取码。
- 每次追加写入操作记录，并防止重复提交。

### 旧数据

- 旧 API 批次缺少数量时，以历史成功取码量作为累计总量，剩余量为 0，避免生成虚构库存。
- 用户可在原批次追加数量，接口和凭证保持不变。

## 验收

1. 文件批次字段无错位或遮挡，状态和备注各占一行。
2. 新建渠道、批次默认停用；状态为横向单选，编辑能正确回显。
3. 日期组件点外或按 `Esc` 关闭且不写入临时值。
4. 页面顶部不再显示“使用说明”，帮助中心文章及 API 文档入口仍可用。
5. 三类筛选区使用稳定合理宽度，最长选项可读，移动端不溢出。
6. 待生效、未启用、已停用的文件批次均可首次生成下载。
7. 已下载文件批次只显示下载记录，不保留或重复展示明文 Key。
8. API 创建数量和单次追加数量均限制为 `1–100,000`。
9. API 追加后剩余量和累计总量更新，接口地址、`client_id`、Secret 不变。
10. 旧 API 批次迁移后不产生额外可取数量。
11. 320px、390px、1280px、1440px 下无根节点横向溢出。
