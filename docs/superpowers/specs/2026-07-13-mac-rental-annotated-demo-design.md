# Mac 端租号功能标注版设计说明

## 目标

将 `Mac端demo/mac端租号功能/` 下 6 个独立 HTML 页面与根据前端功能反推的运营后台整合为一个可直接打开的单文件交互标注 Demo，用于产品评审、设计沟通和开发交接。原始文件保持不变。

输出文件：

`Mac端demo/mac端租号功能/Mac端租号功能-标注版.html`

## Mac 客户端输入页面与流程

| 顺序 | 页面 | 来源文件 | 核心作用 |
|---|---|---|---|
| 1 | 探索页 | `探索页改动.html` | 展示带租号价格与在租数量的推荐内容 |
| 2 | 找游戏页 | `找游戏页改动.html` | 浏览全部游戏并识别可租游戏 |
| 3 | 搜索结果页 | `搜索结果页改动.html` | 在搜索结果中展示租号价格、库存和平台 |
| 4 | 游戏详情页 | `游戏详情改动.html` | 通过“租号开玩”进入交易链路 |
| 5 | 订单确认页 | `租号中心-订单确认.html` | 选择版本、租期和支付方式并计算价格 |
| 6 | 我的订单页 | `租号中心-我的订单.html` | 管理进行中、待支付、已完成和退款订单 |

主链路：探索或找游戏 -> 搜索结果 -> 游戏详情 -> 订单确认 -> 我的订单。

左侧流程导航同时支持直接进入任意页面，便于评审和演示。

## 运营后台业务拆解

旧 `demos/steam租号-后台demo.html` 仅作为后台页面密度和布局参考，不复用其号主管理等旧业务结构。新后台从 Mac 前端的商品展示、下单、账号占用、订单状态和效果评估反推，划分为 4 个模块。

| 模块 | 管理对象 | 核心能力 | 快捷与批量操作 |
|---|---|---|---|
| 租号商品管理 | 游戏、平台、版本、租期、价格、前端展示状态、可租库存 | 配置标准/增强/豪华版，配置 3/7/30 天及永久版价格，控制探索/找游戏/搜索/详情页是否展示租号 | 复制商品配置、复制版本、批量上下架、批量改价、批量同步库存、导出 |
| 账号资源管理 | 第三方账号、关联游戏与版本、占用关系、健康状态 | 同步共享游账号资源，查看可租/占用/异常/下架状态，处理账号与订单的资源关联 | 同步、登录检测、释放占用、下架、重新上架、替换账号、批量检测、批量下架 |
| 订单与售后 | 待支付、租赁中、已结束、已退款、下单失败、售后处理中订单 | 在同一工作台查看订单详情、支付与租期、账号占用、售后单和风险状态 | 续租、结束订单、换号、退款、补偿、释放资源、导出 |
| 效果统计 | 订单、金额、付费用户、库存、账号占用、账号复用、用户复租和转化漏斗 | 统一查看业务结果、库存效率和用户转化，支持按时间、游戏、版本和平台筛选 | 时间切换、环比对比、明细排序、导出 |

前三个管理模块顶部展示与当前业务对象对应的统计卡片；“效果统计”作为独立模块集中评估功能效果。全局提供操作记录，记录批量改价、上下架、退款、换号和强制释放等高风险操作。

账号凭据不得复制或在列表中明文展示。“复制”仅用于复制商品、版本和价格配置。

## 页面架构

采用 `/demo标记` 的单文件三栏结构，并增加“Mac 客户端 / 运营后台”模式切换：

- 左侧导航：固定宽度 `220px`，显示标题、模式切换、Mac 端 6 个页面入口、后台 4 个模块入口和演示控制。
- 中间区域：弹性宽度；Mac 模式容纳 `1076x734px` 画布，后台模式容纳 `1800x1300px` 画布，并按可用空间等比缩放。
- 右侧标注：固定宽度 `400px`，包含“交互说明”和“异常&边界”两个 Tab，可折叠。

所有页面正文直接放在同一 HTML 中，不使用 iframe。每个客户端页面和后台模块拥有独立根节点及页面标识，默认只显示当前模式下的当前页面。

## 样式整合

6 个来源页面使用了不同的 Tailwind 配置和全局样式，后台使用独立的浅色管理系统视觉。合并时按以下规则处理：

1. 建立一份包含所有页面所需颜色、尺寸和字体别名的统一 Tailwind 配置。
2. 将来源页面的 `body`、滚动条和通用类样式限制在对应页面根节点下，避免污染三栏框架。
3. 对重名但含义不同的颜色和组件类增加页面前缀。
4. 保留原页面暗色视觉、图片、文案、卡片布局和 Mac 画布尺寸，不进行无关视觉重设计。
5. 后台沿用浅色、信息密集的表格型管理界面，但业务结构按本设计重新生成。
6. 中间画布使用稳定尺寸和缩放容器，模式切换、页面切换、标号显示和右侧面板折叠不能引发布局跳动。

## 交互设计

### 全局交互

- 点击左侧页面入口，切换中间页面并滚动右侧标注到对应分组。
- 点击“Mac 客户端 / 运营后台”切换模式，同时切换画布尺寸、左侧页面列表和右侧标注分组。
- 点击右侧标注项，中间对应元素出现短暂高亮。
- “显示标号”控制所有页面的数字、全局和异常标号显隐。
- 右侧面板支持收起和展开；收起后中间区域自动获得更多空间。
- 页面切换时保留各页内部状态，例如订单确认页已选择的版本和租期。

### 链路交互

- 探索页的租号信息或推荐游戏可进入游戏详情页。
- 找游戏页的可租游戏卡片可进入游戏详情页。
- 搜索结果中的可租游戏可进入游戏详情页。
- 游戏详情页点击“租号开玩”进入订单确认页。
- 订单确认页支持版本、租期、支付宝和微信支付切换，金额随版本和租期更新。
- 支付完成演示入口进入“我的订单”，新订单以进行中状态展示。
- 我的订单支持订单状态筛选、搜索和典型操作演示，包括启动、续租、去支付、取消订单、查看详情、再次租借、申请售后和删除订单。

### 后台交互

- 租号商品管理支持展开单个游戏查看版本、租期和价格，并可复制商品或版本配置。
- 批量操作只有在勾选数据后可用；改价、上下架和批量同步执行前显示影响范围确认。
- 账号资源管理支持状态筛选、第三方同步、登录检测、强制释放、下架和重新上架。
- 占用中的账号执行下架时，先提示关联订单，并要求选择“订单结束后下架”或“立即换号并下架”。
- 订单与售后通过状态 Tab 和组合筛选统一查询，订单详情同时展示商品、租期、支付、账号资源和售后信息。
- 换号、退款、补偿、结束订单和强制释放均要求二次确认并写入操作记录。
- 页面操作使用前端模拟数据即时反馈，成功或失败结果通过 Toast、状态标签和详情记录体现。

### 效果统计交互

- 顶部支持今日、近 7 天、近 30 天、自定义时间切换，并可按游戏、版本和平台筛选。
- 业务指标卡展示支付订单量、支付金额、付费用户数和付费用户客单价，并显示环比变化。
- 库存指标卡展示总库存、可租数量、已占用数量、异常数量和下架数量。
- 效率指标卡展示账号使用率、账号复用率和用户复租率，并提供口径说明。
- 趋势区展示订单量与支付金额趋势、账号使用率趋势。
- 转化漏斗按“租号曝光 -> 点击租号 -> 提交订单 -> 支付成功 -> 一键上号成功”展示各环节人数、转化率和流失率。
- 游戏明细表按游戏和版本展示订单量、金额、库存、已占用、使用率、账号复用率、用户复租率和退款率，支持排序和导出。

## 标注设计

### 编号规则

- 数字 `1, 2, 3...`：页面内交互和展示规则，使用橙色。
- `G1, G2...`：跨页面全局逻辑，使用蓝色。
- `E1, E2...`：异常和边界处理，使用红色。

### 标注范围

交互说明覆盖：

- 租号价格和在租数量的展示位置。
- 搜索、筛选、页面跳转和返回逻辑。
- “租号开玩”入口及其与“秒玩”“获取游戏”的关系。
- 版本、租期、支付方式和价格联动。
- 订单状态、状态筛选及不同状态下的可用操作。
- 商品、版本、租期、价格和前端展示位置的映射关系。
- 商品复制、版本复制、批量改价和批量上下架。
- 第三方账号同步、占用、检测、释放和下架流程。
- 订单与售后合并查询、换号、退款、补偿和操作留痕。
- 统计时间、游戏、版本和平台筛选，以及环比和导出逻辑。
- 业务指标、库存指标、效率指标、趋势、漏斗和游戏明细之间的数据口径。

异常与边界覆盖：

- 无可租账号、库存耗尽和价格失效。
- 搜索无结果和网络加载失败。
- 支付中断、二维码过期和重复支付。
- 订单超时、启动失败、顶号或账号异常。
- 续租冲突、售后处理中和不可删除订单。
- 商品复制后的唯一字段处理、批量操作部分失败和价格生效冲突。
- 占用账号下架、第三方同步延迟、账号检测失败和强制释放风险。
- 换号无可用库存、退款重复提交和后台高风险操作权限不足。
- 实时库存与周期指标更新时间不同、统计延迟、分母为零和部分第三方数据缺失。

标注内容以产品规则和开发可执行信息为主，不标注纯装饰性视觉细节。

## 数据与状态

Demo 使用前端内存状态，不连接真实接口。统一状态包含：

- 当前页面。
- 标号显示状态和右侧面板状态。
- 搜索关键词和订单筛选状态。
- 当前游戏、版本、租期、支付方式和订单金额。
- 模拟订单状态及操作反馈。
- 当前演示模式和后台当前模块。
- 后台商品勾选、复制来源、批量任务及操作结果。
- 账号同步、检测、占用和上下架状态。
- 订单、售后、退款、换号和操作记录状态。
- 统计时间范围、游戏、版本、平台、环比和排序条件。
- 订单、金额、库存、占用、使用率、账号复用率、用户复租率及漏斗数据。

页面切换通过同一状态对象同步，避免页面之间的数据不一致。

## 统计指标口径

| 指标 | 定义 | 更新方式 |
|---|---|---|
| 支付订单量 | 统计周期内支付成功的租号订单数 | 按统计周期计算 |
| 支付金额 | 统计周期内支付成功订单的实付金额合计，退款金额单独展示 | 按统计周期计算 |
| 付费用户数 | 统计周期内至少支付成功 1 笔租号订单的去重用户数 | 按统计周期计算 |
| 付费用户客单价 | 支付金额 ÷ 付费用户数 | 按统计周期计算 |
| 总库存 | 当前同步到平台且未删除的账号资源数 | 实时快照 |
| 可租数量 | 当前状态为正常、未占用且商品已上架的账号数 | 实时快照 |
| 已占用数量 | 当前存在有效租赁订单并被锁定的账号数 | 实时快照 |
| 异常数量 | 当前检测失败、登录异常或被风控冻结的账号数 | 实时快照 |
| 下架数量 | 当前由系统或运营设置为不可出租的账号数 | 实时快照 |
| 账号使用率 | 统计周期内账号实际占用时长 ÷ 可出租账号总时长 | 按统计周期计算 |
| 账号复用率 | 统计周期内被租用至少 2 次的账号数 ÷ 被租用过的账号数 | 按统计周期计算 |
| 用户复租率 | 统计周期内下单至少 2 次的付费用户数 ÷ 付费用户数 | 按统计周期计算 |

当指标分母为 0 时显示 `--`，不显示 `0%`。当前库存类指标标记“实时”，订单与时长类指标显示统计时间范围和最近更新时间。

## 资源与兼容性

- 保留来源页面的远程图片地址。
- 保留 Tailwind CDN 和现有字体或图标依赖，不额外引入新框架。
- 图片加载失败时显示固定比例的暗色占位，避免布局塌陷。
- 目标浏览器为桌面版 Chrome 和 Edge。
- 输出为单个 HTML，浏览器直接打开即可运行；联网时加载完整图片和 CDN 资源。

## 验证标准

1. 新文件可直接打开，控制台无阻断交互的 JavaScript 错误。
2. 6 个页面均可通过左侧导航访问，顺序与主链路一致。
3. 中间 Mac 画布保持 `1076x734px` 比例，桌面窗口中无横向溢出。
4. 后台画布保持 `1800x1300px` 比例，模式切换后正确缩放且无空白画布。
5. 页面视觉与来源 Demo 的关键结构一致，后台保持浅色、表格型管理界面。
6. 游戏详情到订单确认再到我的订单的主链路可点击完成。
7. 版本、租期和支付方式切换可用，价格显示正确更新。
8. 后台 4 个模块均可访问，商品复制和批量操作、账号上下架、订单换号退款等典型操作可演示。
9. 高风险后台操作均有二次确认和操作记录，账号凭据不明文展示。
10. 效果统计可切换统计周期和筛选条件，订单金额趋势、使用率趋势、转化漏斗和游戏明细正常更新。
11. 实时库存与周期指标有明确标识，账号使用率、账号复用率和用户复租率口径与本文一致。
12. 右侧两个标注 Tab、标号显隐、标注高亮和面板折叠均可用。
13. 所有标注编号唯一，且与中间页面元素对应。
14. 在 `1400x900`、`1920x1080` 两个桌面视口截图检查，无重叠、截断或空白画布。
15. 原始 6 个 HTML 文件未被修改。

## 不在范围内

- 不连接真实租号、库存、支付或订单接口。
- 不重做现有页面品牌视觉。
- 不制作国内和海外双版本切换。
- 不制作号主入驻、用户寄售和租号会员体系。
- 不复制旧租号后台的号主管理和旧统计结构；效果统计按当前 Mac 租号链路重新设计。
- 不修改原始 6 个页面。
- 不提交或推送与本 Demo 无关的工作区改动。
