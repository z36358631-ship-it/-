# 社区文章与马甲号运营后台 Demo 设计方案

## 1. 设计结论

在现有 `demos/社区/社区后台demo.html` 的视觉与交互基础上，新建单文件 Demo：

`demos/社区/社区文章与马甲号运营后台demo.html`

Demo 以运营后台为主体，重点演示运营人员使用马甲号完成文章编辑、预览、提交审核、查看结果及审计追踪的完整闭环。客户端不单独建设，只作为文章编辑页右侧实时预览和文章详情预览弹窗出现。

## 2. 目标与边界

### 2.1 目标

- 让产品、设计、开发能在一个页面内理解社区文章生产和马甲号代运营流程。
- 覆盖文章草稿、审核状态、身份切换、权限限制、操作审计与风险提示。
- 复用现有社区后台的布局、表格、筛选器、弹窗和提示反馈，降低理解成本。
- 所有核心入口和按钮均可点击，形成可演示的前端闭环。

### 2.2 本期范围

- 内容发布工作台。
- 草稿箱与文章管理。
- 马甲号管理与身份切换。
- 客户端文章实时预览。
- 操作记录与风险事件。

### 2.3 不在本期范围

- 完整独立客户端 Demo。
- 真实服务端、数据库、文件上传和审核接口。
- 批量点赞、评论、转发。
- 自动定时互动。
- 虚构消费者评价、购买经历、收益承诺或批量操纵社区数据。

## 3. 信息架构

沿用现有后台左侧导航，新增或调整以下模块：

1. **内容发布**：文章列表和新建内容入口。
2. **草稿箱**：查看自动保存或手动保存的草稿。
3. **马甲号管理**：创建、导入、编辑、启停和删除马甲号。
4. **操作记录**：记录真实操作人和代操作身份的完整链路。
5. **风险事件**：展示高频操作、异常失败和权限拦截事件。

顶部增加固定“当前代操作身份”区域，展示：

- 当前马甲号头像、昵称、UID 和状态。
- 搜索并切换马甲号。
- 退出代操作身份。
- 未选择身份时的醒目提示。

## 4. 核心页面设计

### 4.1 内容发布列表

页面顶部包含“发布图文”“发布文章”“发布视频”三个入口，其中“发布文章”为本 Demo 的完整演示入口，其余入口保留简化交互。

筛选项：

- 文章标题或文章 ID。
- 发布身份。
- 内容状态：草稿、审核中、已发布、已驳回、已下架。
- 分区。
- 发布时间。

列表字段：

- 文章 ID、封面和标题。
- 发布身份。
- 分区与话题。
- 状态。
- 阅读、点赞、评论数据。
- 更新时间。
- 操作：预览、编辑、查看审核、下架。

关键状态交互：

- 已驳回文章可查看原因并继续编辑。
- 已发布文章再次编辑后显示“修改待审核”，旧版本在审核通过前仍保持线上展示。
- 未选择马甲号时点击发布入口，弹出身份选择提示，不进入编辑页。

### 4.2 文章编辑工作台

采用“左侧编辑区 + 右侧手机预览”的双栏布局。

左侧编辑区包含：

- 内容类型 Tab：发布图文、发布文章、发布视频。
- 封面上传区。
- 标题输入框及字数统计。
- 富文本工具栏：标题、粗体、斜体、删除线、下划线、颜色、引用、列表、分割线、图片、链接、游戏卡片。
- 正文编辑区。
- 分区选择。
- 话题选择。
- 游戏卡片选择，支持添加多个并调整顺序。
- 自动保存状态和最近保存时间。

右侧手机预览包含：

- 作者头像、昵称及身份标签。
- 标题、封面和图文混排正文。
- 话题标签。
- 游戏卡片。
- 底部点赞、评论、收藏和分享栏，仅用于视觉验证。
- “刷新预览”按钮，用于明确演示预览同步。

底部固定操作区：

- 取消。
- 保存草稿。
- 预览。
- 提交审核。

提交审核前校验：

- 必须已选择可用马甲号。
- 标题、正文、分区不能为空。
- 封面、话题和游戏卡片按照界面提示进行非阻断或阻断校验。
- 校验失败时在字段附近显示错误，并自动定位第一个错误字段。
- 校验通过后弹出确认框，展示发布身份和文章摘要。

离开保护：

- 内容发生变化且尚未保存时，切换页面或点击取消，提示“保存草稿并离开 / 不保存离开 / 继续编辑”。
- 自动保存成功后显示最近保存时间；模拟失败时保留“重新保存”入口。

### 4.3 草稿箱

草稿来源区分“手动保存”和“自动保存”。

列表支持按标题、创建人、马甲号、更新时间筛选，操作包括继续编辑、复制草稿和删除。删除使用二次确认，并在 Demo 中仅更新本地页面数据。

### 4.4 马甲号管理

页面顶部展示：总账号数、启用数、停用数、今日代操作次数。

筛选项：

- UID 或昵称。
- 状态。
- 前台可见状态。
- 创建时间。

列表字段：

- 头像、昵称、UID。
- 内部标识。
- 后台备注。
- 前台可见。
- 状态。
- 最近使用时间。
- 操作：切换身份、编辑、启用或停用、删除。

创建与编辑弹窗字段：

- 头像。
- 昵称。
- UID；新建时可自动生成，编辑时不可更改。
- 内部标识。
- 后台备注。
- 前台可见开关。
- 状态。

批量导入：

- 支持点击或拖放 CSV/XLSX 文件的模拟交互。
- 展示模板下载、字段说明和导入结果。
- 结果区分成功、重复 UID、缺少必填字段和格式错误。
- 仅模拟账号创建，不提供批量社区互动能力。

### 4.5 身份切换与代操作

点击顶部身份区域或列表中的“切换身份”打开身份选择器：

- 支持按 UID、昵称和内部标识搜索。
- 显示最近使用的马甲号。
- 停用账号不可选择，并展示停用原因。
- 切换成功后，顶部、编辑页作者信息和提交确认框同步更新。

真实员工登录态始终保留在右上角。马甲号只是当前代操作上下文，不替换员工账号。

未选择身份时：

- 可以浏览文章、马甲号和日志。
- 禁用发布、评论等代操作按钮。
- 点击禁用能力时给出选择身份入口。

### 4.6 操作记录

在现有操作记录页基础上增加筛选项：

- 真实操作人。
- 马甲号 UID。
- 模块。
- 操作动作。
- 操作结果。
- 对象 ID。
- 操作时间。

列表字段：

- 操作时间。
- 真实操作人。
- 代操作身份。
- 模块与动作。
- 对象 ID。
- 结果。
- IP/终端摘要。
- 详情。

详情抽屉展示：

- request_id。
- 操作原因。
- 变更前 before。
- 变更后 after。
- 失败原因。
- 风险命中信息。

### 4.7 风险事件

页面使用统计卡和风险事件列表组合展示：

- 今日风险事件数。
- 待处理数。
- 权限拦截数。
- 高频操作告警数。

风险事件示例：

- 停用马甲号尝试发布。
- 短时间频繁切换身份。
- 连续发布失败。
- 非授权人员尝试编辑马甲号资料。

操作包括查看详情、标记已处理和添加备注。风险页不提供绕过权限或批量执行入口。

## 5. 演示主流程

1. 运营人员进入后台，顶部尚未选择代操作身份。
2. 点击“发布文章”，系统要求选择马甲号。
3. 搜索并选择“盖世攻略君”，顶部身份栏更新。
4. 进入文章工作台，填写标题、正文、分区、话题和游戏卡片。
5. 右侧手机界面实时展示客户端文章效果。
6. 点击保存草稿，草稿箱新增记录。
7. 点击提交审核，完成校验和二次确认。
8. 列表新增“审核中”文章，并展示成功反馈。
9. 打开操作记录，可查看真实员工、马甲号、文章 ID 和变更详情。
10. 查看已驳回示例，阅读驳回原因并重新编辑提交。

## 6. 页面与交互状态

Demo 至少提供以下可切换状态：

- 未选择身份 / 已选择启用身份 / 停用身份不可选择。
- 自动保存中 / 保存成功 / 保存失败。
- 表单校验失败 / 提交确认 / 提交成功。
- 草稿 / 审核中 / 已发布 / 已驳回 / 已下架。
- 导入成功 / 部分失败。
- 风险待处理 / 已处理。

所有弹窗、抽屉、Toast、分页和筛选交互均使用前端本地状态模拟，不依赖服务端。

## 7. 视觉与布局原则

- 延续现有 Ant Design 风格：深蓝侧栏、白色内容卡片、浅灰背景。
- 复用原 Demo 的字号、按钮、标签、表格、弹窗和间距体系。
- 当前马甲号使用独立蓝色身份标签，与真实员工账号形成清晰区分。
- 审核中使用橙色、已发布使用绿色、已驳回使用红色、草稿使用灰色。
- 编辑工作台以 1440px 桌面端为主要展示尺寸，低于 1200px 时允许内容区横向滚动，不压缩手机预览至不可读。

## 8. 数据与实现策略

- 以原 Demo 为模板复制成新文件，保留原文件不变。
- 使用单文件 HTML、CSS 和 JavaScript，不引入构建流程。
- 使用静态模拟数据和页面内状态更新完成筛选、切换、提交和反馈。
- 若图片资源不可用，使用稳定渐变占位和首字母头像，避免核心流程依赖外部网络。
- 不实现真实文件解析；批量导入展示文件选择、进度和结果模拟。

## 9. 验收标准

- 新 Demo 文件可直接双击打开，无需启动服务。
- 左侧导航可进入内容发布、草稿箱、马甲号管理、操作记录和风险事件。
- 可以选择和退出马甲号身份，且所有相关区域同步更新。
- 未选择身份时，代发布操作被明确拦截。
- 可以进入文章工作台，编辑主要字段并查看手机端预览。
- 可以保存草稿、触发表单校验、提交审核并看到状态变化。
- 可以创建或编辑马甲号，并演示批量导入结果。
- 可以筛选操作记录并查看 before/after 详情。
- 禁止能力不出现在 Demo 的可执行交互中。
- 原 `社区后台demo.html` 保持不变。

## 10. 三视角评审

### 10.1 运营视角

完整覆盖“选身份—产内容—审状态—查日志”，减少跨页面核对成本。顶部固定身份上下文可降低错用账号风险。

### 10.2 开发视角

单文件增量实现便于演示和交付；身份上下文、文章状态和日志数据应使用统一的前端状态对象，避免页面之间显示不一致。

### 10.3 风控视角

真实员工身份与马甲号身份双重留痕，停用账号不可操作，高风险能力不提供入口，满足演示阶段的审计和边界要求。
