# Demo 2 基准价与地区例外价设计

## 目标

解决全球发行时逐个地区填写价格过长的问题。开发者先设置覆盖全部发行地区的 USD 基准价，仅为少数特殊地区补充当地币种例外价。

仅修改 `demos/开发者后台一期/02-CDKEY商品与供给demo.html` 的商品与 SKU 定价模块，不调整 PRD、后台审核 Demo、发行区域选择和多语言流程。

## 方案

收费 SKU 保留两种定价方式：

- 全球统一价：沿用一个 USD 售价及可选折扣价。
- 分区定价：改为“基准价＋地区例外价”。

选择分区定价后，页面依次展示：

1. 基准价：填写默认售价、默认折扣价和折扣时间。基准币种为 USD，覆盖发行设置中所有未配置例外价的地区。
2. 例外地区：展示“其余 N 个发行地区使用基准价”和“添加例外地区”。添加后仅显示少量例外行，不再平铺全部地区。
3. 例外价：每行显示国家／地区、地区码、当地结算币种、售价、折扣价及移除操作。

## 币种与继承规则

- 基准价使用 USD。平台按汇率与当地尾数规则换算未配置例外价地区的本地展示价；Demo 仅表达规则，不模拟汇率结果。
- 例外地区售价使用该地区结算币种，填写后覆盖基准售价的自动换算结果。
- 例外地区折扣价选填。未填写时，继承基准价的折扣比例；填写后使用当地币种折扣价，且必须低于该地区售价。
- 基准价未设置折扣时，例外地区折扣价仍可单独设置，但须配置有效的公共折扣起止时间。

## 发行区域联动

- 发行设置是地区范围的唯一来源，SKU 内不能新增未发行地区。
- “添加例外地区”仅列出当前已选且尚未配置例外价的发行地区，支持搜索和多选。
- 发行区域新增后，默认继承基准价，不自动生成新行。
- 发行区域移除后，对应例外价从页面隐藏并停止生效；草稿保留原值，重新选择该地区时恢复。
- 提审快照只包含当前发行地区和当前生效的例外价，不携带范围外价格。
- 审核中同时锁定发行区域、基准价和例外价。

## 数据结构

继续复用 SKU 现有字段，减少迁移范围：

```js
{
  pricingModel: 'paid',
  pricingStrategy: 'regional',
  listPrice: '19.99',
  discountPrice: '14.99',
  regionalPrices: {
    JP: { listPrice: '2200', discountPrice: '1650' },
    BR: { listPrice: '59.90', discountPrice: '' }
  },
  discountStartAt: '2026-09-20T10:00',
  discountEndAt: '2026-09-27T10:00'
}
```

- `listPrice`、`discountPrice`：分区定价的 USD 基准价。
- `regionalPrices`：仅保存地区例外价，以两位地区码为键。
- 例外折扣价为空表示继承基准折扣比例。

旧草稿若已逐地区填写价格，不推断跨币种基准价：基准价保持待填写，原地区价格保留为例外价，避免静默改价。旧币种键按当前发行地区展开为地区例外价。

## 校验与定位

- 分区定价必须填写大于 0、最多两位小数的 USD 基准售价。
- 例外地区必须属于当前发行范围，不能重复。
- 例外售价必填，并按对应币种精度校验；当前 Demo 统一限制最多两位小数。
- 例外折扣价填写后必须低于例外售价。
- 任一默认或例外折扣生效时，折扣开始时间必须早于结束时间，结束时间不得早于当前时间。
- 提交失败时自动定位首个错误：基准售价、例外售价、例外折扣价或折扣时间。

## 交互状态

- 无例外价：显示“全部已选发行地区使用基准价”。
- 有例外价：显示例外数量与继承基准价的地区数量。
- 无可添加地区：禁用“添加例外地区”，说明当前发行地区均已设置例外价。
- 删除例外：立即恢复该地区继承基准价，不增加二次确认。
- 免费 SKU：隐藏基准价和例外价，保存时清空全部收费配置。
- 定价方式切换：保留另一方式已填草稿，切回后恢复。

## 验证

- 发行设置选择大量地区时，分区定价默认只显示一行基准价。
- 添加美国、日本、巴西后只显示三条例外价，且币种分别为 USD、JPY、BRL。
- 新增发行地区不增加价格行；移除并恢复例外地区时草稿价格恢复。
- 同币种地区可分别配置例外价。
- 提审快照不包含已移除发行地区的例外价。
- 1440px 与 390px 宽度无横向裁切，添加、搜索、多选、删除和错误定位可操作。
- 多语言现有测试继续通过。
