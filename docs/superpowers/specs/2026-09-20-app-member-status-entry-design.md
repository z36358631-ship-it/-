# APP 会员状态入口设计

## 目标

修复游戏库“会员游戏”Tab 顶部会员状态条与会员中心之间的入口不一致：无论会员是否开通，用户点击状态条都进入会员中心完成查看、开通或续费。

## 现状与问题

- 未开通状态只展示“会员未开通／开通后可畅玩会员游戏”，没有可用入口。
- 已开通状态只有右侧“续费”文字可点击，状态条其他区域不可点击。
- PRD 已定义未开通、已过期和续费入口均进入会员中心，Demo 尚未完整落实。

## 交互设计

1. 将整个会员状态条改为统一可点击入口，点击后使用现有 `membership` 路由进入会员中心。
2. 未开通或已过期：左侧显示“会员未开通”，右侧显示“去开通 ›”。
3. 已开通：左侧显示“会员权益生效中”，右侧显示“有效期至 YYYY.MM.DD　续费 ›”。
4. 会员游戏 Tab 内不创建会员订单，不新增弹窗、Toast 或中间页。
5. 竖屏、横屏、普通版和标注版使用同一状态与路由规则。

## 范围

### 修改

- APP 租号普通版 Demo。
- APP 租号标注版 Demo。
- APP 租号 PRD 中“游戏库”和“游戏库·会员游戏Tab”的交互说明。
- 对应交互契约与回归验证（若现有测试覆盖该区域）。

### 不修改

- 会员游戏／PC游戏／复古游戏的 Tab 顺序和默认选择规则。
- 会员中心页面结构、套餐、价格和支付流程。
- 会员游戏搜索、游戏卡和游戏详情流程。
- Mac 端及运营后台。

## 状态与异常

- 会员状态查询成功：按未开通、已过期、已开通分别展示，点击均进入会员中心。
- 会员状态未知或查询失败：沿用现有加载或重试处理，不误报“已开通”，不创建订单。
- 返回游戏库：恢复“会员游戏”Tab、搜索词和滚动位置，并刷新会员状态。

## 验收标准

1. 未开通状态条任意位置可点击并进入会员中心，页面显示可购买套餐。
2. 已开通状态条任意位置可点击并进入会员中心，页面显示当前套餐和有效期。
3. 横竖屏行为一致，状态条没有嵌套按钮、溢出或无效热区。
4. 普通版、标注版、PRD 和自动化契约口径一致。
5. 公网 Demo 更新后可直接打开并完成以上链路。
