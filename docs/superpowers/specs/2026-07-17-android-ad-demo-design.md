## 1. 设计目标

制作一个可直接用于产品、设计、研发和运营评审的单文件交互 Demo，覆盖：

- 用户端 O1、H1、S1、P1、C1、G1、Q1、L1 八个广告场景；
- 运营后台的广告投放配置、A/B 测试配置和效果统计三页；
- 国内穿山甲与海外 AdMob 两套独立配置；
- 后台发布策略后切换到用户端验证结果的完整链路；
- 触发条件、展示说明、交互说明和异常边界标记。

Demo 优先验证广告能力是否可控、能否回退、是否侵入禁投链路，不连接真实广告 SDK、服务端或外部落地页。

## 2. 设计原则

1. **忠于现有产品**：用户端以用户提供的盖世游戏 App 最新截图为视觉基准，不重新设计导航、页面结构和视觉语言。
2. **体验保护优先**：游戏运行中、启动失败、重连、下载、配置、支付及用户游戏库资产列表不展示被动、自动或插屏广告；正常 PC 启动等待阶段仅允许右侧 L1 静态或无声原生广告，排队阶段仅允许用户主动点击 Q1 后展示激励广告。
3. **配置可验证**：后台草稿不会影响用户端；只有发布后，用户端模拟策略才更新。
4. **地区完全隔离**：国内和海外策略、实验与数据独立保存、独立展示，不做隐式同步。
5. **标识清晰**：用户端被动广告位 O1、H1、S1、P1、L1 参考 TapTap 使用持续可见的小号 `Ad` 标签，不得伪装成编辑精选或自然榜单；主动激励按钮、运营后台和交互说明继续使用中文“广告”。国内正式上线前需由法务和广告平台确认仅用 `Ad` 的合规性。
6. **失败不阻塞**：广告无填充、超时、SDK 异常或配置非法时，原页面和游戏流程继续运行。

## 3. 视觉基准

同一页面存在多张截图时，以修改时间最新者为准。Demo 使用以下基准：

| 场景 | 基准截图 | 用法 |
|---|---|---|
| H1 首页 | `APP核心优化/竞品对比/盖世游戏APP/20260618-120632.jpg` | 最新竖屏首页，插入原生赞助内容 |
| P1 玩游戏 | `APP核心优化/竞品对比/盖世游戏APP/20260521-152127.jpg` | 最新横屏玩游戏页，在“秒玩人气热游”自然卡中插入赞助卡 |
| C1 签到加倍 | 用户提供的云游戏签到卡截图 | 保留原签到卡，点击“签到”后展示原生结果弹层与可选加倍入口 |
| G1 零时长 | `20260521-152127.jpg` 与用户提供的云游戏时长卡截图 | 沿用玩游戏页粉紫毛玻璃视觉，展示零时长激励弹层 |
| Q1 排队加速 | 用户提供的横屏 GTA V 排队截图 | 复原“排队中…预计大于 52 分钟”、免费通道第 822 位和中央“加速排队”区域 |
| O1 开屏 | 用户提供的黑底白色盖世 Logo、最新竖屏首页与横屏游戏库截图 | 串联 Logo 动画、广告中间态和双方向目标页 |
| L1 PC 启动 | 用户提供的“正在安装固件”和“客户端启动中”横屏截图 | 两阶段共用右侧固定原生广告位 |

H1、P1 采用“截图分层切片 + 原生内容块插入”的方式，保留插卡前后的原页面像素，不直接用广告覆盖自然内容。C1、G1 沿用玩游戏页既有粉紫毛玻璃、圆角和按钮语言。Q1 使用真实横屏排队截图，只改造原“加速排队”控制区。O1 串联真实 Logo 与目标页。L1 使用两个真实启动阶段画面，并只占用右侧安全留白。用户在对话中提供但尚未落盘的截图，进入实现前必须保存到本地参考图目录；缺图时不得宣称 1:1 验收通过。

## 4. Demo 总体结构

最终文件命名为：

`demos/Android广告接入-交互标注版.html`

所有界面、交互状态、标注数据和脚本放在同一个 HTML 文件内，不使用 iframe。用于 1:1 复原的截图资源以内嵌 Data URL 方式写入最终 HTML，成品不依赖外部图片目录。

### 4.1 顶层切换

顶部提供：

- `用户端 / 运营后台` 双页面切换；
- `显示标号 / 隐藏标号`；
- `重置演示`。

用户端与运营后台不在同一画面并排，保证手机和后台都获得完整展示面积；两端共享已发布策略、实验和统计状态。国内/海外 Tab 放在运营后台内容容器内，用户端地区作为左侧模拟条件，不占用全局顶栏。

### 4.2 三栏标注框架

遵循 `demo标记` skill：

| 区域 | 宽度/尺寸 | 职责 |
|---|---:|---|
| 左侧导航 | 220px | 当前端页面列表、模拟条件、激活状态 |
| 中间 Demo | 自适应 | H1 竖屏 402×874；P1、C1、G1、Q1、L1 横屏 874×402；O1 支持双方向；后台桌面画布自适应缩放 |
| 右侧标注 | 400px | “交互说明”和“异常&边界”两个 Tab，可折叠 |

用户端左侧导航按旅程排列为 O1、H1、S1、P1、C1、G1、Q1、L1；后台产品容器包含后台名称和自身导航，功能页仅保留广告投放配置、A/B 测试配置、效果统计三页。

### 4.3 标注规则

每条具体交互标注固定包含：

1. 触发条件；
2. 展示说明；
3. 交互说明。

异常条件放入“异常&边界”Tab。编号规则为：

- 数字 `1、2、3…`：页面交互；
- 字母 `G`：全局规则；
- `E1、E2…`：异常与边界。

点击左侧页面时，中间 Demo 切换并将右侧标注滚动到对应章节；点击右侧标注时，中间对应热点闪烁高亮。标号默认关闭，开启后显示角标。

## 5. 用户端场景设计

### 5.1 H1 首页原生混投

**触发条件**

- 用户进入首页；
- 命中 H1 实验且不属于长期 Holdout；
- 通过人群、全局仲裁和频控；
- 内容广告占比抽样命中；
- 广告在限定时间内完成填充。

**展示说明**

- 不替换“今日推荐”，不占默认首位；
- 在“为你推荐”横向列表中先保留至少 3 个自然游戏，再插入同尺寸赞助游戏卡；
- 沿用自然游戏卡的图片比例、圆角、标题位置和间距，只增加持续可见的小号 `Ad` 标识，不使用统一悬浮卡；
- 每次首页访问最多形成一次 H1 有效曝光。

**交互说明**

- 点击卡片打开 Demo 内模拟落地页；
- 关闭后回到原页面和原滚动位置；
- 后台修改 H1 开关、占比、地区、人群或频控并发布后，切回用户端立即按新版本判断；
- 无填充时恢复自然内容，不留空位。

### 5.2 P1 玩游戏页赞助卡

**触发条件**

- 用户进入玩游戏页；
- 至少一组自然内容已经完整展示；
- 命中 P1 实验并通过频控和内容广告占比；
- 本次页面访问尚未产生 P1 有效曝光。

**展示说明**

- 使用 `20260521-152127.jpg` 对应的横屏玩游戏页，不再使用竖屏参考；
- 在“秒玩人气热游”首组中先保留至少 2 个自然游戏，再插入同规格赞助游戏卡；
- 采用页面原有游戏卡形式，仅增加持续可见的小号 `Ad` 标识，不使用统一悬浮卡或全屏蒙层；
- 不显示自然榜单名次、奖牌或虚假评分。

**交互说明**

- 点击打开 Demo 内落地页；
- 关闭后回到原滚动位置；
- 关闭、失败或无填充不改变后续自然游戏顺序；
- 同一次访问继续滚动时不再展示第二张。

### 5.3 C1 签到时长加倍激励

**触发条件**

- 用户位于横屏云游戏页，点击现有“每日签到”卡中的“签到”按钮；
- 基础签到奖励由服务端模拟成功发放；
- C1 已发布策略、人群、地区和运营配置判定允许展示；
- 激励广告可播放。

**展示说明**

- 默认页面不新增广告按钮，不改变原签到卡布局；
- 点击签到后，先展示“签到成功，获得 X 分钟”的盖世原生结果弹层；
- 弹层沿用页面粉紫毛玻璃、圆角和按钮语言，提供“看广告再领 X 分钟”和“完成”两个明确出口；
- `X` 与是否开放加倍均来自后台/服务端模拟配置，Demo 示例可显示“1 小时 → 2 小时”。

**交互说明**

- 基础时长先到账，用户不看广告也能完成签到；
- 用户主动点击“看广告再领 X 分钟”后才播放激励广告；
- 完整观看并校验成功后补发与基础签到相同的时长，原“签到”按钮更新为“已领双倍”；
- 提前关闭、播放失败或校验失败不补发加倍奖励，但不回收已到账的基础签到奖励；
- 重复奖励回调按 `reward_id` 幂等处理，不重复发放。

### 5.4 G1 零时长激励

**触发条件**

- 用户主动点击启动云游戏；
- 服务端模拟状态判定当前可用时长为 0；
- 游戏启动请求尚未创建；
- 奖励次数和模拟容量允许；
- 激励广告可用。

**展示说明**

- 底层使用清晰的横屏玩游戏页，不对整页模糊；
- 弹层沿用原时长/充值卡的粉紫毛玻璃、圆角和按钮样式，明确显示“看约 15 秒广告，获得 5 分钟”；
- 同时提供返回、等待额度恢复等非广告出口；
- 不使用误导文案，不默认自动播放。

**交互说明**

- 点击“看广告得时长”进入模拟播放；
- 完整观看且校验成功后展示到账结果，再继续启动；
- 提前关闭、播放失败或校验失败均不发奖、不扣次数；
- 奖励到账前不得创建游戏启动请求。

### 5.5 Q1 排队加速激励

**触发条件**

- 用户处于免费通道排队中，未进入付费快速通道；
- 服务端模拟预计等待时间大于后台 Q1 等待阈值；
- Q1 开关、人群、地区、版本和独立奖励频控合格；
- 当前游戏意图会话未成功使用 G1/Q1；
- 激励广告可播放。

**展示说明**

- 中间 Demo 自动切换为 874×402 横屏画布，复原 GTA V 背景、“排队中…预计大于 52 分钟”和“免费通道第 822 位”；
- 原中央“加速排队”区域展示“看广告加速排队”；
- 辅助文案展示“约 15 秒｜加速排队并领取 5 分钟｜今日剩 1 次”；
- 不弹出自动广告，不承诺固定提升名次；新预计时间只展示服务端模拟返回值。

**交互说明**

- 用户主动点击后播放模拟激励广告；播放期间排队计时、心跳和原排队位置保持；
- 完整观看并校验成功后，同时演示切入加速通道、增加 5 分钟和预计等待时间刷新；
- “广告期间已排到”状态直接进入游戏，只发 5 分钟；“用户已退出排队”状态只发 5 分钟，不重新入队；
- 提前关闭、播放失败或校验失败不发权益、不扣次数，返回原排队位置；
- 校验超时进入“权益确认中”，自动查询结果且不提供重看入口；
- G1/Q1 成功任一项后，当前会话另一入口隐藏。

### 5.6 O1 老用户低频开屏

**触发条件**

- 用户为符合条件的老用户；
- 本次属于真正冷启动；
- 命中 O1 实验且不属于长期 Holdout；
- 通过后台频控；
- 广告已提前加载完成。

**展示说明**

- Demo 完整演示“黑底白色盖世 Logo 动画 → 全屏 App Open 广告 → 目标页面”；
- 显示小号 `Ad` 标识、跳过倒计时和跳过入口；
- 页面内支持竖屏/横屏启动切换：竖屏目标为最新首页，横屏目标为最新游戏库；
- 不增加等待补加载页面。

**交互说明**

- 倒计时结束后可跳过；
- 点击广告打开 Demo 内落地页，关闭后按当前方向进入首页或游戏库；
- 通过模拟入口验证热启动、Push、Deep Link、崩溃恢复和游戏返回均不展示；
- 广告未预加载完成时跳过广告中间态，直接进入当前方向目标页。

### 5.7 L1 PC 游戏启动等待广告

**触发条件**

- 用户已进入正常 PC 游戏启动流程的“安装固件/运行环境准备”或“Steam 与客户端启动”阶段；
- L1 已发布策略、人群、地区和运营配置判定允许展示；
- 右侧安全区足够且广告已完成加载；
- 当前不属于启动失败、兼容错误、弱网、重连或排障状态。

**展示说明**

- 两个阶段定义为同一个 L1 资源位，页面内提供“阶段一：正在安装固件 / 阶段二：客户端启动中”切换；
- 874×402 画布中广告卡约为 204×140px，定位约为 `top:58px; right:22px`；
- 广告卡使用黑色半透明底、低透明白色描边、盖世同级圆角，上部媒体图、下部标题与小型 CTA，持续显示小号 `Ad` 和 SDK 要求的 AdChoices 标识；
- 不遮挡进度条、进度文字、错误文案、Steam/客户端关系图、麦克风入口和 GameFusion 标识；
- 不对原页面加全局蒙层或模糊，只允许静态或无声原生素材。

**交互说明**

- 两阶段共享同一个 `startup_session_id`、广告请求、素材和曝光身份；切换阶段不刷新素材、不重复计曝光；
- 点击广告打开 Demo 内模拟落地层，启动任务继续执行；关闭后返回最新启动阶段；
- 游戏准备完成时立即结束广告展示并进入游戏，不等待广告；
- 启动失败或进入排障状态时错误信息优先，广告立即隐藏；
- 无填充、超时或 SDK 异常时恢复原纯黑页面，不保留空框、不改变启动布局。

## 6. 运营后台三页设计

### 6.1 国内与海外独立 Tab

三个后台页面顶部统一显示：

`国内（穿山甲） / 海外（AdMob）`

- 两个 Tab 的广告位开关、频控、人群、广告占比和实验配置独立保存；
- 切换 Tab 时，配置、实验和效果统计同步切换地区上下文；
- 国内默认人民币和穿山甲，海外默认美元和 AdMob；
- 不提供隐式同步；如提供“复制配置”，必须由运营明确点击并二次确认。

### 6.2 广告投放配置

**触发条件**

- 运营进入广告管理，并在配置列表中选择 O1、H1、P1、C1、G1、Q1、L1 任一广告位；
- 已选择国内或海外 Tab。

**展示说明**

页面采用“配置列表 + 右侧抽屉”，列表展示：名称、地区、平台、广告位、状态、投放比例、频控摘要、更新时间和操作。新建、查看、编辑在右侧抽屉完成，删除使用二次确认。抽屉支持：

- 全局总开关、全局熔断和当前策略版本；
- 广告位开关；
- 用户范围：新用户、老用户、全部用户、零时长用户；
- 地区对应网络；
- 内容广告占比；
- 频控：一天一次、X 天 X 次、永久一次、自定义冷却；
- 草稿或已发布状态。

选择 Q1 时，在同一配置页追加专属字段：等待阈值、赠送时长、加速等级、Q1 独立频控和 G1/Q1 同会话互斥。付费快速通道为强制排除条件，不提供普通运营关闭入口。

选择 C1 时追加基础签到奖励展示、加倍奖励、服务端幂等和奖励频控字段；正式数值由运营配置，Demo 不替运营决定。选择 L1 时追加阶段一/阶段二开关、素材格式与右侧安全区校验；两个阶段仍属于同一广告位。

**交互说明**

- 支持配置记录的新增、查看、编辑和删除；
- 点击列表行或操作按钮打开对应抽屉；
- 编辑后先保存草稿，不立即影响用户端；
- 点击发布生成新模拟策略版本；
- 切到用户端验证新策略；
- 全局熔断作为顶部紧急操作，优先级高于所有广告位开关和占比。

### 6.3 A/B 测试配置

**触发条件**

- 运营或产品需要创建、调整或查看广告实验；
- 已选择国内或海外 Tab。

**展示说明**

页面采用“实验列表 + 右侧抽屉”，展示实验名称、地区、人群、长期 Holdout、对照组、实验组、流量比例、关联广告位、状态、实验时间和互斥关系。实验流量比例与内容广告占比使用不同字段和区域。

**交互说明**

- 调整分组比例，比例合计必须为 100%；
- 支持创建、查看、编辑、删除、启动和暂停模拟实验，删除使用二次确认；
- 实验启动后锁定核心分组字段，避免中途污染；
- H1 与 P1 首轮实验默认互斥；长期 Holdout 不进入本期新广告实验；
- 选择 Q1 实验模板时展示“对照组 / 仅加时长组 / 加速＋时长组”，比例由运营配置且合计必须为 100%；
- Q1 与 G1 的同会话互斥属于业务安全规则，不因实验分组调整而失效；
- C1、L1 可作为独立实验关联广告位，频率和奖励值仅展示运营配置，不写死产品默认值。

### 6.4 效果统计

**触发条件**

- 广告模拟产生机会、请求、曝光、点击、奖励或收入；
- 用户切换到效果统计页。

**展示说明**

- 顶部卡片：收入、曝光、eCPM、CTR；
- 广告漏斗：机会、请求、填充、渲染、曝光、点击；
- O1、H1、P1、C1、G1、Q1、L1 广告位对比；
- 实验组次日/7 日留存（retention D1/D7）、游戏启动成功率和退出指标；
- 当前止损状态。

Q1 详情区展示入口曝光、点击、视频完成率、双权益成功率、加速前后预计等待、排队退出率、进入游戏率，以及未观看 Q1 用户的等待时间中位数与 P90。

C1 详情区展示签到成功、加倍入口曝光、视频完成、奖励成功、额外时长实际使用和增量云成本。L1 详情区展示两个启动阶段的机会、同请求延续率、有效曝光、点击、启动耗时、启动成功率、启动取消率和错误状态误展示数。

**交互说明**

- 按时间、广告位、实验组以及国内/海外切换；
- 用户端产生模拟曝光、点击或奖励后，统计数据即时更新；
- 指标触发止损阈值时标红，并提供跳转广告投放配置的“暂停广告位”入口。

## 7. 共享状态与数据流

Demo 内部维护以下状态：

- 国内和海外两套广告位配置；
- 当前模拟用户身份、地区和启动来源；
- O1、H1、P1、C1、G1、Q1、L1 的广告请求、填充、曝光和频控状态；
- C1 的基础签到奖励、加倍奖励、`reward_id` 和到账状态；
- Q1 的排队 ID、原位置、通道、服务端预计等待、权益状态、`reward_id` 和 G1/Q1 互斥状态；
- L1 的 `startup_session_id`、当前启动阶段、共享广告请求、素材身份和启动结果；
- A/B 实验分组与长期 Holdout；
- 草稿版本和已发布版本；
- 模拟效果统计。

主数据流为：

```text
后台选择地区与广告位
→ 修改开关、人群、广告占比和频率
→ 保存草稿
→ 发布并生成新策略版本
→ 切换用户端
→ 按地区、用户、实验、频控和占比判断
→ 展示广告或拒绝原因
→ 模拟曝光、点击或奖励
→ 效果统计更新
```

运营配置的内容广告占比不改变 A/B 测试分组；A/B 测试流量比例也不直接等于实际广告曝光概率。

## 8. 异常与边界

- H1、P1 无填充、超时或 SDK 异常时不显示空白卡位；
- C1 必须先发基础签到奖励；广告失败、提前退出或校验失败不补发加倍奖励，也不回收基础奖励；重复 `reward_id` 不重复发放；
- G1 覆盖播放失败、提前退出、服务端校验失败、重复奖励回调和到账超时；
- G1 重复回调只发放一次奖励；
- Q1 覆盖提前关闭、播放失败、校验失败、校验超时、重复 `reward_id`、广告期间已排到和广告期间退出排队；
- Q1 播放失败保持原排队位置；完整观看后已排到/已退出时只发时长，不再发加速；
- 付费快速通道和等待时间未超过阈值时，Q1 入口不展示；
- G1/Q1 同一游戏意图会话成功发放任一权益后，另一入口隐藏；
- O1 覆盖未预加载、非冷启动、频控超限、新用户和 Holdout；
- L1 无填充时恢复原黑色页面；阶段切换沿用同一素材；启动完成或失败立即隐藏；安全区不足时不展示；
- 国内 Tab 选择 AdMob 或海外 Tab 选择穿山甲时阻止发布；
- A/B 分组比例不等于 100% 时阻止启动实验；
- 游戏启动请求创建后，除已发布 L1 右侧静态/无声原生广告外，其他被动、自动和插屏广告请求立即拒绝；排队阶段仅允许用户主动点击 Q1 后发起激励广告请求；
- 频控仅按有效曝光计数，请求失败和无填充不扣次数；
- 全局熔断优先级高于单广告位开关、实验和 100% 内容广告占比；
- 配置缺失或非法时默认不展示广告，并在异常标注中显示拒绝原因。

## 9. 验收路径

1. 国内 H1 设置为 100%，发布后用户端出现穿山甲原生广告；
2. 切到海外后，同一广告位按海外独立配置显示 AdMob 或不展示；
3. P1 设置“永久一次”，首次出现、重进后不再出现；
4. 新用户无法触发 O1，老用户真正冷启动且频控合格时可以触发；
5. C1 点击签到先发基础时长，用户主动观看成功后补发同额时长；失败不影响基础奖励；
6. G1 完整观看后到账，提前关闭或失败不发奖；
7. Q1 仅在免费通道等待超过阈值时展示，完整观看后演示“加速通道＋5 分钟”双权益；
8. Q1 播放期间已排到或退出时只发时长；失败保持原位置；校验超时不要求重看；
9. 同一游戏意图会话 G1/Q1 成功触发总数不超过 1；
10. L1 两阶段固定在右侧安全区并沿用同一素材；不遮挡关键状态，完成或失败立即隐藏；
11. O1 完整演示 Logo → 广告 → 目标页，且竖屏进入首页、横屏进入游戏库；
12. 开启全局熔断后，七个广告位全部停止展示；
13. A/B 分组和效果统计能够按国内/海外分别查看；
14. 投放和实验列表支持增删查改、右侧抽屉和删除二次确认；
15. 草稿未发布时用户端不变化，发布后策略版本和展示结果同步更新；
16. 所有标号、标注项和界面热点可以双向高亮；
17. 用户端和运营后台可以通过顶部入口稳定切换，切换后状态不丢失。

## 10. 非目标

- 不接入真实穿山甲或 AdMob SDK；
- 不请求真实广告素材，不打开外部落地页；
- 不实现正式服务端、账号权限、审批流或账单对账；
- 不实现会员免广告或会员权益；
- 不实现 iOS 广告；
- 不在游戏运行中、启动失败、重连或排障链路展示广告；正常 PC 启动等待仅实现 L1 右侧静态/无声原生广告，排队阶段仅实现用户主动 Q1；
- 不在搜索无结果页和游戏详情页实现赞助广告；搜索结果页仅按已确认的 S1 规则展示原生游戏广告；
- 不扩展第四个及以上运营后台页面。
