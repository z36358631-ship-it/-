## 1. 设计目标

制作一个可直接用于产品、设计、研发和运营评审的单文件交互 Demo，覆盖：

- 用户端 H1、P1、G1、Q1、O1、D1、S1 七个广告场景；
- 运营后台的广告投放配置、A/B 测试配置和效果统计三页；
- 国内穿山甲与海外 AdMob 两套独立配置；
- 后台发布策略后切换到用户端验证结果的完整链路；
- 触发条件、展示说明、交互说明和异常边界标记。

Demo 优先验证广告能力是否可控、能否回退、是否侵入禁投链路，不连接真实广告 SDK、服务端或外部落地页。

## 2. 设计原则

1. **忠于现有产品**：用户端以用户提供的盖世游戏 App 最新截图为视觉基准，不重新设计导航、页面结构和视觉语言。
2. **体验保护优先**：启动中、运行中、失败、重连、下载、领取、配置、支付及用户游戏库资产列表不展示被动、自动或插屏广告；排队阶段仅允许用户主动点击 Q1 后展示一次激励广告。
3. **配置可验证**：后台草稿不会影响用户端；只有发布后，用户端模拟策略才更新。
4. **地区完全隔离**：国内和海外策略、实验与数据独立保存、独立展示，不做隐式同步。
5. **标识清晰**：所有商业内容持续显示“广告”或“赞助推荐”，不得伪装成编辑精选或自然榜单。
6. **失败不阻塞**：广告无填充、超时、SDK 异常或配置非法时，原页面和游戏流程继续运行。

## 3. 视觉基准

同一页面存在多张截图时，以修改时间最新者为准。Demo 使用以下基准：

| 场景 | 基准截图 | 用法 |
|---|---|---|
| H1 首页 | `APP核心优化/竞品对比/盖世游戏APP/20260618-120632.jpg` | 最新竖屏首页，插入原生赞助内容 |
| P1 玩游戏 | `APP核心优化/竞品对比/盖世游戏APP/20260521-152024.jpg` | 登录状态竖屏玩游戏页 |
| G1 零时长 | `20260521-152024.jpg` 与 `20260521-152127.jpg` | 沿用玩游戏页视觉，并参考真实零时长信息 |
| Q1 排队加速 | 用户提供的横屏 GTA V 排队截图 | 复原“排队中…预计大于 52 分钟”、免费通道第 822 位和中央“加速排队”区域 |
| O1 开屏 | 盖世品牌和首页色彩体系 | PRD 新增状态，明确标记为推导设计 |
| D1 游戏详情 | `img_v3_02123_fc615f68-5212-4632-b026-6baffc50519g.jpg` | 最新确认的竖屏详情结构 |
| S1 搜索无结果 | `20260521-152007.jpg` | 沿用搜索输入、历史和热门搜索结构，新增无结果状态 |

H1、P1、D1 等插卡场景采用“截图分段 + 中间插入可交互广告组件”的方式，保留插卡前后的原页面像素，不直接用广告覆盖自然内容。Q1 使用横屏 874×402 画布复原用户提供的排队页，并只改造中央“加速排队”区域。缺少线上截图的 G1、O1、S1 状态沿用现有组件、间距、圆角和毛玻璃语言推导，并显示“PRD 新增状态”标记。

## 4. Demo 总体结构

最终文件命名为：

`demos/Android广告接入-交互标注版.html`

所有界面、交互状态、标注数据和脚本放在同一个 HTML 文件内，不使用 iframe。用于 1:1 复原的截图资源以内嵌 Data URL 方式写入最终 HTML，成品不依赖外部图片目录。

### 4.1 顶层切换

顶部提供：

- `用户端 / 运营后台` 双页面切换；
- `国内 / 海外` 地区切换；
- `显示标号 / 隐藏标号`；
- `重置演示`。

用户端与运营后台不在同一画面并排，保证手机和后台都获得完整展示面积；两端共享已发布策略、实验和统计状态。

### 4.2 三栏标注框架

遵循 `demo标记` skill：

| 区域 | 宽度/尺寸 | 职责 |
|---|---:|---|
| 左侧导航 | 220px | 当前端页面列表、模拟条件、激活状态 |
| 中间 Demo | 自适应 | 用户端竖屏 402×874；Q1 横屏 874×402；后台桌面画布自适应缩放 |
| 右侧标注 | 400px | “交互说明”和“异常&边界”两个 Tab，可折叠 |

用户端左侧导航包含 H1、P1、G1、Q1、O1、D1、S1；后台左侧导航仅包含广告投放配置、A/B 测试配置、效果统计。

### 4.3 标注规则

每条具体交互标注固定包含：

1. 触发条件；
2. 展示说明；
3. 交互说明。

异常条件放入“异常&边界”Tab。编号规则为：

- 数字 `1、2、3…`：页面交互；
- 字母 `G`：全局规则；
- `E1、E2…`：异常与边界。

点击左侧页面时，中间 Demo 切换并将右侧标注滚动到对应章节；点击右侧标注时，中间对应热点闪烁高亮。标号默认关闭，开启后显示角标。

## 5. 用户端场景设计

### 5.1 H1 首页原生混投

**触发条件**

- 用户进入首页；
- 命中 H1 实验且不属于长期 Holdout；
- 通过人群、全局仲裁和频控；
- 内容广告占比抽样命中；
- 广告在限定时间内完成填充。

**展示说明**

- 广告位于第一组自然内容之后，不占“今日推荐”默认首位；
- 沿用首页卡片尺寸和圆角，持续显示“广告”或“赞助推荐”；
- 每次首页访问最多形成一次 H1 有效曝光。

**交互说明**

- 点击卡片打开 Demo 内模拟落地页；
- 关闭后回到原页面和原滚动位置；
- 后台修改 H1 开关、占比、地区、人群或频控并发布后，切回用户端立即按新版本判断；
- 无填充时恢复自然内容，不留空位。

### 5.2 P1 玩游戏页赞助卡

**触发条件**

- 用户进入玩游戏页；
- 至少一组自然内容已经完整展示；
- 命中 P1 实验并通过频控和内容广告占比；
- 本次页面访问尚未产生 P1 有效曝光。

**展示说明**

- 插在第一组完整自然内容之后；
- 采用游戏卡形式，但增加持续广告标识和差异化边框；
- 不显示自然榜单名次、奖牌或虚假评分。

**交互说明**

- 点击打开 Demo 内落地页；
- 关闭后回到原滚动位置；
- 关闭、失败或无填充不改变后续自然游戏顺序；
- 同一次访问继续滚动时不再展示第二张。

### 5.3 G1 零时长激励

**触发条件**

- 用户主动点击启动云游戏；
- 服务端模拟状态判定当前可用时长为 0；
- 游戏启动请求尚未创建；
- 奖励次数和模拟容量允许；
- 激励广告可用。

**展示说明**

- 弹窗明确显示“看约 15 秒广告，获得 5 分钟”；
- 同时提供返回、等待额度恢复等非广告出口；
- 不使用误导文案，不默认自动播放。

**交互说明**

- 点击“看广告得时长”进入模拟播放；
- 完整观看且校验成功后展示到账结果，再继续启动；
- 提前关闭、播放失败或校验失败均不发奖、不扣次数；
- 奖励到账前不得创建游戏启动请求。

### 5.4 Q1 排队加速激励

**触发条件**

- 用户处于免费通道排队中，未进入付费快速通道；
- 服务端模拟预计等待时间大于后台 Q1 等待阈值；
- Q1 开关、人群、地区、版本和独立奖励频控合格；
- 当前游戏意图会话未成功使用 G1/Q1；
- 激励广告可播放。

**展示说明**

- 中间 Demo 自动切换为 874×402 横屏画布，复原 GTA V 背景、“排队中…预计大于 52 分钟”和“免费通道第 822 位”；
- 原中央“加速排队”区域展示“看广告加速排队”；
- 辅助文案展示“约 15 秒｜加速排队并领取 5 分钟｜今日剩 1 次”；
- 不弹出自动广告，不承诺固定提升名次；新预计时间只展示服务端模拟返回值。

**交互说明**

- 用户主动点击后播放模拟激励广告；播放期间排队计时、心跳和原排队位置保持；
- 完整观看并校验成功后，同时演示切入加速通道、增加 5 分钟和预计等待时间刷新；
- “广告期间已排到”状态直接进入游戏，只发 5 分钟；“用户已退出排队”状态只发 5 分钟，不重新入队；
- 提前关闭、播放失败或校验失败不发权益、不扣次数，返回原排队位置；
- 校验超时进入“权益确认中”，自动查询结果且不提供重看入口；
- G1/Q1 成功任一项后，当前会话另一入口隐藏。

### 5.5 O1 老用户低频开屏

**触发条件**

- 用户为符合条件的老用户；
- 本次属于真正冷启动；
- 命中 O1 实验且不属于长期 Holdout；
- 通过后台频控；
- 广告已提前加载完成。

**展示说明**

- 展示全屏 App Open 广告；
- 显示广告标识、跳过倒计时和跳过入口；
- 不增加等待补加载页面。

**交互说明**

- 倒计时结束后可跳过；
- 点击广告打开 Demo 内落地页，关闭后进入首页；
- 通过模拟入口验证热启动、Push、Deep Link、崩溃恢复和游戏返回均不展示；
- 广告未预加载完成时直接进入首页。

### 5.6 D1 游戏详情相关赞助

**触发条件**

- 用户进入游戏详情；
- 已浏览核心启动、引擎和兼容信息；
- 广告进入有效可视区域；
- 通过人群、实验和频控。

**展示说明**

- 位于核心启动按钮和兼容信息之后；
- 使用横向相关赞助卡，持续显示广告标识；
- 每次详情访问最多展示一张。

**交互说明**

- 进入有效可视区域才计模拟曝光；
- 点击广告打开 Demo 内落地页；
- 用户点击启动后立即取消尚未曝光的广告请求；
- 返回详情时保持原页面状态，不在启动链路补展示。

### 5.7 S1 搜索无结果赞助

**触发条件**

- 用户提交搜索；
- 自然结果数量为 0；
- 广告与关键词或识别出的游戏品类相关；
- 通过人群、频控和填充判断。

**展示说明**

- 保留“未找到结果，换个关键词试试”等自然引导；
- 自然引导下方展示一张相关赞助推荐；
- 广告不是唯一出口。

**交互说明**

- 点击推荐打开 Demo 内落地页；
- 用户可修改关键词重新搜索；
- 切换为“存在自然结果”时，S1 赞助区立即消失；
- 无填充或相关性不足时只显示自然引导。

## 6. 运营后台三页设计

### 6.1 国内与海外独立 Tab

三个后台页面顶部统一显示：

`国内（穿山甲） / 海外（AdMob）`

- 两个 Tab 的广告位开关、频控、人群、广告占比和实验配置独立保存；
- 切换 Tab 时，配置、实验和效果统计同步切换地区上下文；
- 国内默认人民币和穿山甲，海外默认美元和 AdMob；
- 不提供隐式同步；如提供“复制配置”，必须由运营明确点击并二次确认。

### 6.2 广告投放配置

**触发条件**

- 运营进入广告管理并选择 H1、P1、G1、Q1、O1、D1、S1 任一广告位；
- 已选择国内或海外 Tab。

**展示说明**

单页展示：

- 全局总开关、全局熔断和当前策略版本；
- 广告位开关；
- 用户范围：新用户、老用户、全部用户、零时长用户；
- 地区对应网络；
- 内容广告占比；
- 频控：一天一次、X 天 X 次、永久一次、自定义冷却；
- 草稿或已发布状态。

选择 Q1 时，在同一配置页追加专属字段：等待阈值、赠送时长、加速等级、Q1 独立频控和 G1/Q1 同会话互斥。付费快速通道为强制排除条件，不提供普通运营关闭入口。

**交互说明**

- 切换广告位加载该地区下的对应策略；
- 编辑后先保存草稿，不立即影响用户端；
- 点击发布生成新模拟策略版本；
- 切到用户端验证新策略；
- 全局熔断作为顶部紧急操作，优先级高于所有广告位开关和占比。

### 6.3 A/B 测试配置

**触发条件**

- 运营或产品需要创建、调整或查看广告实验；
- 已选择国内或海外 Tab。

**展示说明**

展示实验名称、人群、长期 Holdout、对照组、实验组、流量比例、关联广告位、实验时间和互斥关系。实验流量比例与内容广告占比使用不同字段和区域。

**交互说明**

- 调整分组比例，比例合计必须为 100%；
- 支持创建、启动和暂停模拟实验；
- 实验启动后锁定核心分组字段，避免中途污染；
- H1 与 P1 首轮实验默认互斥；长期 Holdout 不进入本期新广告实验；
- 选择 Q1 实验模板时展示“对照组 / 仅加时长组 / 加速＋时长组”，比例由运营配置且合计必须为 100%；
- Q1 与 G1 的同会话互斥属于业务安全规则，不因实验分组调整而失效。

### 6.4 效果统计

**触发条件**

- 广告模拟产生机会、请求、曝光、点击、奖励或收入；
- 用户切换到效果统计页。

**展示说明**

- 顶部卡片：收入、曝光、eCPM、CTR；
- 广告漏斗：机会、请求、填充、渲染、曝光、点击；
- H1、P1、G1、Q1、O1、D1、S1 广告位对比；
- 实验组 D1/D7、游戏启动成功率和退出指标；
- 当前止损状态。

Q1 详情区展示入口曝光、点击、视频完成率、双权益成功率、加速前后预计等待、排队退出率、进入游戏率，以及未观看 Q1 用户的等待时间中位数与 P90。

**交互说明**

- 按时间、广告位、实验组以及国内/海外切换；
- 用户端产生模拟曝光、点击或奖励后，统计数据即时更新；
- 指标触发止损阈值时标红，并提供跳转广告投放配置的“暂停广告位”入口。

## 7. 共享状态与数据流

Demo 内部维护以下状态：

- 国内和海外两套广告位配置；
- 当前模拟用户身份、地区和启动来源；
- H1、P1、G1、Q1、O1、D1、S1 的广告请求、填充、曝光和频控状态；
- Q1 的排队 ID、原位置、通道、服务端预计等待、权益状态、`reward_id` 和 G1/Q1 互斥状态；
- A/B 实验分组与长期 Holdout；
- 草稿版本和已发布版本；
- 模拟效果统计。

主数据流为：

```text
后台选择地区与广告位
→ 修改开关、人群、广告占比和频率
→ 保存草稿
→ 发布并生成新策略版本
→ 切换用户端
→ 按地区、用户、实验、频控和占比判断
→ 展示广告或拒绝原因
→ 模拟曝光、点击或奖励
→ 效果统计更新
```

运营配置的内容广告占比不改变 A/B 测试分组；A/B 测试流量比例也不直接等于实际广告曝光概率。

## 8. 异常与边界

- H1、P1、D1、S1 无填充、超时或 SDK 异常时不显示空白卡位；
- G1 覆盖播放失败、提前退出、服务端校验失败、重复奖励回调和到账超时；
- G1 重复回调只发放一次奖励；
- Q1 覆盖提前关闭、播放失败、校验失败、校验超时、重复 `reward_id`、广告期间已排到和广告期间退出排队；
- Q1 播放失败保持原排队位置；完整观看后已排到/已退出时只发时长，不再发加速；
- 付费快速通道和等待时间未超过阈值时，Q1 入口不展示；
- G1/Q1 同一游戏意图会话成功发放任一权益后，另一入口隐藏；
- O1 覆盖未预加载、非冷启动、频控超限、新用户和 Holdout；
- 国内 Tab 选择 AdMob 或海外 Tab 选择穿山甲时阻止发布；
- A/B 分组比例不等于 100% 时阻止启动实验；
- 游戏启动请求创建后，所有被动、自动和插屏广告请求立即拒绝；排队阶段仅允许用户主动点击 Q1 后发起一次激励广告请求；
- 频控仅按有效曝光计数，请求失败和无填充不扣次数；
- 全局熔断优先级高于单广告位开关、实验和 100% 内容广告占比；
- 配置缺失或非法时默认不展示广告，并在异常标注中显示拒绝原因。

## 9. 验收路径

1. 国内 H1 设置为 100%，发布后用户端出现穿山甲原生广告；
2. 切到海外后，同一广告位按海外独立配置显示 AdMob 或不展示；
3. P1 设置“永久一次”，首次出现、重进后不再出现；
4. 新用户无法触发 O1，老用户真正冷启动且频控合格时可以触发；
5. G1 完整观看后到账，提前关闭或失败不发奖；
6. Q1 仅在免费通道等待超过阈值时展示，完整观看后演示“加速通道＋5 分钟”双权益；
7. Q1 播放期间已排到或退出时只发时长；失败保持原位置；校验超时不要求重看；
8. 同一游戏意图会话 G1/Q1 成功触发总数不超过 1；
9. S1 仅在自然结果为 0 时出现；
10. D1 点击启动后，未曝光广告被取消；
11. 开启全局熔断后，七个广告位全部停止展示；
12. A/B 分组和效果统计能够按国内/海外分别查看；
13. 草稿未发布时用户端不变化，发布后策略版本和展示结果同步更新；
14. 所有标号、标注项和界面热点可以双向高亮；
15. 用户端和运营后台可以通过顶部入口稳定切换，切换后状态不丢失。

## 10. 非目标

- 不接入真实穿山甲或 AdMob SDK；
- 不请求真实广告素材，不打开外部落地页；
- 不实现正式服务端、账号权限、审批流或账单对账；
- 不实现会员免广告或会员权益；
- 不实现 iOS 广告；
- 不在游戏启动中、运行中或其他保护链路展示被动、自动或插屏广告；排队阶段仅实现用户主动 Q1；
- 不扩展第四个及以上运营后台页面。
