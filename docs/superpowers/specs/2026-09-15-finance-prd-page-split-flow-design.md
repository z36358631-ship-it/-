# 财务 PRD 页面拆分与实际页面流程图设计

## 目标

将财务 PRD 从“一个 Tab 混放多个页面状态”改为“一个 Tab 对应一个主页面，抽屉、弹窗和编辑态作为子页面”，并用真实 Demo 截图替换文字流程卡。

## 页面树

- 开发者端
  - 财务主体
    - 修改财务主体
    - 银行证明预览
  - 对账结算
    - 销售分成明细
    - 确认结算
- 运营端
  - 主体汇总
  - 游戏明细
    - 销售分成明细
    - 阶梯分成配置

筛选、分页、确认和导出写在所属页面，不拆成独立页面。

## 产品流程图

流程图使用 3 行 × 4 列真实 Demo 截图，三行互相独立：

1. 财务主体：当前主体 → 修改资料 → 提交审核 → 审核通过并生效。
2. 开发者对账：N+1 账单 → 查看明细 → 确认账单 → 已确认。
3. 运营结算：配置分成规则 → 主体汇总 → 游戏明细 → 勾选并导出。

每行独立编号，箭头只连接本行。图片只保留行标题、步骤名和页面截图；不使用文字说明卡。

## 范围

- 修改 PRD 页面结构、图示、图号和流程图。
- 新增实际页面状态截图与流程合成图。
- 不修改 Demo 功能、字段、金额、状态和业务规则。

## 验证

- 每个主页面只引用一张当前页图。
- 子页面单独使用六要素表并引用对应截图。
- 流程图 12 个画面均来自当前 Demo。
- PRD 质量校验 0 错误、0 警告；全部图片公网可访问。
