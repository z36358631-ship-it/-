# APP MODS 已安装操作统一设计

## 1. 结论

MODS 已安装列表、Steam 个人中心 MODS 卡片和 MOD 详情统一使用三项操作，顺序固定为：

`更新 | 卸载 | 启停开关`

三处读取同一设备状态。更新、卸载、启停分别保留独立动作类型和失败处理，不合并为一个无类型操作。

## 2. 更新状态

- 更新按钮始终显示“更新”。
- 已确认有更新：按钮可点，按钮内部显示红点。
- 无更新或状态未知：按钮禁用，不显示红点。
- 更新完成：清除可更新状态和红点。
- 更新失败且新版本仍可用：恢复可点击状态和红点。
- 删除卡片右上角黄色圆点，不增加其他更新标记。

更新信息来自目录同步或页面刷新，本期不提供“检查更新”按钮。

## 3. 卡片与详情操作

- 已安装列表、Steam 个人中心和详情的操作顺序、文案、状态源一致。
- 列表与个人中心的更新、卸载、开关操作均阻止卡片点击，不打开详情。
- 点击卡片内容区仍进入 MOD 详情。
- 卸载直接绑定当前 MOD 打开统一确认弹窗；取消后恢复原焦点和滚动位置。
- 卸载成功后，已安装列表、Steam 个人中心和详情同步移除该 MOD；失败时保留原状态。
- 启停使用开关，成功后直接更新状态，不显示成功 Toast；失败时恢复原值并提示。
- 横竖屏切换后保持按钮、红点、确认弹窗和当前前台操作状态，不重复触发动作。

## 4. 下载与更新中断

- 本期不支持断点续传。
- 下载和更新仅在 APP 前台执行。
- 切页或旋转不视为中断，当前前台任务继续且不重复创建。
- 断网、进入后台或进程退出后，任务结束为“已中断”，清理未完成临时文件和进度。
- 返回前台不自动恢复；用户重试时从 0 创建新任务。
- 更新中断时保留旧版本和原启用值。

## 5. 验收

1. 三处已安装内容均展示“更新、卸载、启停开关”。
2. 有更新时仅更新按钮显示红点；页面无黄色圆点。
3. 三项操作通过鼠标、触控或键盘执行时均不误开详情。
4. 卸载确认框绑定正确 MOD，取消不改变状态，确认后同步移除。
5. 断网或进入后台后不保留下载、更新进度，重试从 0 开始。
6. 横竖屏截图中操作完整、无重叠、无截断。
