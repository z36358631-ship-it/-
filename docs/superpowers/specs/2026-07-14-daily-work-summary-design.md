# 每日分类工作汇总设计

## 目标

在现有每日 18:30 交接自动化之外，为个人 Obsidian 仓库每天新增一份独立的分类工作汇总：

`D:\大超个人仓库\40-复盘与周报\日记\YYYY-MM-DD-工作汇总.md`

交接文档继续服务于任务续接和风险提醒；工作汇总只记录当天实际完成的工作，便于按项目和工作类型回顾。

## 生成方式

复用现有 `codex exec` 调用。Codex 在更新 `HANDOFF.md` 的同时，生成工作区临时文件 `.tmp/handoff/daily-work-current.md`。PowerShell 脚本校验两个文件均存在且非空后，将分类摘要同步到个人仓库。

目标文件使用 `CODEX-DAILY-WORK:START/END` 托管区块。当天重复执行时只替换托管区块，保留用户在区块外添加的内容。

## 内容结构

工作汇总固定包含以下分类；没有事实可记录的分类写“无”，不编造内容：

1. 项目工作：按项目名称分组，记录功能、Demo、需求或交付成果。
2. 产品与文档：记录 PRD、方案、设计、交接规范等文档工作。
3. 自动化与工具：记录脚本、任务调度、知识库同步和工作流改进。
4. 验证与发布：记录测试、检查、部署、提交、预览地址和验证结果。
5. 问题与处理：记录当天发现并已处理的问题；未解决事项只简述现状。
6. 主要产物：列出当天新增或更新的关键文件和可访问链接。

## 数据边界

- 只记录当天能够从工作区、Git、日志和现有交接中核实的事实。
- 不复制“下一人注意事项”“不得覆盖文件”等交接专用内容。
- 不把历史工作重复记成当天成果。
- 不修改产品代码、不提交或推送任何内容。

## 失败处理

如果 Codex 返回失败、`HANDOFF.md` 缺失或临时工作汇总为空，脚本终止并保留诊断日志，不写入不完整的个人仓库汇总。成功后删除诊断日志和临时文件，保留紧凑成功日志。

## 验证

修改后执行 PowerShell 语法检查，并实际运行脚本。验证当天交接日记仍可更新、分类工作汇总创建成功、托管标记完整、人工区块不会被覆盖、计划任务最近运行结果为 `0`。
