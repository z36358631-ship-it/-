# 盖世游戏渠道 Key 投放设计

> 状态：已确认  
> 日期：2026-09-16  
> 适用产物：`13-开发者平台与渠道分销demo.html`  
> 替代：`2026-09-16-gamehub-channel-distribution-redesign-design.md` 中销售、收益、渠道回传和结算设计

## 1. 产品定位

盖世为企业开发者提供 CDKEY 生成、交付、兑换校验和审计能力。开发者自行将 Key 投放到外部渠道。

盖世不参与：

- 开发者与渠道签约。
- 商品定价和促销。
- 渠道收款、退款和拒付。
- 开发者与渠道对账、开票和结算。

因此平台只展示自身可验证的 Key 数据，不展示销量、销售额、收益或结算结果。

## 2. 三方职责

| 角色 | 负责 |
|---|---|
| 盖世 | Key 生成、API 发码、文件交付、兑换校验、权限、安全和审计 |
| 开发者 | 选择渠道和销售项，与渠道约定价格、售后及结算 |
| 第三方渠道 | 终端销售、收款、退款、拒付和用户服务 |

创建渠道时显示一句必要说明：`渠道销售、售后与结算由你与渠道自行约定。`

完整责任边界和数据口径放入帮助中心，业务页不放长篇说明。

## 3. 信息架构

单游戏控制台保留两个入口：

1. `渠道与供货`
2. `分销数据`

### 3.1 渠道与供货

使用横向子 Tab：

- `渠道管理`
- `文件批次`

页面标题下不显示副标题。移除企业认证说明条、列表介绍和重复口径说明。帮助入口放在标题操作区。

#### 渠道管理

包含：

- 创建渠道。
- 选择本体或 DLC 销售项。
- 选择接口自动发码或下载兑换码文件。
- 管理 API 凭证。
- 暂停、恢复或停止渠道。

列表字段：

- 渠道名称和编号。
- 销售项。
- 供货方式。
- 合作状态。
- API 或文件状态。
- 最近供货时间。
- 操作。

本页不再重复显示发放、兑换等统计；统计集中到“分销数据”。

#### 文件批次

列表字段：

- 批次编号。
- 渠道。
- 销售项和 SKU。
- 生成数量。
- 有效期。
- 状态。
- 创建或下载时间。
- 操作。

### 3.2 分销数据

仅展示平台可验证的数据。

顶部指标：

- 发放量。
- 兑换量。
- 未兑换量。
- 兑换率。

列表按渠道、销售项和 SKU 归类，字段为：

- 渠道名称和编号。
- 销售项。
- 商品名称。
- SKU。
- 供货方式。
- 发放量。
- 兑换量。
- 未兑换量。
- 兑换率。
- 最近兑换时间。

页面不显示：

- 销量。
- 退款和拒付。
- 单价、币种、销售额和销售净额。
- 预估收益和应结金额。
- 销售清单导入。
- 结算表下载。

## 4. 数据口径

| 指标 | 定义 |
|---|---|
| 发放量 | API 成功返回 Key 的数量，加文件成功下载后已交付的 Key 数量 |
| 兑换量 | 用户在盖世成功兑换的 Key 数量 |
| 未兑换量 | 发放量减兑换量；不代表渠道未售库存 |
| 兑换率 | 兑换量 ÷ 发放量；发放量为 0 时显示“—” |

约束：

- 发放量不等于销量。
- 兑换量不等于销量。
- 未兑换量不等于渠道库存。
- 文件下载不等于销售完成。
- API 渠道订单号只用于幂等和追踪，不用于计算收入。

## 5. API 供货

- 渠道凭证属于渠道，不属于批次。
- API 不填写数量，不显示额度和补量。
- 同一渠道订单重复请求返回原 Key；同单异参返回冲突。
- 页面记录请求量、成功量、失败量、最近调用和 Key 兑换结果。
- 一次性 Secret 仅在创建或轮换时显示，后续不回显。
- API 不要求回传售价、退款、拒付或结算数据。

## 6. 文件供货

- 开发者填写渠道、销售项、数量和有效期后直接生成。
- 当前单文件最多生成 10,000 个 Key。
- 当前规模采用同步生成：点击后按钮显示“生成中…”，成功后立即下载并写入下载记录。
- 列表不保留常驻“生成中”状态。
- 文件已生成但浏览器未开始下载时记为“待下载”，允许再次下载同一文件，不重新生成 Key。
- 文件名为：`盖世游戏兑换码_渠道名_批次号.csv`。
- 文件字段为：`cdkey,sku_id,valid_until`。
- HTML、页面状态和日志不固化或回显明文 Key；仅下载文件在生成时持有明文。
- 下载成功后，Key 计为已交付，不得回库或重复分配。
- 下载失败时不记为已交付，保留原参数并允许重试。

文件批次状态：

- 待下载。
- 已下载。
- 已取消。
- 已到期。
- 生成失败。

## 7. 渠道合作状态

渠道状态：

- 合作中。
- 已暂停，可恢复。
- 已停止。
- 风险暂停，由平台处置。

停止合作后：

1. 立即停止 API 新发码和新建文件。
2. 未下载文件取消，不再提供下载。
3. 已下载 Key 不回库，仍按原有效期兑换。
4. 历史发放、兑换和审计记录只读保留。
5. 不进入30天清算，不生成结算单。

停止合作须二次确认，并明确已下载 Key 仍可能在外部渠道流通。

## 8. 帮助中心

“发行与供给”目录保留并调整为：

1. 渠道投放使用说明。
2. 接口自动发码接入指南。
3. API 鉴权、发码、查询和错误码。
4. 下载兑换码文件教程。
5. Key 状态与兑换数据口径。
6. 文件批次和下载记录说明。
7. 停止合作与已交付 Key 处理。
8. 三方责任与渠道结算边界。

运营后台继续支持中英文配置；后台操作界面使用中文，对外文章按开发者所选语言展示。

## 9. 异常与恢复

- API 发码超时：使用原渠道订单号查询，不换订单号重试。
- 重复订单异参：返回冲突，不改变原发放结果。
- 凭证泄露：暂停凭证并轮换 Secret。
- 文件生成失败：显示原因并用原参数重试。
- 文件下载中断：未完成交付时不计发放量。
- Key 兑换失败：保留错误码、时间、渠道和 SKU，供开发者排查。
- 渠道停止后请求发码或下载：拒绝并返回渠道已停止。

## 10. Demo 验收

1. `渠道与供货`下有“渠道管理／文件批次”横向子 Tab。
2. 页面移除副标题、蓝色介绍条和重复说明。
3. 渠道管理列表不重复展示发放和兑换统计。
4. `销售与收益`改为`分销数据`。
5. 分销数据只展示发放、兑换、未兑换和兑换率。
6. 页面不存在销量、退款、拒付、金额、收益、销售导入和结算文案。
7. 文件下载名明确为兑换码文件，真实下载内容为随机演示 Key。
8. 文件生成使用按钮加载态，不保留常驻“生成中”列表状态。
9. 停止合作后直接进入“已停止”，不出现“清算中”或30天清算。
10. 帮助中心8篇文章同步新口径，并保持中英文 ID 一致。
11. 320px、390px、1280px 和1440px无根节点溢出。
12. 现有企业认证权限、API Secret 安全和 Key 指纹校验继续有效。

## 11. 明确不做

- 渠道账号和渠道自助后台。
- 渠道准入和线上签约。
- 商品定价、促销和订单管理。
- 渠道销量、退款和拒付回传。
- 销售账单导入。
- 对账、结算、开票和打款。
- 用发放量或兑换量推算销量。
