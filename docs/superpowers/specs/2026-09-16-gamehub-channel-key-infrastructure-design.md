# 盖世游戏渠道 Key 投放设计

> 状态：已确认
> 日期：2026-09-16
> 适用产物：`13-开发者平台与渠道分销demo.html`
> 替代：`2026-09-16-gamehub-channel-distribution-redesign-design.md` 中销售、收益、渠道回传和结算设计

## 1. 产品定位

盖世为已完成企业认证的开发者提供 Key 生成、交付、兑换校验和审计能力。开发者先建渠道，再为该渠道创建供给批次，并自行将 Key 投放到外部渠道。

盖世不参与：

- 开发者与渠道签约。
- 渠道身份核验。
- 商品定价和促销。
- 渠道收款、退款和拒付。
- 开发者与渠道对账、开票和结算。

因此，平台只展示自身可验证的供给和兑换数据，不展示销量、销售额、收益或结算结果。

## 2. 三方职责

| 角色 | 职责 |
|---|---|
| 盖世 | 生成 Key、API 发码、文件下载、兑换校验和审计 |
| 开发者 | 创建渠道和批次，选择销售项与供给方式，向渠道交付 Key |
| 第三方渠道 | 销售、收款、退款、拒付和用户服务 |

渠道名称和编号仅是开发者自定义的管理标签，不代表盖世已核验渠道身份或实际收件人。

## 3. 信息架构

单游戏控制台保留两个一级入口：

1. `渠道与供给`
2. `分销数据`

`渠道与供给`内使用两个横向子 Tab：

1. `渠道管理`
2. `批次管理`

页面不显示副标题、长说明和重复提示。帮助入口放在标题操作区。

## 4. 渠道管理

### 4.1 页面用途

渠道管理只维护合作对象及合作时间，不配置销售项、供给方式、数量或 API 凭证。

用户须先创建渠道，再到批次管理创建供给批次。

### 4.2 筛选

- 渠道名称或编号。
- 合作时间范围。
- 状态：全部、启用、停用。

合作时间使用统一日期范围组件。筛选按区间相交返回；结束时间为空表示长期有效。

点击“查询”刷新列表，点击“重置”恢复全部渠道、全部状态和不限时间。

### 4.3 列表

字段：

- 渠道名称。
- 渠道编号。
- 合作时间。
- 状态。
- 备注。
- 更新时间。
- 操作。

操作：

- 查看。
- 编辑。
- 启用或停用。
- 删除。

### 4.4 创建与编辑

字段：

| 字段 | 规则 |
|---|---|
| 渠道名称 | 必填，开发者自定义，同一游戏内不可重名 |
| 渠道编号 | 创建后自动生成，全局唯一，不可编辑 |
| 合作开始时间 | 必填，默认当天 |
| 合作结束时间 | 选填；不填表示长期合作，不得早于开始时间 |
| 状态 | 启用或停用，默认启用 |
| 备注 | 选填，最多 200 字 |

创建成功后留在渠道列表，并可继续创建批次。

编辑时可改名称、合作时间、状态和备注，不可改渠道编号。若缩短合作时间导致批次超出新时间范围，提交前明确提示；确认后，超出范围的批次停止新供给。

### 4.5 启用、停用和删除

- 停用渠道须二次确认。
- 渠道停用后，其全部批次停止新供给。
- 再次启用后，仅恢复未删除、未结束且自身为启用状态的批次。
- 删除渠道须二次确认，并采用软删除。
- 删除后渠道移出默认列表，全部批次停止新供给，历史供给、兑换和审计记录保留。
- 已删除渠道不可直接恢复；如需继续合作，重新创建渠道。
- 已下载文件中的 Key 不因渠道停用或删除而失效，仍按 Key 原有效期兑换。

## 5. 批次管理

### 5.1 页面用途

批次表示一次明确的供给配置。每个批次只能属于一个渠道、一个销售项和一种供给方式。

供给方式：

- `下载兑换码文件`：生成指定数量的 Key 文件，由开发者自行交给渠道。
- `接口取码`：渠道按接口文档请求 Key，不预设数量或额度。

### 5.2 筛选

- 批次名称或编号。
- 渠道名称或编号。
- 创建时间范围。
- 供给方式。
- 状态。

创建时间使用统一日期范围组件。点击“查询”刷新列表，点击“重置”恢复全部条件。

### 5.3 列表

字段：

- 批次名称和编号。
- 渠道。
- 销售项和 SKU。
- 供给方式。
- 数量：仅文件批次显示；API 批次显示“—”。
- 生效时间。
- 状态。
- 最近供给时间。
- 操作。

操作：

- 查看。
- 编辑。
- 启用或停用。
- 删除。
- 文件批次：下载文件。
- API 批次：管理接入。

### 5.4 创建

通用字段：

| 字段 | 规则 |
|---|---|
| 批次名称 | 必填，开发者自定义，同一游戏内不可重名 |
| 批次编号 | 创建后自动生成，全局唯一，不可编辑 |
| 所属渠道 | 必填，只可选未删除渠道 |
| 销售项 | 必填，可选游戏本体或 DLC |
| 供给方式 | 必填，下载兑换码文件或接口取码 |
| 生效开始时间 | 必填，默认当天 |
| 生效结束时间 | 选填；不填表示长期有效，不得早于开始时间 |
| 状态 | 启用或停用，默认启用 |

文件批次增加：

| 字段 | 规则 |
|---|---|
| Key 数量 | 必填，整数，单批 1～100,000 |
| Key 有效期 | 必填，不得早于批次生效开始时间 |

API 批次不填数量，不设单次或累计额度。同一“渠道＋SKU”只能有一个启用中的 API 批次；冲突时阻止启用，并指向现有批次。

创建成功后返回批次列表。文件批次先创建记录，再由用户点击“下载文件”；API 批次进入“管理接入”获取接入信息。

### 5.5 文件下载

- “下载文件”触发真实 CSV 下载。
- 文件名：`盖世游戏兑换码_渠道名_批次编号.csv`。
- 文件字段：`cdkey,sku_id,valid_until`。
- 下载中按钮显示“生成中…”，成功后状态显示“已下载”。
- 下载完成后，页面、日志和持久化数据不回显明文 Key；仅保存 Key 指纹和下载审计。
- 下载文件必然包含可交付给终端用户的明文 Key。本期降低平台内批量泄露风险，不承诺文件离开平台后仍不可见。
- 首次下载成功后不可再次下载同一批 Key；文件丢失时须新建批次。
- 浏览器已接收文件响应即记为已下载。用户取消本地保存时，平台也不恢复该批次的下载资格。
- 下载失败且浏览器未收到完整文件时不计供给，可用原批次重试。
- 已下载 Key 不因批次停用、删除或渠道停用而回收，仍按 Key 原有效期兑换。

本期不做成员权限和下载二次验证。平台记录创建账号、下载账号、时间、IP、设备和结果。

### 5.6 API 接入

- API 凭证属于具体 API 批次，不属于渠道。
- 接入页展示 API 文档链接、批次编号、渠道编号、SKU、Client ID 和一次性 Secret。
- Secret 仅在创建或轮换时显示一次，后续不回显。
- 同一渠道订单号重复请求返回原 Key；同单异参返回冲突。
- API 不要求渠道回传售价、退款、拒付或结算数据。
- 停用 API 批次后立即停止新发码；再次启用后恢复发码。

### 5.7 编辑限制

未下载且未调用的批次可编辑名称、渠道、销售项、供给方式、数量、生效时间和状态。

文件已下载或 API 已调用后：

- 不可改渠道、销售项、供给方式和文件数量。
- 可改批次名称、结束时间、状态和备注。
- 缩短结束时间不影响已下载或已发出的 Key。

### 5.8 启用、停用和删除

- 停用批次须二次确认。
- 文件批次停用后不可下载；已下载 Key 继续有效。
- API 批次停用后停止新发码；已发 Key 继续有效。
- 再次启用前须重新校验渠道状态、生效时间和 API 唯一性。
- 未下载且未调用的批次可硬删除。
- 已下载或已调用的批次采用软删除，停止后续供给，历史 Key、下载、调用、兑换和审计记录保留。
- 删除批次须二次确认；已发 Key 不回收。

## 6. 生效规则与状态

新供给仅在以下条件同时满足时允许：

```text
渠道未删除
+ 渠道已启用
+ 批次未删除
+ 批次已启用
+ 当前时间在渠道合作时间内
+ 当前时间在批次生效时间内
```

列表展示业务状态，操作仍以启用／停用为主。

渠道状态：

- 待生效。
- 合作中。
- 已停用。
- 已结束。

批次状态：

- 待生效。
- 供给中。
- 已停用。
- 已结束。
- 受渠道限制：渠道停用、结束或删除时显示。
- 已下载：仅文件批次，表示文件已完成一次交付。

列表不显示平台介入类状态。

## 7. 分销数据

### 7.1 筛选

- 渠道名称或编号。
- Key 发放时间范围，默认近 30 天。

默认近 30 天按用户本地日期计算，包含当天及此前 29 个自然日。筛选条件同时更新顶部指标和列表。

### 7.2 指标

- 发放量。
- 兑换量。
- 未兑换量。
- 兑换率。

### 7.3 列表

按渠道、销售项、SKU 和供给方式归类，展示：

- 渠道名称和编号。
- 销售项和 SKU。
- 供给方式。
- 发放量。
- 兑换量。
- 未兑换量。
- 兑换率。

### 7.4 口径

| 指标 | 定义 |
|---|---|
| 发放量 | 筛选范围内，API 成功返回的 Key 数量，加文件首次下载成功的 Key 数量 |
| 兑换量 | 上述 Key 中，截至查询时已成功兑换的数量 |
| 未兑换量 | 发放量减兑换量；不代表渠道未售库存 |
| 兑换率 | 兑换量除以发放量；发放量为 0 时显示“—” |

页面不显示销量、退款、拒付、单价、币种、销售额、收益、对账或结算数据。

## 8. 帮助中心

“发行与供给”目录保留：

1. 渠道与批次使用说明。
2. 接口取码接入指南。
3. API 鉴权、发码、查询和错误码。
4. 下载兑换码文件教程。
5. Key 状态与兑换数据口径。
6. 启停、删除与已发 Key 处理。
7. 三方责任与渠道结算边界。

运营后台支持中英文配置；后台操作界面使用中文，对外文章按开发者所选语言展示。

## 9. 异常与校验

- 渠道停用、结束或删除：禁止其批次继续供给。
- 批次停用、结束或删除：禁止继续下载或调用。
- 渠道或批次时间范围无效：阻止提交并在时间字段下显示错误。
- 文件数量为空、非整数、小于 1 或大于 100,000：阻止创建。
- 文件生成失败：保留批次和原参数，允许重试。
- API 超时：用原渠道订单号查询，不换订单号重试。
- 重复订单异参：返回冲突，不改原发放结果。
- API Secret 泄露：开发者可轮换 Secret，旧 Secret 立即失效。
- 同一“渠道＋SKU”已有启用中的 API 批次：阻止新批次启用。
- 软删除对象不再出现在默认列表，但历史记录仍可在审计数据中追溯。

## 10. Demo 验收

1. `渠道与供给`下仅有“渠道管理／批次管理”两个横向子 Tab。
2. 渠道管理支持新增、查询、查看、编辑、启用、停用和删除。
3. 批次管理支持新增、查询、查看、编辑、启用、停用和删除。
4. 渠道层不出现销售项、供给方式、数量和 API 凭证。
5. 批次创建必须选择渠道、销售项、供给方式和生效时间。
6. 文件批次数量可自定义，单批范围为 1～100,000；API 批次无数量和额度。
7. 文件批次操作为“下载文件”，并能下载包含演示 Key 的 CSV。
8. API 批次操作为“管理接入”，且接入信息含帮助中心 API 文档链接。
9. 同一“渠道＋SKU”只允许一个启用中的 API 批次。
10. 渠道和批次均可启用或停用，且停用后禁止新供给。
11. 渠道删除、已供给批次删除采用软删除；未供给批次可硬删除。
12. 已供给批次不可改渠道、销售项、供给方式和文件数量。
13. 已下载或已发 Key 不因渠道或批次停用、删除而失效。
14. 渠道管理和批次管理均支持渠道与时间筛选；日期控件样式一致。
15. 分销数据默认近 30 天，仅展示发放、兑换、未兑换和兑换率。
16. 页面不出现销量、退款、拒付、金额、收益或结算文案。
17. 页面不出现平台介入状态或处置入口。
18. 页面不显示副标题、长说明和重复提示。
19. 帮助中心同步两层模型、API 接入、文件下载和启停删除规则。
20. 320px、390px、1280px 和 1440px 无根节点溢出。
21. 现有企业认证权限、Secret 安全和 Key 指纹校验继续有效。

## 11. 明确不做

- 渠道账号和渠道自助后台。
- 第三方渠道身份核验。
- 渠道准入和线上签约。
- 开发者组织成员权限和下载二次验证。
- PGP、公钥绑定和加密压缩包。
- 商品定价、促销和订单管理。
- 渠道销量、退款和拒付回传。
- 销售账单导入。
- 对账、结算、开票和打款。
- 用发放量或兑换量推算销量。
