# 盖世游戏渠道 Key 投放设计

> 状态：已确认
> 日期：2026-09-16
> 适用产物：`13-开发者平台与渠道分销demo.html`
> 替代：`2026-09-16-gamehub-channel-distribution-redesign-design.md` 中销售、收益、渠道回传和结算设计
> 本轮增补：列表筛选、下载记录抽屉、渠道生效时间、分销周期和单批文件上限

## 1. 产品定位

盖世为企业开发者提供 CDKEY 生成、交付、兑换校验和审计能力。开发者自行将 Key 投放到外部渠道。

盖世不参与：

- 开发者与渠道签约。
- 商品定价和促销。
- 渠道收款、退款和拒付。
- 开发者与渠道对账、开票和结算。

因此平台只展示自身可验证的 Key 数据，不展示销量、销售额、收益或结算结果。

## 2. 三方职责

| 角色 | 负责 |
|---|---|
| 盖世 | Key 生成、API 发码、文件交付、兑换校验、权限、安全和审计 |
| 开发者 | 选择渠道和销售项，与渠道约定价格、售后及结算 |
| 第三方渠道 | 终端销售、收款、退款、拒付和用户服务 |

创建渠道时显示一句必要说明：`渠道销售、售后与结算由你与渠道自行约定。`

完整责任边界和数据口径放入帮助中心，业务页不放长篇说明。

## 3. 信息架构

单游戏控制台保留两个入口：

1. `渠道与供货`
2. `分销数据`

### 3.1 渠道与供货

使用横向子 Tab：

- `渠道管理`
- `文件批次`

页面标题下不显示副标题。移除企业认证说明条、列表介绍和重复口径说明。帮助入口放在标题操作区。

#### 渠道管理

包含：

- 创建渠道。
- 选择本体或 DLC 销售项。
- 选择接口自动发码或下载兑换码文件。
- 设置生效开始和结束时间。
- 管理 API 凭证。
- 暂停、恢复或停止渠道。

筛选项：

- 渠道名称或编号。
- 生效时间范围。

生效时间筛选按区间相交返回：渠道生效区间与所选时间范围有交集即命中。结束时间为空表示长期有效。

默认展示全部渠道且不限制时间；点击“查询”后刷新列表，点击“重置”恢复默认值。

列表字段：

- 渠道名称和编号。
- 销售项。
- 供货方式。
- 合作状态。
- API 或文件状态。
- 生效时间。
- 最近供货时间。
- 操作。

本页不再重复显示发放、兑换等统计；统计集中到“分销数据”。

#### 文件批次

筛选项：

- 渠道名称或编号。
- 创建时间范围。

默认展示全部渠道且不限制时间；点击“查询”后刷新列表，点击“重置”恢复默认值。

列表字段：

- 批次编号。
- 渠道。
- 销售项和 SKU。
- 生成数量。
- 有效期。
- 状态。
- 创建或下载时间。
- 操作。

“查看下载记录”使用右侧抽屉，展示文件名、批次、数量、下载账号、下载时间和次数。桌面端使用右侧抽屉，手机端使用全屏面板；不显示明文 Key 安全说明等提示条。

### 3.2 分销数据

仅展示平台可验证的数据。

筛选项：

- 渠道名称或编号。
- Key 发放时间范围，默认近 30 天。

默认近 30 天按用户本地日期计算，包含当天及此前 29 个自然日。筛选条件同时作用于顶部指标和下方列表；点击“重置”恢复全部渠道和默认近 30 天。时间范围用于圈定发放 Key 的批次，兑换量统计这些 Key 截至查询时已成功兑换的数量，不按兑换事件时间另算一套口径。

顶部指标：

- 发放量。
- 兑换量。
- 未兑换量。
- 兑换率。

列表按渠道、销售项和 SKU 归类，字段为：

- 渠道名称和编号。
- 销售项。
- SKU。
- 供货方式。
- 发放量。
- 兑换量。
- 未兑换量。
- 兑换率。

页面不显示：

- 销量。
- 退款和拒付。
- 单价、币种、销售额和销售净额。
- 预估收益和应结金额。
- 销售清单导入。
- 结算表下载。

## 4. 数据口径

| 指标 | 定义 |
|---|---|
| 发放量 | 所选渠道和发放时间范围内，API 成功返回 Key 的数量，加文件生成完成并触发浏览器下载后的 Key 数量 |
| 兑换量 | 上述发放 Key 中，截至查询时已在盖世成功兑换的 Key 数量 |
| 未兑换量 | 上述发放 Key 中尚未兑换的数量，即发放量减兑换量；不代表渠道未售库存 |
| 兑换率 | 兑换量 ÷ 发放量；发放量为 0 时显示“—” |

约束：

- 发放量不等于销量。
- 兑换量不等于销量。
- 未兑换量不等于渠道库存。
- 文件下载不等于销售完成。
- API 渠道订单号只用于幂等和追踪，不用于计算收入。
- 后端时间统一存 UTC，页面按用户本地时区展示和提交。

## 5. API 供货

- 渠道凭证属于渠道，不属于批次。
- API 不填写数量，不显示额度和补量。
- 同一渠道订单重复请求返回原 Key；同单异参返回冲突。
- 页面记录请求量、成功量、失败量、最近调用和 Key 兑换结果。
- 一次性 Secret 仅在创建或轮换时显示，后续不回显。
- API 不要求回传售价、退款、拒付或结算数据。

## 6. 文件供货

- 开发者填写渠道、销售项、数量和有效期后直接生成。
- 数量允许输入任意整数，单批范围为 1～100,000 个 Key。
- 单批上限不是渠道额度；开发者可继续创建新批次，不设累计数量上限。
- 当前规模采用同步生成：点击后按钮显示“生成中…”，成功后立即下载并写入下载记录。
- 列表不保留常驻“生成中”状态。
- 文件名为：`盖世游戏兑换码_渠道名_批次号.csv`。
- 文件字段为：`cdkey,sku_id,valid_until`。
- HTML、页面状态和日志不固化或回显明文 Key；仅下载文件在生成时持有明文。
- 文件生成完成并触发浏览器下载后，Key 计为已交付；浏览器取消保存也不得回库，因为平台无法确认明文是否已暴露。
- 生成或返回完整文件前失败时不计发放量，保留原参数并允许重试。

文件批次状态：

- 已下载。
- 已取消。
- 已到期。
- 生成失败。

## 7. 渠道合作状态

创建渠道时：

- 生效开始时间必填，默认当前时间。
- 生效结束时间选填；不填表示长期有效。
- 结束时间必须晚于开始时间。
- 开始和结束时间复用平台现有时间选择组件，不新增一套交互。
- 开始时间未到时状态为“待生效”，不允许 API 发码或创建文件。
- 结束时间到达后状态为“已结束”，停止新供货；已交付 Key 仍按自身有效期兑换。
- 生效时间只控制渠道供货，不代表合作协议、销售或结算周期。

渠道状态：

- 待生效。
- 合作中。
- 已暂停，可恢复。
- 已结束。
- 已停止。
- 风险暂停，由平台处置。

停止合作后：

1. 立即停止 API 新发码和新建文件。
2. 未完成的生成操作不新增文件记录。
3. 已下载 Key 不回库，仍按原有效期兑换。
4. 历史发放、兑换和审计记录只读保留。
5. 不进入30天清算，不生成结算单。

停止合作须二次确认，并明确已下载 Key 仍可能在外部渠道流通。

## 8. 帮助中心

“发行与供给”目录保留并调整为：

1. 渠道投放使用说明。
2. 接口自动发码接入指南。
3. API 鉴权、发码、查询和错误码。
4. 下载兑换码文件教程。
5. Key 状态与兑换数据口径。
6. 文件批次和下载记录说明。
7. 停止合作与已交付 Key 处理。
8. 三方责任与渠道结算边界。

运营后台继续支持中英文配置；后台操作界面使用中文，对外文章按开发者所选语言展示。

## 9. 异常与恢复

- API 发码超时：使用原渠道订单号查询，不换订单号重试。
- 重复订单异参：返回冲突，不改变原发放结果。
- 凭证泄露：暂停凭证并轮换 Secret。
- 文件生成失败：显示原因并用原参数重试。
- 文件下载中断：未完成交付时不计发放量。
- Key 兑换失败：保留错误码、时间、渠道和 SKU，供开发者排查。
- 渠道停止后请求发码或下载：拒绝并返回渠道已停止。
- 渠道未生效或已结束时请求发码或创建文件：拒绝并返回当前生效状态。
- 渠道结束时间不晚于开始时间：阻止创建并在时间字段下显示错误。
- 文件数量为空、非整数、小于 1 或大于 100,000：阻止生成并显示允许范围。

## 10. Demo 验收

1. `渠道与供货`下有“渠道管理／文件批次”横向子 Tab。
2. 渠道管理支持按渠道和生效时间筛选；文件批次支持按渠道和创建时间筛选。
3. 创建渠道可设置开始和结束时间，结束可空；无效区间不能提交。
4. 页面移除副标题、蓝色介绍条和重复说明。
5. 渠道管理列表不重复展示发放和兑换统计。
6. `销售与收益`改为`分销数据`。
7. 分销数据默认近 30 天，渠道和发放时间筛选同时更新指标和列表。
8. 分销数据移除重复的“商品名称”和“最近兑换时间”，只展示发放、兑换、未兑换和兑换率。
9. 页面不存在销量、退款、拒付、金额、收益、销售导入和结算文案。
10. 文件数量可自定义，单批只允许 1～100,000，不设渠道累计额度。
11. 文件下载名明确为兑换码文件，真实下载内容为随机演示 Key。
12. 文件生成使用按钮加载态，不保留常驻“生成中”列表状态。
13. 下载记录使用右侧抽屉，手机端全屏；抽屉不显示非必要提示条。
14. 停止合作或生效结束后停止新供货，不出现“清算中”或30天清算；已交付 Key 继续按自身有效期兑换。
15. 帮助中心8篇文章同步新口径，并保持中英文 ID 一致。
16. 320px、390px、1280px 和1440px无根节点溢出。
17. 现有企业认证权限、API Secret 安全和 Key 指纹校验继续有效。

## 11. 明确不做

- 渠道账号和渠道自助后台。
- 渠道准入和线上签约。
- 商品定价、促销和订单管理。
- 渠道销量、退款和拒付回传。
- 销售账单导入。
- 对账、结算、开票和打款。
- 用发放量或兑换量推算销量。
