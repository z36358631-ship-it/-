# 工作日家庭作息表 A4 图片版设计

## 1. 目标

生成一张可直接打印的 A4 横向 PNG 作息表，供家庭贴墙查看。页面需要在一张纸内清楚展示共同早晨、普通日、课外班日、统一转场话术、共同底线和两周完成记录。

## 2. 输出规格

- 文件格式：PNG。
- 画布：A4 横向，`3508 × 2480 px`，按 300 DPI 打印尺寸设计。
- 背景：白色；内容距纸张边缘保留安全区。
- 中文字体：使用系统可靠中文字体回退，正文在原尺寸下可清晰阅读。
- 页面不出现浏览器控件、说明文字或预览边框。

## 3. 信息结构

### 3.1 页头

- 标题：`工作日家庭作息表`。
- 摘要：`托班已提供晚餐｜接送与晚间执行：爸爸或妈妈`。
- 目标：`普通日 21:15 熄灯｜课外班日 21:25–21:30 熄灯`。

### 3.2 共同早晨

| 时间 | 安排 |
|---|---|
| 07:25 | 温和叫醒 |
| 07:30–07:45 | 如厕、洗脸、穿衣 |
| 07:45–08:00 | 早餐 |
| 08:00–08:05 | 刷牙、梳头、检查书包 |
| 08:05–08:10 | 穿鞋、出门 |

早晨不复盘前一晚，不使用“因为你昨晚拖延”等追责话术。

### 3.3 普通日：周二、周三、周五

| 时间 | 安排 |
|---|---|
| 19:00–19:25 | 爸爸或妈妈接回；喝水、简短聊天、放松 |
| 19:25–20:25 | 自由玩耍，优先非屏幕活动 |
| 20:20 / 20:24 | 5分钟预告 / 1分钟预告，启动可视计时器 |
| 20:25–20:50 | 收尾转场、洗澡 |
| 20:50–21:00 | 睡衣、刷牙、如厕 |
| 21:00–21:10 | 简单整理书包、准备次日衣服 |
| 21:10–21:15 | 短绘本、拥抱或聊天 |
| 21:15 | 熄灯 |

### 3.4 课外班日：周一、周四

差异项：

| 日期 | 课程安排 |
|---|---|
| 周一 | 19:00 爸爸或妈妈接；按需喝水或少量点心；19:30–20:30 写字课 |
| 周四 | 托班已提供晚餐；爸爸或妈妈接，按需补水；19:00–20:30 画画课 |

共同流程：

| 时间 | 安排 |
|---|---|
| 20:30–约20:45 | 爸爸或妈妈接，返程回家 |
| 到家–21:00 | 安静自由玩耍；避免屏幕、追逐和大型拼搭，最晚21:00停止 |
| 21:00–21:10 | 快速冲洗或最低必要清洁，不洗头 |
| 21:10–21:20 | 刷牙、睡衣、如厕 |
| 21:20–21:25 | 3–5分钟短故事、拥抱或聊天 |
| 21:25–21:30 | 熄灯 |

## 4. 底部辅助区

### 4.1 统一话术

`“玩耍时间结束了。你自己走，还是爸爸或妈妈牵手一起走？”`

等待约10秒；不动则平静陪同转场，不反复说理。基础3–5分钟亲密收尾始终保留。

### 4.2 共同底线

1. 睡眠边界不变，清洁和整理可降级。
2. 不拖拽、不压制、不临时加罚。
3. 谁当班谁执行共同方案至熄灯。

### 4.3 两周完成记录

提供两行、每行周一至周五共10个勾选格。完成标准：按目标时间熄灯，并且没有临时加罚或吼叫。

## 5. 版式规则

- 页面主体只分为两条主流程：左侧普通日，右侧课外班日。
- 周一和周四只在课外班日顶部显示差异，不重复共同流程。
- 每条时间与安排保持同一视觉行，避免大块空白。
- 熄灯时间使用深色横条强调；课外班日使用暖黄色作轻微区分。
- 底部辅助区字号不小于主表正文的90%，不得为塞入内容而明显缩小。

## 6. 验证

- 图片尺寸必须为 `3508 × 2480 px`。
- 在 A4 横向原比例下无文字裁切、重叠或溢出。
- `07:25` 叫醒与 `08:10` 出门均明确显示。
- 普通日只出现一次并标记周二／周三／周五；课外班日只出现一次并分别标记周一与周四差异。
- 所有接送和陪同执行人统一表述为“爸爸或妈妈”。
