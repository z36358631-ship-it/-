# Mac MODS 内容发现与已安装管理设计

- 日期：2026-07-30
- 状态：设计已确认，连续实施
- 唯一产品文件：`demos/Mod与发行人/Mod功能Mac端demo.html`
- 游戏：饥荒联机版（DST）
- 游戏标识：`steam:322330`
- 前置版本：`5dd5c257 feat(mods): match mac reference screens`

## 1. 背景

现有 Mac Demo 已按运营参考图还原窗口、游戏详情、MODS 列表和详情弹窗，但 MODS 入口仍只是单行管理入口，列表也只有基础搜索和安装操作。此次在不改变“外部非官方来源、当前设备本地安装管理”本质的前提下，将 MODS 的内容发现路径调整为与创意工坊相似的结构：

- 游戏详情露出 3 个热门 MOD、内容总数和“查看全部”。
- 列表增加“浏览 / 已安装”双 Tab。
- 浏览支持排序，已安装支持排序与状态筛选。
- 列表和详情补充下载量、更新时间等内容数据。

创意工坊仍是官方订阅内容；MODS 仍是外部非官方内容，使用安装、启停、更新和卸载语义。两者只共享信息架构和视觉层级，不共享数据和业务状态。

## 2. 范围

### 2.1 本轮目标

1. 只修改 Mac Demo。
2. 保留 2160×1480 固定画布和现有 Mac 视觉结构。
3. 将游戏详情中的 MODS 区域重构为热门内容模块。
4. 新增“浏览 128 / 已安装 N”双 Tab。
5. 使用 8 条固定样例表达外部同步源返回的首批内容。
6. 默认提供 4 条已安装数据，覆盖完整管理状态。
7. 保留统一状态源、安装幂等、更新失败保留旧版和调试接口。

### 2.2 非目标

- 不修改两个 APP Demo。
- 不实现创意工坊订阅业务。
- 不实现真实网络请求、分页接口、下载和文件写入。
- 不新增发布、审核、点赞、收藏、评论和跨设备同步。
- 不展示启动检查、加载证据和异常恢复。

## 3. 产品口径

### 3.1 内容规模与数据来源

- `128 个 MOD`：外部同步来源返回的目录总数。
- 下载量：外部来源同步的累计下载字段，不是盖世官方统计。
- Demo 仅内置 8 条固定样例，代表当前首批加载结果。
- 列表明确显示“共 128 个，当前加载 8 个”。

### 3.2 全链路标识

游戏详情入口、浏览列表、已安装列表和详情弹窗均持续表达：

```text
非官方来源 · 仅此设备
```

“仅此设备”只描述安装、启停、更新和卸载状态；内容目录总数和下载量来自外部同步源。

## 4. 信息架构

### 4.1 游戏详情 MODS 热门模块

MODS 区域与创意工坊采用相同层级：

```text
MODS
非官方来源 · 热门推荐
128 个 MOD
查看全部
3 个热门 MOD 卡片
```

每个热门卡片展示：

- 封面。
- MOD 名称。
- 累计下载量。

交互：

- 点击热门卡片直接打开该 MOD 详情。
- 点击“查看全部”进入 MODS 列表，默认选中“浏览 128”。
- 从热门卡片打开详情后关闭，返回游戏详情原位置。

### 4.2 MODS 列表顶部

列表顶部保留返回详情、标题、搜索和刷新，新增：

```text
浏览 128
已安装 4
```

- 默认 Tab：浏览。
- 搜索、排序、筛选和滚动位置按 Tab 独立保存。
- 安装和卸载后，“已安装 N”、入口数字和列表结果从同一状态派生。

## 5. 浏览 Tab

### 5.1 排序

排序项：

1. 热门推荐。
2. 下载量。
3. 最近更新。
4. 名称。

排序规则：

- 热门推荐：`popularity_rank` 升序。
- 下载量：`download_count` 降序。
- 最近更新：`updated_at` 降序。
- 名称：按显示名称升序。

### 5.2 卡片字段

每张卡片展示：

- 名称。
- 一句简介。
- 累计下载量。
- 最近更新时间。
- 最新版本。
- 文件大小。
- 兼容状态。
- 非官方来源。
- 当前设备安装状态。

操作：

- 未安装：安装、详情。
- 安装中：显示任务阶段和进度。
- 已安装：显示启停与更新状态，点击进入详情管理。

### 5.3 固定样例

Demo 内置 8 条：

| MOD | 下载量 | 默认安装状态 |
|---|---:|---|
| 小地图 HUD | 18.6 万 | 已安装、已启用 |
| 组合状态 | 14.2 万 | 已安装、未启用、有新版本 |
| 智能堆叠 | 9.8 万 | 已安装、已启用 |
| 季节时钟 | 7.6 万 | 已安装、更新失败并保留旧版 |
| DST Large Mod B | 6.3 万 | 未安装 |
| DST Large Mod A | 5.8 万 | 未安装 |
| 快速采集助手 | 4.1 万 | 未安装 |
| 夜间照明优化 | 3.7 万 | 未安装 |

热门模块固定使用：

1. 小地图 HUD。
2. 组合状态。
3. 智能堆叠。

## 6. 已安装 Tab

### 6.1 默认状态

默认展示 4 条，并覆盖：

- 已安装、已启用。
- 已安装、未启用。
- 有新版本。
- 更新失败、保留旧版。

### 6.2 排序和筛选

排序：

- 最近安装。
- 名称。

筛选：

- 全部。
- 已启用。
- 未启用。
- 可更新。

“可更新”包含 `update_available` 和最近一次更新任务失败但旧版仍可用的 MOD。

### 6.3 管理交互

- 启用和停用只影响当前设备。
- 更新失败保留 `installed_version`、`active_version_pointer` 和最近一次启停值。
- 卸载需要二次确认，只移除当前设备安装文件，不删除存档和用户配置。
- 安装、启停、更新和卸载后，筛选结果与数量立即重算。

## 7. 详情弹窗

保留现有大封面、独立滚动说明区和固定底栏。

封面下新增数据摘要：

- 累计下载量。
- 最近更新。
- 当前最新版本。
- 文件大小。
- 兼容状态。

说明区包含：

- 功能说明。
- 常见问题。
- 兼容性说明。
- 外部非官方来源。
- 当前设备本地管理提示。

底栏状态：

- 未安装：安装到此设备。
- 安装中：显示任务阶段和进度。
- 已安装：启用或停用、检查更新或更新、卸载。
- 更新失败：保留旧版、重试更新、卸载。
- 来源未知：不提供可执行更新。

## 8. 状态模型

每条 MOD 新增：

```text
download_count
updated_at
popularity_rank
installed_at
compatibility_label
featured
```

UI 状态新增：

```text
activeTab
browseSort
installedSort
installedFilter
searchByTab
scrollTopByTab
detailReturnScreen
```

派生视图负责：

- 3 个热门 MOD。
- 浏览排序结果。
- 已安装排序与筛选结果。
- 入口和 Tab 的安装数量。
- 列表与详情一致的数据摘要。

数据流继续使用：

```text
事件 → dispatch → reducer → derive → render
```

不得在 DOM 中单独维护数量、排序或安装状态。

## 9. 异常与反馈

- 搜索无结果：当前 Tab 内显示空状态，不改变其他 Tab。
- 已安装筛选无结果：显示“没有符合当前筛选的已安装 MOD”。
- 刷新失败：保留旧列表，提示“刷新失败，已展示上次内容”。
- 重复安装：复用同一 `task_id`。
- 来源未知：展示来源状态，不出现更新操作。
- 更新失败：旧版本继续可用，启停状态不改变。

## 10. 视觉约束

- 保留 2160×1480 固定画布与整体等比缩放。
- 侧栏、主内容左边界、两列卡片和详情弹窗基准不变。
- MODS 热门模块与创意工坊同层级，但通过标题、来源文案和本机状态清晰隔离。
- 3 个热门卡片使用真实内容封面或内嵌设计素材，不复用创意工坊订阅卡片数据。
- 单文件离线运行，不引入 CDN、网络图片、远程字体、XHR、`fetch` 或 iframe。
