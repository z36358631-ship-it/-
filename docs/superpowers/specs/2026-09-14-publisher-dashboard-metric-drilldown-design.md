# 发行平台数据看板指标下钻设计

## 目标

面向已认证且拥有单游戏数据权限的开发者，在一个游戏控制台内回答两个问题：游戏的获量是否变化，以及玩家质量是否变化。开发者可直接点击指标卡，按自然日查看当前指标的明细，并切换图表、刷新、全屏或导出。

## 页面结构

1. 只保留「曝光转化」和「用户数据」两个页签。
2. 筛选项保持单行，支持时间、商品类型、来源位置、地区和固定 Mac 平台。移除「来源分析」表格不影响保留来源筛选。
3. 页签下方是可点击指标卡。指标名称旁的问号只用于显示口径，不触发指标切换。
4. 指标卡下方只有一个共享详情面板。移除「站内转化」漏斗和「来源分析」整块内容。

## 指标

「曝光转化」包含：有效曝光、游戏卡点击率、详情页访问、详情获取转化率、成功获取、履约成功、新增预约用户数。预约指标按首次预约成功日归属，取消预约不回溯改写历史新增。

「用户数据」包含：活跃玩家数、新增玩家数、次日留存、3 日留存、7 日留存、平均游戏时长。三个留存指标在一个组合卡内显示，但可分别点击下钻。

## 交互与口径

- 两个页签分别记住上次选中的指标。
- 详情默认显示图表，可切换为表格。表格和导出包含选定区间的每一个自然日；图表也保留每日数据点，仅稀疏显示横轴文案。
- 区间 UV 是跨日去重值，不等于每日 UV 之和。转化率用区间分子除以区间分母，不平均每日百分比。
- 留存按首次启动 cohort 日期展示。未观察满 1、3、7 日的 cohort 显示「—」。
- 刷新在详情面板内显示加载态和最近刷新时间。全屏只放大共享详情面板，Esc 可退出。
- CSV 导出绑定当前游戏、页签、指标、筛选和日期区间，与图表及表格复用同一份数据。

## 响应式

宽屏下指标卡保持紧凑对齐。小屏下指标卡和筛选项均可水平滚动，表格可水平滚动并固定日期列。页面根节点不产生水平溢出。
