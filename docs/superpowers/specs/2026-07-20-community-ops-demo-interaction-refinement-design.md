# 社区运营后台 Demo 交互收敛设计

## 1. 变更结论

本设计用于调整 `demos/社区/社区文章与马甲号运营后台demo.html`，并覆盖原设计中以下内容：

- 取消“发布前先选择马甲号”的独立步骤。
- 移除草稿箱页面及草稿相关交互。
- 移除风险事件页面及风险事件相关交互。

调整后的新增业务范围聚焦两个页面：

1. 内容发布。
2. 马甲号管理。

操作记录继续保留，只记录上述两个页面产生的业务操作。

## 2. 内容发布页面

### 2.1 内容列表

页面顶部保留三个发布入口：

- 发布图文。
- 发布文章。
- 发布视频。

三个入口点击后均直接打开发布详情，不再检查或弹出马甲号选择窗口。

列表顶部内容类型 Tab 包含：

- 全部内容。
- 图文。
- 文章。
- 视频。

点击 Tab 后立即过滤列表，并更新选中状态。筛选区支持标题或内容 ID、发布马甲号、审核状态；查询和重置均更新列表结果。

列表字段包括：

- 内容封面、标题和内容 ID。
- 内容类型。
- 发布马甲号。
- 分区与话题。
- 审核状态。
- 互动数据。
- 更新时间。
- 操作。

每条内容提供以下可交互操作：

- 预览：打开客户端详情预览。
- 编辑：打开发布详情并回填原内容。
- 复制：以当前内容为模板创建新内容；新内容不继承原内容 ID、审核状态、发布时间和互动数据。
- 审核详情：展示当前审核状态；已驳回内容展示驳回原因。
- 操作记录：跳转操作记录页面并按当前内容 ID 筛选。

分页控件需要有点击反馈。当前 Demo 数据不足一页时，点击下一页提示“已是最后一页”。

### 2.2 发布详情

发布详情使用同一个工作台承载图文、文章和视频，通过顶部 Tab 切换内容类型。点击不同发布入口时，默认选中对应 Tab。

发布详情第一项为必填字段“发布马甲号”：

- 支持按 UID、昵称和内部标识搜索。
- 展示账号头像、昵称、UID、内部标识和状态。
- 停用账号出现在结果中但不可选择，并显示停用原因。
- 从马甲号管理点击“使用该身份发布”进入时，自动预选对应账号。
- 未选择马甲号时允许继续编辑；提交审核时校验并定位到该字段。

发布马甲号只属于当前编辑内容，不再维护全局“当前代操作身份”，避免全局身份与文章身份不一致。

### 2.3 不同内容类型

#### 图文

- 标题。
- 多图上传模拟，至少支持添加、预览和删除。
- 正文描述。
- 分区、话题和游戏卡片。

#### 文章

- 封面。
- 标题。
- 富文本正文。
- 分区、话题和游戏卡片。

#### 视频

- 视频文件上传模拟。
- 视频封面。
- 标题和内容描述。
- 分区、话题和游戏卡片。

切换内容类型时同步更新字段文案、上传区域和客户端预览形态。已输入的公共字段保留；类型专属素材分别保存于当前前端状态。

### 2.4 发布操作

底部操作包含：

- 取消：有未提交修改时弹出离开确认。
- 预览：刷新右侧客户端预览并给出反馈。
- 提交审核：校验发布马甲号及当前内容类型的必填字段。

移除以下能力：

- 保存草稿。
- 自动保存。
- 草稿状态。
- 草稿复制与删除。

提交确认框必须再次展示内容类型、标题和发布马甲号。确认后：

- 新建内容生成新 ID，状态为“审核中”。
- 编辑内容更新原 ID，状态改为“审核中”。
- 复制内容生成新 ID，状态为“审核中”，互动数据清零。
- 记录一条内容发布操作日志。

## 3. 马甲号管理页面

### 3.1 列表与筛选

支持以下筛选：

- UID 或昵称。
- 状态。
- 前台可见状态。

查询和重置立即更新列表。统计卡随数据变化同步更新账号总数、启用数和停用数。

### 3.2 单账号操作

每个马甲号提供：

- 使用该身份发布：仅启用账号可点击；直接打开发布详情并预选该账号。
- 编辑：修改昵称、内部标识、后台备注、前台可见状态和启停状态。
- 启用或停用：二次确认后更新账号状态。
- 删除：未被内容引用时二次确认后删除；已被内容引用时阻止删除并提示停用。

若编辑操作将账号改为停用状态，该账号在发布详情中不可再选择。

### 3.3 创建与批量导入

创建马甲号弹窗校验昵称和内部标识，保存后生成 UID 并更新列表和统计卡。

批量导入支持：

- 点击选择 CSV/XLSX 文件。
- 拖放 CSV/XLSX 文件。
- 非支持格式拦截。
- 模拟展示导入进度。
- 展示成功、重复 UID、缺少昵称和格式错误数量。

## 4. 操作记录

操作记录仅覆盖内容发布和马甲号管理，不再展示身份切换与风险事件模块数据。

需要记录的动作包括：

- 内容发布：新建并提交、编辑并提交、复制并提交。
- 马甲号管理：创建、编辑、启用、停用、删除、批量导入。

每条记录包含：

- 操作时间。
- 真实操作人。
- 关联马甲号 UID；无关联账号时显示“-”。
- 模块与动作。
- 对象 ID。
- 操作结果。
- request_id。
- before 与 after。
- 失败原因。

内容列表点击“操作记录”后进入操作记录页面，并自动按内容 ID 筛选。

## 5. 页面移除与数据清理

从侧栏移除：

- 草稿箱。
- 风险事件。

从 Demo 代码和初始化流程移除：

- 草稿页面结构和渲染逻辑。
- 草稿数据、保存、复制和删除逻辑。
- 风险事件页面、数据和处理逻辑。
- 全局当前马甲号栏。
- 发布入口的身份前置拦截。

保留马甲号搜索选择能力，但只在发布详情内部使用。

## 6. 交互覆盖标准

### 6.1 内容发布

- 三个发布入口均可打开对应类型详情。
- 四个内容类型 Tab 均可过滤列表。
- 查询、重置、分页均有实际结果或明确反馈。
- 预览、编辑、复制、审核详情和操作记录均可点击并产生对应结果。
- 发布详情三个类型 Tab 均可切换。
- 发布马甲号可搜索、选择、清除；停用账号不可选。
- 上传区、富文本工具、分区、话题、游戏卡片、预览、取消和提交均可交互。

### 6.2 马甲号管理

- 查询、重置、创建、编辑、启用、停用、删除、批量导入均可交互。
- “使用该身份发布”可打开发布详情并预选账号。
- 所有成功或失败操作均有 Toast 或弹窗反馈，并同步写入操作记录。

## 7. 验收标准

- 点击任一发布入口均直接进入发布详情，不出现身份前置弹窗。
- 发布详情内可选择马甲号，未选择时只有提交动作被拦截。
- 侧栏不再出现草稿箱和风险事件。
- 页面中不再出现保存草稿、自动保存或风险处理按钮。
- 内容列表复制后打开新内容编辑状态，提交后生成新 ID 且互动数据为 0。
- 内容发布和马甲号管理的全部可见操作均具备可验证反馈。
- 操作记录只包含两个页面产生的操作类型。
- 原社区基础后台文件保持不变。
- 静态脚本检查和 Edge 浏览器交互回归通过，无 JavaScript 运行异常。
