# 云存档租号式收银台与存档合并设计

## 1. 背景

现有云存档 Demo 同时存在顶部月套餐销售卡、存档详情双购买按钮、通用确认弹窗和独立“月包存档”分区。入口重复，支付确认缺少支付宝、微信支付和明确的第三方支付拉起过程。

本设计用现有租号收银台的操作方式统一云存档购买链路，并合并“月包存档”和“已购存档”。本设计覆盖并替代以下旧设计：

- `2026-07-27-cloud-save-monthly-pass-design.md` 中 3.1～3.4 的 C 端入口、购买和“我的存档”结构。
- `2026-07-27-cloud-save-compact-pass-card-design.md` 的全部顶部套餐卡设计；顶部套餐卡不再保留。

¥6 永久购买、¥18/30 天月度套餐、非自动续费、套餐周期、退款、作者奖励和后台业务规则保持不变。

## 2. 已确认结论

1. 存档广场和“我的存档”移除顶部月套餐销售卡，不保留独立“开通套餐”入口。
2. 未获得当前存档权益时，卡片、详情页和游戏中存档面板只显示一个“购买”按钮。
3. 点击“购买”后打开租号式订单确认页，在同一页面展示存档内容、购买方案、支付方式、订单金额和“确认支付”。
4. 购买方案包含：
    - ¥6 单次购买：永久使用当前存档。
    - ¥18 月度套餐：30 天内全部存档不限次使用，非自动续费。
5. 订单确认页默认选中 ¥6 单次购买，用户可切换为 ¥18 月度套餐。
6. 支付方式包含支付宝和微信支付。
7. 点击“确认支付”后才拉起所选渠道的支付弹窗或支付 SDK。
8. “我的存档”合并“月包存档”和“已购存档”为“已获得存档”。
9. 月套餐到期后，套餐存档继续保留，显示“套餐已到期”和“续费后使用”。
10. 月套餐开通后必须展示套餐有效期。

## 3. 核心购买路径

```text
存档卡片/存档详情/游戏中存档面板
→ 点击“购买”
→ 打开订单确认页
→ 默认选中 ¥6 单次购买
→ 用户确认或切换为 ¥18 月度套餐
→ 选择支付宝或微信支付
→ 点击“确认支付 · ¥18/¥6”
→ 拉起对应支付弹窗或支付 SDK
→ 支付成功
→ 发放权益并返回来源页
```

订单确认页是唯一的购买方案选择和支付确认页面。不得在它之前增加“选择购买方式”弹窗，也不得在点击“确认支付”后再增加一层普通业务确认框。

## 4. 页面设计

### 4.1 存档广场

- 移除顶部“云存档月度套餐”销售卡。
- 未获得权益的存档卡按钮统一为“购买”，按钮不直接写 ¥6 或 ¥18。
- 存档卡仍可展示“月包可用”，说明该存档包含在月度套餐权益中。
- 点击卡片进入存档详情；点击“购买”直接打开订单确认页。
- 月套餐有效时按钮显示“使用”；永久购买后按钮显示“使用”；当前已加载时显示“使用中”。

### 4.2 存档详情

- 移除页面内并列的“¥6 永久购买”和“¥18 开通套餐”按钮或权益卡。
- 无权益时底部只显示“购买”。
- 月套餐有效时显示“立即使用”；如用户仍需永久权益，可从详情的“购买永久权益”次级入口进入订单确认页并默认选中 ¥6。
- 已永久拥有时显示“使用”。
- 月套餐已到期且未永久购买时显示“续费后使用”；点击后进入订单确认页并默认选中 ¥18。
- 游戏中存档详情复用相同按钮和状态。

### 4.3 租号式订单确认页

订单确认页覆盖当前 App 内容，关闭后返回来源页并保留滚动位置。

#### 4.3.1 存档内容

- 封面。
- 存档标题。
- 所属游戏。
- 来源：官方存档或玩家寄售。
- 当前存档是否包含在月套餐权益中。

#### 4.3.2 购买方案

|方案|价格|权益|默认状态|
|---|---:|---|---|
|永久拥有当前存档|¥6|永久使用当前存档；购买后不受月套餐到期影响|从普通“购买”或“购买永久权益”进入时默认选中|
|云存档月度套餐|¥18|支付成功后立即生效；30 天内全部官方及玩家寄售存档不限次使用；非自动续费|用户可主动切换；从“续费后使用”进入时默认选中|

切换购买方案后，商品名称、权益说明、实付金额和确认支付按钮金额立即更新。

#### 4.3.3 支付方式

- 支付宝。
- 微信支付。
- 优先选中用户上次成功使用的支付方式；没有记录时默认支付宝，与现有租号收银台一致。
- 支付方式不可同时选中。

#### 4.3.4 订单汇总

- 商品名称。
- 当前存档或套餐适用范围。
- 实付金额。
- 套餐生效与到期时间预估；实际时间以支付成功后的服务端周期为准。
- 非自动续费和退款规则提示。
- 主按钮：“确认支付 · ¥18”或“确认支付 · ¥6”。

### 4.4 支付弹窗

点击“确认支付”后：

1. 客户端创建或复用待支付订单。
2. 拉起所选支付宝或微信支付 SDK。
3. Demo 使用覆盖当前订单确认页的模拟支付弹窗，展示支付渠道、商品名称和金额。

支付结果：

|结果|处理|
|---|---|
|支付成功|关闭支付弹窗和订单确认页，查询服务端权益并刷新来源页|
|用户取消|关闭支付弹窗，返回订单确认页，保留购买方案和支付方式|
|支付失败|返回订单确认页并显示失败原因，不创建权益|
|支付结果未知|保持订单待确认状态并查询原订单，不重复创建订单或发放权益|
|重复点击确认支付|复用同一待支付订单，按钮进入处理中状态|

支付成功后不再显示“购买成功”确认弹窗；使用轻提示反馈结果。

### 4.5 我的存档

页面结构调整为：

1. 本地存档。
2. 已获得存档。
3. 我的寄售。

“月包存档”和“已购存档”不再单独分区。

#### 4.5.1 套餐有效期

不恢复顶部套餐销售卡。在“已获得存档”标题下方显示一行套餐状态：

|套餐状态|文案|
|---|---|
|未开通|不显示套餐状态行|
|有效|月度套餐有效至 YYYY-MM-DD HH:mm|
|剩余不超过 3 天|月度套餐将于 YYYY-MM-DD HH:mm 到期|
|已到期|月度套餐已于 YYYY-MM-DD HH:mm 到期|

有效期使用服务端时间，支付成功、续费成功、App 回到前台或重新进入页面时刷新。

#### 4.5.2 统一存档列表

|权益状态|卡片标记|主操作|
|---|---|---|
|永久购买|永久拥有|使用/使用中|
|月套餐有效|套餐可用|使用/使用中|
|月套餐到期|套餐已到期|续费后使用|
|同时拥有永久和套餐权益|永久拥有|使用/使用中|

- 同一存档只显示一次，按规范化存档 ID 去重。
- 权益展示优先级：永久权益 > 有效月套餐 > 已到期月套餐。
- 点击“续费后使用”进入订单确认页并默认选中 ¥18 月度套餐。
- 套餐到期不删除已加载形成的本地游戏进度，不阻止用户启动已有本地游戏。

## 5. 状态与数据

1. 订单确认页选中的方案、支付方式和来源页在支付完成前保存在本次会话中。
2. 权益发放以服务端支付结果为准，不根据 Demo 按钮点击直接判定。
3. ¥6 订单成功后写入永久存档权益。
4. ¥18 订单成功后创建独立 30 天套餐周期，并返回准确的 `start_at` 与 `end_at`。
5. “我的存档”套餐有效期以当前有效周期的 `end_at` 展示；存在未来续费周期时，展示续费后的最终有效期并标明已续费。
6. 订单、支付回调和权益发放均需幂等。

## 6. 异常与边界

- 未登录：点击“购买”先完成登录，成功后恢复原存档和购买入口。
- 未实名：仅国内按现有规则完成实名认证后恢复购买。
- 存档下架：订单确认前再次校验；不可售时关闭收银台并刷新来源页。
- 套餐停售：订单确认页只展示 ¥6；已生效套餐不受影响。
- ¥6 单买停售：订单确认页只展示 ¥18；已有永久权益不受影响。
- 两种方案均不可售：不打开订单确认页，提示当前暂不可购买。
- 套餐状态请求失败：不得默认放行使用，保留永久权益判断并允许刷新重试。
- 横竖屏切换：保留已选方案、支付方式、待支付订单和来源页。

## 7. 埋点建议

- 购买按钮点击。
- 订单确认页曝光。
- 购买方案切换。
- 支付方式切换。
- 确认支付点击。
- 支付 SDK 拉起结果。
- 支付成功、失败、取消和结果未知。
- 套餐有效期曝光。
- “续费后使用”点击。

关键参数包含来源页面、存档 ID、方案类型、金额、支付方式、订单号、套餐状态和支付结果。

## 8. 验收标准

1. 存档广场和“我的存档”不再显示顶部套餐销售卡。
2. 无权益存档在卡片、详情和游戏中入口均只有一个“购买”按钮。
3. 点击“购买”直接进入租号式订单确认页。
4. 普通入口默认选中 ¥6 永久购买，用户可切换为 ¥18 月度套餐。
5. 订单确认页同时提供支付宝、微信支付和带金额的“确认支付”按钮。
6. 点击“确认支付”后才出现对应支付弹窗。
7. 支付取消后回到订单确认页并保留选择。
8. “我的存档”只保留一个“已获得存档”分区，不重复显示同一存档。
9. 月套餐有效时显示准确到分钟的有效期。
10. 月套餐到期后存档仍保留并显示“续费后使用”。
11. 支付回调重复、页面旋转或返回前台不会重复创建订单或发放权益。

## 9. 三视角评审

- 用户视角：购买入口收敛为一个按钮，用户可在同一收银台比较两种权益；默认推荐月套餐但保留主动切换，避免隐藏单买。
- 开发视角：复用租号的订单确认、支付方式和支付拉起结构；云存档只新增商品、权益和支付结果处理，减少重复组件。
- 商业视角：移除独立套餐卡减少页面干扰，默认 ¥6 保持用户原有购买习惯；¥18 月套餐在同一收银台中作为可比较方案展示，避免强推套餐损伤信任。

评审未发现阻断实施的硬伤。
