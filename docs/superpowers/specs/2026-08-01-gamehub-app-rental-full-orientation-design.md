# 盖世游戏 APP 租号功能横竖屏全链路设计

## 1. 文档信息

- 日期：2026-08-01
- 状态：已确认设计
- 目标端：盖世游戏 APP 竖屏、横屏
- 业务基线：Mac 租号 PRD V4.0
- 视觉基线：现有盖世游戏 APP 历史真实截图

## 2. 背景与目标

Mac 端已形成游戏租号、会员、订单、Steam 登录和到期处理闭环。本期将同一套业务能力落到盖世游戏 APP，并同时覆盖竖屏与横屏完整链路。

本期不是将 Mac 页面缩小后搬到手机，也不是将竖屏页面直接拉宽，而是：

1. 共用一套权益、价格、订单、账号和登录状态。
2. 竖屏与横屏分别使用符合现有 APP 的原生布局。
3. 用户旋转屏幕后继续当前操作，不重新选择、不重复下单、不重新取号。
4. 已拥有、已导入或可直接启动游戏的用户优先走原有路径，租号不抢占主操作。
5. 降低 SKU、会员和手动登录产生的认知与信任成本。

## 3. 用户价值与设计原则

用户价值按“新体验 − 旧体验 − 替换成本”评估。本期核心用户不是所有用户，而是没有当前游戏权益、希望低成本立即开始游玩的用户。

设计原则：

- 先判断能否直接玩，再决定是否展示租号。
- 每个页面只突出一个主操作。
- 低承诺套餐优先展示，其他租期折叠到“更多租期”。
- “单游戏永久畅玩”与“永久会员”使用不同名称和权益说明。
- 一键上号为默认路径，账号、密码和验证码仅作为手动登录辅助信息。
- 横竖屏能力一致、状态连续，但布局不要求像素级相同。
- 已支付、进行中订单按订单快照履约，不受后续会员库状态变化影响。

## 4. 方案选择

采用“同一业务状态机、两套方向布局”的方案。

不采用两套独立业务 Demo，避免状态和规则重复维护；不采用简单响应式拉伸，避免横屏形成被拉宽的手机页面。

### 4.1 共用状态

- 用户登录、地区和灰度状态。
- 游戏拥有、导入和安装状态。
- 游戏会员库状态。
- 首次体验资格。
- 单游戏永久畅玩权益。
- 会员类型和有效期。
- SKU、价格版本和30分钟订单快照。
- 账号库存、分配和健康状态。
- 订单、支付、使用单和到期状态。
- Steam 账号、密码、验证码与短时授权状态。

### 4.2 方向布局

- 竖屏：底部五项导航、纵向信息流、全屏交易页和底部轻面板。
- 横屏：顶部导航、多列游戏墙、左右双栏交易页和居中轻弹窗。
- 旋转屏幕仅触发布局切换，不重建业务状态。

| 玩游戏－PC游戏 | 单列或双列游戏列表，支持可租号筛选 | 顶部筛选与横向游戏列表 |

## 6. 权益判断

客户端按以下顺序判断：

1. 用户是否命中租号功能地区与灰度。
2. 用户是否已经拥有、导入或安装当前游戏。
3. 当前游戏是否加入会员游戏库。
4. 用户是否拥有有效会员、单游戏永久畅玩或进行中订单。
5. 用户是否还有首次体验资格。
6. 当前账号库存、SKU 和价格版本是否可用。

### 6.1 主操作矩阵

| 用户状态 | 主操作 | 次级操作 |
|---|---|---|
| 已拥有且可启动 | 启动游戏 | 隐藏租号购买入口 |
| 已拥有但未安装 | 下载游戏 | 不主动推荐租号 |
| 有进行中租号订单 | 继续游戏 | 登录信息、续租或购买长期权益 |
| 未入会员库、无权益 | 2小时租用 | “更多租期”内选择3–23小时、日租、周租 |
| 已入会员库、首次体验可用 | 首次体验 | 单游戏永久畅玩、开通会员 |
| 已入会员库、首次体验已使用 | 单游戏永久畅玩 | 开通会员 |
| 已入会员库、有效会员 | 会员畅玩 | 查看会员有效期 |
| 已购买单游戏永久畅玩 | 启动或下载 | 不再展示当前游戏购买套餐 |

### 6.2 SKU 规则

- 游戏未加入会员游戏库：提供用户自选2–23小时时租、日租、周租，会员不可使用。
- 游戏加入会员游戏库：仅提供全平台一次的首次体验、单游戏永久畅玩和开会员引导。
- 首次体验已支付后，列表仅显示“可租号”，详情页按用户权益展示长期方案。
- 游戏加入会员库后，后台原时租、日租、周租配置保留但失效。
- 游戏移出会员库后，系统校验原价格，通过后自动恢复；校验失败进入待修复并停止新创单。
- 单游戏订单与会员订单独立结算。
- 会员中心固定按月度、年度、永久顺序展示套餐。

## 7. 完整链路

### 7.1 租号链路

发现游戏 → 游戏详情 → 判断权益与 SKU → 选择套餐 → 确认订单 → 30分钟内支付 → 锁定账号 → 一键上号或手动登录 → 下载/启动目标游戏 → 到期前15分钟提醒一次 → 到期 T0 结束或在订单中处理售后。

### 7.2 会员链路

游戏详情、个人中心或会员游戏库 → 独立会员中心 → 选择月度、年度或永久会员 → 支付 → 更新个人中心会员状态 → 返回会员游戏库 → 对符合条件的游戏使用会员畅玩。

### 7.3 手动登录链路

有效使用单 → 选择手动登录 → 打开 Steam 登录页 → 打开租号登录信息 → 查看或复制账号、密码 → 在 Steam 提交 → Steam 要求验证时按需获取并复制 Steam Guard 验证码 → Steam 会话、下载或启动校验登录结果。

订单“登录信息”和 Steam 登录页内的租号信息读取同一使用单、账号和有效验证码，不重复取号。订单入口不拉起或聚焦 Steam。

### 7.4 横竖屏连续性

以下状态在旋转后必须保留：

- 当前页面、游戏和滚动定位。
- 所选版本、套餐和时长。
- 订单号、价格快照和倒计时。
- 支付中、支付成功和分配中状态。
- Steam 登录方式、账号输入状态和验证码倒计时。
- 进行中订单、剩余时长和临期提醒记录。

## 8. 交易与安全

- 确认订单默认选择2小时套餐，其他时长放入“更多租期”。
- 进入确认订单后锁定价格与权益快照30分钟。
- 支付前再次检查库存；支付后分配失败自动退款。
- 价格版本变化时要求用户重新确认，不静默加价。
- 默认使用一键上号，手动登录为次级入口。
- 账号、密码和验证码只在有效使用单与短时授权内展示。
- APP 进入后台、订单结束、退款、换号或到期后立即隐藏并清理敏感信息。
- 验证码过期只刷新验证码，不重复分配账号。
- 租赁会话只允许获取、下载和启动订单目标游戏。

## 9. 临期与到期

- 服务端 `expire_at` 为唯一时间基准。
- 仅在到期前15分钟展示一次顶部居中提醒：“租用时间快结束了，是否继续畅玩？”
- 不设置到期前5分钟或1分钟提醒。
- 用户关闭15分钟提醒后，本次使用单不重复弹出临期提醒。
- 到期 T0 未获得新权益时，立即结束游戏、撤销会话、清除敏感展示、释放账号。
- 本地安装包后续启动时，按当前游戏最新 SKU 模式重新引导。

## 10. 异常处理

| 异常 | 处理 |
|---|---|
| 下单前无库存 | 主按钮置灰，提示“暂时无可用账号” |
| 支付后分配失败 | 自动退款，订单显示处理结果 |
| 价格变化 | 返回确认订单重新确认 |
| 登录信息授权失效 | 重新验证当前使用单，不重复取号 |
| 验证码过期 | 刷新验证码，账号与订单不变 |
| 游戏移出会员库 | 进行中使用继续，新取号按新规则处理 |
| 地区或灰度未命中 | 隐藏新曝光并阻止新交易，已支付权益继续履约 |
| 旋转屏幕 | 只重排布局，不清空状态或重复请求 |
| 网络中断 | 保留本地操作状态，恢复后按订单号幂等查询 |

## 12. Demo 设计

普通 Demo 为单文件、可操作、共享状态的横竖屏原型：

- 提供横屏、竖屏切换。
- 提供典型用户状态切换，用于验证权益分流。
- 页面跳转必须从真实入口发生，不依赖标注导航完成主流程。
- 覆盖“发现 → 详情 → 选购 → 支付 → 登录 → 启动 → 15分钟临期提醒 → 到期/继续畅玩”。
- 覆盖会员中心、会员游戏库、个人中心会员状态和租号订单。
- 覆盖未入会员库、已入会员库、首次体验已使用、有效会员、已有游戏等状态。

普通 Demo 完成后再生成交互标注版。标注版使用左侧页面导航、中间可操作 Demo、右侧规则与异常说明，不改变普通 Demo 的业务逻辑。

## 13. 自检与评审

### 13.1 功能自检

- 横竖屏旋转后状态、输入和倒计时不丢失。
- 已拥有或已导入游戏用户不会被租号入口阻断。
- 每个页面只有一个主操作。
- 单游戏永久畅玩与永久会员不会混淆。
- 账号、密码和验证码不常驻裸露。
- 所有可点击元素均有真实反馈。
- 仅在到期前15分钟提醒一次，不存在5分钟或1分钟提醒。

### 13.2 视觉自检

- 逐页对照历史 APP 截图检查导航、层级、色彩、圆角、间距和卡片密度。
- 竖屏不出现 Mac 侧边栏结构。
- 横屏不使用竖屏页面简单拉伸。
- 游戏封面、头像、支付图标和 Steam 登录界面使用真实素材。

### 13.3 状态场景

- 未入会员库的时租、日租和周租。
- 已入会员库的首次体验、单游戏永久畅玩和会员。
- 首次体验已使用、有效会员、已有游戏。
- 待支付、支付成功、分配账号、进行中、已到期、退款中。
- 无库存、价格变化、分配失败、验证码过期和网络异常。
- 会员库加入、移出和历史订单快照。
- 地区与灰度未命中。
- 确认订单、支付、登录和进行中使用阶段的横竖屏切换。

## 15. 非本期范围

- 不重新制作一套租号运营后台。
- 不修改已经确认的供应商账号采购、后台商品和会员库管理口径。
- 不新增 APP 底部导航项。
- 不增加5分钟或1分钟临期提醒。
- 不支持租赁账号操作订单目标游戏之外的游戏。
