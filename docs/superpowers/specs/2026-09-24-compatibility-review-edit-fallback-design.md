# 兼容性评价：编辑入口与同配置自动兜底

依据：用户 2026-09-24 截图及明确修正要求，属于 GUANWANGGAID-25 现行 Demo 的局部修复。

- 自己的评价更多菜单增加“编辑”，放在“删除”之前，调用已有 editMyReview，回填原星级、文字、图片和分享状态；提交更新原评价并保留原快照。
- 同配置（同游戏＋同 GPU）没有可见评价时，自动切到“全部”，同步 Tab 高亮、重置分页并显示全部可见评价。首次进入、再次选择同配置及删除最后一条同配置评价均适用。
- 隐藏、删除的评价不算有效结果。全部也为空时显示“暂无评价”；我的为空时显示“暂无我的评价”，不切换我的筛选。
- 不增加提示、页面、弹窗或后台功能；保留现有菜单、弹窗、排序、分页和快照模型。

冲突 CR-013：旧 PRD 与规格规定空态手动切换；本轮明确要求自动切换，以本轮要求替代。来源为用户本轮截图及现有 DOM；不套用不同版本的底部操作 Sheet。组件样式由现有 ci-more-item 与 chip 派生（derived），不声明严格像素还原通过。

验收：通过真实菜单点击编辑并保存，评价 ID/数量及快照不变；同配置有数据仍停留；仅其他 GPU、隐藏同 GPU、全空、我的空、删除最后一条同配置等状态的 Tab/内容/分页一致。保存截图并进行原尺寸审图。
