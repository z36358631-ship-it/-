# 盖世游戏 V6.1.1 使用说明手册

# 一、平台简介

盖世游戏是一款面向移动设备的 PC 游戏平台，支持浏览与查找游戏、云游戏秒玩、PC 游戏与复古游戏下载、Steam/Epic 账号接入、本地游戏导入、游戏库管理、手柄连接及横竖版界面切换。

本文档依据盖世游戏安卓版 **V6.1.1（6.1.1_CN）** 实际运行界面编写，适用于包名 `com.xiaoji.egggame`、版本号 `versionCode 123` 的客户端。

### 2. 横版整体布局

掌机模式不是将竖版页面简单旋转，而是针对横屏、掌机和手柄操作重新排版：

1. 顶部左侧集中显示游戏库、玩游戏、主页、排行榜和我的五个频道，当前频道会展开名称。
2. 顶部右侧显示搜索、竖版切换、设备/手柄、时间、Wi-Fi 和电量等状态。
3. 页面底部在支持手柄快捷操作的页面显示对应按键提示。
4. 列表和卡片由竖向单列或双列改为横向多列，优先利用横屏宽度。

# 四、核验范围与限制

1. 本手册内容来自 V6.1.1 实机界面及真实交互核验，不使用 PRD、Demo 或旧版手册推断未上线功能。
2. 已核验首次启动、主要频道、搜索、详情、游戏库导入与管理、账号入口、设备中心、基础设置，以及探索/掌机模式切换。
3. 当前环境没有进行中的下载任务，因此未说明暂停、继续、删除等下载任务操作。
4. 当前环境没有完整启动 PC 游戏进入模拟器内部，因此未沿用 V5.3 手册中的游戏内抽屉、性能、触屏按键等说明。
5. 云游戏时长页未加载具体套餐，因此不写价格、套餐数量及支付流程。
6. 涉及账号绑定、游戏资产、推荐内容、榜单、房间数量和可用启动方式的页面均为条件展示，实际结果以用户当前账号、设备和服务状态为准。
