# GUANWANGGAID-32｜PC 模拟器竞品真机体验：结论与行动

> **先做什么：** P0 先修 Neon Abyss 默认启动、异常退出识别和失败恢复；不要继续优先打磨详情页或商业化入口。<br>
> **验证范围：** NX729J / Android 15；本地 EXE：Prodeus、Neon Abyss；GameHub、233 乐园、GameNative。

## 一、核心结论

| 结论 | 真机事实 | 决策含义 |
|---|---|---|
| **GameHub 的“游戏库体验”领先，但“启动确定性”落后。** | 自动补全封面、中文名、简介、标签、评分等信息；但 Neon Abyss 默认路径连续两次约 12—16 秒静默返回详情。 | 保留元数据与资产感优势；P0 从信息包装转向“本机是否能玩、失败后怎么办”。 |
| **233 已证明同一游戏、同一设备存在可玩路径。** | Neon Abyss 首次选择 EXE、安装 Bionic 后约 20 秒进入可接收输入的场景；二次启动不再选择 EXE。 | 学习“成功配置自动记忆”和组件进度可见；不等同于 233 引擎全面领先。 |
| **新手需要先被分流到自己的任务，而非直接面对内容或参数。** | 233 的“导入 PC 游戏”是最明确第一步；GameHub 首页未回答“我有文件时从哪开始”；GameNative 的技术术语与捐赠提示门槛最高。 | 首启按“我有游戏文件 / 我有 Steam 或 Epic / 我还没有游戏”分流；高级参数仅放高级模式。 |

## 二、接下来怎么做

| 优先级 | 做什么 | 完成标准 |
|---|---|---|
| P0 | **修复默认启动并自动尝试候选配置。** 复现 Neon Abyss 的 `returnCode=139`，对同一游戏按候选配置 A/B/C 恢复。 | NX729J、同一文件，冷/热启动各连续 3 次进入可接收输入的实际场景。 |
| P0 | **把异常变成可恢复状态。** 区分主动退出、异常退出和系统终止；失败时说明失败阶段、已尝试方案、重试/切换入口。 | `returnCode != 0` 且未进入 game loaded 不得记为 `normalExit=true`；不能静默回详情。 |
| P0 | **让兼容性可决策。** 在游戏库、搜索和详情统一显示“本机一键可玩 / 需要配置 / 暂不建议 / 待验证”。 | 状态来自真实“游戏 × 机型 × 引擎 × 配置”样本；无数据只显示“待验证”，不显示 `--`。 |
| P1 | **首启按用户资产分流。** 只在未完成引导时询问来源与游戏经验，导向本地文件、Steam/Epic 或推荐游戏。 | 首次成功后记录结果；已完成用户不重复引导。 |
| P1 | **把首次环境准备讲清楚。** 说明组件、大小、空间、网络、预计时间和当前阶段；成功配置自动复用。 | 用户在启动前可知道等待成本；二次启动不重复要求已成功完成的选择。 |
| P2 | **沉淀配置与手柄资产。** 将成功/失败结果反哺推荐，接入盖世手柄时自动加载已验证映射。 | 按游戏、机型、引擎、配置、结果可查询和复用。 |

### 必要边界

- 本轮结论不是全平台性能或兼容率排名；两款游戏只用于发现游戏级、配置级问题。
- GameNative 1.1.1 的 Steam、登录后启动、存档、退出和商业化未验证：设备已有在线会话，未获授权使用。
- 未执行付款、订阅、租号或账号绑定。

## 三、调研路径与边界（附录）

### 3.1 统一口径

`同一 NX729J 真机 / 同一网络 / 同一批 EXE → 导入 → 默认启动 → 标题页与可玩场景分开记录 → 退出 → 二次启动`

到标题页仅记“启动”；进入可接收输入的实际场景才记“可玩”。涉及登录、支付、Steam 会话或会改变用户资产的节点立即停止，标记“未验证”。

### 3.2 各产品实走路径

- **GameHub：** `首页/游戏库 → 本地导入 → 选择 EXE → 自动识别 → 详情/默认推荐配置 → 环境准备 → 启动 → 侧栏/退出 → 再次启动`<br>
  Prodeus 已走通；Neon Abyss 两次均在默认启动后返回详情。

- **233 乐园：** `PC 游戏页 → 导入 PC 游戏/扫描目录 → 首次选择 EXE → Bionic/Loading → 标题页 → 可玩场景 → 侧栏/Android 返回 → 再次启动`<br>
  Prodeus、Neon Abyss 均走通；Neon Abyss 成功后不再选择 EXE。

- **GameNative：** `启动 → 项目介绍/分享提示 → 首页 → 搜索本地游戏 → Unknown → 选择 EXE → 容器/Wine/语言/分辨率/音频 → 启动`<br>
  仅走到 0.9.0 的搜索、Unknown 和手工配置；1.1.1 遇已有 Steam 会话停止。

### 3.3 纯新手复测路径

`强制停止 App → 启动 → 记录首屏与第一个可执行动作 → 判断是否能回答“我该从哪里开始”`

未清数据、未退出账号、未新建账号；结果只判断首屏任务清晰度，不等同于全新账号首开。
