# 六向环阵调防 UI 灰盒 v0.1

## 目标与边界

本界面只验证“看懂六线威胁—选择守卫—调往空守位—观察结果”这一条体验链路。它是高质量灰盒，不承担世界观、角色/IP、正式场景、装饰插画或商业化入口；所有伤害、索敌、胜负和合法移动均由领域层提供，UI 不重复计算。

## 信息层级

1. **中央核心危险**：中央始终显示完整度数值与环形余量；低于三分之一时才使用红色外扩脉冲，核心受击只震动 220ms，不全屏闪烁。
2. **当前来敌与抵达时间**：六个入口就地展示方向、敌人形状、数量与抵达时间；高危线同步提高轨道亮度，但不遮挡敌人。
3. **守卫位置与克制记忆**：重击、连击、横扫固定使用不同轮廓、颜色和单字标签；选中后显示薄荷色选择环。
4. **当前操作窗口**：底部状态条持续显示“演示/预备调防/自动交战/中段救场/结算”以及剩余秒数。仅预备和救场窗口点亮合法空守位。
5. **波次、暂停与声音**：波次位于左上；暂停与声音均保持可见，且触控区不小于 44×44 CSS px。

威胁视觉映射由应用层根据领域选择器结果生成：`nearestDistance ≤ 2` 或当前预计核心伤害 `≥ 3` 为“高危”，其余 `score > 0` 为“注意”，无威胁为“平静”。这只改变颜色和亮度，不改变战斗规则。

## 颜色、形状与文字三重编码

| 对象 | 颜色 | 形状 | 文字 |
|---|---|---|---|
| 重击守卫 | 靛蓝 | 六边形 | 重 / 重击 |
| 连击守卫 | 青绿 | 圆形 | 连 / 连击 |
| 横扫守卫 | 琥珀 | 圆角方形 | 扫 / 横扫 |
| 群敌 | 珊瑚红 | 三角形 | 群 |
| 速敌 | 紫色 | 菱形 | 速 |
| 甲敌 | 橙色 | 方形 | 甲 |

颜色只增强识别，不承担唯一语义。深色表面上的正文、按钮文字与状态色按照 WCAG AA 对比度设计；键盘焦点使用 3px 薄荷色外框。

## 单屏布局

- 根容器固定 `100dvh` 且 `overflow: hidden`，安全区内边距通过 `env(safe-area-inset-*)` 处理。
- 战场统一使用 `viewBox="0 0 390 640"`；中央核心坐标为 `(195, 300)`，六条防线以 60° 等分。
- 页面由顶部 HUD、可压缩战场、底部指挥条三行组成。战场保持 SVG 比例并优先缩放，不把核心操作挤到滚动区域。
- 验证视口为 `360×800`、`390×844`、`430×932`。三档宽度均保留完整战场、波次、暂停、静音和调防状态。

## 操作与状态

- 调防不使用拖拽：先点击/键盘激活守卫，再点击/激活薄荷色虚线空守位。
- 每个守卫和目标守位均有至少 58 SVG 单位直径的透明热区；在最窄 360px 视口仍超过 44 CSS px。
- 非指挥窗口的守卫从键盘顺序中移除并标记 `aria-disabled`；已占用位置不显示为目标。
- 暂停冻结战局并在核心上方显示克制的“已暂停”状态；继续按钮仍位于底部固定位置。
- 结算层只显示一个主因、一个改进提示、关键回放摘要和“再守一次”，不自动重开、不默认诱导奖励。

## 动效与声音

| 反馈 | 时长 | 表现 |
|---|---:|---|
| 调防落位 | 190ms | 缩放回弹，不跨屏画装饰轨迹 |
| 命中 | 150ms | 守卫提亮、短攻击线、敌人短位移与提亮 |
| 击败 | 180ms | 缩小并淡出 |
| 核心受击 | 220ms | 核心局部水平震动 |
| 危险线 | 1000ms 循环 | 轨道亮度呼吸，不全屏闪烁 |

声音由 Web Audio 在首次用户交互后生成短促的移动、命中、击败、警告和核心受击音。静音按钮始终可见；浏览器不支持、拒绝授权或上下文创建失败时静默降级。系统启用“减少动态效果”后，所有动效压缩为 1ms。

## 禁止项

- 不增加题材美术、角色立绘、场景原画、背景故事、正式名称或 IP 元素。
- 不增加技能按钮、建造、升级、资源、卡牌、装备、商店、任务、排行和二级页面。
- 不用大面积闪烁、屏幕震动、粒子雨、漂浮伤害数字遮挡倒计时或预告。
- 不把威胁强度、合法移动、伤害或胜负逻辑写入 UI。

## 集成合同

`GameScreen` 接收领域状态的可呈现子集、选择器输出 `SelectorView`、最近一次视觉反馈事件和五个动作回调。应用层负责把 `laneLength`、`selectLaneThreat`、`selectNextArrival`、`selectLegalDestinationLanes`、`selectPhaseLabel`、`selectPrimaryFailureCause` 的结果映射为 `SelectorView`；UI 只呈现这些结果。
