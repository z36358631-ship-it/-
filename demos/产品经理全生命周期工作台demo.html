个人产品工作台
LOCAL SERVICE REQUIRED

工作台已升级为本机 Codex 服务

需求、运行事件和结果现在由受保护的本地 Broker 提供。请从终端启动服务，再使用终端给出的本机会话地址进入。

本机安全边界
静态文件只保留启动指引

直接双击此文件无法访问受保护 API，也不会生成任何伪运行结果。

01

打开项目终端

将终端工作目录切换到当前仓库根目录。

02

启动本地 Broker

运行 npm.cmd run workbench:start，等待服务输出地址与令牌。

03

打开终端给出的地址

地址仅监听 127.0.0.1，首次进入会安全保存本次会话令牌。

PowerShell npm.cmd run workbench:start
示例入口格式：http://127.0.0.1:4317/?token=本次会话令牌。请以终端实际输出为准。
