## 第一份 Demo 的关键交互

- 首页点击“登录”直接打开双栏弹窗，不跳转独立登录页。中文使用 11 位手机号＋6 位验证码，英文使用邮箱＋6 位验证码；两种语言都支持盖世游戏 App 扫码，未注册账号登录时自动注册。
- 登录后选择“注册平台开发者”可直接进入控制台；选择“认证企业开发者”进入认证介绍。企业认证预计 5 个工作日内完成。
- 控制台使用顶部横向 Tab：数据总览、游戏管理、接入资料、成为开发者。数据总览仅展示游戏数据范围；游戏管理、接入资料和具体单游戏能力为后续 PRD 占位。
- 企业认证不保存草稿，先阅读介绍，再在一个页面填写企业工商、银行结算、厂商联系人和授权签署信息；支持清空重填、附件参考示例、协议全文和正式提交。
- 工商执照、银行账户证明为必传图片；运营端只读查看提交快照，通过受控预览打开附件，银行账号仅显示后四位。
- 运营审核支持关键词、状态和日期组合筛选；待审核申请可通过／拒绝，已通过申请可下架。所有处理均包含成功、失败和幂等反馈。
- 帮助中心采用左侧目录＋右侧文章正文，支持搜索、结果跳转和关键词高亮；“控制台”入口仅在帮助中心显示。对外合作邮箱统一为 `dev@xiaoji.com`。
- 内容配置支持认证介绍、保密协议、发行协议、帮助文章和联系我们的中文／English 内容。文章正文为可插入文字、列表、链接和图片的富文本；双语校验通过后原子发布。

## 响应式与演示边界

- 第一份 HTML 为可双击打开的离线单文件，不加载外部脚本、样式、字体、图片、接口或 iframe。
- 页面适配宽屏、1280px 桌面和 320／390px 手机视口；手机端不产生根节点横向溢出。
- 所有操作只保留在当前浏览器会话；刷新后恢复初始数据，不使用远程持久化。
- 实际验证码、扫码授权、文件上传、附件鉴权、审核通知和内容发布由正式服务端处理。
- 游戏详情、游戏上架、SDK 服务、开发者服务、CDKEY、包体发布和精准化投放只在本期相关位置说明或占位，由后续 PRD 定义完整业务规则。
