# 盖世游戏 App 帮助中心

- `帮助中心demo.html`：独立 App 前端，含设置入口、目录文章列表、图文视频正文、横竖屏及阅读异常状态。
- `帮助中心后台demo.html`：独立运营后台，含导航目录／目录子文档、同对象六语编辑（含印地语）、图文视频插入及逐条发布。

两个文件均可双击离线运行，不依赖远程资源。各自保存本次页面会话内的示例数据，刷新恢复初始内容；两个文件之间没有接入真实内容接口，也不跨窗口同步数据。

前端从“设置 → 帮助中心”进入，点“图文与视频阅读示例”体验播放器。后台点“目录子文档 → 编辑”，可用本地图片和视频体验插入、修改草稿、返回列表和发布。未发布内容与已发布快照分离；列表输入权重并保存，只调整顺序。国内包与海外包独立维护；帮助中心不设置客户端版本门槛。点击每行“多语言”打开弹窗，在同一对象下增删改各语言文案，默认语言必须完整，其他语言可全空、不可半填。

前端工具栏的包、APP协议、语言是演示条件，不是新增 App 设置项。选择海外包及印地语可查看样例。日／葡／俄语编辑能力可操作，示例翻译为空时按包回退；当前演示界面文案覆盖中文、英语及印地语，其他界面语种仍使用英语示例。完整翻译与实机校对需运营提供。

构建：`node demos/帮助中心/build.mjs`。

交互验收：`node demos/帮助中心/verify.mjs`；本次评审增量：`node demos/帮助中心/verify-review.mjs`。此命令通过内部联调页面验证同一数据模型的发布读取，不代表两个独立 Demo 已接通真实 API。

前端截图：`node demos/帮助中心/capture-frontend.mjs`；总览：`python demos/帮助中心/compose-frontend.py`。

页面图：`public/prd/app-help-center-20260924/`。PRD：`prd/帮助中心/【PRD】盖世游戏App帮助中心.md`。

当前边界：横屏为根据现有结构推导的方案，未取得同版本横屏设置实机稿；字体和系统栏不声称与 Android 像素一致。示例图文和短视频为演示素材，不代表正式操作教程。Demo 图片 10 MB、视频 30 MB 的本地插入限制不代表生产规格。

V1.3：列表操作栏“编辑、删除、多语言”；文章APP协议支持截图中的8项多选，与国内/海外包共同控制可见性。前端演示工具栏可选择当前APP协议。验证：`node demos/帮助中心/verify-protocol.mjs`。

V1.4：移除帮助中心版本字段和筛选，版本控制归灰度；“多语言”打开弹窗，查看各语言文案并新增、编辑、删除翻译草稿，仍在列表按对象统一发布。
