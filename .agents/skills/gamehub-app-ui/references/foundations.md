# 基础规范

## 事实层与实现层

- 页面事实来自 `assets/screen-catalog.json`：45 张 V6.1.1 实机图，36 张竖屏、9 张横屏。
- 组件事实来自 `assets/figma-components.json`：每项必须保留 `measured`、`derived` 或 `missing-source`。
- 实现使用真实 DOM；复杂媒体和产品图标可使用 `assets/visual-sources/` 中已登记的局部资产。
- 原稿证据、实现与回归图必须分开；原稿不能冒充实现。

## 三层令牌

实现时引用 `assets/gamehub-app-tokens.css`，按 `Primitive → Semantic → Component` 使用。

### Primitive

- 基底：`#0E0E10`；横屏环境背景允许依据原稿使用更深的 `#060607` 至 `#0D0D0E`。
- 表面：`#171719`、`#242426`、`#29292D`、`#34343A`。
- 主文字：`#F2F2F2` / `#E6E6E6`；次文字：`#808081`；禁用：`#5F5F64`。
- 实测青蓝边框：约 `rgb(43,195,223)`。
- 实测主按钮中段：约 `rgb(0,118,176)`，上浅下深并带底部高光，不使用单一通用蓝渐变。
- 品牌黄：`#FFC928`；成功绿：`#00C777`；错误红：`#FF5C64`。
- 间距：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。
- 圆角：8 / 12 / 16 / 20 / 24 / 32 / pill；具体以来源组件为准。

### Semantic

- 背景区分 `base`、`environment`、`media-overlay`。
- 表面区分 `default`、`elevated`、`selected`。
- 操作区分品牌主操作、青蓝业务操作、次操作和危险操作。
- 边框以 8%–24% 白色透明度建立层级，禁止用浓重阴影代替结构。

### Component

- 竖屏青蓝按钮源尺寸 `270×71`；本次实测视觉圆角约 24px，边界框仍为 `270×71`。
- 竖屏五栏导航源尺寸 `1080×148`，单栏 216px。
- 掌机顶部导航源高度约 62–72px，具体按页面状态测量。
- 搜索输入、卡片、弹层和焦点环必须从组件登记值或目标页原稿取得，不得凭印象套值。

## 排版

- 离线预览内嵌本地字体，不依赖在线字体。
- 字体匹配必须单独验证；Windows/Chrome 与 Android 的字形栅格差异不能被整页分数掩盖。
- 游戏名最多两行；横屏密集卡默认一行省略。
- 数字与单位保持同一基线；缺失评分显示“暂无评分”，不显示 `0`。
- 当原稿字形无法由本地字体复现时，保留组件 `FAIL`，并在来源记录中说明，不得把文字截图覆盖到 DOM 上。

## 竖屏 Shell

- 源画布 `1080×2400`，预览约 `402×893`。
- 顶部包含状态安全区和工具栏；底部五栏导航固定，正文独立滚动。
- 首页与频道使用纵向流；搜索结果一排 2 个，平台标识位于封面。
- 触控目标不小于 44×44 逻辑像素。

## 掌机横屏 Shell

- 源画布 `2400×1080`，预览约 `874×393`。
- 顶部导航和状态区固定；正文使用横向轨道、多列、左右双面板或沉浸 Hero。
- 焦点元素提供明确焦点环和 LB/RB、A/B 等手柄提示。
- 不旋转、拉伸、整体缩放竖屏 DOM；不复用竖屏底部导航。
- 横屏掌机不是 Mac 桌面；Mac 需独立适配层。

## 图形、媒体与可访问性

- 使用项目内图片、Figma 导出 SVG 或已登记局部裁片；禁止 Emoji 代替产品图标。
- 局部裁片必须在 `visual-baselines.json` 登记来源和边界，不得等于整页。
- 复杂媒体可复用原资产；按钮文字、Tab、卡片结构、账号状态和交互必须保留真实 DOM。
- 常规反馈 140–180ms，弹层 220–260ms，并尊重 `prefers-reduced-motion`。
- 可操作控件具备可读名称、可见焦点和键盘/手柄路径；模态关闭后焦点返回触发点。
