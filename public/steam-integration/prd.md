## 一、文档概述

### 1.1 背景概述

盖世游戏现有 Steam 入口使用自建的数据、成就、好友及工坊页面。本次替换入口后的体验，接入新版 Steam 界面，同时保留盖世游戏库内的 PC 游戏与导入游戏入口。

替换后需补齐协议确认、首次组件准备和返回路径，并处理已登录用户升级、原游戏继续启动及账号资料展示。

【2026.11.6修改】依据为产品改动总结、APK、线上截图及10月30日、11月5日、11月6日评审记录。国内网络体验及 SDK 能力待实测；本期不定制 SDK 内导入入口、盖世来源分类或非 Steam 游戏同步。APK 在 MuMu Android 12 中停在原生库加载失败，尚未实测登录后的真实功能。

### 1.2 需求边界

| 边界类型 | 范围说明 |
|---|---|
| 产品边界 | Android 盖世游戏 APP，覆盖手机竖屏、掌机横屏的 Steam 入口、相关设置及游戏启动。游戏库结构和未接入平台沿用现状；不新增 Web、Mac 或后台页面。 |
| 业务边界 | 【2026.11.6修改】盖世负责入口、协议、组件准备、启动页及运行衔接；登录、账号、库、好友、工坊、悬浮功能按 SDK 实际能力接入。含国内网络优化及升级数据核对；不新增 SDK 内导入入口、盖世来源分类或非 Steam 游戏双向同步。 |
| 运营边界 | 悬浮球活跃玩法本期不纳入，后续另定；本期不新增签到、积分、任务、奖励、广告、消息中心或红点，也不提示限免或未来收费，网络优化纳入技术方案评估，暂不定义加速收费；皮肤收费、存档分享和运营资源位不在本需求内。 |
| 人力边界 | 产品负责规则，设计负责横竖屏和状态稿，客户端负责盖世页面及运行衔接；组件提供方确认分发、同步接口和原生能力，技术侧评估网络方案，测试验证真机及升级，法务核对声明和分发许可。 |

### 1.3 术语定义

| 术语 | 定义与判断口径 |
|---|---|
| Steam 大屏模式 | Steam 大卡片界面，适合手柄操作；不改变盖世游戏自身的探索／掌机模式。 |
| Steam 窗口模式 | Steam 桌面式界面，适合触屏／鼠标；不指 Android 分屏或系统小窗。 |
| 运行组件 | 首次进入 Steam 所需下载和准备的内容，与下载具体游戏区分；真实组件组成、大小和空间需求待确认。 |
| 游戏记录同步 | 【2026.11.6修改】读取 SDK 支持的 Steam 游戏安装与下载记录，更新盖世状态；接口待确认。不含盖世导入项写入 Steam，不转移购买权益。 |
| 新启动／恢复会话 | 新启动指重新启动 Steam；恢复会话指返回盖世后重新打开仍在运行的 Steam。两者的模式、缩放和悬浮球状态不同。 |
| 进入成功／游戏启动成功 | 进入成功指 Steam 界面及原目标可用；游戏启动成功指收到实际运行成功结果。协议提交、下载完成、登录成功分别是中间步骤。 |

## 二、产品说明

### 2.1 产品／方案简介

面向通过盖世游戏使用 Steam 的玩家，提供从游戏库进入、从需 Steam 能力的游戏操作进入、设置 App 启动进入 Steam 三种路径。盖世完成进入前的准备和运行中的控制，Steam 提供账号与内容页面。

【2026.11.6修改】本期重点是首次进入、会话恢复、Steam 账号与安装状态核对，升级保留已有账号和本机游戏。页面操作和结果见第三章；真实接入依赖见第五章。

## 三、功能需求

### 3.1 C 端 Android APP

【2026.11.6修改】Steam 登录、账号、原生页、悬浮球及其设置均为 SDK 接入占位；以下控件按实际能力和布局核对，不据此定制 SDK 内功能。

以下规则适用于手机竖屏与掌机横屏；涉及布局和输入的差异在对应页面内说明。国内网络优化方案尚未确定，不据此改变国内包与海外包的既有可用范围；原生运行支持范围见第五章。

## 四、支撑及非功能需求

### 4.1 埋点与数据需求

**数据结论：** 新增。[建议方案] 记录协议、登录、游戏运行、启动页设置、显示调整及 Steam 界面停留／返回。事件名称和原生结果映射需对齐现有规范，本期不新增报表或目标阈值。

#### 4.1.1 统计口径

一次入口操作关联一次进入尝试；取消后重进建立新尝试。只读声明往返和页面重绘不重复记曝光。协议提交成功不等于登录或游戏运行成功。

密码有效提交、扫码实际发起认证分别关联登录尝试；刷新二维码建立新尝试。请求与结果使用同一标识，每次尝试最多记录一个明确终态，重复结果去重；无结果不当作失败。扫码与密码任一路径成功只进入一次。扫码认证开始时点需原生能力提供。

以下指标为建议口径：按请求或曝光发生日归组，时间窗口为北京时间每日0:00—24:00；按对应尝试去重。迟到结果回补原发生日，未返回结果单列为“尚无结果”，不计为失败；统计截止时间以数据提取时间为准。

| 指标 | 分子／分母 | 去重对象 | 用途 |
|---|---|---|---|
| 协议确认完成率 | 已成功提交的入口尝试数／协议弹窗已展示的入口尝试数 | entry_attempt_id | 观察协议页流失；不代表所有Steam入口转化。 |
| 登录成功率 | 收到成功结果的登录尝试数／实际发起认证的登录尝试数 | login_attempt_id | 分扫码、密码观察认证结果；不含复用已有登录态。 |
| 游戏启动成功率 | 收到运行成功结果的游戏尝试数／实际发起运行的游戏尝试数 | game_attempt_id | 观察各入口运行成功率；明确重试是新尝试。 |
| 返回盖世会话占比 | 当日主动返回盖世的会话数／当日前台可见且可交互的 Steam 会话数（含跨日延续） | session_id，按日 | 7.0上线后判断触达是否需调整。 |
| 每会话可见时长 | 会话内有效可见片段时长之和 | session_id、visibility_id，按日 | 排除后台和游戏独占时间；未闭合片段单列。 |

会话恢复沿用 session_id，每次重新可见新建 visibility_id。可见时长从界面可交互至离开可见界面计时，不含后台或游戏独占；异常退出无回执不补成功或虚构时长。跨日片段按北京时间0点拆分；当日可见与返回按 session_id 去重，分子须属于当日分母集合。

### 6.2 演示边界

- 浏览器打开或刷新回到游戏库；点击 Steam 才进入首次协议确认弹窗。“模拟重新打开 App”验证已保存的启动页，不等于刷新浏览器。
- 演示中的账号、二维码、下载量、启动结果和原生内容均为模拟。测试凭据仅保留在内存，不联网提交；账号管理、导入和开发者选项的真实能力以 Steam 接入结果为准。
- 模拟 App 重启会结束模拟下载任务并保留有效下载量，再次进入复用；真实进程回收与续传能力仍待接入验证。
- 模拟 App 重开只演示已确认的身份与本机记录保留；原生身份核对中、读取失败或应用外退出／换号后的恢复尚未模拟，需接入验证。
- 原型外框的状态切换控件仅用于评审，不属于 App 功能。【2026.11.6修改】网络、Steam 安装状态与账号回显均为模拟；不证明 SDK 接口或持久化已接通。本期不定制 SDK 内导入和来源分类。
