## 冲突裁决

### CR-07-001：具体可复用资源位尚未盘点

- 采用项：C 端只证明复用现有推荐单元外壳；运营排期页显示“盘点阻塞”并禁用确认排期。
- 弃用项：自拟资源位名称、入口、素材尺寸，或复用历史广告后台示例位。
- 理由：避免把待确认能力伪装为现状，且不扩大一期范围。
- 影响：`07-resource-slot.png`、`07-placement-schedule.png`。
- 置信度：高。

### CR-07-002：实机基线包含第三方游戏素材

- 采用项：保留页面结构、密度与色彩层级，媒体与封面改用原创抽象渐变。
- 弃用项：实机图中的第三方游戏海报、Logo、人物与品牌素材。
- 理由：避免品牌和版权风险；本任务只需证明页面结构与业务状态。
- 影响：两张 C 端图及后台素材预览。
- 置信度：高。

### CR-07-003：精准投放与现有推荐文案的边界

- 采用项：用户侧沿用现有推荐外壳，不显示人群规则、优先级、频控或被圈选原因。
- 弃用项：新增“为你精准投放”“广告”等解释标签、弹窗或新频道。
- 理由：方案 A 的圈选与执行均在运营侧，且 PRD 明确不新增客户端入口。
- 影响：`07-resource-slot.png`、`07-landing-state.png`。
- 置信度：高。

### CR-07-004：两种交付方式不能同时成为一个商品的主状态

- 采用项：详情证据以一期包体闭环的“盖世直接下载”为主状态；在同页证据边界说明“第三方平台激活”沿用同一区块并完整展示激活限制。数据看板与流程图分别展示两条交付分支。
- 弃用项：在同一商品详情同时放置两套主操作，或新增交付方式切换入口。
- 理由：保持单游戏、单商品的真实用户心智，不发明切换能力。
- 影响：`07-landing-state.png`、`07-developer-dashboard.png`、`07-targeting-flow.png`。
- 置信度：高。
