状态主线草稿 → 上传中 → 待提交 → 测试中 → 测试不通过／通过 → 待发布 → 已发布；未发布版本可撤回，已发布版本不可直接删除。
发布失败候选版本保持待发布，用户继续使用原线上版本；平台可重试，不自动切换到其他版本。
一期边界不含多正式分支、Mac／Linux、预载、P2P、复杂增量更新、开发者自助灰度或回滚。
