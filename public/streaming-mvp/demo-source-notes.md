# 串流 MVP Demo 来源与边界

本文件对应 `demo.html`。本次只实现经过五轮评审的六类页面，不改变研究原文或原 Mac HTML。

## 使用

- 可离线双击，无 CDN、远程图片、字体或运行依赖。
- URL：`?platform=app|landscape|mac&page=devices|setup|session|files|settings|error`。
- 右下角评审浮钮切端、选状态及注入离线/忙/缺权限/网络中断/撤权状态；不是正式产品功能。
- `window.demoState` 为实时状态，`window.getState()` 返回副本。`window.demo.action()`、`navigate()`、`injectFault()`、`connect()`供测试。
- 所有设备、文本、游戏画面、文件及进度均为显式演示数据，不连接任何电脑、不读取磁盘、不伪装实测。

## 范围

设备列表、首次准备/信任、桌面会话、文件传输、主机连接设置、错误状态。游戏/文档/AI按钮位于模拟远端桌面任务栏，不是新建三个产品导航或 AI 平台。

中文编辑支持 1—10000 字符及多行，输入文字与发送 Enter 分开；明确操作后才读取系统纯文本剪贴板，拒权时保留手动粘贴路径。传输一次一项、单文件≤100MB，进度→完整性校验→完成；可取消、失败整份重试、同名副本，传输中断开先确认取消。屏幕切换暂时暂停输入；断线不接收输入，不清除尚未发送的草稿；撤销或断开不关闭远端程序。

初次请求信任只能在控制端发起；外部评审工具“模拟请求到达主机”只注入请求，不授予信任。Mac本机请求卡片有“允许并信任”与“拒绝”；Windows请求使用明确标注“Windows主机本地确认”的示意视图，分别允许与拒绝。APP设置只管理会话画质、帧率、声音及0—100音量；会话“连接设置”始终打开会话面板，不跳至本机管理。Mac侧栏“本机设置”独立管理允许被控、当前控制者、本机停控与信任撤销。

本机 `localAllow/localTrusted/localIncomingSession/localRequest` 与目标 `targetAllow/targetTrusted` 分离：关闭这台Mac被控、停控或撤销手机，只结束入站控制，不结束Mac主动连接Windows的出站会话。远端卡片管理只读状态，不冒充本机设置。授权有效期2分钟、恢复资格30秒及默认30FPS是产品设计值，不是实测结果。结束锁屏选项已按最终PRD移除。

## 冲突与限制

- CR-DEMO-01：技能要求完整45页证据展厅；本次用户明确要求串流6页交付。采用限定范围，未把研究证据展厅加入正式产品。证据图与最终回归由主管单独交付。
- CR-DEMO-02：新版 Mac 基线只有设计稿，没有已上线串流。新增串流是方案，不标为既有能力。
- CR-DEMO-03：新页面没有同尺寸真实对照图，不能给像素复刻 PASS。本次仅声明继承外壳与令牌，不声称95%视觉一致；系统字体使用本地回退，未声称Android字形精确复现。
- 真正中文输入法、系统权限、锁屏采集、画质码率、设备驱动、手柄和网络中继都需要工程实现及六组合真机验收。Demo中的画质/声音/缩放仅表示选项和状态，不编码真实流。
- 原导航超出串流的功能仅展示范围说明，不捏造游戏商店/社区功能。
- 真实文件选择未接本地磁盘；示例文件选择器用于呈现单文件流程，隐私数据不进入原型。

2026-09-25 终审补充15项检查通过，页面脚本异常0：会话设置留在会话、音量状态、关闭本机不影响出站连接、本机请求拒绝/允许、停控隔离、撤销隔离、文本原样追加及真实换行、远端纯文复制入口与内容、传输校验期间撤权使旧回调不能报成功、远端管理名称及Windows主机拒绝/允许。撤销目标访问立即清空草稿、按键并失败所有未完成传输；同名副本及不自动执行仍保留。
