# 盖世串流一期 MVP 方案

2026-09-24｜供 CTO 确认范围、依赖和验收标准

**一期在盖世 APP 和 Mac 中增加“连接自己的电脑”：同账号找到设备，首次授权后进入桌面，用同一条连接玩游戏、临时办公或继续电脑上的 AI 任务。保留完成任务必需的输入、声音、文件和恢复能力；专用终端、远程开机、隐私屏、云电脑等独立能力后置。**

Android、iOS、Mac 主控到 Windows、Mac 被控的六种组合是一期覆盖目标，不是当前已实现清单。工程先贯通公共链路，再逐组合完成验收；没有资源和引擎评估，不承诺上线日期。

## 一、为什么做，先服务谁

首批服务已有盖世用户：电脑有游戏或工作任务，人希望离开桌面继续操作。用户当前可用 UU 远程解决；UU 已有游戏、办公、文件和终端能力，因此“也能远控”“支持 AI”不足以让用户迁移。

盖世应争取两项具体收益：玩家少切一个 App、少重复配置操控；临时办公和 AI 用户能在同一会话中读清内容、正确输入并取回结果。前者有现有游戏和手柄用户基础，后者依赖实际小屏操作体验。尚未使用盖世的纯办公用户，一期还缺少独特迁移动机，不作为首批获客承诺。

| 用户 | 一期完成的任务 | 体验重点 |
|---|---|---|
| 新手玩家 | 连接电脑，从桌面启动已安装游戏并退出 | 首次授权易懂；不会被启动器、键盘或隐藏退出入口卡住 |
| 资深玩家 | 用实体手柄连续游玩，按网络调画质 | 输入正确、状态可见、断线后无卡键；不承诺电竞级延迟 |
| 产品经理 | 改文档局部文字，保存并取回 | 中文选字、多行编辑、精准定位 |
| UI 设计师 | 看设计稿、改文案、导出文件 | 文字清晰、缩放准确；不做专业色彩验收承诺 |
| 美术 | 查看渲染进度，切屏并取预览图 | 找到原工作窗口；不承诺压感绘画 |
| 研发 | 回到原 IDE/终端，补指令、看构建结果 | 符号输入、长文本与快捷键；不新建终端体系 |
| 测试 | 复现桌面操作，保存并取回截图 | 操作不重放、结果可确认；不承诺远端物理外设测试 |
| 运营/行政 | 紧急修改表格，交付保存后的文件 | 数字/中文输入及正确文件版本 |
| 电脑 AI 用户 | 回到原会话，补要求、处理确认、查看产物 | 保留上下文，换行与提交分开，断开后任务继续 |

九类角色用于检查遗漏，不是九套需求，也不是已访谈的九组用户。新手默认自动画质，资深保留少量参数和快捷操作，共用同一套页面。

## 二、界面与端分工

APP 在现有游戏库内新增明确的“远程电脑”文字入口，不先要求选择游戏，也不增加游戏、办公、AI 三个导航。原设备图标的落点尚无足够证据，不将它认定为串流入口；原“我的设备”已有手柄语义，不能直接混成远程电脑列表。

Mac 沿用用户提供的[开发标注版界面](demo-source-notes.md)，侧栏加入串流入口，进入同账号电脑列表；“本机允许被控”独立说明和设置。串流会话操作栏与客户端全局导航区分，用户始终知道自己正在操作哪台电脑。原稿没有串流页，本次是新增设计，不能描述成现有能力。

| 控制端→被控端 | 主要任务 | 单独验收重点 |
|---|---|---|
| Android→Windows | 游戏、办公、电脑 AI | 真机中文输入、触控坐标、手柄、声音、文件 |
| iOS→Windows | 游戏、办公、电脑 AI | iOS 输入法、后台恢复、剪贴板权限、文件保存 |
| Mac→Windows | Windows 游戏及连续办公 | 焦点、系统快捷键、全屏、鼠标捕获与释放 |
| Android→Mac | 原 Mac 工作及 AI 任务 | Mac 录屏/控制权限、锁屏、中文及文件访问 |
| iOS→Mac | 原 Mac 工作及 AI 任务 | Mac 被控条件与 iOS 限制同时通过 |
| Mac→Mac | 在另一台 Mac 继续原任务 | 双端权限区分、快捷键归属、切屏和文件权限 |

被控端负责采集、编码、声音、输入处理和访问控制；控制端负责画面、操控、文件及会话状态。游戏能否运行由被控电脑决定，串流不会让 Mac 获得 Windows 游戏的本地兼容能力。Windows 被控服务是必要交付，不因用户界面重点是 APP/Mac 而省略。

## 三、逐项功能范围

“一期”表示本次规格必须交付；功能是否通过以真实端组合验收为准。完整竞品候选池另见[UU 官方 116 项功能盘点](research/UU官方功能盘点.md)，不将其全部纳入盖世。

| 功能介绍 | 解决什么问题 | 对盖世的价值 | 一期判断 |
|---|---|---|---|
| 同账号电脑列表：显示设备名和状态 | 找不到要连接的电脑 | 承接所有场景的共同入口 | 一期 |
| 首次可信授权：主机确认控制端 | 登录账号不等于允许控制电脑 | 建立可解释的访问关系 | 一期 |
| 本机允许被控开关 | 用户需要暂停远程访问 | 用户能决定何时开放电脑 | 一期 |
| 撤销控制端授权 | 换设备后旧端仍可访问 | 降低信任成本 | 一期，终止现有会话 |
| 主机本地停止控制 | 本人回到电脑要收回控制 | 保留机主最终控制权 | 一期 |
| 局域网连接 | 家中换位置玩或工作 | 承接高频近距离使用 | 一期 |
| 外网连接 | 出差、外出无法访问家中电脑 | 使办公和 AI 场景成立 | 一期，含连通回退 |
| 单控制者占用提示 | 两端输入相互干扰 | 避免错误操作和任务破坏 | 一期，不自动抢占 |
| 桌面会话 | 启动器、文档、AI 窗口各不相同 | 一个基础能力承接三类任务 | 一期 |
| 精准指针 | 手机点不中小按钮 | 降低办公和启动游戏门槛 | 一期 |
| 画面缩放与复位 | 字太小或放大后迷失位置 | 提升小屏可读性 | 一期 |
| 中文输入与选字 | 组词未完成就进入远端 | 减少文档和 AI 纠错 | 一期 |
| 多行文字编辑 | 换行被误当成提交 | 避免指令或表格误操作 | 一期 |
| 纯文本复制粘贴 | 长指令需要重新输入 | 缩短补充要求的路径 | 一期，粘贴不附回车 |
| 必要系统快捷键 | 被本机系统拦截或作用错端 | 保证保存、切窗等基本任务 | 一期，保留键给替代入口 |
| 桌面/游戏操控切换 | 同一输入方式不适合所有任务 | 共用会话而不牺牲操控 | 一期，明确手动切换 |
| 已有物理屏选择 | 工作窗口位于另一显示器 | 避免连上却找不到任务 | 一期，一次显示一屏 |
| 单实体手柄 | 玩家不能沿用惯用操控 | 发挥盖世硬件与玩家基础 | 一期，分端核对映射 |
| 基础触屏布局 | 无手柄无法操作游戏 | 保留最低可玩路径 | 一期，不承诺全游戏适配 |
| 远端声音及音量 | 游戏或工作反馈听不到 | 完成基本音画体验 | 一期，不含麦克风直通 |
| 自动画质 | 用户不会调编码参数 | 降低首次使用门槛 | 一期 |
| 基础画质/帧率档位 | 网络与设备能力不同 | 给资深用户可理解的调整 | 一期，不保证实际帧率 |
| 单文件发送 | 手机材料无法交给电脑 | 完成临时修改和 AI 输入 | 一期，普通单文件≤100MB |
| 单文件取回 | 结果留在电脑无法交付 | 让办公任务真正完成 | 一期，普通单文件≤100MB |
| 传输进度与取消 | 不知道是否完成或想停止 | 减少等待和误判 | 一期 |
| 文件校验与冲突处理 | 半成品被报成功、同名被覆盖 | 保证产物可信 | 一期，同名生成副本 |
| 失败原因与重试 | 不知道是网络、授权还是主机问题 | 降低放弃和支持成本 | 一期，失败不删设备 |
| 断线恢复与输入清理 | 重连后卡键、重复点击或提交 | 避免恢复造成二次损失 | 一期，不重放旧输入 |
| 后台回前台恢复 | 返回后状态不明 | 适应手机临时切应用 | 一期，恢复画面后再接输入 |
| 明确断开并返回 | 找不到退出，只能强关 App | 完成一轮使用闭环 | 一期，保留远端程序 |
| 专用终端/多会话 | 希望直接管理命令行任务 | 可拓展开发者使用 | 后置，先接续原桌面 |
| 远程开机 WOL | 电脑关机时无法访问 | 扩展无人值守范围 | 后置，涉及硬件与配置 |
| 隐私屏 | 现场旁人可能看到内容 | 扩展敏感办公场景 | 后置，当前明确现场可见 |
| 虚拟多屏 | 需要新增或同时使用多个屏幕 | 扩展重度桌面工作 | 后置 |
| 跨账号远程协助 | 帮助别人操作电脑 | 拓展客服/亲友协助 | 后置，超出自用电脑 |
| 宏与键位市场 | 重复动作或复杂个性化操控 | 服务重度游戏用户 | 后置，先保基本操控 |
| 云电脑 | 用户没有可用主机 | 增加云算力供给 | 后置，不新增商业业务 |

## 四、不能省略的操作规则

主机需开机、联网且服务运行；离线不显示可用的唤醒按钮。允许被控与系统录屏/辅助功能等权限分开引导。首次建立信任后可无人值守连接，不要求每次由主机现场点击；新增控制端不能仅凭同账号直接接管。

会话冻结、断线、失焦或切后台时停止新输入，释放修饰键、鼠标长按和摇杆。恢复前先核对授权、占用并取得最新画面；不补发离线点击、文字或 AI 提交。原会话保留 **30 秒恢复资格是设计默认值，不是恢复成绩或保证**；超时释放占用，用户可重试或返回。

缩放和移动画面不能变成远端点击；切物理屏先停输入、重算坐标。中文先完成选字，换行与发送区分；粘贴不自动提交。断开返回设备列表，原游戏、文档和 AI 程序继续运行。授权撤销则立即停控，不能自动恢复。

文件一次传一个普通文件，≤100MB 为本方案设计默认值，不是 UU 限制或实测传输上限。先写临时文件，完整校验后报成功；同名生成副本，不覆盖。取消或失败保留源文件、清理半成品，用户手动整份重试；一期不承诺断点续传。结束会话仅断开并保留程序，不提供结束后系统锁屏选项；远端物理屏仍可能被现场看到。

## 五、五轮评审改变了什么

以下为专家框架和角色场景交叉审查，不是真人访谈或投票。

| 轮次 | 暴露的问题 | 最终修正 |
|---|---|---|
| R1 独立提案 | 只连接画面不能交付任务；全面复制 UU 过大 | 保留共同会话和三类任务必需能力 |
| R2 交叉质疑 | 六组合被误当同日承诺；工作窗口可能在副屏 | 六组合逐项验收；加入物理屏切换，虚拟屏后置 |
| R3 方案收敛 | 三套场景导航会分裂流程；并发和文件规则不足 | 一个设备列表；单控制者；文件校验及同名副本 |
| R4 失败反证 | 公开评论涉及连不上、输入法、退出困难和卡顿 | 失败保留设备、明确退出、完整中文输入、冻结停输入 |
| R5 发布复核 | 规格和竞品成绩可能被写成盖世已实现 | 分开规格、竞品实测、盖世验收；采用任务完成与再用指标 |

评审记录：[用户价值](research/五轮评审/R5-用户价值.md)、[技术交付](research/五轮评审/R5-技术交付.md)、[用户场景](research/五轮评审/R5-用户场景.md)。

## 六、推进顺序与发布门槛

先由产品与客户端/引擎负责人核对旧实现、可复用操控、主机服务、Mac 权限和中继依赖，给出工作量；数据负责人明确连接和任务口径。再将一条真实设备链路贯通到任务完成，随后扩展其余组合。APP/Mac 原型和 PRD 对照同一功能清单；原型可点不算引擎通过。无资源数据时不排固定周数。

**发布前必须满足：**六组合分别完成授权、连接、输入、文件、断开与恢复；游戏使用主机实际支持的样本，文档能保存取回，原 AI 会话能正确收到补充要求。覆盖离线、锁屏、撤权、占用、切网、弱网和后台返回。错设备操作、撤权后继续控制、旧命令重放及错误覆盖文件均阻断发布。不能用平均延迟或一张首帧截图代替连续任务证据。

首要指标是独立任务完成率，游戏、文件、AI 分开；辅助看首次成功耗时、输入纠错、失败恢复，以及首次完成后 7 日主动再用。再用率分母为完成首次任务且观察满 7 日的人，分端组合及新手/资深记录。与 UU 同设备、网络、任务比较，成功率不退步，并在至少一个主场景减少操作或纠错；当前没有基线，不编目标数字。中继带宽、长会话和支持成本同步核算，不用免费无限中继换短期时长。

## 七、研究依据与当前证据

UU 官方已覆盖 116 项候选功能；[版本演进](research/UU版本演进与宣发重点.md)显示其持续补齐输入、文件、多屏和终端，不能据发布时间直接排列盖世需求。[iOS 评价](research/UU%20iOS评价问题.md)中的连接、输入法、退出和卡顿投诉支持故障检查方向，不代表整体发生率。原始来源：[UU 帮助](https://uuyc.163.com/help/)、[App Store 功能/历史](https://apps.apple.com/cn/app/id1642306791)、[Apple 公开评价](https://itunes.apple.com/cn/rss/customerreviews/id=1642306791/sortBy=mostRecent/json)。

既有模拟器 UU 4.42.0→Windows 已记录连接及单文件往返校验，中文和游戏任务未完成。真机 UU 4.39.1 由另一线程继续取证，结果按交付证据索引逐项引用，不能用菜单截图证明任务完成。以[真机证据口径](证据说明.md)和[功能证据映射](竞品体验与证据.md)核对完成程度，不把版本和环境拼成一条成功流程。

盖世现状依据[APP 与 Mac 基线](demo-source-notes.md)。本方案没有上传原始个人截图，没有把专家推演换算为“98%成功率”；充分把握来自真实任务和逐组合验收。

真机新增证据：141号图显示电脑测试记事本收到手机输入的“你好”；多行、文件往返和游戏流程因另一设备接管而尚未完成。详见[竞品体验与证据](竞品体验与证据.md)。
