# 远程入口位置建议

**建议移动端放在首页固定工具区，入口叫「远程」；进入后是「远程电脑」。Mac 放在主侧栏，名称同样为「远程」。** Windows 和 Mac 属于设备信息，不设两个平台 Tab。远程工作区不带入「PC游戏／复古游戏」。

用户要找的是自己的电脑，连接后才决定玩游戏、改文档或使用电脑上的 AI。把唯一入口藏在游戏库，办公用户容易误以为这里只能启动游戏；把办公和游戏分成两个远程入口，又会使同一台电脑出现两套连接路径。

| 位置 | 用户如何理解 | 代价 | 本轮决定 |
|---|---|---|---|
| 首页固定「远程」入口 | 从首页连接电脑，不预设连接后的任务 | 需在首页找到稳定、易识别的位置 | 推荐作为主入口 |
| 游戏库中的「PC远程」 | 把远程理解为游戏来源或运行方式 | 工作场景难发现，Mac 设备名称也容易被误解 | 不作为唯一入口；后续可评估游戏场景快捷入口 |
| 新增第六个底栏 | 远程是与社区、游戏库并列的业务 | 挤占已有导航，尚无使用频次依据 | 本轮不增加 |
| 我的／设置 | 配置已有设备 | 高频连接路径深，容易被当作设置项 | 不作为主入口 |

入口与工作区分开处理：UU 的设备列表、设备详情、进入桌面及文件传输路径作为本轮复刻依据；盖世首页入口属于产品建议，不是 UU 实测结论。当前没有完整首页原稿，Demo 直接打开远程工作区，另提供明确标注为建议的入口草图，不把草图当作已经落地的首页。

移动端竖屏、横屏共用同一个入口语义及设备列表。横屏只重排空间，不新增 Windows／Mac 切换。Mac 侧栏进入工作区后，用窗口内返回恢复上一级；无需先选择「游戏」还是「办公」。

一期仍优先完成连接、控制、输入、文件和退出。终端、宏、无线副屏等在复刻中用于对照竞品，不因出现于 Demo 就纳入一期。入口是否需要升级为底栏，应在真实使用后看首页入口的发现率和重复连接路径，不以竞品功能数量决定。
