# UU远程官方功能与场景盘点

调研日期：2026-09-24。用途：为盖世游戏 APP 与 Mac 串流重构提供完整候选功能池，随后依据实机体验切出一期 MVP。

**UU远程已覆盖游戏、办公、远程AI/开发三类任务，核心共用设备连接、桌面传输、输入、声音及安全能力。专用终端、文件传输和多屏是独立扩展能力；云电脑属于另一个付费算力业务。**

本文件是官方公开资料盘点，不是实测完成清单。已检查官网下载页、特色功能页、帮助目录和帮助站点地图，保存页面文本与URL到同目录 `uu-official-sources`。没有操作用户电脑，没有注册、购买或开启被控。官方宣传的“零延迟”“无损”“最高144帧”等不作为实测结论。

- 官网为 `https://uuyc.163.com/`，页面使用网易下载域名并链接 App Store `id1642306791`；不使用 `uuyc163.com` 等仿冒或未证实域名。
- 2026-09-24 实时下载页：Windows、macOS、Android 为 4.42.0；iOS 为 4.41.0；TV 为 3.5.0。App Store 搜索缓存显示 4.40.0，因此版本基线以实际下载安装后记录为准，不能把搜索缓存版本当最新安装版本。

## 3. 影响盖世 APP / Mac 方案的关键区别

| 事项 | 官方资料能支持的结论 | 对后续方案的影响 |
|---|---|---|
| Mac主控和Mac被控 | 两者均有，但权限和外设能力不对称 | 必须分别写“Mac去控Windows”和“手机去控Mac”，不能写一个笼统Mac支持 |
| 手机问电脑AI | 远程桌面可操作已有AI窗口；专用终端只管理UU自己创建的会话 | 不能把“连上终端”说成“无缝接管用户原有Codex会话” |
| 专用终端断开 | 主控离开时会话保留；被控进程结束后不恢复 | 会话重接不等于跨进程任务持久化 |
| 普通文件传输 | Mac被控需双方≥4.37且同账号；Mac远协传输不支持 | 一期应明确自用设备链路；不要借“全端互传”跳过组合验收 |
| 文件拖拽 | 仅Win到Win；普通传输支持续传，拖拽不支持 | APP/Mac不承诺桌面拖拽等价能力 |
| 手机剪贴板 | 仅纯文本，帮助明确移动与Windows；图片和富文本不能概括为全端通用 | AI长指令和文档文字可作为独立基础链路；文件另走传输 |
| Mac麦克风 | 被控端暂不支持麦克风直连 | 不把Mac远程会议或语音AI列为已打通场景 |
| 显示质量 | Android无4:4:4真彩；HDR帮助仅Win到Win；Mac虚拟屏上限4K60无HDR | 禁止全端统一写4K144 HDR；画质选项应随能力显示 |
| 多屏 | 手机可切屏，但不能主动创建虚拟副屏；电脑可建最多3个虚拟屏 | 移动和Mac控制菜单应分端处理 |
| 无线副屏 | 仅Win作为主屏，APP作副屏；不能Mac作主屏，不支持镜像 | 不与普通串流混为一个功能 |
| Android被观看 | 支持同账号APP看Android，不能远程点击、滑动或输入 | “支持安卓被控”会误导，应叫安卓屏幕共享 |
| WOL开机 | Win硬件、BIOS、网卡、辅助设备缺一不可；iOS不能作唤醒中转 | 首次配置引导与失败原因是单独工作量，不能只画开机按钮 |
| 观看模式 | 重连默认回操控；观看时暂停输入、麦克风和剪贴板 | 场景状态与安全状态必须一起验收 |
| 安全锁 | 锁本地UU设置和退出，不等于锁远端系统，也不阻止发起远控 | 三种“锁”分别描述：系统锁屏、客户端锁、连接授权 |

## 5. 资料冲突与实机检查缺口

1. 官方帮助页日期与正文新版本能力并不完全同步。例如终端页显示2025-01-18，却含4.39多会话；应以正文和安装版本联合记录，不用日期推断上线时间。
2. Mac宣传页泛称144帧，虚拟屏帮助明确Mac虚拟屏最高60帧；二者场景不同，不能向所有Mac连接推广144帧。
3. 旧远协教程仍写双端登录，新特色页明确被控免登录；以当前端内流程为准。CLI的term范围也比GUI终端文档窄。
4. 磁盘共享资料指向测试群包，不能算所有用户稳定版都有。云设备配置、优惠、单价、库存与App内购买应另录端内当日状态。
5. 尚未形成性能实测：无同机同网延迟、码率、掉帧、温升或断网恢复成绩。本文件不能据此认定UU行业最快。
6. 首次登录、绑定确认、账户风控、设备重命名、原有连接被抢占、系统中文输入、自动解锁凭证方式、网络统计、离线/超时/黑屏提示、长时保活等端内细节，需由实机主流程覆盖表补充。官方存在某能力不等于对应设备组合已成功。
7. 官网页面的“用户评价”属于营销展示，不作为独立用户研究证据；价格口径也不用于推导盖世愿付费率。

UU远程应研究为一套远程使用自有电脑的完整产品：连接与权限是共同底座，游戏看操控和实时性，办公看精准输入与文件交付，AI看原有上下文、持续会话与结果取得。优先由实机证据确认APP→Win、APP→Mac、Mac→Win、Mac→Mac四个方向，决定一期承诺哪些组合。专用终端、WOL、多屏与高级画质分别计算依赖；云电脑、无线副屏、跨账号协助、批量运维和磁盘测试能力进入完整功能池，不自动进入一期。
