# R4：用户最可能在哪一步放弃

已读全部 R3 和 iOS 评价。下表是角色反证推演，不是真人测试；同类问题合并，修改既有会话规则，不另建功能平台。

| 用户与放弃点 | 必须修改的规则 |
|---|---|
| 新手玩家：进入后找不到退出，以为只能强关 App | 会话操作栏始终可唤出；“断开连接”返回设备列表，写清远端程序继续运行；系统返回先收键盘/工具层，不意外关闭游戏。 |
| PM、运营：中文选字丢失，Enter 把未完成内容提交 | 手机先完成本地组词，再发已确认文字；换行与 Enter 键明确区分。粘贴不附加回车；发送前确认远端焦点，断线不自动重发。 |
| UI、美术：放大后点偏，或找不到另一屏窗口 | 缩放、拖动画面不变成远端点击；提供缩放复位；物理屏切换按当前屏重算坐标。旧屏消失后暂停输入，显示可选屏，不直接点击新屏相同位置。 |
| 研发：Mac 快捷键落在本机，误关本地文件 | 会话失焦即停止转发并释放修饰键；重新聚焦后才收新输入。系统保留键使用已有工具栏替代，不能宣称所有组合键均直传。 |
| 测试：切后台回来状态未知，重复点击改变复现步骤 | 恢复先呈现远端最新画面、确认可控，再允许输入；不回放离线点击。操作过或未执行不能判明时，不伪报成功。 |
| 资深玩家：网络波动后摇杆持续偏转，回不到正常操作 | 失联及操控切换时释放按键、摇杆归中；恢复后读取新的实体状态。不能以保留旧按键状态冒充无缝恢复。 |

iOS 公开评论分别提到输入法、双指误触、退出困难及连接失败，支持上述检查方向；不证明本表每个场景已发生，也不能推算频率。

证据口径更正：真机 UU 为 **4.39.1**，模拟器为 **4.42.0**；先前 R3 他稿的 4.37 不采用。真机控制截图尚未完成；模拟器中文输入未通过，不把规则建议写成能力已实现。六组合均需独立完成焦点、输入、退出、恢复与切屏检查。
