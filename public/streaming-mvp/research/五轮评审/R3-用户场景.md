# R3：统一方案能完成哪些任务

已读全部 R2。**认可一条桌面连接承接三类任务，不增加游戏、办公、AI 三套导航。**九类角色用于检查遗漏，不建立九套功能。

| 角色 | 一期能承接的任务 | 不能据此承诺 |
|---|---|---|
| 新手玩家 | 连电脑、处理启动器、用基础触屏/手柄进入游戏 | 每款游戏都有完善触屏方案 |
| 资深玩家 | 基础手柄游玩、调画质、重连 | 电竞级延迟、所有外设和游戏兼容 |
| 产品经理 | 修改 PRD 局部文字、保存并取回 | 手机具备桌面同等编辑效率 |
| UI 设计 | 查看设计稿、改文案、导出文件 | 专业色准、逐像素视觉验收 |
| 美术 | 切到渲染窗口、看进度、取回预览 | 精细绘画、压感、颜色定稿 |
| 研发 | 操作原 IDE/终端、补指令、查日志 | 独立终端、端口映射、任务托管 |
| 测试 | 复现桌面步骤、保存并取回截图 | 物理外设验证、多机自动化测试 |
| 运营/行政 | 局部修改表格、取回单文件 | 隐私办公、远程会议、批量资料管理 |
| 电脑 AI 用户 | 回原会话、补指令/确认、取回产物 | AI 通知、新建会话体系、关机续跑 |

这些是方案可覆盖的任务，并非实测通过。手机依赖精准指针、缩放与完整输入闭环；Mac 依赖焦点和快捷键正确归属。单文件往返须能选中路径，不扩成文件管理器。

**入口仍有可发现性风险：**手机沿用游戏库设备入口可以，但入口及落地页要明确写“远程电脑”，不能只画无名设备图标或先要求选择游戏；否则办公用户找不到。Mac 侧栏“串流”进入同账号电脑列表；本机“允许连接”说明被控资格，与主动连接其他电脑分开。

六组合保留，按真实设备逐项验收。没有隐私屏时，办公室现场可能看见操作；没有 WOL 时，电脑须开机联网。支持游戏只代表控制运行设备，不改变该电脑原有游戏兼容性。
