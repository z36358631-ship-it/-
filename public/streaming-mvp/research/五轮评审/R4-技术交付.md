# 第四轮：失败优先规则

以下时间值为设计默认值，不是实测成绩。

| 反证场景 | 明确处理 |
|---|---|
| 已撤销授权 | 终止当前控制并清输入；旧凭证不能重连，显示“访问已取消”，只能重新获得主机授权 |
| 主机忙 | 显示正在被控制，不自动抢占；原会话结束后允许重试，主机本地始终可停控 |
| 连接中断占用 | 原会话保留30秒恢复资格；超过后释放。重连仍检查授权与占用，不能复活已结束会话 |
| 电脑锁屏 | 显示系统锁屏并由用户输入系统凭证，不保存密码、不自动解锁；无权限采集锁屏时明确提示，不显示旧画面冒充在线 |
| 切网或断流 | 显示连接中断、禁止新输入；30秒内自动恢复，超时提供重试和返回设备，不删除设备或关闭程序 |
| 文件失败 | 暂存内容不算完成；失败写明网络、空间或权限原因；手动整份重试，成功后才生成副本并可打开。源文件改变须重新选择 |
| 快捷键落在本机 | 远控窗口失焦即停输入；系统保留键提供会话内发送入口，不能同时影响两端；明确鼠标释放动作 |
| 后台恢复 | 切后台释放修饰键、拖拽和摇杆；回来先恢复画面与授权，不重放文字、点击或提交 |

**修正R3：**重试核对权限及源文件，不保留可绕过撤销的访问句柄。

无WOL时离线不能展示可唤醒按钮；无隐私屏时明确物理屏可见。主机拒控后不得自动恢复。

工程另列超时、输入清理、会话去重、锁屏采集、原子文件落盘和中继实现差距。不满足时报告具体缺口，不在PRD写“后续再定”。
