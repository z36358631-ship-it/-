# 第五轮：技术交付检查

**范围可进入规格，工程与发布未获通过。**同账号、单控制者、不抢占；共用桌面承接游戏、办公及原AI窗口。保留中文输入、纯文剪贴板、物理屏单选、单手柄/触控、声音、自适应质量、单文件往返、授权撤销与重连；无终端、WOL、隐私屏。

## 六组合契约

每行验授权→连接→任务→文件→断开→重连，含离线、忙、撤权、锁屏、切网、后台。

| 组合 | 额外必须举证 |
|---|---|
| Android→Windows | 真机中文组词/多行、触控坐标、手柄、游戏启动器、声音及文件hash |
| iOS→Windows | iOS输入法、系统返回与后台限制、剪贴板授权、手柄断连和文件保存 |
| Mac→Windows | 窗口/全屏、焦点、快捷键归属、鼠标捕获释放、游戏及办公操作 |
| Android→Mac | Mac录屏/辅助功能授权、锁屏进入、中文输入、文件选择与取回 |
| iOS→Mac | 上述Mac被控规则与iOS交互同时通过，不能引用Android成绩 |
| Mac→Mac | 双端权限区别、系统快捷键替代、焦点丢失、多物理屏坐标及文件权限 |

游戏以主机支持游戏为样本；各组合完成文档修改取回、原AI会话补指令。无Mac设备结果记“未执行”，不能签通过。

## 状态规则

设备列表区分离线、可连接、被占用、需授权；会话区分连接中、锁屏待登录、可操作、网络中断恢复中、恢复失败、访问已取消、主动结束。冻结或中断暂停输入，释放修饰键/鼠标/摇杆，不重放旧操作。撤销及主机停控立即终止访问。

恢复资格保留30秒是设计默认值，不保证30秒内恢复；超时释放占用并显示重试/返回，重新核验权限。文件仅校验完整后报成功，同名存副本；失败保留源文件、清理半成品，由用户整份重试。

## 发布门槛与缺口

六组合的授权、输入、文件完整性、退出、撤销、占用和恢复关键用例必须全部通过；不允许错设备操作、旧命令重放、文件覆盖或撤权后继续控制。代表任务有真实设备连续证据；性能记录覆盖局域网、公网和移动网络，不能只报平均延迟。
