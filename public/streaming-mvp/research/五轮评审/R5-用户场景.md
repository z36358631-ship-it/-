# R5：用户任务与最终范围

**认可一期做“在盖世接上自己的电脑，完成原任务再离开”。**六组合保留：Android/iOS/Mac 主控→Windows/Mac 被控；先内部逐链路贯通，再按实际验收放行。本结论来自角色推演、UU功能及公开评论分析，不是真人访谈结果，也不承诺成功概率。

| 用户 | MVP任务承诺 | 一期不承诺 |
|---|---|---|
| 新手玩家 | 配对、连接、从桌面启动已有游戏、基础触屏/手柄操作、退出 | 所有游戏都有专属触屏布局 |
| 资深玩家 | 实体手柄游玩、基础画质调整、断线恢复 | 电竞级延迟、宏、全外设兼容 |
| PM | 修改文档局部文字，保存并取回 | 手机等同桌面编辑效率 |
| UI设计 | 查看原稿、改文案、导出单文件 | 专业色彩与逐像素验收 |
| 美术 | 查看渲染进度、切已有屏幕、取预览图 | 压感绘画、颜色定稿 |
| 研发 | 在原IDE/终端补指令、查看构建结果 | 独立终端、端口映射、任务托管 |
| QA | 复现桌面步骤，保存并取回截图 | 远端物理外设测试、批量自动化 |
| 运营/行政 | 紧急改表、保存并取回单文件 | 隐私屏、批量资料管理、远程会议 |
| 电脑AI用户 | 回到原会话，补要求、处理确认、查看并取回产物 | AI平台、新会话体系、关机续跑 |

手机重点是短操作、中文输入与精准定位；Mac重点是连续键鼠、窗口和快捷键。原系统、软件和游戏许可仍是任务前提，串流不改变主机运行兼容性。

**保留的操作规则：**手机原设备入口明确“远程电脑”；Mac侧栏串流进入同账号设备，本机允许连接单独控制。不增三类场景导航。工具条随时可找，断开返回设备且不关程序。中文选字完成后发送，换行不等于提交，粘贴不附回车。缩放和移动画面不触发远端点击；切屏重算坐标，旧屏消失先停输入。失焦、切后台、断线释放键鼠和摇杆；回来先呈现新画面、核验权限，再接新输入，不重放文字或点击。

**为何在盖世用：**已有盖世玩家可以少切应用，沿用经核对可复用的操控习惯；同一连接顺手处理文档或AI任务。此收益需要实际操作证明，不能仅凭入口合并宣称更方便。已有UU用户若已配好设备、依赖远程开机、隐私屏、专业终端或成熟键位，仍会选UU；一期允许并用，不以卸载UU为目标。尚未使用盖世的纯办公用户暂缺独特迁移动机。

**证据边界：**UU真机4.39.1、模拟器4.42.0分别记录。已知模拟器→Win连通及单文件往返hash一致，不证明盖世或其他端通过；模拟器中文输入未通过，真机证据仍在采集。最终逐组合验游戏、文件、AI任务及退出恢复；记录真实完成、纠错和再次使用，不用使用时长替代成功。
