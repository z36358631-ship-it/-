## 一、文档概述

### 1.1 背景概述

用户希望通过手机或另一台电脑继续使用自己电脑上的游戏、文件和软件。当前方式是使用第三方远控，或先进入盖世游戏的游戏库或 Mac 侧栏，账号和入口依附于盖世游戏。本次将远程电脑独立成一套产品，用户打开独立 App 或电脑客户端，使用盖世账号登录后查看自己的电脑，再主动发起连接。流程参照已留存的 UU 远程实机资料；远控操作沿用已评审版本，不因独立化额外引入远程协助、陌生设备连接或会员规则。

|---|---|

### 1.3 术语定义

| 术语 | 说明 |
|---|---|
| 盖世账号 | 复用盖世游戏的用户身份，以服务端返回的同一 UID 识别用户；独立产品不另建一套同手机号账号。 |
| 登录 | 当前独立客户端取得有效的盖世账号会话。拉起盖世 App、扫码识别或手机确认本身均不等于该客户端登录完成。 |
| 允许被控 | 用户在电脑客户端开启被控能力，并满足系统权限。与账号登录、主控端连接及远端系统锁屏解锁分别判断。 |
| 同账号电脑 | 已在独立电脑客户端登录当前盖世账号的电脑；是否在线、是否允许被控分别展示。登录手机 App 不会把手机列为被控电脑。 |


## 二、产品说明

### 2.1 产品／方案简介

| 项目 | 说明 |
|---|---|
| 产品／方案定位 | 独立移动 App 与电脑客户端，复用盖世账号，访问自己的电脑。 |
| 目标用户 | 希望在手机或另一台电脑继续使用个人电脑的用户。 |
| 核心目标 | 两端登录同一盖世身份后，找到有权限的电脑，主动连接并使用，退出后远端程序继续运行。 |
| 使用场景 | 手机或另一台电脑作为主控，在家、公司或其他网络连接自己的电脑；支持局域网与公网，目标电脑完成独立客户端登录及被控权限。 /2026.10.28修改 |
| 功能概述 | 地区登录和授权衔接同账号设备、详情及远控；移动端底部为我的设备/我的，扫一扫、帮助中心、检查更新、关于集中在我的，退出位于昵称右侧；电脑更多下拉承接教程、帮助、原页检查更新及关于；退出位于账户面板昵称右侧，设置保留左侧入口。双端采用浅色模式，远控沿用当前Demo的输入、观看、文件、电源与快捷启动；移动端按键与布局复用盖世已有模块，本Demo保留用户截图主页结构，以可操作线框演示既有模块交互，不另建独立三Tab主页或另一套布局业务规则。 /2026.10.28修改 |

## 四、支撑及非功能需求

### 4.1 埋点与数据需求

**数据结论：**改造原远程入口与登录归因，复用连接、会话、文件、电源、游戏和工具事件。旧“游戏库入口曝光/点击”不再作为独立版入口转化；保留历史数据原含义，独立产品按产品和版本区分。Demo 不向生产上报。

本轮我的/帮助搜索/版本/关于为页面与入口调整，不新增统计目标或埋点；扫码继续归入电脑端登录尝试，不将手机扫描或确认记作登录成功。埋点先保留当前事件设计；接入新自有平台或Firebase的选择、接口和迁移口径待数据团队确认，不同时重复计数。按键与布局本轮提供可操作的复用交互线框，Demo不向生产上报业务事件；正式接入盖世已有模块时沿用其有效事件与数据口径，具体映射需核对，本地演示成功不能作为真实云服务成功。以下三项为既有独立登录改造的新增事件；每项包含登录业务参数及产品归属。账号、事件ID、客户端版本、环境等SDK公参复用原字典，接入前核对映射。 /2026.10.28修改

|---|---|---|---|
