一、文档概述

1.1 背景概述

用户在家中或办公室不便坐在电脑前时，仍会需要继续游戏、处理文件，或使用电脑上已登录的软件。目前主要依靠第三方远控，或把文件发到手机、重新登录应用。前者需要切换产品寻找设备，后者难以保留电脑上的窗口、任务和运行环境。/2026.9.30修改

本需求让盖世用户在同一局域网内，通过 APP 连接自己的电脑，或通过 Mac 连接另一台电脑。优先交付 APP 和 Mac；Windows 端仍有客户端开发依赖，接入随被控能力就绪后开放，不承诺同步上线。同账号设备集中展示，用户可进入桌面、传输文件或执行电源操作。APP 提供触控、键盘、悬浮鼠标和横竖屏布局；Mac 提供设备分栏、独立远控窗口、控制中心和双栏文件传输。/2026.9.30修改

流程参考 UU 远程的设备状态、连接检查和文件入口，并融入盖世现有导航。本期不保留手机被控、终端和「全部设备」。ChatGPT 首批适配手机布局，支持继续电脑中的对话、查看历史和关联文件，减少缩放电脑窗口的操作。游戏快捷入口则在用户自己的电脑启动盖世或 Steam 游戏，手机仅负责远程显示和操作。当前用户需先进入电脑桌面，再寻找软件或游戏，手机上的点选和文字输入步骤较多。

本版用于评审页面、交互与异常处理。Demo 使用样例数据，不建立真实连接、执行系统命令、传输文件或调用模型；相关能力须由客户端实现并验证。

二、产品说明

2.1 产品／方案简介

APP「我的设备」页可通过右上角旋转图标切换横竖屏：竖屏位于连接教程右侧，横屏位于更多左侧，切换保留当前所选设备。用户选择电脑，确认状态后进入桌面、传输文件或执行电源操作；APP 另提供 ChatGPT 和游戏快速启动。Mac 本机设置用于配置当前 Mac 的被控和文件接收偏好，不修改远端设备。

右下角常驻「APP」「Mac」Demo 切换入口；状态面板按项提供「缺省」「穷举」，点击直接更新页面。方向和场景在演示设置中选择；这些入口仅用于评审，正式产品不展示。

2.2 产品流程

APP：入口 → 我的设备 → 详情 → 连接检查 / 接管 → 桌面操作 → 退出回详情；文件传输可独立进入。

Mac：远程入口 → 左列表右详情 → 连接检查 / 接管 → 远控窗口 → 控制中心与连接质量；文件传输可从详情、更多或控制中心进入，并返回来源。本机设置：左下角设置 → 调整五项偏好 → 保存 → 选择左侧设备回详情，不建立连接。

APP ChatGPT：设备详情快速启动 → 对话工作区 → 选择历史 / 新对话 → 输入、发送 / 停止 → 查看关联文件 → 返回详情；工作区随时可切换到同一电脑的远程桌面。横屏历史常驻左侧，右侧显示对话与输入；竖屏历史通过抽屉展开。

APP 游戏：快速启动 → 自动横屏 → 连接所选电脑 → 打开盖世或 Steam → Steam 未登录时先登录 → 启动游戏并显示虚拟按键 → 退出回原设备详情。

4.1.2 上报与去重规则

  1. 下表事件均为新增，由主控客户端上报；主机或服务端结果先回传主控，不能两端重复计数。共用字段为：event_id、occurred_at、account_key、platform、app_version、environment、visit_id；对应电脑时加 target_os。
  2. 同一次逻辑操作生成 operation_id；每次真正发起或主动重试生成 attempt_id，自动补报沿用原 event_id。开始、受理、结束分别生成事件，终态同一 attempt_id 只能有一个。响应超时只说明未确认结果，不等于设备未执行。
  3. event_id 用于接收端幂等；客户端缓存断网期间事件，恢复后带原发生时间补报，不重复累计。连接成功即开始 session_id；自动恢复同一存活会话不新建，用户重新连接则新建尝试和会话。
  4. 仅采集统计字段，不采集设备名称、硬件标识、IP、文件名、绝对路径、文件内容、对话正文、历史标题、提示词、附件内容、密码或剪贴板。账号使用现有分析标识；关联 ID 使用随机业务 ID，不从用户内容生成。
  5. 入口曝光前创建 visit_id，点击进入后沿用；非入口直达工作区新建。
  6. 不在每次渲染、鼠标移动、按键或网络采样时上报；页面按进入记录，工具按主动操作记录，网络按状态阶段记录。测试与 Demo 数据使用 test／demo 环境，生产报表只统计 production。
