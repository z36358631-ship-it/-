# 盖世远程方案评审 V4.22

| 功能 | 说明 |
|---|---|
| 登录与场景分流 | 本期只做国内：手机号验证码、手机盖世游戏 App 授权、电脑扫码登录；移除海外邮箱、Google 登录及地区切换。中文/English只切换展示文案。登录后选择办公或非办公，分别进入 AI 会话和设备列表，可通过导航切换。/2026.10.30修改 |
| AI 会话列表 | 顶部设备 Tab 筛选，按 ChatGPT、Claude、WorkBuddy 连续分组；每组只显示一个软件图标，每条只有标题与时间，不再展开电脑、软件和文件夹。/2026.10.29修改 |
| 连接指引 | 无设备、无会话时保留连接帮助；设备子 Tab 不重复显示连接卡片或设备在线栏。/2026.10.29修改 |
| 三款客户端电脑画面 | 点击会话右侧 ›，将会话标识传至对应电脑，打开 ChatGPT、Claude 或 WorkBuddy 与主题；窗口串流另行选择全桌面或指定窗口。/2026.10.29修改 |
| 手机适配直接对话（条件性增强） | 上方默认只读预览电脑 AI 对话，下方发送消息，同步展示模拟 AI 回复；保留网页预览切换、按目标放大及草稿恢复。根据技术方案确定，技术支持后实现。/2026.10.29修改 |
| 文字与语音输入 | 输入框提示“发消息或按住说话”：点击打字，按住输入区或话筒，松手模拟转文字并自动发送；Enter 发送，Shift+Enter 换行。保留原文字草稿和图片附件，取消或切换上下文不发送；语音与 AI 回复均为本地演示，不启用麦克风。/2026.10.29修改 |
| 手机图片与修改意见 | 手机选图后可预览、移除，与文字一起发送到 AI 附件；也可传到当前电脑的剪贴板，再在远端使用。串流页顶部提供图片入口。 |
| AI 账号管理 | 按电脑和软件管理已登录账号；切换账号后显示对应会话。ChatGPT、Claude 添加账号直接打开所选电脑对应软件登录；WorkBuddy 直接拉起该电脑登录页；离线、禁控或占用时阻止跳转。/2026.10.29修改 |
| 触屏交互优化（重点攻坚） | 重点优化串流中的网页翻页、浏览器和长会话滚动，以及滚动条操作。针对双指滚动、上下滑动容易误触点击或拖动等问题，提升键鼠 / 触屏连续操作的流畅度，作为用户可直接感知的体验优化重点；效果需通过真机串流验证。 |
| 鼠标 / 触控模式选型 | 参考盖世 InGame 侧边栏已有的点对点映射、触屏、拖动等操作模式及窗口自由缩放能力，在网页浏览、会话滚动、点击、拖动和缩放场景下对比验证，选定一种最适合本期的默认操作方式进行替换和打磨。当前待评估选型，不全部照搬。 |
| 通用远控与异常 | 设备列表连接电脑；保留桌面 / 单窗口、缩放、键盘、仅观看等操作。离线或禁控不允许连接，设备占用需确认接管。 |
| Demo 评审状态 | 保留缺省、穷举、无会话、加载、失败、离线、禁控和占用；穷举包含运行中、待输入、待批准、任务失败、未读与无标记六种会话状态。/2026.10.29修改 |
| 会话状态与双入口 | 状态在标题左侧，时间在下；右侧依次对话气泡、›。气泡进入适配对话演示（待继续技术调研，方案待确定），› 打开电脑客户端。未读蓝点与任务完成区分。/2026.10.29修改 |
| 消息通知 | 仅保留四类 Push：任务完成、失败、待输入、待批准。设置中控制开启；后台且系统允许时提醒，同事件去重，历史不补发。移除站内信及通知未读，点击 Push 打开对应电脑软件主题。/2026.10.30修改 |
| 账号注销 | 手机账号区、电脑账户弹层增加注销账号。二次确认后清理当前会话并返回登录；取消不变。Demo仅模拟注销，真实账号删除与数据处理待后端确认。/2026.10.30修改 |
