## 一、文档概述

### 1.1 背景概述

- **需求背景：** [已确认] 重构盖世串流，让用户离开电脑后，能用 APP 或另一台 Mac 继续游戏、临时修改文档，以及操作电脑上已有的 AI 软件。
- **当前方式：** 用户可通过 UU 远程访问自己的电脑。盖世 APP 个人中心“我的设备”用于手柄；首页/游戏库右上无名设备图标尚无点击证据，不能认定为远程电脑入口；提供的 Mac 界面有首页、游戏库等导航，没有远程电脑页面。本期在原产品框架中加入串流。
- **问题：** 仅能看到桌面不足以完成任务。手机点不中、中文输入错误、粘贴误提交、结果拿不回来或断线重放操作，都会让连接失去价值。
- **证据：** UU 官方功能与公开评价显示输入、文件、连接恢复是共同需求；本次模拟器到 Windows 的连接与文件往返已有记录，不能代表盖世或其余端组合通过。本文定义交付行为，图示为产品原型，不是现有引擎能力证明。

### 1.2 需求边界

| 边界类型 | 范围说明 |
|---|---|
| 产品边界 | Android/iOS APP、Mac 主控；Windows/Mac 被控服务及本机设置。六种组合为一期目标，分别通过实际设备测试后开放。主机设置属于用户客户端，不新增运营后台。 |
| 业务边界 | 同账号访问本人已授权电脑；一个设备列表、一个桌面会话，承接游戏、办公和原 AI 窗口。包含单文件双向传输、单物理屏、单手柄、授权撤销和恢复。不做跨账号协助、远程开机、隐私屏、虚拟屏、独立终端、AI 托管、云电脑、目录或批量文件管理、麦克风直通。 |
| 运营边界 | 提供开机联网、系统授权、文件保存及失败排查说明；不新增活动、权益或付费套餐。 |
| 人力边界 | 产品与设计负责页面及操作规则；APP/Mac 客户端负责主控体验；Windows/Mac 被控负责人负责权限、会话与文件处理；服务端负责设备关系、信任及连接服务；测试逐组合留证；数据负责本文事件口径。 |

### 1.3 术语定义

| 术语／缩写 | 英文全称（按需） | 定义与判断口径 |
|---|---|---|
| 主控端 | 无 | 用户手持或正在操作、显示远程画面的 APP 或 Mac。 |
| 被控端／主机 | 无 | 实际运行游戏、文档和 AI 软件的 Windows 或 Mac 电脑。 |
| 信任授权 | 无 | 主机本地允许当前账号下某一主控设备访问；同账号登录本身不构成授权。 |
| 桌面会话 | 无 | 主控与某一主机的独占控制连接；远端运行的程序共用该会话。 |
| 物理屏 | 无 | 被控系统当前识别且能够采集的实际显示器；一次展示其中一屏。 |
| 连接成功 | 无 | 授权和占用校验通过，主控收到当前画面且输入通道可用；不是只建立网络连接。 |

## 二、产品说明

### 2.1 产品／方案简介

| 项目 | 说明 |
|---|---|
| 产品／方案定位 | 在盖世连接自己的电脑，完成原来的任务，再安全离开。 |
| 目标用户 | 优先服务已有盖世用户：想换位置玩电脑游戏的人，以及临时处理文档或继续电脑 AI 任务的人。 |
| 核心目标 | 用户能完成授权、连接、正确操作、取回单文件、退出及故障恢复；不靠“连上了”代替任务完成。 |
| 使用场景 | 家中换位置玩游戏；外出修改并取回文档；回到电脑原 AI 会话补要求、处理确认和查看产物。主机须开机、联网、服务运行，软件及游戏由主机正常运行。 |
| 功能概述 | APP 游戏库内新增明确的“远程电脑”文字入口，原手柄入口不变；Mac 侧栏“串流”进入同账号列表。会话内手动切换桌面或游戏操控，不设三套场景导航。 |

| 输出／后置条件 | 选定电脑进入授权或连接流程；正常退出会话后回到列表，设备状态重新获取。 |
| 补充说明 | 1. 设备已撤销、服务关闭或账号变更时，以最新校验结果阻止连接；旧卡片不是授权凭据。<br>2. 同一主机同时收到两个请求，只允许一个取得控制权，另一个返回被占用，不自动顶掉前者。<br>3. 主控账号退出后立即结束会话并清空该账号列表缓存；重新登录仍须核对有效信任。 |

|---|---|---|---|

#### 3.1.2 添加电脑与首次授权

| 要素 | 内容说明 |
|---|---|
| 功能简介 | 主机准备说明、新控制设备的可信授权。 |
| 场景描述 | 用户首次在 APP 或另一台 Mac 连接自己的电脑。 |
| 输入／前置条件 | 两端使用同一盖世账号；主机安装对应客户端或被控组件，具备本机操作条件。 |
| 需求描述 | **图示：**<br>![电脑设置引导](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@a7dfc25b408b726ef1c48a2c183e96b33c661a82/public/prd/streaming-mvp/app-setup.png)<br>**详细说明：** 图为主控引导页；主机实际授权在本机设置中完成，主控不能代替主机授予自己访问权。<br>**展示说明：**<br>1. 按顺序展示“在电脑登录同一账号”“允许此电脑被连接”“完成系统权限”“在电脑确认本次设备授权”，以及“重新检查”与返回操作。<br>2. 显示当前目标电脑、主控设备类型及各步骤完成状态；没有目标电脑时先说明电脑端准备方法，不伪造已发现设备。<br>3. 授权等待时显示“请在电脑上允许此设备连接”；说明授权后可再次连接，电脑现场屏幕可能显示远程操作。<br>**交互说明：**<br>1. 用户在主机开启被控并补全权限后，主控点击“重新检查”，根据真实返回更新步骤；未完成项继续指出对应主机和操作。<br>2. 对首次连接的主控设备发起授权请求；主机显示账号、请求设备名及类型，机主选择允许或拒绝。允许后建立该主控与该主机的信任关系，再进入连接校验。<br>3. 拒绝后主控显示“电脑未允许本次连接”，可返回或重新请求；返回取消本次等待，不撤销此前已有信任。<br>4. 请求有效期为 2 分钟的设计默认；超时显示“授权请求已过期”，用户主动重新请求，旧请求不能再次授予权限。 |
| 输出／后置条件 | 主机准备完成且首次请求被允许后，该设备成为可信主控；通过在线及占用校验才进入会话。 |
| 补充说明 | 1. 后续连接有效可信设备不要求每次现场同意；新安装、更换设备或信任已撤销则重新授权。<br>2. 主机未安装、关机、休眠或服务不可用时，说明需在主机完成准备，不显示唤醒成功。<br>3. Mac 系统权限从实际授权状态读取；拒绝、退出设置或授权后要求重启相关进程时，步骤保持未完成，不能仅凭打开系统设置判定成功。<br>4. Windows 系统安全桌面或 Mac 锁屏无法采集、无法输入时，停在明确受限状态，不绕过系统身份验证。 |

#### 3.1.3 桌面会话

| 要素 | 内容说明 |
|---|---|
| 功能简介 | 远程画面、桌面与游戏操控、文本输入、物理屏切换及退出。 |
| 场景描述 | 用户在同一台电脑内切换游戏启动器、游戏、文档、IDE 或原 AI 会话。 |
| 输入／前置条件 | 主机允许被控，当前主控信任有效且取得唯一控制权；系统采集与输入权限有效。 |
| 需求描述 | **图示：**<br>![APP桌面会话](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@a7dfc25b408b726ef1c48a2c183e96b33c661a82/public/prd/streaming-mvp/app-session.png)<br>![Mac桌面会话](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@a7dfc25b408b726ef1c48a2c183e96b33c661a82/public/prd/streaming-mvp/mac-session.png)<br>![APP横屏会话](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@a7dfc25b408b726ef1c48a2c183e96b33c661a82/public/prd/streaming-mvp/landscape-session.png)<br>**详细说明：** 三图为同一会话在 APP 竖屏、Mac 窗口与 APP 横屏的表现；远端桌面始终显示被控电脑真实当前画面。<br>**展示说明：**<br>1. 会话栏持续显示目标电脑名、连接状态、桌面/游戏操控、文字输入、物理屏、文件、设置和断开入口；工具栏收起后仍保留可见的展开柄，不能遮住唯一退出路径。<br>2. 新会话默认桌面操控。桌面画面等比适配，不拉伸；提供缩放、拖动画面及复位。游戏操控显示基础方向、摇杆及标准手柄按钮，不根据窗口标题自动切模式。<br>3. 文字输入区显示待输入文字、多行编辑、明确的“发送文字”“换行”及“粘贴文本”；内容为空或还在输入法组词时，发送不可用。这里的发送只把文字写入远端，不代表 AI 或软件中的提交。<br>4. 显示可用物理屏名称及当前屏；只有一屏时显示当前屏但不提供无效切换。文件、设置打开会话内面板；远端窗口内容不作为本地功能导航。<br>5. 连接中、锁屏、恢复中与操作受限状态覆盖远端画面并说明原因；冻结画面不显示“可操作”。<br>**交互说明：**<br>1. 桌面模式以相对指针实现精准定位，移动手指移动鼠标，轻点完成单击，双击对应双击，明确右键按钮执行右键；拖拽用长按后移动，抬起释放。双指缩放/移动仅改变本地视图，不向远端发送点击。复位恢复适配比例。<br>2. 点击桌面/游戏切换时先释放全部输入，再切换操控层；游戏触控与实体手柄共用一个虚拟手柄槽。触控或实体手柄激活时另一来源先归零，不叠加相反轴值。<br>3. 中文完成选字后再发送已确认文本；输入区允许 1—10000 个字符，保留换行和空格。超长时保留草稿并提示拆分，取消不发送。收到远端写入确认才清空本地草稿；失败保留草稿，禁止自动重复写入。确认丢失时提示“发送结果未确认，请先查看远端”，用户核对后决定是否再次发送。<br>4. 用户明确点击粘贴才读取系统剪贴板，过滤为纯文本并先放入编辑区；写入远端不附带 Enter。远端复制文本通过明确复制操作取回，并经系统权限允许后写入本地剪贴板；图片、富文本和文件不走剪贴板同步。<br>5. 快捷操作分别发送远端 Enter、Esc、Tab、复制、粘贴、保存和切换窗口；Enter 为独立明确操作，文字换行和粘贴不触发它。不同主机将复制/保存映射为其原生快捷键。<br>6. 切物理屏先停止输入并清理按键，再获取新屏画面及尺寸，更新坐标后恢复操作；切换失败保留原屏，原屏已消失则保持停止输入，要求重新选择。<br>7. 点击断开或确认系统返回离开会话后，结束控制并返回设备列表，释放占用及全部输入。电脑上的游戏、文档和 AI 程序继续运行，不自动关闭程序、退出系统账号或锁定电脑。 |
| 输出／后置条件 | 用户在目标电脑完成操作；断开后主控回列表，主机停止接收本会话输入并可被下一次连接。 |
| 补充说明 | 1. 不读取或保存系统密码；锁屏需要用户按系统流程认证。无法控制安全桌面时明确要求在主机完成认证。<br>2. 手柄拔出、App 后台、窗口失焦、模式切换、屏幕变更、网络中断或退出时释放键盘、鼠标及摇杆状态，不保留按住状态。<br>3. 返回前台必须重新核验权限与占用、取得新画面后才收输入；离线操作、文字、粘贴及 AI 提交均不排队、不重放。<br>4. 游戏是否可运行由主机系统、硬件和许可决定；Steam 登录、游戏启动器及 AI 确认仍在原桌面操作。串流不代替登录、不新建 AI 会话。<br>5. 主机现场屏幕可见，远程与现场共用桌面；敏感公司电脑不是本期优先场景。主机本地停止控制或撤销授权优先于任何主控操作。 |

| 场景 | 共同行为 | 端差异 | 限制与降级 |
|---|---|---|---|
| APP 竖屏与横屏 | 使用同一会话、输入草稿、当前物理屏和状态 | 横屏扩大画面并重排工具栏；旋转时先清理输入、重新计算显示区域 | 旋转不重连、不拉伸、不改变远端分辨率 |
| iOS 主控 | 中文确认、多行及明确粘贴 | 使用 iOS 输入法、文件选择器、剪贴板授权；回前台后恢复资格重新检查 | 系统拒绝权限则提示“未获得剪贴板访问权限”，保留手动输入 |

## 四、支撑及非功能需求

### 4.1 埋点与数据需求

**数据结论：** 新增。生产埋点只记录连接、功能及状态结果，不以时长推断游戏、文档或 AI 任务成功。“首次连接后七日再用”来自生产连接事件；“首次完成任务后七日再用”来自明确记录任务结果的试用，两者分母不同，分别报告，不得互换名称或合并。任务完成情况由有明确任务与用户同意的试用记录采集，不能读取窗口内容自动判断。

#### 4.1.1 指标口径

| 指标名称 | 口径（含公式、分子和分母） | 去重与时间窗口 | 数据源与决策用途 |
|---|---|---|---|
| 连接成功率 | 当日成功到可操作态的连接尝试数／当日发起连接尝试数；主动取消单列，仍计入总尝试 | attempt_id 去重；按发起日归属，结果回补；端组合分别统计 | stream_connect_start 与 stream_connect_result；定位连接损耗 |
| 首次成功连接耗时 | 用户首个成功尝试的 result.duration_ms；同时报告 P50、P90，不把失败记 0 | user_key 首次成功；日/版本，排除未成功用户并另报其人数 | 连接事件；评价首次体验 |
| 中断恢复成功率 | 30 秒窗口内恢复可操作的中断次数／开启自动恢复的中断次数 | recovery_id 去重，按中断日归属 | stream_recovery_result；判断恢复作用，不混入主动退出 |
| 文件传输成功率 | 校验且落盘成功的传输尝试数／已启动的传输尝试数；取消单列 | transfer_id 去重；日/端组合/方向 | stream_transfer_start 与 stream_transfer_result；判断文件闭环 |
| 首次连接后七日再用率 | 首次成功日 D 后的 D+1 至 D+7 自然日内再次主动连接成功的用户数／已首次成功且观察至 D+7 日结束的用户数 | user_key 去重；按首次成功日期分组，使用当地自然日 | 连接事件；反映再用，不能命名为任务复用率 |
| 试用首次完成任务后七日再用率 | 首次任务完成日 D 后 D+1 至 D+7 自然日内，再次主动使用串流完成任务的参与者数／首次任务已完成且观察至 D+7 日结束的参与者数 | 按经用户同意的试用参与者标识去重；游戏、文档、AI 分组；未满观察窗口不入分母 | 试用任务结果及七日回访记录；不能只凭连接事件判定，不记录任务正文 |
| 试用任务完成率 | 独立完成既定任务且结果经用户确认的任务数／开始的既定任务数；游戏、文档、AI 分开 | 试用记录按参与者×任务×端组合去重；完整一次试用 | 人工记录实际步骤、错误及结果，不采集任务正文；指导体验修改 |

#### 4.1.2 埋点事件

下表均为新增。公共参数在每行完整列出；客户端重试上报保持同一事件业务标识，接收端幂等去重。连接和文件尝试产生唯一终态；重试是新尝试。无法实时上报时仅缓存无内容的事件，恢复网络补报，不补发操作指令。

| 事件 | 页面／类型 | 触发与成功 | 参数 |
|---|---|---|---|
| stream_devices_view | C端远程电脑／新增 | 列表页面真实展示一次；再次进入产生新 page_view_id，后台刷新不重报 | user_key, client_platform, client_version, page_view_id, device_count |
| stream_connect_start | C端列表／新增 | 用户点击连接，通过本地参数检查并发起请求；同次重复点击不上报新尝试 | user_key, client_platform, client_version, host_platform, attempt_id |
| stream_connect_result | C端连接／新增 | 本次成功可操作、失败或取消时各尝试只报一个终态；成功必须首帧与输入就绪 | user_key, client_platform, client_version, host_platform, attempt_id, result, failure_reason, duration_ms, transport |
| stream_session_end | C端会话／新增 | 已成功会话终止一次；中断恢复成功不当作结束，窗口超时才结束 | user_key, client_platform, client_version, host_platform, attempt_id, end_reason, duration_ms |
| stream_recovery_result | C端异常恢复／新增 | 每次中断恢复窗口结束时上报恢复、失败或用户取消；重新手动连接走连接事件 | user_key, client_platform, client_version, host_platform, attempt_id, recovery_id, result, failure_reason, duration_ms |
| stream_input_result | C端会话文字／新增 | 明确发送文本或远端复制一次产生一个结果；只记录交付结果，不等于软件执行成功 | user_key, client_platform, client_version, host_platform, attempt_id, input_id, input_action, result, failure_reason |
| stream_transfer_start | C端文件／新增 | 文件选择与校验通过、开始传输时上报；选择取消不算开始 | user_key, client_platform, client_version, host_platform, attempt_id, transfer_id, direction, size_bucket |
| stream_transfer_result | C端文件／新增 | 每次传输落盘校验成功、失败或取消时上报一个终态 | user_key, client_platform, client_version, host_platform, attempt_id, transfer_id, direction, size_bucket, result, failure_reason, duration_ms |
| stream_host_access_change | C端主机设置／新增 | 用户允许、拒绝、撤销信任、切换被控或停止控制的操作生效后上报；失败不伪报生效 | user_key, client_platform, client_version, host_platform, access_action |

#### 4.1.3 参数说明

| 参数 | 类型／必填 | 说明 | 枚举／示例 |
|---|---|---|---|
| user_key | string／是 | 经处理的账号分析标识；不用手机号、邮箱或昵称 | 例如匿名账号标识 u_8f12 |
| client_platform | enum／是 | 事件发起客户端；主机设置事件可为 Windows | android＝Android APP；ios＝iOS APP；mac＝Mac 客户端；windows＝Windows 被控客户端 |
| client_version | string／是 | 发起客户端实际版本 | 例如 版本号+构建号 |
| host_platform | enum／是（引用事件） | 被控电脑系统 | windows＝Windows 主机；mac＝Mac 主机 |
| page_view_id | string／是（引用事件） | 一次列表真实展示标识 | 例如随机 UUID，不含设备名 |
| device_count | int／是（引用事件） | 本账号已登记电脑数量，不是当前分页数量 | 例如 2；最小 0 |
| attempt_id | string／是（引用事件） | 一次主动连接尝试及成功会话标识 | 例如随机 UUID；自动恢复沿用、手动重连新建 |
| result | enum／是（引用事件） | 对应动作终态 | success＝达到本事件成功标准；failed＝未达到且已终止；cancelled＝用户主动取消 |
| failure_reason | enum／是（引用事件） | 动作失败主因，成功固定 none；按权威终态填写 | none＝成功无错误；user_cancel＝用户取消；offline＝主机离线；busy＝主机被占用；auth_required＝需要信任；auth_rejected＝授权被拒绝；auth_expired＝请求过期；revoked＝授权撤销；host_stopped＝主机停止控制；permission＝系统或文件权限不足；network＝网络失败；timeout＝超时；<br>locked＝锁屏受限；unsupported＝能力不支持；source_changed＝源文件改变；no_space＝空间不足；integrity＝完整性校验失败；unknown＝无法确定原因 |
| duration_ms | int／是（引用事件） | 对应动作从开始到终态的毫秒数；会话为连接成功到最终结束，含恢复时间 | 例如 1500；最小 0；用单调时间计算，不能以设备时钟相减 |
| transport | enum／是（引用事件） | 连接终态时已建立链路类型，不采集 IP | direct＝直连；relay＝中继；none＝未建立链路 |
| end_reason | enum／是（引用事件） | 已成功会话最终结束原因 | user_disconnect＝用户断开；host_stop＝主机停控；revoked＝撤权；account_exit＝账号退出；recovery_timeout＝恢复超时；host_unavailable＝主机关闭/休眠/服务退出；permission_lost＝必要权限丢失；client_exit＝客户端退出；unknown＝其他无法判定 |
| recovery_id | string／是（引用事件） | 每次中断恢复窗口唯一标识 | 例如随机 UUID |
| input_id | string／是（引用事件） | 明确文本动作唯一标识，用于结果去重 | 例如随机 UUID，不由正文生成 |
| input_action | enum／是（引用事件） | 用户明确发起的文本功能 | send_text＝发送本地编辑的文字；paste_text＝从剪贴板取入并确认发送；copy_remote＝将远端已复制纯文本取回 |
| transfer_id | string／是（引用事件） | 一次文件传输尝试标识，整份重试生成新值 | 例如随机 UUID |
| direction | enum／是（引用事件） | 文件相对主控的方向 | upload＝主控到主机；download＝主机到主控 |
| size_bucket | enum／是（引用事件） | 文件大小分档，避免上传精确文件特征 | zero＝0字节；small＝大于0且不超过1MB；medium＝大于1且不超过10MB；large＝大于10且不超过100MB |
| access_action | enum／是（引用事件） | 在主机本地实际生效的访问操作 | allow_host＝开放本机被控；disable_host＝关闭本机被控；trust_device＝允许一个主控；reject_device＝拒绝当前请求；revoke_device＝撤销一个主控；stop_control＝停止当前控制 |

不采集文字、剪贴板、AI 指令、文件名、路径、文件内容、窗口标题、画面或完整设备名。支持日志使用随机故障编号关联状态；数据与会话内容隔离。

### 4.2 技术需求

| 需求项 | 具体要求 |
|---|---|
| 连接与网络 | 局域网和公网都须形成完整连接闭环；直连不可用时尝试可用中继，仍失败时给出解释及重试。网络切换、弱网、后台与主机休眠按第三章处理；不能只证明同网段首帧。 |
| 正确性 | 不允许错设备输入、撤权后继续控制、旧命令重放、同名覆盖或半成品报成功。文件校验应覆盖双向传输；断开、失焦、切屏、切后台与手柄断连均检查输入归零。 |
| 性能与成本 | 30/60 FPS 是请求档位；测试记录连接耗时、实际帧率、延迟、卡顿、流量及中继占比，区分网络、设备和端组合，不用均值掩盖长尾。中继会话需能按无内容标识核算带宽和时长，不对外承诺免费无限资源。 |
| 安全 | 控制信令、画面和文件链路须加密并校验端身份；信任绑定账号、主控设备与主机，不依赖可伪造名称。权限撤销优先于连接缓存。账号退出停止访问；授权日志仅记录主体标识、动作和时间，不记录桌面内容。 |
| 数据存储 | 本地文字草稿仅保留在当前会话内存，断开或账号退出清除，不自动写云端。传输临时文件在失败、取消或下次服务启动清理；成功文件由用户管理，不因退出会话删除。授权关系按用户撤销结果失效，保留审计依既有隐私制度。 |
| 发布控制 | 按真实通过的主控/被控组合开放；未通过组合显示“当前版本暂不支持此电脑连接”，不可用其他平台结果替代。六组合目标全部完成前，不宣传已全面覆盖。 |

以下每行都执行授权→连接→三类任务→文件→退出→恢复，覆盖离线、被占用、撤权、锁屏、切网与后台返回。任务样本为主机实际可运行的游戏、能保存并取回的文档，以及能正确收到多行补充要求的原 AI 窗口；证据含连续操作和结果，不只截图入口。

| 主控→被控 | 单独核对的输入与系统行为 | 文件与退出要求 | 通过条件 |
|---|---|---|---|
| Android→Windows | 真机中文组词、多行、横竖屏坐标、手柄、启动器、声音 | 双向完整性一致；退出、切后台、断线输入归零 | 全流程真实设备通过；模拟器不能替代 |
| iOS→Windows | iOS 输入法、剪贴板权限、系统返回、后台及手柄断连 | 系统选择/保存、取消和同名副本正确 | 独立 iOS 证据，不能复用 Android 成绩 |
| Mac→Windows | 窗口/全屏、焦点、保留快捷键替代、鼠标释放 | 文件保存权限、失焦及退出无卡键 | 键鼠连续游戏及办公任务通过 |
| Android→Mac | Mac 录屏/辅助功能、锁屏、真机中文和物理屏 | 用户目录可访问范围与双向校验 | 同时通过 Android 主控和 Mac 被控规则 |
| iOS→Mac | iOS 系统约束与 Mac 权限/锁屏同时覆盖 | 系统文件保存及后台中断处理 | 独立两端组合证据，不能拼接别组成绩 |
| Mac→Mac | 区分两台 Mac 的授权、快捷键、焦点及物理屏坐标 | 双端目录权限、文件校验及正确主机退出 | 无真实 Mac 测试即不能标记通过 |
