## 一、文档概述

### 1.1 背景概述

用户的游戏、工作文件和 AI 任务主要留在自己的电脑上。离开电脑后，常见需求是继续运行中的游戏、临时处理文件，或接着使用电脑上已登录的软件。现有方式是使用第三方远控连接电脑，或把文件发到手机、重新登录应用。后两种方式不能同时延续原有窗口、任务上下文和电脑环境；第三方远控则需要离开盖世，另行寻找设备和连接入口。

本需求面向已有电脑的盖世用户，将远程访问接入盖世 APP 和 Mac 客户端：手机连接 Windows / Mac，Mac 连接另一台电脑。用户以同一账号找到设备，在详情页选择进入桌面、传输文件或执行电源操作。手机侧补齐触控、键盘、悬浮鼠标和横竖屏适配；Mac 侧提供常驻设备列表、远控窗口、控制中心及双栏文件传输。

当前竞品参考以 UU 远程的设备、连接和操作流程为主。借鉴其明确的设备状态、连接检查和独立文件入口，同时按盖世现有导航融入功能，移除手机被控、终端和「全部设备」等本期不保留的入口。ChatGPT 首批提供手机显示适配，让用户在手机上继续电脑中的对话、查看历史及关联文件，减少缩放完整电脑窗口的操作。

本版交付用于确认页面、操作和异常处理。Demo 使用样例设备与数据；真实连接、系统权限、文件传输和 ChatGPT 接入仍需客户端实现与验证，不以原型中的可点击状态作为能力已上线的依据。

## 二、产品说明

### 2.1 产品／方案简介

围绕「找到自己的电脑 → 确认可用状态 → 完成远程任务 → 返回」组织功能。APP 从游戏库或我的设备进入，Mac 从首页远程入口进入。设备详情承接连接、管理、文件与电源操作；APP 另提供 ChatGPT 快速启动。Mac 本机设置独立于远端设备，配置本机被访问及文件接收偏好。

右下角状态面板仅供评审：点击某一项的「缺省」或「穷举」直接切换当前 Demo，演示设置用于切换平台、方向和场景；正式产品不展示该面板。

### 2.2 产品流程

![双端产品流程](https://cdn.jsdelivr.net/gh/z36358631-ship-it/-@63c67ea8c976e1bd3e443bcd8efc7c2cbf647eed/public/prd/streaming-mvp/prd-app-mac-flow.png)

APP：入口 → 我的设备 → 详情 → 连接检查 / 接管 → 桌面操作 → 退出回详情。详情可独立进入文件传输或 ChatGPT。

Mac：远程入口 → 左列表右详情 → 连接检查 / 接管 → 远控窗口 → 控制中心与连接质量；文件传输可从详情、更多或控制中心进入，并返回来源。左下角设置为独立的本机配置分支，不建立连接。
