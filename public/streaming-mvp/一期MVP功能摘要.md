# 盖世远程一期 MVP

核心目标：从手机或 Mac 连接自己的电脑，继续游戏、临时办公或使用已有软件。

| 能力 | 一期要解决的问题 | 主要内容 |
|---|---|---|
| 设备列表 | 找到要连接的电脑 | 同账号设备、在线离线、统一设备列表 |
| 设备详情 | 连接前知道设备是否可用 | 进入桌面、状态、独立文件入口 |
| 连接处理 | 避免不知情抢占与失败无出口 | 连接、占用接管或取消、失败重试 |
| 桌面控制 | 继续现有游戏和软件 | 指针、触控、窗口与桌面切换 |
| 输入 | 完成文字和电脑操作 | 中文、基础键盘与必要快捷键 |
| 显示与声音 | 看清、听到、适应网络 | 基础画质帧率、缩放和声音 |
| 文件 | 带入资料、取回结果 | 上传、下载、任务与同名处理 |
| 安全与退出 | 知道在控制谁、如何结束 | 仅观看、退出、连接丢失后停止输入 |

移动端入口推荐首页固定「远程」，Mac 放主侧栏；不把游戏库作为唯一入口，不分 Windows／Mac Tab。

本轮 Demo 按已采集 UU 核心流程重做，同时保留竞品工具用于对照。终端、宏、副屏、开机、工具排序及应用快速启动不自动纳入一期。
