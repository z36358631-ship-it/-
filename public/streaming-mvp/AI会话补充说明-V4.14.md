# 盖世远程 AI 会话补充说明 · V4.14

本文件记录本轮 Demo 的现行规则；旧 PRD 与 Word 中不一致的游戏、云分享等描述仍不适用于本期。真实远控、原生会话读取、图片传递、剪贴板与第三方账号授权未接入。/2026.10.28修改

| 修改项 | 展示与交互 | 异常与结果 |
|---|---|---|
| 在线与离线 | 手机和电脑 AI 会话按所属电脑在线/离线分组并计数；忙碌、禁控另显示标签；卡片使用 VS Code、Claude、WorkBuddy 软件图标。 | 离线不可发起远控；手机可看保存的历史，但不能发送、操作实时预览或传图。/2026.10.28修改 |
| 连接指引 | 列表与缺省态均可查看：两端登录同一盖世账号、电脑开启远控权限、打开支持的 AI 客户端建立会话。 | 无设备、无会话、加载中、失败分别展示；失败可重试。/2026.10.28修改 |
| 默认进入电脑画面 | 点击会话，打开该电脑对应的 VS Code、Claude 或 WorkBuddy 桌面窗口；显示各软件不同的侧栏与工作区结构。 | 保留离线、禁控、接管、只观看、窗口关闭及来源返回规则；窗口画面为 DOM 模拟，不声称精确复刻或已适配真实服务。/2026.10.28修改 |
| 预览与对话 | 手机次级入口进入上方网页预览、下方 AI 历史与输入的组合页；预览可收起、切换内容、放大为浏览器串流，返回恢复会话与草稿。 | 电脑离线、禁控或浏览器窗口关闭时说明原因并禁用放大。手机原生对话（待继续技术调研，方案待确定）。/2026.10.28修改 |
| 手机图片 | 原生输入区可选图、查看缩略图、移除，随修改意见发送或仅发图片；串流顶部“图片”打开手机操作面板。 | 图片留在浏览器内存；离线、禁控、只观看和 AI 窗口关闭时禁止发送；退出盖世账号清理记录。/2026.10.28修改 |
| 电脑剪贴板 | 手机选图发送到当前电脑的剪贴板面板，查看结果后可粘贴为当前 AI 附件，再随消息发送。 | 各电脑分别保存模拟记录，不写入真实系统剪贴板、不调用真实远控服务。/2026.10.28修改 |
| AI 账号管理 | 会话页“AI 账号”入口，按电脑和软件查看已登录的脱敏示例账号、切换当前账号；会话内容与草稿按账号隔离，切回恢复。 | 离线、禁控、忙碌时不切换；不会修改盖世登录账号及 UID。新增账号引导在该电脑客户端登录，外侧按钮模拟登录完成；不收集真实密码或令牌。当前采用按电脑/软件管理方案，未引入统一凭证库。/2026.10.28修改 |
| 演示状态 | 产品壳外提供缺省态（无设备）、穷举态（完整样例）、无会话、加载、失败、全部离线、禁控、忙碌；手机另有预览与对话、预览已关闭。 | 未登录不可通过演示按钮绕过登录；切换演示状态不清除当前账号草稿。/2026.10.28修改 |

软件图标来源记录在 `assets/ai-icons/sources.json`，离线内嵌到双端 HTML。本地 PRD 仅同步本轮增量说明，完整章节、PRD HTML 和 Word 仍待整体同步。
