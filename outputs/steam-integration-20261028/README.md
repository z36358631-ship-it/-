# 盖世游戏 Steam 接入评审包

打开 `Steam接入Demo.html` 即可离线使用。右下角“演示”展开悬浮面板，可切换评审状态；面板可收起。

## 当前流程

游戏库 Steam → 勾选协议 → 组件准备弹窗 → 扫码或账号密码登录 → Steam。

- 新用户与旧版已登录用户首次进入新方案，都必须主动勾选；继续才保存。旧登录状态不能绕过接入确认。
- 确认后保留有效Steam登录态；首次及新启动固定大屏。后续恢复有效会话保留当前模式。
- 【2026.11.6修改】非 Wi-Fi 下载先提示；准备可关闭／取消，停止任务并回来源页，不支持暂停或后台收起。
- 竖屏上扫码、下账号密码；横屏左右排列。二维码仅为演示，不可真实登录。
- 悬浮球最小化只缩成图标，不关闭Steam；无关闭和设置开关。

- 启动后进入可选主页、社区、游戏库、Steam；未设置（含旧版缺字段）竖屏主页、横屏游戏库，保存后下次冷启动生效。用演示面板“模拟重新打开 App”验证。
- 【2026.11.6修改】需 Steam 能力的游戏操作统一检查协议、组件；非 Steam 导入沿用盖世。SDK 内不新增导入入口、来源分类或双向同步。
- Steam成功登录后卡片显示昵称头像；首次Steam库轻提示可直达启动页设置。

## 重建与检查

在本目录执行 `npm install`、`npm run build`、`npm test`。需要Node.js和已有Chrome；可用 `CHROME_PATH` 指定浏览器路径。`npm run capture` 生成本轮页面截图；`npm test` 检查本轮行为与产物，`test:legacy` 仅保留旧版用例，不代表现行规则。

所有构建输入位于本目录。Demo不调用真实登录、下载、消息或游戏服务；输入仅内存保存。真实APK在当前MuMu环境启动受阻，原生运行、迁移、输入和法务文本仍需核对。

悬浮菜单右上“−”直接最小化为小图标，底部不再重复提供最小化项；模式切换移至面板右上设置；一级保留100%—150%缩放。账号管理、导入账号已按样图呈现，认证与导入为内存模拟；开发者选项仍作占位，具体以接入 Steam Demo 为准。

浏览器每次打开或刷新均重置Demo，展示游戏库，点击Steam后进入协议确认（默认未勾选，新启动固定大屏）。验证设置记忆请使用演示面板“模拟重新打开 App”；App启动页偏好保留；旧Steam模式／记忆偏好不再参与新启动。

用户流程图.html 已更新为实际 Demo 页面串联，采用参考评审长页，含首次进入、悬浮球、账号管理、设置四类流程，实际截图可点击放大。build-page-flow.mjs为生成源，随npm run build一起生成。

账号界面源：account-view.mjs；GitHub Pages产物由build-public.mjs生成。发布仅更新public/steam-integration三文件，不合并整个开发分支。
