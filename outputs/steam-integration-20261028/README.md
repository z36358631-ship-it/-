# 盖世游戏 Steam 接入评审包

打开 `Steam接入Demo.html` 即可离线评审，不需启动构建服务。该HTML包含图片和图标，不调用真实Steam、登录、消息、下载或游戏服务。

- `Steam接入PRD-Draft.md`：页面六要素PRD评审稿。
- `方案与功能清单.md`：功能范围与承接清单。
- `用户流程图.html`：首次进入、返回与设置两张详细流程图。
- `免责声明.md`：用户提供的完整正文，保留原文；法律及服务事实仍需核对。
- `prd-assets/`：当前页面图与横向产品流程图。
- `交付说明.md`：操作路径、验证结果和真实接入边界。

## 当前规则

首次点击 Steam，先在游戏库上弹出免责声明全文；“知晓并同意”保存版本并继续模式选择，“不同意”关闭弹窗并停留游戏库。同版本不重复，有效会话直接恢复。模式页仅选择大屏/窗口与记忆开关；运行组件的下载、校验、准备、启动及异常均在游戏库上的弹窗内显示，收起后暂停下载并保留进度。登录页回显此前同意；若手动取消勾选后点击登录，仍弹声明，“不同意”保留输入；进入功能页须等待真实登录结果。声明链接只读不授权。

悬浮球不支持关闭或设置开关；“最小化悬浮球”将球缩成小图标，Steam页面不变；点击小图标恢复常规球并展开菜单。

## 重建与检查

在本目录执行 `npm ci`、`npm run build`、`npm test`。需要 Node.js、已有 Chrome。测试使用 Windows 常见Chrome路径；其他路径可设置 `CHROME_PATH`。`npm run capture` 重截PRD页面与横向流程图。

构建输入均在本目录的 `assets/` 与 `免责声明.md`；测试仅操作本地Demo模拟数据。账号和密码字段仅用于演示，不要输入真实凭证；不持久化或向网络提交输入。

APK在当前MuMu环境启动受阻，登录、迁移、游戏运行与手柄能力仍须真机联调。这里的验证仅覆盖原型行为。
