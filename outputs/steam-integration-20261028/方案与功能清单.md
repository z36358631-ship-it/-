## 结论

保留盖世游戏库的 Steam 入口，替换入口后的旧 Steam 数据页。盖世负责首次使用准备与返回路径，Steam 原生界面负责库、好友聊天、商店和工坊；游戏运行仍需接回盖世引擎。本稿与 Demo 用于评审承接规则，不代表 SDK 已接通或 APK 已通过兼容性验收。

## /idea 收敛记录

1. 需求核对：用户已确认替换边界、四个承接点与交付物。
2. 第一性原理：玩家要能进入、能使用、能回来；不能丢账号及本机游戏，不能将下载完成误判成可启动。
3. 方案比较：A 保留入口并补最小承接（推荐）；B 旧库与新库并存（增加选择、同步及维护成本，偏离替换目标）；C 直接打开独立 APK（当前缺少盖世内返回与数据承接，无法覆盖目标）。
4. 奥卡姆剃刀：复用 Steam 好友/工坊，不新造聊天和任务中心；声明、模式、准备各承载必要动作，不夹带全局缩放、社区改版、皮肤和存档分享。
5. Reflection：用户视角要求两类模式分清、100%后明确准备阶段、悬浮球与宿主返回路径清楚；开发视角要求原生库兼容、系统球改应用内 View、模式切换以实际结果为准；商业视角要求迁移和运行桥接先验证。本方案把这些写成边界和接入门槛，不能以 Demo 覆盖未验证能力。

## 功能清单

状态含义：“本轮必需”为用户明确要求；“承接核对”为输入资料指向、需联调确认；“待定”为本次不作上线承诺。

| ID | 功能 | 页面及具体规则 | 状态 / 证据 |
|---|---|---|---|
| F01 | Steam 入口替换 | 维持游戏库 PC/复古、Steam/Epic/导入三卡和我的游戏结构；只替换 Steam 点击后的路径 | 本轮必需；当前 6.3.1 实机 |
| F02 | 首次登录声明授权 | 声明移到Steam登录页：账号密码框下展示“第三方 Steam 服务调用免责声明”链接与默认不勾选项。勾选后点击登录保存声明版本并提交本次登录；未勾选点击登录则弹出可滚动正文及提示“该服务由 Steam 提供，请认真查阅该服务调用相关声明”，主按钮“知晓并同意”，次操作“不同意”为纯文字。不同意仅关闭弹窗，留在登录页保留输入；同意保存版本并继续本次登录请求，只有实际登录成功回执后才进功能页。只读阅读不自动同意，同版本免重复、声明更新再确认；请求失败保留当前输入并允许重试 | 本轮必需；用户提供原文保存于免责声明.md，法律及事实表述未核验 |
| F03 | Steam 启动模式 | 大屏模式 / 窗口模式；大屏默认选中（沿用 APK 可见首屏），记住我的选择采用右侧开关，默认关闭，位于模式卡片下方。模式页不再放协议，也不以同意状态限制继续。窗口指 Steam 桌面式界面，非 Android 分屏；与盖世探索/掌机独立 | 本轮必需；默认记忆规则为本方案建议 |
| F04 | 记忆与设置修改 | 打开记忆开关并继续后在本设备记忆；关闭则每次新启动询问。线上设置第一组“下载任务”下新增“Steam 设置”入口；进入子页查看“启动模式”和声明全文。启动模式可选每次询问/大屏/窗口，下次新启动生效。恢复已收起会话保留原模式，不中断正在运行的游戏 | 本轮必需；APK 有热切换线索，但本方案不承诺即时切换或强制重启 |
| F05 | 首次组件准备 | 区分未下载、下载中、暂停、下载失败、校验中、准备中、准备失败、可用；显示真实字节比例。大小未返回时显示“正在获取包体信息”，不伪造总量 | 本轮必需；实际组件大小/分发形式待研发确认，不能把 194,418,297 字节 APK 大小当线上组件大小 |
| F06 | 下载中断与恢复 | 同一版本复用下载任务；离开页暂停，重新进入可继续；网络失败保留有效分片，重试不建立重复任务；空间不足原位说明、清理后重试；校验不通过则重新获取损坏组件内容，准备失败仅重试准备，不进入 Steam | 必需异常闭环；续传/暂存能力待联调，Demo 只模拟 |
| F07 | 下载后的进入 | 下载 100% 只进入校验/准备；组件准备就绪且 Steam 界面可用后进入登录/授权环节，不能当作登录成功；功能页须在声明授权与实际登录回执满足后进入。启动失败留在承接页重试或返回，不重新下载已校验有效包 | 必需异常闭环；此次 APK 暴露启动失败 |
| F08 | 应用内悬浮球 | 盖世宿主页内 View，默认49px常规球，点击展开菜单。“最小化悬浮球”只收起菜单并缩为30px小图标，Steam当前页、模式与会话不变；点击小图标恢复49px常规球并展开菜单。大小两态均可拖动吸边；当前会话返回盖世再恢复时保留缩小态，新会话默认常规球。不支持关闭，也没有设置开关；不依赖系统悬浮窗权限 | 本轮必需；APK 系统覆盖球需改造，不能直接照搬 |
| F09 | 收起与返回 | “返回盖世游戏”是与最小化悬浮球独立的动作，收起Steam并保留会话，再进恢复；不等于退出或注销。保留宿主返回控件/系统返回路径；没有关闭悬浮球操作 | 承接必需；跨 Activity/进程驻留与后台回收待联调 |
| F10 | 好友与消息 | 进入 Steam 原生好友/聊天；通知点击定位对应 event，准备或登录期间保留目标，完成后继续；失效事件展示不可用并允许返回 | 会议承接核对；Demo 仅示意路由，不发消息、不假造通知成功 |
| F11 | 创意工坊 | 进入对应 Steam 原生工坊；不维护两套展示；目标游戏上下文需保留，未提供 AppID 时不能假装定位成功 | 会议承接核对；Demo 示意原生落点 |
| F12 | 游戏启动桥接 | Steam 中启动或接受邀请，应由盖世运行游戏并透传必要启动参数；进入游戏成功需实际运行回执，不能用点击/启动动画计成功 | 会议承接核对；必须技术验证 |
| F13 | 已下载/导入可见 | 升级后盖世我的游戏、本机已下载及导入项保持可见；Steam 拥有、已安装与本地导入是不同身份，不能混作购买权益 | 图 4；迁移与目录识别待验证，不承诺导入项自动成为 Steam 库权益 |
| F14 | 账号与迁移 | 核对旧登录态可复用性、多账号切换的同步/检测逻辑、下载记录和临时文件归属；失效则回登录页，完成声明授权和登录后回到原目标；切号不得显示上个账号私有列表。登录失败保留本次账号密码输入，重试不绕过实际回执；Demo仅用测试输入演示，不保存或发送真实凭证 | 图 4；无凭据复制或迁移实现承诺 |
| F15 | 包版本与更新 | Steam 客户端/插件/引擎依赖需明确兼容组合；升级不能覆盖用户游戏与存档。失败保留最后有效组件或阻止启动，不破坏原数据 | 图 4；更新及回退策略待工程验证 |
| F16 | 手柄与输入 | 大屏导航、确认/返回、焦点；窗口模式输入与软键盘；蓝牙手柄问题单列实机检查，不能由键盘模拟宣称通过 | 图 4；Demo 提供键盘演示，实体手柄未测 |
| F17 | 网络可达性 | Steam 登录/商店/社区/下载分别验证可达性；失败显示所属阶段，允许重试和返回，不无限加载 | 会议承接核对；加速线路/资质/付费规则仍待定 |
| F18 | 活跃玩法 | 悬浮球可承载盖世活跃内容的方向保留；不在本版加入签到、积分、任务、奖励或广告 | 用户明确待定 |

## 主流程与规则

```mermaid
flowchart TD
  A[盖世游戏库 点击 Steam] --> B{有效会话且登录仍有效?}
  B -- 是 --> R[恢复 Steam 当前页面与模式]
  B -- 否 --> C{已记住启动模式?}
  C -- 否 --> F[选择大屏或窗口 可开启记忆]
  C -- 是 --> G{组件已准备且版本可用?}
  F -- 取消 --> Z[返回盖世游戏库]
  F -- 继续 保存模式偏好 --> G
  G -- 否 --> H[下载组件 显示进度]
  H -- 暂停或离开 --> I[保留有效进度]
  I -- 继续或再次进入 --> H
  H -- 网络或空间异常 --> J[原位错误说明]
  J -- 解决后重试 --> H
  H -- 字节下载完成 --> K[校验与准备]
  K -- 校验失败 --> K1[重新下载损坏组件内容]
  K1 --> H
  K -- 准备失败 --> L[准备失败 可重试或返回]
  L -- 重试 --> K
  L -- 返回 --> Z
  K -- 就绪 --> M[启动 Steam]
  G -- 是 --> M
  M -- 失败 --> N[启动失败 可重试或返回]
  N -- 重试 --> M
  N -- 返回 --> Z
  M -- 可用 --> O{原生登录仍有效?}
  O -- 是 --> Q[进入 Steam 库或原目标]
  O -- 否 --> P[Steam登录页 账号密码与声明授权]
  P -- 点声明链接 --> V[只读正文 不自动同意]
  V -- 返回 保留输入 --> P
  P -- 点击登录 --> D{同版本已同意或本次已勾选?}
  D -- 是 保存本次同意版本 --> T[提交本次登录请求 等待实际回执]
  D -- 否 --> E[弹出可滚动声明 主按钮知晓并同意]
  E -- 文字操作不同意 --> P
  E -- 知晓并同意 保存版本 --> T
  T -- 实际成功 --> Q
  T -- 失败 --> P1[保留输入与原目标 可重试]
  P1 -- 重试 --> P
  P -- 返回盖世 --> Z
  Q --> S[菜单返回盖世游戏或宿主返回 收起 Steam]
  R --> S
  S --> Z
```

最小化悬浮球只改变球的显示形态，不离开Steam；两种形态均可拖动吸边。当前会话往返盖世保持缩小态，新会话恢复常规球。

恢复会话需检查组件和实际登录状态；声明版本更新不打断有效会话，仅在下次登录授权时重新确认。不能仅凭本地会话标记绕过实际有效性检查。

## Demo 边界

- 采用真实 DOM 实现入口、声明、模式、准备进度、设置和悬浮球；可切竖屏/掌机横屏，二者独立布局。
- 具备正常、暂停、断网、空间不足、校验失败、启动失败等可切换演示状态；用演示状态按钮切换，不作为产品新增入口。
- Steam 桌面式/大屏式库、好友、工坊属于参考截图绘制的交互模拟，均在演示外框标识。APK实测未到登录页，本轮账号密码与授权页属于演示模拟；请仅输入测试内容，不保存或发送真实凭证，不发生真实下载/发消息/游戏启动。
- 声明正文采用用户提供的原文，保存于免责声明.md，不代表法律条款或事实表述已经核验。原文“使用即同意”“公布即生效”与本方案的明确同意及版本更新再确认存在差异，需法务核对；本轮交互按明确授权执行。
- 不修改 Epic、导入和其他既有页面；演示中未覆盖入口标为范围外，不伪造其实现。

## 接入前必须拿到的证据

1. ARM64 真机正常启动、两种模式切换、手机/掌机输入与返回测试。
2. Steam→盖世游戏启动/邀请桥接成功与失败回执。
3. 旧账号、下载记录、已下载文件、导入游戏的迁移前后对账；不得用清空重装验证迁移。
4. 应用内悬浮球在目标宿主进程/窗口中可见，不提供关闭及开关；宿主返回路径可用；无系统悬浮窗授权依赖。
5. 组件下载、校验、版本兼容及更新失败恢复；实际包体大小与所需空间。
6. 免责声明正式文本与分发许可、网络服务能力边界确认。
