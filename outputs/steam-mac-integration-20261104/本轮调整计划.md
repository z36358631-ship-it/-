# Mac 双模式与评审布局调整

依据：本轮用户批准上轮分析，并要求左侧功能切换、右侧 Demo。

决定 D-MAC-02：替代原“Steam 窗口/大屏”，使用“盖世模式/Steam 原生大屏”；默认盖世模式，窗口大小不是业务模式。盖世模式保留重构库、详情和启动承接，不强制展示原生 Steam 页面。
决定 D-MAC-03：详情区分盖世评价与 Steam 评测、本地 MOD 与创意工坊；成就摘要和 DLC 示例数据标为占位，原生页面定位为待联调演示。
决定 D-MAC-04：固定左侧评审功能栏，右侧 1280×835 逻辑客户端，按可用空间缩放；不把评审控件做进产品。

- [x] 宿主：host.js/css 保留现有布局，补自有 Steam 库和详情功能区、启动状态及偏好。
- [x] Steam：steam.js/css 改 hub/big 模式、公共门禁、盖世承接及原生详情路由。
- [x] 评审壳：controls.js/css、build.mjs 改为左栏+右侧客户端，无 iframe。左栏提供页面、详情功能和异常场景。
- [x] 更新截图流程、README、验收记录及运行状态；Android 无需修改。
- [x] 验证首次和旧登录、默认模式、记忆、原生功能目标、模式切换、账号/下载同步、左栏与缩窗；检查真实DOM截图。
- [x] 发布原 Mac 独立地址并核验，保留原 Android 产物。

技术边界：演示两种体验及推荐分工，不承诺后台启动、原生深链、成就/DLC接口与 Mac MOD 安装已可用。
