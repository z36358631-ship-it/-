# Mac Demo 双模式试稿验收

本轮替代上一版窗口/大屏语义，采用盖世模式/Steam原生大屏。证据以 evidence-v2 为准，旧 evidence 为历史记录。

| 层级 | 本轮结果与证据 |
|---|---|
| 源文件 | host/steam/controls 已构建为单文件，评审栏与客户端DOM分离，无iframe。 |
| 机器验证 | verify-v2.cjs 11项行为检查通过；verify-final-v2.cjs核验原生直达与成就数据一致；verify-artifacts.cjs核验24张流程图和本地跳转。 |
| 专业判断 | 产品经理、交互设计师只读实测；开发审查模块门禁与路由。修复未安装游戏直接启动，修复场景分类残留，统一成就摘要。人工查看shell/detail/mode、MOD、原生功能及1024缩窗截图。 |
| Git | 提交与推送记录以本轮Git日志为准。 |
| 公开预览 | 发布后以 Pages在线验证.json 记录为准。 |
| 远程资源 | 图片与脚本内嵌，无外链运行依赖。 |

## 主要通过项
- 首次与旧登录均需协议；默认盖世，登录后回自有库。
- 盖世启动保留游戏目标；未安装先进入Steam下载，回写后才启动。
- 成就、评测、DLC、工坊携游戏定位，返回恢复详情标签，不改启动偏好。
- 盖世评价与Steam评测、本地MOD与工坊分开；示例值来源明确。
- 账号门禁、切号隔离、下载回写、网络和同步重试。
- 大屏球拖动、最小化、100%–150%缩放；切回盖世保留会话。
- 左栏切换、1280×835逻辑视口、缩放坐标、1024×720外框无横向溢出。

后台启动、原生深链、MOD安装和Mac SDK均未真实接入。本轮为可评审的产品试稿。
