# Mac Steam 接入 Demo · 连接与显示分离

当前决定 D-MAC-05 替代 D-MAC-02：删除“盖世模式”选择。连接账号和打开原生界面是两条不同路径，窗口/全屏仅描述原生界面显示方式。

## 当前流程
- 连接 Steam：首次确认协议 → 扫码或密码登录 → 停留盖世游戏库。无模式卡片、无记忆开关，不准备原生界面组件。有效旧登录仍需首次协议确认。
- 打开原生界面：选择窗口/全屏（默认窗口，可记住）→ 按需准备组件/登录 → 原生页面。首次未确认协议时在显示方式页勾选。
- 设置仅管理原生显示偏好。普通盖世连接不受其影响。
- 悬浮球窗口/全屏只改当前会话；返回盖世独立操作，保留原游戏与详情标签。
- 盖世内保留成就摘要、独立评价、本地 MOD 入口；Steam 成就/评测/DLC/工坊按需进入原生对应功能。
- 未安装游戏先承接原生下载，下载记录回写后显示启动；已安装游戏启动保留目标。

## 演示与基线
左侧功能栏、右侧可操作客户端；左栏提供连接账号、原生入口、窗口、全屏及状态切换。客户端逻辑1280×835，可适应窗口或100%显示；无iframe。刷新重置，初始游戏库；模拟重开遵循设置，Mac默认发现。
沿用 GameHub 1.0.0（74ddda9f）重构实机页面。账号、数据、二维码、下载、运行均为演示。原生窗口化、页面深链、Mac后台启动与 MOD 安装需联调。资源位不耦合。

构建 `node build.mjs`；当前行为检查 `node verify-v3.cjs`；当前证据 `evidence-v3/`；页面流程 `node build-review.mjs`。旧verify/verify-v2与旧evidence目录均为历史语义，不作本轮证据。Android产物不变。
