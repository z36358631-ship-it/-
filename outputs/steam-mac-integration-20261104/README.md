# Mac Steam 接入 Demo · 双模式试稿

当前决定：默认盖世模式，另一种为 Steam 原生大屏。替代上一版“Steam 窗口 / 大屏”理解；窗口尺寸不是业务模式。

## 使用
左侧固定评审功能栏，右侧为可操作 Mac 客户端。可切换原页面/新方案、页面、详情功能、两种模式与异常状态。上方支持适应窗口或100%查看。客户端逻辑视口1280×835，无iframe。

Demo 默认展示游戏库；模拟重开 App 遵循设置，Mac 默认发现。刷新浏览器重置演示数据。

## 页面与功能分工
| 页面/功能 | 本轮表现 |
|---|---|
| 游戏库 | 保留重构版平台标签。登录后在盖世自有库展示 Steam 游戏与盖世导入。 |
| 模式与协议 | 默认盖世模式，可选原生大屏。首次和旧登录用户首次均需勾选；阅读不自动同意。 |
| 准备和登录 | 公共前置步骤；准备弹窗无暂停/收起/取消，失败重试。扫码/密码均为模拟。 |
| 盖世详情启动 | 已安装才显示启动；保留目标并回盖世展示启动交接。未安装显示“在 Steam 下载”，完成后更新按钮。 |
| 成就 | 盖世保留摘要；完整成就入口携游戏目标进入原生大屏。 |
| 评价 | 盖世评价与 Steam 评测分区，评分和评论不混用。 |
| DLC | 盖世显示信息占位，具体内容通过 Steam 入口承接。 |
| MOD | 本地 MOD 管理保留盖世入口；创意工坊另行进入 Steam。订阅不代表安装或兼容。 |
| 返回 | 从原生功能返回时恢复原游戏与详情标签。 |
| 悬浮球 | 大屏内 Logo 球可拖动，右上减号最小化，内容缩放100%–150%；切回盖世不改下次启动偏好。 |
| 设置 | 保留 Mac 原有设置布局；“进入主屏时”原四项加 Steam，模式偏好为盖世/原生大屏，可取消记忆。 |

按需打开原生成就、评测、DLC或工坊不修改启动偏好。首次需协议时只说明本次进入原生功能，避免选了盖世却落到原生。

## 技术边界
本次是产品试稿。数据与界面为占位，不代表已完成 Steam 服务、原生深链、后台启动、Mac 运行容器或 MOD 安装。资源位不耦合。

后台启动、按游戏定位原生页面、两种UI共用会话及任务状态、Mac能力与安卓7.0的差异，均需研发联调确认。

## 基线与验证
沿用 GameHub 1.0.0（74ddda9f）实机资料：发现、平台标签游戏库、详情、常规设置和 Steam 设置。公开页面只使用演示账号。
本轮入口：`node build.mjs`；行为检查：`node verify-v2.cjs`；截图流程：`node build-review.mjs`。证据目录 `evidence-v2/`。旧 `verify.cjs` 与 `evidence/` 为前版记录，已被本轮语义替代，不作为本轮通过证据。
单文件 `MacSteam接入Demo.html` 可离线打开；`review.html` 为同版页面流程图。Android产物未改。
