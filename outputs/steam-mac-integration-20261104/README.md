## 当前流程
- 点击游戏库 Steam 入口：确认协议→ 按需准备组件 → 扫码或密码登录 → 进入 Steam 大屏模式。组件下载、校验和准备在弹窗中展示；可关闭取消，停止本次任务及跳转。【2026.11.6修改】
- 首次进入，以及旧版已登录用户升级后首次进入，均在进入弹窗主动勾选免责声明。阅读协议不等于同意；有效登录态可复用。
- 无首次模式选择及记忆开关；新启动固定大屏，有效会话恢复当次模式；已确认的协议不重复勾选。
- Steam 设置保留账号与既有功能，移除新增的启动模式和记忆偏好。
- 悬浮球右上设置中的模式切换只改当前会话，新启动仍为大屏；返回盖世是独立操作，保留原游戏与详情标签。
- 盖世内保留成就摘要、独立评价、本地 MOD 入口；Steam 成就/评测/DLC/工坊按需进入原生对应功能。
- 未安装游戏先承接原生下载，下载记录回写后显示启动；已安装游戏启动保留目标。
