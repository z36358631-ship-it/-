# Mac Steam 接入 Demo · 窗口模式与大屏模式

当前决定 D-MAC-06 废弃 D-MAC-05 的双入口拆分，恢复“点击 Steam → 选择模式 → 进入 Steam”的主路径。两种模式均进入 Steam，不再提供“盖世模式”选项。D-MAC-03 的详情分工与 D-MAC-04 的左栏评审布局继续有效。

## 当前流程
- 点击游戏库 Steam 入口：选择窗口模式或大屏模式（默认窗口）→ 按需准备组件 → 扫码或密码登录 → 进入所选 Steam 模式。组件下载、校验和准备在弹窗中展示。
- 首次进入，以及旧版已登录用户升级后首次进入，均在模式选择页主动勾选免责声明。阅读协议不等于同意；有效登录态可复用。
- 可勾选“记住我的选择”。已同意且记住后，再次进入使用所选模式；未记住则再次选择模式，不重复要求已完成的协议确认。
- Steam 设置管理下次进入的窗口模式 / 大屏模式与记忆偏好。
- 悬浮球模式切换只改当前会话，不覆盖设置；返回盖世是独立操作，保留原游戏与详情标签。
- 盖世内保留成就摘要、独立评价、本地 MOD 入口；Steam 成就/评测/DLC/工坊按需进入原生对应功能。
- 未安装游戏先承接原生下载，下载记录回写后显示启动；已安装游戏启动保留目标。

## 演示与基线
左侧功能栏、右侧可操作客户端；左栏提供首次进入、旧版已登录、模式选择、窗口模式、大屏模式及异常状态切换。客户端逻辑1280×835，可适应窗口或100%显示；无iframe。刷新重置，初始游戏库；模拟重开遵循设置，Mac默认发现。
沿用 GameHub 1.0.0（74ddda9f）重构实机页面。账号、数据、二维码、下载、运行均为演示。原生窗口化、页面深链、Mac后台启动与 MOD 安装需联调。资源位不耦合。

构建 `node build.mjs`；本轮证据目录 `evidence-v4/`；页面流程 `node build-review.mjs`（保持26张页面图）。本轮构建、行为检查与发布结果以更新后的验收说明为准，不复用 D-MAC-05 的通过结论。`verify-v3.cjs`、`evidence-v3/` 及更早版本均为历史语义。Android产物不变。
