# Mac 重构版接入 Steam

基于“处理 Mac 重构验收问题”对话中 GameHub 1.0.0（74ddda9f）实机资料，按 1280×835 逻辑视口重建相关页面。未操作验收中的 Mac。

## 页面范围
| 页面 | 保留与变化 |
|---|---|
| 发现、全局导航 | 保留重构包侧栏、顶栏、精选与推荐结构，承担默认启动落地。 |
| 游戏库 | 保留平台胶囊、搜索筛选、管理平台、导入游戏；Steam 入口后进入新流程。登录后回显演示昵称与头像。 |
| 游戏详情 | 保留封面和启动区；启动携带游戏目标进入 Steam。 |
| 常规设置 | 沿用“进入主屏时”，保留发现、游戏库、云游戏、手游库，新增 Steam。Mac 默认发现。 |
| Steam 设置 | 保留账号、语言、下载地区等原有分组，新增启动模式与记忆偏好。 |
| Steam 接入 | 模式选择、协议勾选、组件准备、模拟登录、游戏分类、账号管理、悬浮球、网络与同步异常。 |

Demo 为方便评审默认打开游戏库。右下演示工具可切换“重构版原页面 / Steam 新方案”、首次与旧版已登录、加载失败及空态；模拟重开按设置进入对应落地页。浏览器刷新重置。

## 业务规则
- 首次模式默认窗口；协议未勾选不能继续。旧版已登录首次也需确认，可复用演示登录态。
- 准备过程位于弹窗，显示下载、校验与准备；无暂停、收起或取消，失败重试。
- 悬浮球使用 Logo，可拖动；面板右上“−”最小化为图标，无关闭和开关。会话模式与缩放不改下次启动偏好。
- Steam 游戏与盖世导入分组展示；导入不代表购买权益。同步失败保留已有列表，网络失败支持重试。
- 设置里的原“启动加速”只保留基线展示，不代表本期新增供应商、收费或联网优化开关。
- 资源位独立，本 Demo 不耦合。

## 使用与限制
运行 `node build.mjs` 生成单文件 `MacSteam接入Demo.html`，直接浏览器打开。测试脚本 `verify.cjs` 生成证据和截图。
登录、二维码、下载、账号导入、同步和游戏启动为模拟交互；不采集真实密码、Token，不代表 Mac 容器、Steam 服务或 SDK 已接通。范围外的发现、云游戏和手游业务仅保留导航承接。
