## 一、文档概述

### 1.1 背景概述

Mac 用户现通过盖世游戏库、详情和设置管理 Steam。本期接入新组件，解决进入、账号与游戏同步、国内访问问题。

### 1.2 需求边界

| 边界类型 | 范围说明 |
|---|---|
| 产品边界 | Mac 重构版 GameHub 1.0.0；Android 另行维护。 |
| 业务边界 | Steam 入口、详情、设置及运行衔接；其他平台、盖世社区不改。 |
| 运营边界 | 资源位另立项；不含活跃玩法、加速收费、存档分享；本期不加限免预告、悬浮球广告或消息中心。 |
| 人力边界 | 产品／设计定规则；客户端接入；组件方确认能力；测试验证。 |

### 1.3 术语定义

| 术语 | 定义与判断口径 |
|---|---|
| 窗口模式 | Steam 桌面布局，适合键鼠。 |
| 大屏模式 | Steam 大卡片与手柄布局，非单纯全屏。 |
| 盖世导入 | 本机导入游戏，不代表 Steam 购买权益。 |

## 二、产品说明

### 2.1 产品／方案简介

| 项目 | 说明 |
|---|---|
| 方案定位 | 沿用 Mac 页面，接入 Steam。 |
| 目标用户 | 新用户及旧版升级用户。 |
| 核心目标 | 默认大屏进入，继续原操作，返回后数据一致。 |

## 四、支撑及非功能需求

### 4.1 埋点与数据

**数据结论：** 改造。[建议方案] 新增停留与返回统计；数据侧核对后接入，不新增报表。

- 协议完成率＝提交成功尝试数／弹窗展示尝试数；按日、按进入尝试去重。
- 返回率＝当天主动返回盖世的会话数／当天前台可见且可交互的 Steam 会话数（含跨日延续）；按会话去重，分子须属于分母集合。
- 停留时长＝同会话可见片段时长之和；跨日按统计日期拆分，后台、游戏独占不计。异常退出无回执时不补造时长或返回事件。7.0上线后据此评估触达，不预设异常阈值。

| 事件 | 页面／类型 | 触发与成功 | 参数 |
|---|---|---|---|
| steam_consent_show | 协议弹窗／改造建议 | 实际展示，每次进入一次；查看声明返回不重记。 | platform, entry_attempt_id, declaration_version, entry_context |
| steam_disclaimer_checkbox_change | 协议弹窗／复用建议 | 主动改变勾选值；初始化、回显不记。 | platform, entry_attempt_id, declaration_version, consent_checked |
| steam_consent_submit | 协议弹窗／改造建议 | 点击进入且同意保存成功；每次进入一次。 | platform, entry_attempt_id, declaration_version |
| steam_session_enter | Steam界面／新增建议 | 界面可见且可交互；每个可见片段开始记一次。 | platform, session_id, visibility_id, entry_source, launch_mode, is_restore |
| steam_session_leave | Steam界面／新增建议 | 离开可见界面；每片段一次，记实际时长。 | platform, session_id, visibility_id, entry_source, launch_mode, is_restore, duration_ms, leave_reason |

| 参数 | 类型／必填 | 说明 | 枚举／示例 |
|---|---|---|---|
| platform | enum／是 | 客户端 | mac＝Mac 客户端 |
| entry_attempt_id | string／协议事件必填 | 进入标识；取消重进换新值 | 示例：entry_a213 |
| declaration_version | string／协议事件必填 | 生效声明版本 | 示例：20261105-v1，正式值待审定 |
| entry_context | enum／展示必填 | 弹窗原因 | first_use＝首次；legacy_login＝旧登录首次接入；version_change＝声明更新 |
| consent_checked | boolean／勾选必填 | 本次手动值，非提交结果 | true＝勾选；false＝取消 |
| session_id | string／会话事件必填 | 新启动生成；返回再进及前后台恢复沿用 | 示例：session_a213 |
| visibility_id | string／会话事件必填 | 可见片段标识；进入、离开共用，恢复时新建；重试沿用 | 示例：visible_a213 |
| entry_source | enum／会话事件必填 | 片段入口，离开沿用 | steam_card＝Steam卡片；game_action＝游戏操作；app_launch＝App启动；account_manage＝账号管理；resume＝后台或游戏返回 |
| launch_mode | enum／会话事件必填 | 片段开始时模式，离开沿用 | window＝窗口；big＝大屏 |
| is_restore | boolean／会话事件必填 | 是否恢复有效会话 | true＝恢复；false＝新启动 |
| duration_ms | integer／离开必填 | 本片段可见毫秒数，不含后台或游戏独占 | 示例：12000 |
| leave_reason | enum／离开必填 | 离开原因 | return_host＝主动返回盖世；app_background＝App后台；session_end＝会话结束；game_foreground＝游戏独占前台 |

新事件替代 steam_mode_show／steam_mode_submit；不再上报模式选择、记忆参数。进入与离开按片段配对去重，不将恢复次数计为新会话。

### 4.2 接入与数据要求

| 需求项 | 具体要求 |
|---|---|
| 国内网络 | 优化登录、库、商店、社区、下载；优先免费，不满足再评估采购。不新增加速页、开关、收费入口；不将体验耗时作为性能承诺。 |
| 状态同步 | 登录、切号、退出、重开后同步真实身份；私有记录按账号隔离；失败、未知、空态分开。 |
| 游戏同步与升级 | 导入与下载双向可见、来源分开；迁移保留登录态、游戏、下载、存档，不以重装清空替代。 |
| 成功依据 | 认证、安装、同步、运行各取真实回执，点击或动画结束不算成功；Demo 账号、数据、下载及模拟操作仅占位，以实际接入为准。 |
| 凭据与协议 | 不存明文密码；日志、埋点不含密码／Token。声明沿用用户原文作审核稿，律师审定后上线，并核对实际服务。 |
