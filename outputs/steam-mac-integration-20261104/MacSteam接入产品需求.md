## 一、文档概述

### 1.1 背景概述

Mac 用户现通过盖世游戏库、详情和设置管理 Steam。本期接入新组件，解决进入、账号与游戏同步、国内访问问题。

### 1.2 需求边界

| 边界类型 | 范围说明 |
|---|---|
| 产品边界 | Mac 重构版 GameHub 1.0.0；Android 另行维护。 |
| 业务边界 | Steam 入口、详情、设置及运行衔接；其他平台、盖世社区不改。 |
| 运营边界 | 资源位另立项；不含活跃玩法、加速收费、存档分享。 |
| 人力边界 | 产品／设计定规则；客户端接入；组件方确认能力；测试验证。 |

### 1.3 术语定义

| 术语 | 定义与判断口径 |
|---|---|
| 窗口模式 | Steam 桌面布局，适合键鼠。 |
| 大屏模式 | Steam 大卡片与手柄布局，非单纯全屏。 |
| 盖世导入 | 本机导入游戏，不代表 Steam 购买权益。 |

## 二、产品说明

### 2.1 产品／方案简介

| 项目 | 说明 |
|---|---|
| 方案定位 | 沿用 Mac 页面，接入 Steam。 |
| 目标用户 | 新用户及旧版升级用户。 |
| 核心目标 | 进入所选模式，继续原操作，返回后数据一致。 |
| 使用场景 | 进入 Steam、操作游戏、查看内容、设置启动页。 |
| 功能概述 | 盖世负责入口与衔接；Steam 提供原生功能。 |

## 四、支撑及非功能需求

### 4.1 埋点与数据

**数据结论：** 复用建议，补 Mac 标识；生产事件待核对，不新增报表。

模式确认完成率＝提交成功尝试数／弹窗展示尝试数；按日、按进入尝试去重，不代表登录或游戏启动成功。

| 事件 | 页面／类型 | 触发与成功 | 参数 |
|---|---|---|---|
| steam_mode_show | 模式弹窗／复用建议 | 实际展示，每次进入记一次；查看声明返回不重记。 | platform, entry_attempt_id, declaration_version, entry_context |
| steam_disclaimer_checkbox_change | 模式弹窗／复用建议 | 主动改变勾选值；初始化、回显不记。 | platform, entry_attempt_id, declaration_version, consent_checked |
| steam_mode_submit | 模式弹窗／复用建议 | 点击进入且模式、同意保存成功；每次进入记一次。 | platform, entry_attempt_id, declaration_version, launch_mode, remember_choice |

| 参数 | 类型／必填 | 说明 | 枚举／示例 |
|---|---|---|---|
| platform | enum／是 | 客户端 | mac＝Mac 客户端 |
| entry_attempt_id | string／是 | 进入标识；取消重进换新值 | 示例：entry_a213 |
| declaration_version | string／是 | 生效声明版本 | 示例：20261104-v1 |
| entry_context | enum／展示必填 | 弹窗原因 | first_use＝首次；legacy_login＝旧登录首次接入；ask_mode＝已同意但未记忆 |
| consent_checked | boolean／勾选必填 | 本次手动值，非提交结果 | true＝勾选；false＝取消 |
| launch_mode | enum／提交必填 | 本次模式 | window＝窗口；big＝大屏 |
| remember_choice | boolean／提交必填 | 后续偏好 | true＝记住；false＝每次询问 |
